# netsis-expert-ai

Logo Netsis 3 Enterprise resmi dokümantasyonundan çıkarılan **1.936 adet Markdown makaleyi** RAG (Retrieval-Augmented Generation) kaynağı olarak saklamak için hazırlanmış teknik bilgi tabanı deposu.

## Depo yapısı

- `knowledge-base/markdown/`: Resmi dokümanlardan çıkarılan tüm Markdown makaleler (1.936 dosya)
- `knowledge-base/metadata/`: Makale indeksleri ve RAG tarafında kullanılacak metadata dosyaları
- `knowledge-base/rag/chunks/`: Chunk çıktıları (isteğe bağlı/üretim çıktısı)
- `knowledge-base/rag/embeddings/`: Embedding çıktıları (isteğe bağlı/üretim çıktısı)

Detaylar için `knowledge-base/README.md` dosyasına bakın.
