# Demirbaş Ek Bilgileri Girişi

Demirbaş Ek Bilgileri Girişi, demirbaş bilgi kartlarındaki sayısal ve alfa sayısal alanlara hızlı bilgi girişi için kullanılan bölümdür. Demirbaş Ek Bilgileri Girişi ekranında bulunan alanların aktif hale gelmesi için, ilgili alanlara Demirbaş → Kayıt → Parametre Girişi → Kullanıcı Tanımlı Sahalar bölümünden başlık tanımlaması yapılması gerekir.
