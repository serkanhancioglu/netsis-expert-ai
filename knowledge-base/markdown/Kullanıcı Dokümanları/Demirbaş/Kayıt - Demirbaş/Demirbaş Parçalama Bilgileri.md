# Demirbaş Parçalama Bilgileri

Demirbaş Parçalama Bilgileri, birden fazla miktarda alınmış demirbaşların tutar olarak parçalanması için, baz alınacak bilgilerin kaydedildiği bölümdür. Demirbaş Parçalama Bilgileri bölümünden girilen bilgiler doğrultusunda parçalama işleminin gerçekleştirilmesi için Demirbaş → İşlemler → Demirbaş Parçalama bölümünün kullanılması gerekir.

Demirbaş Parçalama Bilgileri ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Demirbaş Parçalama Bilgileri Ekranı |  |
| --- | --- |
| Baz Demirbaş Kodu | Parçalanacak demirbaş kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, demirbaş kodları arasından seçim yapılır. |
| Yeni Demirbaş Kodu | Parçalama işleminden sonra oluşacak yeni demirbaş kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, demirbaş kodları arasından seçim yapılır. |
| Yeni Demirbaş İsmi | Yeni demirbaş kodunun isminin girildiği alandır. |
| Alış Fiyatı | Parçalama işleminden sonra oluşacak yeni demirbaş kodu için kaydedilecek alış fiyatının girildiği alandır. Baz alınacak demirbaştan birden fazla demirbaş kodu üretilebilir. Yeni oluşacak demirbaşların alış tutarları toplamının, baz alınacak demirbaş kodunun alış fiyatına eşit olması gerekir. |
| Devir Düz. Tutar | Eğer Döviz Amortisman uygulaması varsa, yeni oluşacak demirbaş kartları için atanması istenen firma döviz tutarlarının girildiği alandır. |
| Döviz Tutar | Rapor amaçlı olarak yeni oluşacak demirbaş kartları için döviz alış tutarlarının girildiği alandır. |
