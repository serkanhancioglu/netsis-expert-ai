# Teşvik Bilgi Girişi

Teşvik Bilgi Girişi ekranı; Yatırım Genel Bilgileri, Yatırım Tutar/Finansman Bilgileri ve Yatırım Ek Bilgiler sekmesi olmak üzere üç sekmeden oluşur.

**Yatırım Genel Bilgileri**

Yatırım Genel bilgileri, yatırımlarını teşvik alarak yapan firmaların, teşvik bilgilerinin girilmesini sağlayan bölümdür.

Teşvik Bilgi Girişi ekranı Yatırım Genel Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Teşvik Bilgi Girişi Ekranı |  |
| --- | --- |
| Teşvik No | Yatırımlarını teşvik alarak yapan firmaların teşvik numarasını girdiği alandır. |
| Belge No | Teşvik numaraları bazında belge numarası girilen alandır. |
| Belge Tarihi | Belgenin alındığı tarihin girildiği alandır. |
| Başlangıç/Bitiş Tarihi | Teşviğin başlangıç ve bitiş tarihinin girildiği alandır. |
| Açıklama | Teşviğin açıklamasının girildiği alandır. |
| Sektörü ve Konusu | Yatırım teşvik sektör ve konusunun girildiği alandır. |
| Cinsi | Teşvik cinsinin girildiği alandır. |
| Yeri | Teşvik yerinin girildiği alandır. |
| Kapasitesi | Teşvik kapasitesinin girildiği alandır. |
| Elektrik Gücü | Yatırım yapılırken kullanılan elektrik gücünün girildiği alandır. |
| İhracat Taahhüdü | Yatırım için verilen ihracat taahhüdünün girildiği alandır. |
| Yatırım İndirimi | Yatırım indiriminin girildiği alandır. |
| İstihdam | Yatırım için kullanılan istihdamın girildiği alandır. |
| Döviz Kullanımı | Yatırımdaki döviz kullanımının girildiği alandır. |

**Yatırım Tutar/Finansman Bilgileri**

Yatırım Tutar/Finansman Bilgileri, yapılacak yatırıma ait tutar ve finansman bilgilerinin girildiği sekmedir.

Teşvik Bilgi Girişi ekranı Yatırım Tutar/Finansman Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Teşvik Bilgi Girişi Ekranı |  |
| --- | --- |
| Teşvik No | Yatırım Genel Bilgileri sekmesinden girilen teşvik numarasının izlendiği alandır. |
| Açıklama | Teşvik Numarası açıklamasının izlendiği alandır. |
| Sabit Yatırım | Yapılacak yatırıma ait sabit yatırım tutarının girildiği alandır. |
| Arazi-Arsa | Yapılacak yatırıma ait arazi ve arsa tutarının girildiği alandır. |
| Bina-İnşaat | Yapılacak yatırıma ait bina ev inşaat tutarının girildiği alandır. |
| Makine-Teçhizat | Yapılacak yatırıma ait makine ve teçhizat tutarının girildiği alandır. |
| İthal | Yapılacak yatırıma ait ithal tutarın girildiği alandır. |
| Yerli | Yapılacak yatırıma ait yerli tutarın girildiği alandır. |
| Diğer Harcamalar | Yapılacak yatırıma ait diğer harcamaların tutarının girildiği alandır. |
| Gümrük Vergisi | Yapılacak yatırıma ait gümrük vergisi tutarının girildiği alandır. |
| İşletme Sermayesi | Yapılacak yatırıma ait işletme sermayesi tutarının girildiği alandır. |
| Toplam Yatırım | Yapılacak yatırımın toplam tutarının girildiği alandır. |
| Öz Kaynaklar | Yapılacak yatırıma ait öz kaynakların girildiği alandır. |
| Yabancı Kaynaklar | Yapılacak yatırıma ait yabancı kaynak tutarının girildiği alandır. |
| Gümrük Muafiyeti | Yapılacak yatırıma ait gümrük muafiyet tutarının girildiği alandır. |
| Toplam Finansman | Yapılacak yatırıma ait toplam finansman tutarının girildiği alandır. |
| Asgari Yatırım | Yapılacak yatırımın asgari tutarının girildiği alandır. |

**Yatırım Ek Bilgiler**

Yatırım Ek Bilgiler sekmesinde, teşviği kaydeden Kullanıcının Adı, teşvikin kaydedildiği tarih, daha önceden kaydedilen bir teşvik üzerinde değişiklik yapılmış ise değişikliği yapan kullanıcının adı ve değişiklik tarihi bilgi amaçlı olarak izlenebilecektir. Bunun dışında, ilgili teşvik için özel notlar girilecek ise bu sayfa kullanılabilir.

Teşvik Bilgi Girişi ekranı Yatırım Ek Bilgiler sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Teşvik Bilgi Girişi Ekranı |  |
| --- | --- |
| Teşvik No | Yatırım Genel Bilgileri sekmesinden girilen teşvik numarasının izlendiği alandır. |
| Açıklama | Teşvik Numarası açıklamasının izlendiği alandır. |
| Kayıt Yapan | Teşviği kaydeden kullanıcı adının izlendiği alandır. |
| Kayıt Tarihi | Teşviğin kaydedildiği tarihin izlendiği alandır. |
| Değişiklik Yapan | Daha önceden kaydedilen bir teşvik üzerinde değişiklik yapılmışsa, değişikliği yapan kullanıcı adının izlendiği alandır. |
| Değişiklik Tarihi | Daha önceden kaydedilen bir teşvik üzerinde değişiklik yapılmışsa, değişiklik tarihinin izlendiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Teşvik Bilgi Girişi kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
