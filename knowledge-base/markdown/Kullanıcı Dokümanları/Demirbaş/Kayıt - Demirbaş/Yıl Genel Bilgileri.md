# Yıl Genel Bilgileri

Yıl Genel Bilgileri, yıllık amortisman oranlarının, demirbaş genelinde uygulanan amortisman tipinin ve taban değerin girilmesi için kullanılan bölümdür.

Yıl Genel Bilgileri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Yıl Genel Bilgileri Ekranı |  |
| --- | --- |
| Yıl | Amortisman Tipi, Amortisman Oranı ve Taban Değer alanları için baz alınacak yıl bilgisinin girildiği alandır. |
| Amortisman Tipi Amortisman Oranı | İlgili yıl için Amortisman Oranı ve Amortisman Tipi bilgileri, Şirket Genel Bilgileri bölümüne ve Demirbaş Bilgi Kartına program tarafından yansıtılır. |
| Taban Değer | Kanunen o yıl için tespit edilen değerlerin girilmesi gerekir. Eğer, demirbaş sabit kartlarını tanımlarken girilen alış fiyatları, ilgili cari yıl için tanımlanan değerleme tabanından küçükse, program otomatik olarak "Yeniden Değerleme" alanını seçer. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yıl Genel Bilgileri kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../_assets/2df4b343310bcd16b01e.jpg)butonuna tıklanması gerekir.
