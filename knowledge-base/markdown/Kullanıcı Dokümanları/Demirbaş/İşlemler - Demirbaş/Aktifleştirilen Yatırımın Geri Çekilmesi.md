# Aktifleştirilen Yatırımın Geri Çekilmesi

Aktifleştirilen Yatırımın Geri Çekilmesi, daha önceden aktife geçirilen demirbaşların, aktiften geri alınmaları için kullanılan bölümdür.

Aktifleştirilen Yatırımın Geri Çekilmesi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Aktifleştirilen Yatırımın Geri Çekilmesi Ekranı |  |
| --- | --- |
| Proje No | Aktiften geri alınacak demirbaşın proje kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodlarına ulaşılır. |
| Demirbaş Kodu | Aktiften geri alınacak demirbaş kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, demirbaş kodlarına ulaşılır. |
| Adet Parçalama Yapıldı | Adet parçalama yapılmışsa işaretlenmesi gereken seçenektir. |
| ![](../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
