# Banka Hesap Hareketlerinde Kullanılan Özel Tuşlar

"Banka Hesap Hareketi" ekranında kullanılan yardımcı tuşlar, ekran üzerinde iken farenin sağ tuşu ile ekrana gelir.

![](../../../../../_assets/c4f94178e34696c6688b.png)

"Banka Hesap Hareketi" ekranında kullanılan yardımcı tuşlar ve içerdiği bilgiler şunlardır:

| Banka Hesap Hareketleri Ekranı Özel Tuşlar |  |
| --- | --- |
| Diğer Bilgiler | Banka hareketi ile ilgili ek bilgilere ulaşılmasını sağlayan seçenektir. |
| Banka Hesap Sabit İzleme | İlgili hesabın "Banka Hesap Kayıtları" bölümündeki bilgilerinin izlenmesini sağlayan seçenektir. ![](../../../../../_assets/269d52ef356000d04f9a.png) |
| Yevmiye Detay | İlgili hareketin muhasebeye aktarılması halinde yevmiye fişine ulaşılmasını sağlayan seçenektir. |
| Detay Bilgi | Banka hareketlerindeki kaydın hareket detayına ulaşılmasını sağlayan seçenektir. **Örneğin:** Banka hareket kayıtlarında bir Havale/EFT hareketi varsa, ilgili havale kaydına ait detay bilgilere ulaşılması sağlanır. |
| Gönder | "Gönder" seçeneği ile, banka hareket bilgileri Excel’e aktarılabilir, grafik hazırlanabilir ve akıllı gride gönderilebilir. |
