# Banka Şube Bazında Parametreler

Banka Şube Bazında Parametreler, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Banka Şube Bazında Parametreler ekranı, bankalar ile ilgili yapılan işlemlerde alınan masraf, komisyon gibi tutarların muhasebe entegrasyonu ve stopaj için şube bazında hesap kodlarının girilmesini sağlayan ekrandır.

Banka Şube Bazında Parametreler ekranında yer alan parametreler ve içerdiği bilgiler şunlardır:

| Banka Şube Bazında Parametreler Ekranı |  |
| --- | --- |
| BSMV Oranı | Banka Sigorta Muamele Vergisi oranının şube bazında tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| KKDF Oranı | Kaynak Kullanım Destekleme Fonu oranının şube bazında tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| SSDF Oranı | Savunma Sanayi Destekleme Fonu oranının şube bazında tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| MSIGV Oranı | Menkul Sermaye İradı Gelir Vergisi oranının şube bazında tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Damga Vergisi Muhasebe Kodu | Damga vergisi için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| İşlem Masrafı Muhasebe Kodu | İşlem masrafı için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Teminat Mektubu Komisyonu Muhasebe Kodu | Teminat mektubu komisyonu için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Faiz Giderleri Muhasebe Kodu | Faiz giderleri için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Faiz Gelirleri Muhasebe Kodu | Faiz gelirleri için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Kredi Faiz Komisyonu Muhasebe Kodu | Kredi faiz komisyonu için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Özel İşlem Vergisi Muhasebe Kodu | Özel işlem vergisi için muhasebe kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Faiz Tahakkuk Hesabı | Faiz tahakkuk için hesap kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Stopaj Muhasebe Kodu | Stopaj için muhasebe hesap kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodları arasından seçim yapılır. |
| Kart Masrafları Satış Anında Entegrasyona Aktarılsın | Kart masraflarının satış yapılırken entegrasyona aktarılması için kullanılan parametredir. |
| Kart Masrafları Satış Anında Entegrasyona Toplu Aktarılsın | Kart masraflarının satış yapılırken entegrasyona toplu olarak aktarılması için kullanılan parametredir. |
| Kredi Kartı Tahsilatları Nakit Kasaya İşlensin | Kredi kartı tahsilatlarının nakit kasaya işlenmesi için kullanılan parametredir. |
| Bankada Döviz Çevrim Tipi Atansın | Bankada döviz çevrim tipinin atanması için kullanılan parametredir. |
| Lokal Döviz Çevrim Tipi | Lokal döviz çevrim tipi seçilmesi içi kullanılan alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile, Döviz Alış/Satış, Efektif Alış/Satış seçeneklerinden biri seçilir. |
| Firma Kredi Kartlarında Limit Aşıldığında | Firma kredi kartlarında limit aşıldığında, işlemin durdurulması veya uyarı verilmesini sağlayan parametredir. |
| Hesap Özeti Kullanılsın | Bu parametre işaretli olduğunda, hesap özeti geldiğinde "Hesap Özeti Kaydı Oluştur" butonu ile 300'den 103 hesaba tutarların aktarıldığı fiş kaydı oluşur. Aksi halde, "Hesap Özeti Kaydı Oluştur" butonu pasif halde kalır ve sadece ödeme yapılması istendiğinde "Ödeme Oluştur" butonu kullanılır. |

| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | İşaretlenen parametrelerden vazgeçilmesi halinde kullanılan butondur. |
