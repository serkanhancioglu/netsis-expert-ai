# Banka Yetkili Kayıtları

Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Banka Yetkili Kayıtları, banka şubesinde çalışan, firma ile ilgilenen yetkililerin ve departman bilgilerinin tanımlandığı bölümdür. Banka Yetkili Kayıtları; Yetkili Bilgiler-1 ve Yetkili Bilgiler-2 sekmelerinden oluşur.

**Yetkili Bilgileri-1**

![](../../../../../_assets/bd78ef7443d48595f4c8.png)

Yetkili Bilgileri-1 sekmesinin alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Banka Yetkili Kayıtları Ekranı |  |
| --- | --- |
| Yetkili Kodu | Banka yetkili kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, yetkili kodlarına ulaşılır. |
| Yetkili İsmi | Banka yetkili isminin girildiği alandır. |
| Banka Ana Kod | "Banka Ana Kod Kayıtları" bölümünden tanımlanan banka kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, ana kodlara ulaşılır. |
| Banka Şube Kodu | "Banka Şube Kayıtları" bölümünden tanımlanan şube kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodlarına ulaşılır. |
| Çalıştığı Bölüm | Yetkilinin çalıştığı bölümün seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile bölümler arasından seçim yapılır. |
| Unvanı | Yetkilinin unvan bilgisinin girildiği alandır. |
| E-Posta | Yetkiliye ait e-posta adresinin girildiği alandır. |
| Telefon 1,2,3-Dahili 1,2,3 | Yetkiliye ait telefon ve dahili numara bilgisinin girildiği alanlardır. |
| Faks | Yetkiliye ait faks numarasının girildiği alandır. |

**Yetkili Bilgileri-2**

![](../../../../../_assets/4b904ff6cb79fb2b1bc5.png)

Yetkili Bilgileri-2 sekmesinin alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Banka Yetkili Kayıtları Ekranı |  |
| --- | --- |
| Yetkili Kodu | Yetkili Bilgileri-1 sekmesinde tanımlaması yapılan yetkili kodunun izlendiği alandır. |
| Adres, İl, İlçe, Posta Kodu, Ülke | Tanımlaması yapılan yetkiliye ait adres, il, ilçe, posta kodu, ülke gibi bilgilerin girildiği alanlardır. |

İlgili alanlara bilgi girişi yapıldıktan sonra "Kaydet" ![](../../../../../_assets/865524a70e225c89c107.jpg) butonuna basılarak kayıt oluşturulur. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
