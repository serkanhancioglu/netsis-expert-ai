# Kredi Limiti Tanımlama

Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Banka şubeleri bazında, bir bankanın müşteriye kredi türü olarak verdiği limitin (sınırın) girildiği alandır. Kredi Limiti; Banka Genel Müdürlüğü ve/veya diğer birimler tarafından bankalar kanunundaki sınırlamalar dahilinde, gerçek veya tüzel kişiye kullandırılmak üzere tahsis edilen kredinin azami tutarıdır.

![](../../../../../_assets/b62c084b1eb6003b28f7.png)

Kredi Limiti Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Kredi Limiti Tanımlama Ekranı |  |
| --- | --- |
| Ana Kod | "Banka Ana Kod Kayıtları" bölümünden tanımlanan banka ana kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, ana kodlara ulaşılır. |
| Şube Kodu | "Banka Şube Kayıtları" bölümünden tanımlanan şube kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodlarına ulaşılır. |
| Kredi Türü | Kredi limiti verilecek kredi türünün seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile kredi türleri arasından seçim yapılır. |
| Teminat Tipi | "Kayıt/Teminat Tipi Tanımlama" bölümünden tanımlanan teminat tipinin seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, teminat tiplerine ulaşılır. |
| Döviz Tipi | Kredinin dövizli olması halinde ilgili döviz tipinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tiplerine ulaşılır. |
| Kredi Limiti | Banka şubesi bazında, bankanın müşteriye kredi türü olarak vermiş olduğu limitin tanımlandığı alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra "Kaydet" ![](../../../../../_assets/865524a70e225c89c107.jpg) butonuna basılarak kayıt oluşturulur. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
