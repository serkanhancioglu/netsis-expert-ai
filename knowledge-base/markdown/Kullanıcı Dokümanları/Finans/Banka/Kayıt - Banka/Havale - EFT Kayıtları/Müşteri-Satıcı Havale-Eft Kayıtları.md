# Müşteri/Satıcı Havale/Eft Kayıtları

Müşteri/Satıcı Havale/Eft Kayıtları, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Müşteri/Satıcı Havale/Eft Kayıtları, müşteri/satıcı ile banka arasında yapılan havale işleminin kaydedildiği bölümdür. Müşteri/Satıcı Havale/Eft Kayıtları; Ön Sorgulama, Havale/EFT Bilgileri, İşlem Masrafı/BSMV Bilgileri sekmelerinden oluşur.

**Ön Sorgulama**

![](../../../../../_assets/4edb31dc1204289a03f6.png)

Müşteri/Satıcı Havale/Eft Kayıtları ekranı Ön Sorgulama sekmesi alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Müşteri/Satıcı Havale/EFT Kayıtları Ekranı |  |
| --- | --- |
| Banka Hesap Kodu | Havalenin yapılacağı banka kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodlarına ulaşılır. |
| Gelen | İlgili bankaya satıcı/müşteri tarafından havale kaydı yapılması halinde işaretlenmesi gereken seçenektir. |
| Gönderilen | Satıcıya/müşteriye ilgili banka tarafından havale kaydı yapılması halinde işaretlenmesi gereken seçenektir. |
| ![](../../../../../_assets/c102c4379c4bac16132c.png) Diğer Sayfa | "Havale/EFT Bilgileri" sekmesine geçmek için kullanılan butondur. |

**Havale/EFT Bilgileri**

![](../../../../../_assets/f4ae2c1b1b17b8263ab3.png)

Müşteri/Satıcı Havale/Eft Kayıtları ekranı Havale/EFT Bilgileri sekmesi alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Müşteri/Satıcı Havale/EFT Kayıtları Ekranı |  |
| --- | --- |
| Referans No | Yapılan Havale/EFT işlemlerine en fazla 15 karakterden oluşan alfa numerik takip numarası verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans numaralarına ulaşılır. |
| İşlem Tarihi | Yapılan Havale/EFT işlemine ait tarihin girildiği alandır. İçinde bulunulan günün tarihi program tarafından otomatik olarak ekrana getirilir. |
| Efektif Tarihi | İleri tarihli bir Havale/EFT emri için kullanılan alandır. **Örneğin:** Cumartesi günü verilen bir EFT emrinin gerçekleşme tarihi olarak düşünülebilir. |
| Dekont No | Yapılan Havale/EFT işlemine banka tarafından verilen işlem numarasının rapor amaçlı takibinin yapıldığı alandır. |
| Cari Rapor Kodu | Cari → Kayıt → [Cari Parametreleri](<../../../Cari/Kayıt - Cari/Cari Parametreleri.md>) → “Hareketlerde Rapor Kodu Sorulsun” parametresinin işaretli olması halinde, "Rapor Kodu" alanında olduğu gibi raporlama amacıyla en fazla 15 karakter uzunluğunda kod girilen alandır. |
| Cari Kodu | İşlem yapılan cari hesap kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlara ulaşılır. |
| Rehber | "Ön Sorgulama" sekmesinde "Gönderilen" seçeneğinin işaretlenmesi halinde aktif hale gelir. Cari hesap kodu girildikten sonra, ilgili Havale/EFT işleminin nereye (hangi bankanın hangi şubesindeki hesabına) yapılacağı ile ilgili bilgilerin tespit edilmesini sağlayan rehberlerin seçildiği butondur. "Cari" seçilmesi halinde, rehbere sadece "Cari Kodu" alanındaki cari hesaba ait, Cari → Kayıt → [Cari - Banka Kayıtları](<../../../Cari/Kayıt - Cari/Cari - Banka Kayıtları.md>) bölümünde girilen banka bilgileri gelir. "TCMB" seçilmesi halinde ise, [T.C.M.B Kayıtları](<../TCMB Kayıtları/T.C.M.B Banka Şube Kayıtları.md>) bölümünde girilen banka ve şubeleri gösteren rehber aktif hale gelir. "TCMB Ana Kod" ve "TCMB Şube Kod" alanlarının yanında yer alan rehber butonu ile ilgili banka ve şube kodları seçilerek işleme devam edilir. |
| Banka Hesap No | Müşteri/Satıcı Havale/EFT işlemine ait banka hesap numarasının girildiği alandır. |
| IBAN | Müşteri/Satıcı Havale/EFT işlemine ait IBAN numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari banka rehberine ulaşılır. |
| Değişsin | Bu alanda ön değer olarak "Döviz tutarı" tercihi seçili olarak ekrana gelir. Bu şekildeki işlem klasik döviz uygulaması işlemidir. Yani, girilen kur ve döviz tutarına göre TL tutar hesaplanır. "Kur" seçilirse, döviz tutarı sabit kalır ve girilen TL tutara göre kur hesaplanır. "Tutar" seçeneği ise, kuru sabit tutup girilen TL tutara göre döviz tutarını hesaplar. |
| Döviz Tutar | Havale/EFT işleminin, döviz tipi 0 (sıfır) dan farklı bir hesap için yapılması durumunda aktif hale gelen alandır. Havale/EFT döviz tutarının girilmesinin ardından kur bilgileri ekranı görüntülenir. ![](../../../../../_assets/93e3616857517ad67d1a.png) |
| Tutar | Havale/EFT tutarının girildiği alandır. |
| Açıklama | Yapılan işleme ait banka hareket kayıtlarına işlenecek rapor amaçlı açıklama bilgisinin girildiği alandır. Program tarafından “HAVALE CARİ İSİM” açıklaması ön değer olarak aktarılır. İstendiğinde, kullanıcı tarafından değişiklik yapılabilir. |
| Cari Açıklama | İlgili cari harekete işlenecek rapor amaçlı açıklama bilgisi girilen alandır. Program tarafından “HAVALE BANKA HESAP İSMİ” açıklaması ön değer olarak aktarılır. İstendiğinde, kullanıcı tarafından değişiklik yapılabilir. |
| Yevmiye Açıklama | Havale/EFT işlemi sonucu, entegrasyon havuzuna aktarılacak kayıtlara ait rapor amaçlı açıklama bilgisi girilen alandır. Program tarafından “HAVALE NOLU DEKONT” açıklaması ön değer olarak aktarılır. İstendiğinde, kullanıcı tarafından değişiklik yapılabilir. |
| Muhasebe Referans Kod | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../../../../Muhasebe/Muhasebe Modülü/Kayıt - Muhasebe/Muhasebe Parametreleri.md>) → Yevmiye → "Fişlerde Referans Kodu Sorulsun" parametresinin işaretlenmesi ile aktif hale gelen alandır. Seçilen hesap tipine göre referans kodunun sorgulanmasını sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket/Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>)nda “Proje Uygulaması Var” parametresinin işaretlenmesi halinde ekrana gelen alandır. İlgili havale kaydına ait proje kodunun girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodlarına ulaşılır. |
| Plasiyer Kodu | Yardımcı Programlar → Kayıt → [Şirket/Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>)nda “Plasiyer Uygulaması Var” parametresinin işaretlenmesi halinde ekrana gelen alandır. Havale/EFT kayıtları ekranındaki "Ön Sorgulama" sekmesinde "Gönderilen" seçildiğinde, Banka Hesap Hareketlerine "Alacak", Cari Hareket Kayıtlarına "Borç" kaydı aktarılır. "Ön Sorgulama" sekmesinde "Gelen" seçildiğinde ise, Banka Hesap Hareketlerine "Borç", Cari Hareket Kayıtlarına "Alacak" kaydı aktarılır. |

**İşlem Masrafı/BSMV Bilgileri**

Müşteri/Satıcı Havale/Eft Kayıtları ekranı İşlem Masrafı/BSMV Bilgileri sekmesi, "Ön Sorgulama" sekmesinde "Gönderilen" seçeneğinin işaretlenmesi durumunda aktif hale gelen sekmedir. BSMV, işlem masrafının girildiği durumlarda sorgulanır.

![](../../../../../_assets/575d6a2ea9bb76e243b9.png)

Müşteri/Satıcı Havale/Eft Kayıtları ekranı İşlem Masrafı/BSMV Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Müşteri/Satıcı Havale/EFT Kayıtları Ekranı | İşlem Masrafı |
| --- | --- |
| Banka Hesap Kodu | Havale/EFT işlem masrafının yapılacağı banka kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodlarına ulaşılır. |
| Muhasebe Kodu | Havale/EFT işlem masrafının yapılacağı muhasebe kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Muhasebe Referans Kodu | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../../../../Muhasebe/Muhasebe Modülü/Kayıt - Muhasebe/Muhasebe Parametreleri.md>) → Yevmiye → "Fişlerde Referans Kodu Sorulsun" parametresinin işaretlenmesi ile aktif hale gelen alandır. Seçilen hesap tipine göre referans kodunun sorgulanmasını sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket/Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>)nda “Proje Uygulaması Var” parametresinin işaretlenmesi halinde ekrana gelen alandır. İlgili havale kaydına ait proje kodunun girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodlarına ulaşılır. |
| Döviz Tutar | Banka hesabının dövizli olması durumunda dövizli tutarın girildiği alandır. |
| Tutar | Havale/EFT işlem masrafı tutarının girildiği alandır. |
| Müşteri/Satıcı Havale/EFT Kayıtları Ekranı | BSMV |
| Muhasebe Kodu | "Banka Sigorta Muamele Vergisinin" kaydedileceği muhasebe kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Muhasebe Referans Kodu | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../../../../Muhasebe/Muhasebe Modülü/Kayıt - Muhasebe/Muhasebe Parametreleri.md>) → Yevmiye → "Fişlerde Referans Kodu Sorulsun" parametresinin işaretlenmesi ile aktif hale gelen alandır. Seçilen hesap tipine göre referans kodunun sorgulanmasını sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket/Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>)nda “Proje Uygulaması Var” parametresinin işaretlenmesi halinde ekrana gelen alandır. İlgili havale kaydına ait proje kodunun girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodlarına ulaşılır. |
| Döviz Tutar | Banka hesabının dövizli olması durumunda dövizli tutarın girildiği alandır. |
| Tutar | BSMV tutarının girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
