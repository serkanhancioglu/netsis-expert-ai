# Banka Kesinti Tip Tanımlamaları

Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Banka Kesinti Tip Tanımlamaları, bankalar tarafından farklı işlemlerde kesilen komisyon tiplerinin tanımlanmasını sağlayan bölümdür. Komisyon oranları sözleşmenin yapılacağı bankaya göre değişeceği için, bu bölümde sadece kesinti tiplerinin tanımlamaları yapılır.

![](../../../../../_assets/8870c0d2c5cbac11b8cc.png)

Banka Kesinti Tip Tanımlamaları ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Banka Kesinti Tip Tanımlamaları Ekranı |  |
| --- | --- |
| Tip Kodu | Kesinti tiplerine atanan kodların tanımlandığı alandır. Tip kodları en fazla 8 karakterden oluşur. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kesinti tip rehberine ulaşılır. |
| Açıklama | Tanımlanan kesinti tipi için açıklama girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
