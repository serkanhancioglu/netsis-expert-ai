# Firma Kredi Kartı Ödeme Kayıtları

Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Firma Kredi Kartı Ödeme Kayıtları; Hazırlık çalıştırılmasını, Hesap Özeti Kaydı oluşturulmasını, Ödeme Kaydı oluşturulmasını ve Hızlı Ödeme Kaydı yapılmasını sağlayan bölümdür.

Firma Kredi Kartı Ödeme Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Firma Kredi Kartı Ödeme Kayıtları Ekranı |  |
| --- | --- |
| Hesap Özeti Başlangıç Tarihi | Hesap Özeti Başlangıç Tarihi'nin girildiği alandır. Varsayılan olarak mevcut ayın ilk günü otomatik gelir. |
| Hesap Özeti Bitiş Tarihi | Hesap Özeti Bitiş Tarihi'nin girildiği alandır. Varsayılan olarak mevcut ayın son günü otomatik gelir. |
| Son Ödeme Tarihinin Başlangıç Tarihi | Son ödeme gününün başlangıç tarihinin girildiği alandır. |
| Son Ödeme Tarihinin Bitiş Tarihi | Son ödeme gününün bitiş tarihinin girildiği alandır. |
| Firma Kredi Kartı | Firma kredi kartının seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılır. |
| Hesap Özeti Tutarı | Firma kredi kartı hesap özeti tutarının girildiği alandır. |
| Faiz Tutarı | Firma kredi kartı faiz tutarının girildiği alandır. |
| Ödenecek Tutar | Firma kredi kartına ait ödenecek tutarın girildiği alandır. |
| Hızlı Ödeme Kaydı İçin Kasa Kodu | Hızlı ödeme kaydının oluşturulacağı kasa kodunun tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlı kasa kodları arasından seçim yapılır. |
| Ödenecek Vadesiz Hesap | Firma kredi kartı ödemesinin yapılacağı vadesiz hesabın tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile banka kodları arasından seçim yapılır. |
| Ödeme Tarihi | Son ödeme tarihinin girildiği alandır. |
| Hazırlık | Hazırlık işleminin çalıştırılması için kullanılan butondur. |
| Tümünü Seç | Grid ekrandaki kayıtların hepsinin seçilmesi için kullanılan butondur. |
| Seçimi Kaldır | Grid üzerinden seçilen bir kaydın seçiminin kaldırılması için kullanılan butondur. |
| Hesap Özeti Kaydı Oluştur | "Hesap Özeti Kaydı Oluştur" parametresi işaretli olduğunda aktif hale gelir. Hesap özeti kaydının oluşturulmasını sağlayan butondur. Hesaplanan hesap özeti tarihine aşağıdaki gibi bir muhasebe fişi kaydedilir. Ayrıca, ilgili firma kredi kartı hesabına ait bankanın hareketine de buradaki tutar ile yani 300 hesaptaki tutar ile bir (borç) hareket kaydı atılır. **Örneğin:** ```text<br>Hesap Kodu Borç Alacak<br>``` ```text<br>300.01 2.360 TL<br>``` ```text<br>103 2.360 TL<br>``` |
| Ödeme Kaydı Oluştur | Ödeme kaydının oluşturulması için kullanılan butondur. |
| Hızlı Ödeme Kaydı | Eksik olan kayıtları varsa, butona tıklandığında ekrana gelecek olan "Hızlı Ödeme Kaydı" ekranından girişlerin yapılıp tekrar hazırlık çalıştırarak, Hesap Özeti tutarlarının bankadan gelen tutar ile aynı olmasını sağlar. |
