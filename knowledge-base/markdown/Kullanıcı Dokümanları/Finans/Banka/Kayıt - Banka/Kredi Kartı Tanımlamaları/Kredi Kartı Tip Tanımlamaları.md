# Kredi Kartı Tip Tanımlamaları

Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Kredi Kartı Tip Tanımlamaları, kredi kartı tiplerinin rapor amaçlı girildiği bölümdür.

Örneğin; Master, Visa.

![](../../../../../_assets/8435f6b01c79512fdaba.png)

Kredi Kartı Tip Tanımlamaları ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Kredi Kartı Tip Tanımlamaları Ekranı |  |
| --- | --- |
| Tip kodu | Kredi kart tipleri için verilen kodların tanımlandığı alandır. En fazla 8 karakterden oluşan bir kod girilmesi gerekir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kart tipleri arasından seçim yapılır. |
| Açıklama | Kredi kartı tipi olarak girilen koda ait açıklama bilgisinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
