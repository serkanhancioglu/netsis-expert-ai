# MT940 Kayıtları

MT940 Kayıtları, bankadan MT940 formatında alınan hesap hareketleri ile cari, banka, muhasebe ve çek kayıtlarının program tarafından otomatik olarak oluşturulmasını sağlayan bölümdür. Entegrasyon süreci ile ilgili kullanım bilgilerinin tanımlanmasına yönelik ekranlara, "Banka/Kayıt" menüsünün içinde yer alan "MT940" bölümünden ulaşılır.
