# İşlem Kodları

İşlem Kodları, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Sistem üzerinde standart işlem kodları otomatik olarak oluşturulur. Mevcut işlem kodları dışında, çalışılan banka tarafından desteklenen ek işlem kod kayıtları da bu bölümden tanımlanır.

![](../../../../../_assets/7c80b18583dd5da242ab.png)

Swift İşlem Kodları ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Swift İşlem Kodları Ekranı |  |
| --- | --- |
| İşlem Kodu | Çalışılan banka tarafından desteklenen ek işlem kodunun tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlı işlem kodlarına ulaşılır. |
| Açıklama | Tanımlaması yapılan işlem koduna ait açıklama bilgisinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.
