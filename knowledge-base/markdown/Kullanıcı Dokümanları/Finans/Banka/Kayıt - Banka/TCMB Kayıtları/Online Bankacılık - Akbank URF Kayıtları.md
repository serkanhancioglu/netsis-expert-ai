# Online Bankacılık: Akbank URF Kayıtları

Online Bankacılık: Akbank URF Kayıtları, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Akbank online bankacılık işlemleri kullanan müşterilerin, kullanacakları uygulamalara ait Akbank bankasından aldıkları kodları Akbank URF ekranına tanımlamaları gerekir. Buraya tanımlanan bilgiler Akbank ile haberleşmede kullanılan XML dosyasında yer alır.

![](../../../../../_assets/1a2ef7da4482e6a3a063.png)

Akbank URF ekranında yer alan alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Akbank URF Ekranı |  |
| --- | --- |
| Maaş Ödemeleri Sistemi | Maaş ödemeleri ile ilgili Akbank bankasından alınan kodun girildiği alandır. Maaş Ödemeleri Sistemi alanı, "Personel Maaş Ödemesi" işlemlerinde kullanılır. |
| Çek Ödeme/Akıbet Sistemi | Çek Ödeme/Akıbet Sistemi ile ilgili Akbank bankasından alınan kodun girildiği alandır. Çek Ödeme/Akıbet Sistemi alanı, "Çek Akıbet", "Tahsil Çekleri" ve "Firma Çekleri" işlemlerinde kullanılır. |
| Toplu Ödeme Sistemi | Toplu ödeme sistemi ile ilgili Akbank bankasından alınan kodun girildiği alandır. Toplu Ödeme Sistemi alanı, "Ödeme Emri" ve "Ödeme Emri Akıbeti" işlemlerinde kullanılır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Akbank URF ekranında girilen bilgilerin kaydedilmesini sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Akbank URF ekranında girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
