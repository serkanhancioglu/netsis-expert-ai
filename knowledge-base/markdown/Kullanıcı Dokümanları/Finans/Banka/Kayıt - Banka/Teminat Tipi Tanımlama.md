# Teminat Tipi Tanımlama

Teminat Tipi Tanımlama, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Teminat Tipi Tanımlama, kredi teminat tiplerinin kaydedilmesini sağlayan bölümdür. Açılacak olan kredi hesaplarında ilgili kredi kullandırılırken, kredi borçlusunun şahsi taahhütlerinin yanı sıra, kredinin geri dönüşünü sağlamak amacıyla kredi türüne göre ek teminatlar alınır. Alınan bu teminatlar, kredibilitesi yüksek görülen gerçek ve/veya tüzel kişilerin kefaletleri olacağı gibi, gerçek ticari ilişkilerden kaynaklanan senet, çek, uygun görülecek emtia, hisse senedi, mevduat rehini ve ekspertiz değerinin yeterli olması kaydıyla menkul rehini, ticari işletme rehini, gayrimenkul ipoteği gibi maddi teminat talebi de olabilir. Teminat tipleri, kredi tipli tanımlanan banka hesaplarında belirtilir ve rapor amaçlı kullanılır.
