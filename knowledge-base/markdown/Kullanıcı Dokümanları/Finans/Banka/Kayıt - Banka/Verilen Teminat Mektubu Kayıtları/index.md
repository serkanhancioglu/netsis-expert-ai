# Verilen Teminat Mektubu Kayıtları

Verilen Teminat Mektubu Kayıtları, Finans Bölümü'nde, "Kayıt/Banka" menüsünün altında yer alır. Verilen Teminat Mektubu Kayıtları, müşterilere veya diğer firmalara verilen teminat mektuplarının kaydedilmesini sağlayan bölümdür. Verilen Teminat Mektubu Kayıtları; Teminat Mektubu ve Teminat Mektubu Komisyonu sekmelerinden oluşur.

**Teminat Mektubu**

Teminat mektubuna ait tanımlamaların yapıldığı sekmedir.

**![](../../../../../_assets/5f9640f7ddca311219ef.png)**

Verilen Teminat Mektubu Kayıtları ekranı Teminat Mektubu sekmesinin alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Verilen Teminat Mektubu Kayıtları Ekranı |  |
| --- | --- |
| Kayıt No | Teminat mektuplarının takibinde kullanılması için en fazla 15 karakterden oluşan alfa numerik kodlama yapılan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıt numaralarına ulaşılır. |
| Kayıt Türü | "Devir" ve "Yeni Kayıt" olmak üzere iki seçenekten oluşur. Alanın sağ tarafında yer alan aşağı ok butonu ile seçim yapılır. "Devir" olarak kayıt yapıldığında, Banka Hesap Hareketleri ve Entegrasyon bölümüne kayıt aktarılır. Cari Hareket Kayıtları bölümüne devir için herhangi bir kayıt aktarılmaz. "Durumu" alanı "Açık" olarak kayıt yapıldığında, Banka Hesap Hareket Kayıtları bölümüne "Virman" tipinde alacak kaydı, Borç Muhasebe Hesap Koduna borç kaydı aktarılır. "Kapalı" olarak kayıt yapıldığında ise, Banka Hesap Hareket Kayıtları bölümüne "Virman" tipinde borç kaydı, Teminat Mektubu Muhasebe Koduna alacak kaydı aktarılır. |
| Şube Kodu | Şubeli çalışmalarda sadece merkezde iken aktif hale gelen alandır. Merkez, şubesi adına müşteriye verdiği teminat mektubu kaydını şube kodu belirterek yapar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodlarına ulaşılır. |
| Durumu | Açık, Kapalı, İade ve Tahsil seçeneklerinden oluşan alandır. Teminat mektubunun durum bilgisinin girilmesini sağlar. Teminat mektubu ilk kayıttan sonra "Açık" değerini alır. İlgili mektubun işlemi bittikten sonra farenin sağ tuşu ile ekrana gelen "Teminat Mektubu Kapatma" seçeneği kapatma işleminin yapılmasını sağlar. |
| Kapanış Tarihi | Teminat Mektubu Kapatma işlemi sonrası, program tarafından yapılan kapatma işlem tarihinin otomatik olarak ekrana getirildiği alandır. |
| Teminat Tipi | Seçilen banka hesap kodunda tanımlı teminat tip/tipleri, alanın sağ tarafında yer alan aşağı ok butonu yardımıyla seçilir. |
| Süre Tipi | Vadeli ve Vadesiz olmak üzere iki seçenekten oluşur. Alanın sağ tarafında yer alan aşağı ok butonu ile seçim yapılır. Verilen teminat mektubunun geçerlilik tarihi ileri tarihli ise (vadesi dolmamışsa) "Vadeli" olarak seçilmesi gerekir. |
| Tarih | İlgili mektubun kayıt tarihinin girildiği alandır. |
| Vade Tarihi | "Süre Tipi" alanında "Vadeli" seçeneğinin seçilmesi ile aktif hale gelir. Vade tarihinin girilmesini sağlar. |
| Seri No | Teminat mektubu için en fazla 10 karakterden oluşan alfa numerik seri numarası girilen alandır. |
| Teminat Mektup No | Teminat mektubuna banka tarafından verilen, en fazla 15 karakterden oluşan alfa numerik mektup numarasının girildiği alandır. |
| Cari Kodu | Teminat mektubunun hangi cariye verildiğini kaydetmek için cari kod bilgisi girilen alandır. |
| Banka Hesap Kodu | Teminat mektup tutarının virman edileceği kredi tipli hesap kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, banka hesap kodlarına ulaşılır. |
| Borç Muhasebe Hesap Kodu | Teminat mektup tutarının karşılık belirtileceği muhasebe hesap kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodlarına ulaşılır. |
| Referans Kodu | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../../../../Muhasebe/Muhasebe Modülü/Kayıt - Muhasebe/Muhasebe Parametreleri.md>) → Yevmiye → "Fişlerde Referans Kodu Sorulsun" parametresinin işaretlenmesi ile aktif hale gelen alandır. Seçilen hesap tipine göre referans kodunun sorgulanmasını sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Plasiyer Kodu | Yardımcı Programlar → Kayıt → [Şirket-Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) → "Plasiyer Uygulaması Var" parametresinin işaretlenmesi ile aktif hale gelen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, plasiyer kodlarına ulaşılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket-Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) → “Proje Uygulaması Var" seçeneğinin işaretlenmesi ile aktif hale gelen alandır. Proje uygulamasında, her türlü giriş/çıkış işlemlerinde proje kodu sorgulanır ve boş bırakılmaz. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodlarına ulaşılır. |
| Döviz Tipi | Seçilen banka hesabının dövizli (verilen teminat mektubu döviz üzerinden) olduğu durumlarda aktif hale gelen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tipleri arasından seçim yapılır. |
| Döviz Tutar | Verilen teminat mektubunun döviz tutarının girildiği alandır. İlgili tutar, kayıt sırasında sorulacak kur ile hesaplanıp "Tutar" alanına aktarılır. |
| Tutar | Verilen Teminat mektubuna ait tutar bilgisinin girildiği alandır. |
| Komisyon Oran | Teminat mektubuna ait banka tarafından verilen komisyon oranının girildiği alandır. |
| Açıklama | Teminat mektubu ile ilgili açıklama bilgisi girilen alandır. |

**Teminat Mektubu Komisyonu**

"Teminat Mektubu" sekmesinde kaydedilen komisyonun izlenmesini sağlayan sekmedir.
