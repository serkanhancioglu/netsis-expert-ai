# Banka Hareket Kontrolü

Banka Hareket Kontrolü, Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Banka Hareket Kontrolü, alınan çeşitli listelerde, "Banka Hesap Kayıtları" bölümündeki borç/alacak tutar ve bakiyesinin Banka Hesap Hareketleri ile tutmaması durumunda veya SQL ile kayıtlara dışarıdan müdahale edilmesi (kayıt girişi, düzeltme veya iptali) durumunda kullanılan bölümdür. Kontrol işlemi kullanıcı hatalarını düzeltmez. Bu işlem, hareket kayıtlarının tekrar kontrol edilerek kümülatif rakamların yeniden oluşturulması ve bu rakamların hesap kayıtlarındaki kümülatif rakamların tutulduğu bölüme yeniden yazılmasını sağlar.

![](../../../../_assets/207a28c58250d346592d.png)

Banka Hareket Kontrolü ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Banka Hareket Kontrolü Ekranı |  |
| --- | --- |
| Banka Hesap Kodu | Hareketleri kontrol edilecek banka hesap kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. Boş bırakılması halinde, tüm banka hesap hareket kayıtları kontrol edilir. Hareket kontrol işlemini "Admin" olan kullanıcı yapar. "Admin" olmayan kullanıcı menüsünde bu bölüm yer almaz. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
