# Banka Hesap Kodu Değişikliği

Finans Bölümü'nde, "İşlemler/Cari " menüsünün altında yer alır. Banka Hesap Kodu Değişikliği; "Banka Hesap Kayıtları" bölümünde tanımlanan banka hesap kodunun, tüm hareketlerde ve programın diğer entegre bölümlerinde değiştirilmesini sağlayan bölümdür.

![](../../../../_assets/500e1b207c596b2e6ac5.png)

Banka Hesap Kodu Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Banka Hesap Kodu Değişikliği Ekranı |  |
| --- | --- |
| Eski Banka Hesap Kodu | Değiştirilecek banka hesap kodu bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, banka hesap kodları arasından seçim yapılır. |
| Yeni Banka Hesap Kodu | Yeni banka hesap kodunun girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
