# Fatura Aktarımı

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Fatura Aktarımı, firma tarafından sistem aracılığıyla bankaya iletilecek fatura bilgilerinin oluşturulduğu bölümdür.

![](../../../../../_assets/15f2cae50b04dc30370a.png)

Fatura Aktarımı ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Fatura Aktarımı Ekranı |  |
| --- | --- |
| Hesap Kodu | Fatura aktarımı yapılacak bankaya ait hesap kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Banka İsmi/Şube İsmi/IBAN | "Hesap Kodu" alanında seçilen hesabın; ismi, şube ismi ve IBAN numarasının izlendiği alandır. |
| Desen Kodu | Fatura aktarımı yapılırken kullanılacak desene ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, desen kodları arasından seçim yapılır. |
| ![](../../../../../_assets/605a968d1ae355d77063.png) Temizle | Ekranın "Ön Sorgulama" bölümündeki alanlara girilen bilgilerin temizlenmesi için kullanılan butondur. |
| Belge No | Bankaya fatura aktarımı yapılacak belge numara/numaralarının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, aktarımı yapılmayan (tahsilat adayı) faturalar arasından seçim yapılır. |
| Tarih Aralığı | Bankaya fatura aktarımı yapılacak belgeler için tarih aralığı kısıdı verilen alandır. |
| Cari Kodu | Aktarımı yapılacak fatura için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| ![](../../../../../_assets/59314626e8703f048c3f.png) Görüntüle | Girilen bilgiler doğrultusunda, aktarımı yapılacak fatura/faturaların listelenmesi için kullanılan butondur. |
| ![](../../../../../_assets/d15ca1ad68365b9a1a84.png) Tümünü Seç | Aktarım için listelenen faturaların hepsinin seçilmesini sağlayan butondur. |
| ![](../../../../../_assets/f5ffb212771284b3d8d5.png) Tümünü Kaldır | Listelenen faturaların hepsinin seçilmesi halinde, tümünün seçiminin kaldırılmasını sağlayan butondur. |
| ![](../../../../../_assets/8833f068cbeed8fea3e4.png) Dosya Oluştur | Seçilen faturaları içeren tahsilat dosyasının (TXT) oluşturulması için kullanılan butondur. Butona basıldıktan sonra, dosyanın kaydedileceği yer belirlenir. Oluşan dosya, bankaya iletilir. |
