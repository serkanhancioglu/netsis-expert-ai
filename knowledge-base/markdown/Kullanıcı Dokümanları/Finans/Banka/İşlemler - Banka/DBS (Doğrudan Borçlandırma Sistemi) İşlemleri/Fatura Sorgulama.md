# Fatura Sorgulama

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Fatura Sorgulama, bankaya iletilen fatura bilgilerinin izlendiği bölümdür. Sorgulama seçenekleri kullanılarak daha önce bankaya aktarılan fatura listelerinin görüntülenmesi sağlanır. Görüntülenen listenin içinde, banka gönderimi iptal edilmesi istenen faturalarda isteğe bağlı değişiklik yapılabilir.

![](../../../../../_assets/6bfc1f1c7dce61906807.png)

Fatura Sorgulama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Fatura Sorgulama Ekranı |  |
| --- | --- |
| Belge No | Sorgulaması yapılacak fatura için belge numarası kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, belge numaraları arasından seçim yapılır. |
| Tarih Aralığı | Sorgulaması yapılacak fatura için tarih aralığı kısıdı verilen alandır. |
| Cari Kodu | Sorgulaması yapılacak fatura için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Banka | Grid ekranda listelenen belgeye ait banka bilgisinin izlendiği alandır. |
| Cari Kodu/Cari İsmi | Grid ekranda listelenen belgeye ait cari kod ve ismin izlendiği alandır. |
| Fatura No | Grid ekranda listelenen belgeye ait fatura numarasının izlendiği alandır. |
| Tutar | Grid ekranda listelenen belgeye ait fatura tutarının izlendiği alandır. |
| Gönderildi | Grid ekranda listelenen belgelerin içinde, banka gönderimi iptal edilmesi istenen faturalarda isteğe bağlı değişiklik yapılmasını sağlayan seçenektir. **Örneğin:** Grid ekranda listelenen faturanın üzerinde fare ile çift tıklandığında; "Gönderildi" seçeneği işaretli ise, faturanın bankaya gönderildiği anlaşılır. Seçenekteki işaret kaldırılarak fatura gönderimi iptal edilir. |
| ![](../../../../../_assets/8fc04e715a062a675b8e.png) Listele | Ekranın ön sorgulama bölümündeki alanlara kısıt verildikten sonra, faturaların grid alanda listelenmesini sağlayan butondur. |
| ![](../../../../../_assets/605a968d1ae355d77063.png) Temizle | Girilen kısıtların temizlenmesi için kullanılan butondur. |
