# Dosya Desen Kopyala

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Dosya Desen Kopyala, kayıtlı bir dosya deseninin yeni desen koduna kopyalanmasını sağlar.

![](../../../../../_assets/197517074ed2de85045b.png)

Dosya Desen Kopyala ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Dosya Desen Kopyala Ekranı |  |
| --- | --- |
| Yeni Desen Kodu | Oluşturulması istenen yeni desen kodunun girildiği alandır. |
| Şube Kodu | Oluşturulması istenen yeni desen kodu için şube kodu belirlenen alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile şube kodları arasından seçim yapılır. |
| ![](../../../../../_assets/00c94b97b6bf32026325.png) Kopyala | Grid alanda listelenen dosya desenleri arasından, kopyalanması istenen dosya desenine fare ile çift tıklandığında ilgili satır gri renge dönüşür. Kopyala ![](../../../../../_assets/00c94b97b6bf32026325.png) butonuna basıldığında, seçilen dosya deseni yeni desen koduna kopyalanır. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden ve kopyalama işleminden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
