# Dosya Desen Sakla

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Dosya Desen Sakla, oluşturulan dosya deseninin TXT uzantılı olarak bilgisayarın sabit diskinde saklanması için kullanılan bölümdür.

![](../../../../../_assets/79a0f119be376864bbb6.png)

Dosya Desen Sakla ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Dosya Desen Saklama Ekranı |  |
| --- | --- |
| Desen Kodu | Saklanması istenen desen kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, desen kodları arasından seçim yapılır. "Desen Kodu" alan isminin üzerine fare ile çift tıklandığında, görüntülenen "Dosya Desen Oluşturma" ekranı üzerinden yeni bir dosya deseni tanımlanabilir. |
| Dosya Adı | Saklanması istenen dosya deseni için dosya adının girildiği alandır. Dosyanın saklanacağı yeri belirlemek için yükle ![](../../../../../_assets/f5494a9691693fdb71d7.png) butonu kullanılır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin kaydedilmesi için kullanılan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
