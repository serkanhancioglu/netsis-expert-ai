# Dosya Desen Yükle

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Dosya Desen Yükle, önceden saklanmış bir dosya desenini veri tabanına yüklemek için kullanılan bölümdür.

![](../../../../../_assets/7947ebf18ac180d7fe2d.png)

Dosya Desen Yükle ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Dosya Desen Yükleme Ekranı |  |
| --- | --- |
| Dosya Adı | Sabit diske desen dosya adının girildiği alandır. Dosyanın saklanacağı yeri belirlemek için yükle ![](../../../../../_assets/f5494a9691693fdb71d7.png) butonu kullanılır. |
| Desen Kodu | Yüklenmesi istenen desen dosyası için kod bilgisi girilen alandır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanması için kullanılan alandır. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
