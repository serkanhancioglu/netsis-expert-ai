# Faiz Tahakkuk Mahsubu

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Faiz Tahakkuk Mahsubu, faiz tahakkuk mahsubunun oluşturulmasını sağlar.

![](../../../../_assets/ee9d8ea08e479776f243.png)

Faiz Tahakkuk Mahsubu ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Faiz Tahakkuk Mahsubu Ekranı |  |
| --- | --- |
| Yıl Kodu | Oluşturulması istenen faiz tahakkuk mahsubu için yıl bilgisi girilen alandır. |
| Detaylı/Kümüle | **Kümüle** seçeneğinin işaretlenmesi durumunda ilgili ay içinde farklı fişlerde bulunan faiz tahakkukları kümüle edilerek muhasebeleştirilir. **Detaylı** seçeneği işaretlendiğinde ise, her faiz tahakkuku için ayrı ayrı muhasebeleştirme işlemi yapılır. |
| Ay Kodu | Oluşturulması istenen faiz tahakkuk mahsubu için ay bilgisi girilen alandır. |
| Hesap Tipi | Oluşturulacak faiz tahakkuk mahsubu için hesap tipi seçilen alandır. Alanın sağ tarafında bulunan aşağı ok butonu ile, hesap tipleri arasından seçim yapılır. |
| Hesap Kodu Aralığı | Seçilen hesap tipine uygun başlangıç ve bitiş hesap kodu aralığı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Rapor Kodu | Oluşturulacak faiz tahakkuk mahsubu için rapor kodu girilen alandır. "Banka Hesap Kayıtları" ekranındaki rapor kodu alanına göre kısıt verilerek, uygun hesaplar için işlem yapılmasını sağlar. |
| Banka Hesap Kayıtlarındaki Muhasebe Hesap Kodları Kullanılsın | İşaretlendiğinde, faiz tahakkuk işlemi yapıldığı zaman "Banka Hesap Kayıtları" ekranında girilen muhasebe kodları kullanılır. İşaretlenmediğinde ise, "Faiz Tahakkuk Mahsubu" ekranında girilen muhasebe kodları kullanılır. |
| Faiz Muhasebe Kodu | Faiz tahakkuk mahsubu için faiz muhasebe kodu girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Tahakkuk Muhasebe Kodu | Faiz tahakkuk mahsubu için tahakkuk muhasebe kodu girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Muhasebe Referans Kodu | Muhasebe → Kayıt → Muhasebe Parametreleri → Yevmiye → “Fişlerde referans kodu sorulsun” parametresinin aktif olduğu durumlarda, seçilen hesap tiplerine göre referans kodu sorgulanır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket-Şube Parametre Tanımları](<../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) → “Proje Uygulaması Var" seçeneğinin işaretlenmesi ile aktif hale gelen alandır. İlgili proje kodu, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçilerek girilir. |
| Açıklama | Faiz tahakkuk mahsubu için açıklama bilgisi girilen alandır. "Faiz Tahakkuk Kaydı" açıklaması otomatik olarak ekrana gelir. Kullanıcı, açıklama bilgisi üzerinde değişiklik yapabilir. |
| Muhasebe Kayıtları Oluşturulmasın | Muhasebe kaydı oluşturulması istenmediğinde kullanılan seçenektir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/249197106fa4d90d9fe9.png) Çıkış | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
