# Faiz Tahakkuk İptali

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Faiz Tahakkuk İptali, oluşturulan faiz tahakkukunun iptal edilmesini sağlar.

![](../../../../_assets/0017d512a1a5103ffce2.png)

Faiz Tahakkuk İptali ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Faiz Tahakkuk İptali Ekranı |  |
| --- | --- |
| Yıl Kodu | İptal edilmesi istenen faiz tahakkuk için yıl kısıdı girilen alandır. |
| Ay Kodu | İptal edilmesi istenen faiz tahakkuk için ay kısıdı girilen alandır. |
| Hesap Tipi | İptal edilmesi istenen faiz tahakkuk için hesap tipi kısıdı girilen alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile, hesap tipleri arasından seçim yapılır. |
| Hesap Kodu Aralığı | İptal edilmesi istenen faiz tahakkuk için hesap kodu aralığı kısıdı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/249197106fa4d90d9fe9.png) Çıkış | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
