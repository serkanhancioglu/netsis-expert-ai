# Faiz İşleme - Kapatma Özel Tuşları

Faiz İşleme-Kapatma ekranında kullanılan özel tuşlar, ilgili kayıt çift tıklandığında sağ klik ile ekrana gelir.

![](../../../../../_assets/318c7a15e5f14b0e1d03.png)

Faiz İşleme-Kapatma Özel Tuşları menüsünde yer alan seçenekler ve içerdiği bilgiler aşağıdaki şekildedir:

| Faiz İşleme/Kapatma Ekranı Özel Tuşları |  |
| --- | --- |
| Kaydı İptal Et | Seçilen kaydın iptal edilmesini sağlayan seçenektir. |
| Banka Talimat Basımı | Seçilen kaydın banka talimat basımını sağlayan seçenektir. |
| Gönder | Cari hareket kayıtlarının grid ekranında iken, seçilen harekete ait sağ fare tuşu ile ekrana gelen "Gönder" seçeneği sayesinde grid ekranındaki bilgiler Excel'e gönderilir. |
