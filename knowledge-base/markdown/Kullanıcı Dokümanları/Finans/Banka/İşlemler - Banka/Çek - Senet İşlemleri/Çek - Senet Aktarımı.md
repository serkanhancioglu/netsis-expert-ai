# Çek - Senet Aktarımı

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Çek-Senet Aktarımı, firma tarafından sistem aracılığıyla bankaya iletilecek çek/senet bilgilerinin oluşturulduğu bölümdür.

![](../../../../../_assets/08577d26c298e920fe3f.png)

Çek/Senet Aktarımı ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Çek/Senet Banka Entegrasyonu Ekranı |  |
| --- | --- |
| Hesap Kodu | Çek/Senet aktarımı yapılacak bankaya ait hesap kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Banka İsmi/Şube İsmi/IBAN | "Hesap Kodu" alanında seçilen hesabın; ismi, şube ismi ve IBAN numarasının izlendiği alandır. |
| Desen Kodu | Çek/Senet aktarımı yapılırken kullanılacak desene ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, desen kodları arasından seçim yapılır. |
| ![](../../../../../_assets/605a968d1ae355d77063.png) Temizle | Ekranın "Ön Sorgulama" bölümündeki alanlara girilen bilgilerin temizlenmesi için kullanılan butondur. |
| Çek/Senet | Aktarımı yapılacak belgenin seçildiği alandır. Çek aktarımı yapılacaksa "Çek", Senet aktarımı yapılacaksa "Senet" seçeneği seçilir. |
| Numara Aralığı | Bankaya çek/senet aktarımı yapılacak belge numara/numaralarının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, aktarımı yapılmayan çekler/senetler arasından seçim yapılır. |
| Vade Tarih Aralığı | Bankaya çek/senet aktarımı yapılacak belgeler için vade tarih aralığı kısıdı verilen alandır. |
| Cari Kodu | Aktarımı yapılacak çek/senet için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| ![](../../../../../_assets/59314626e8703f048c3f.png) Görüntüle | Girilen bilgiler doğrultusunda, aktarımı yapılacak çeklerin/senetlerin listelenmesi için kullanılan butondur. |
| ![](../../../../../_assets/d15ca1ad68365b9a1a84.png) Tümünü Seç | Aktarım için listelenen çeklerin/senetlerin hepsinin seçilmesini sağlayan butondur. |
| ![](../../../../../_assets/f5ffb212771284b3d8d5.png) Tümünü Kaldır | Listelenen çeklerin/senetlerin hepsinin seçilmesi halinde, tümünün seçiminin kaldırılmasını sağlayan butondur. |
| ![](../../../../../_assets/8833f068cbeed8fea3e4.png) Dosya Oluştur | Seçilen çekleri/senetleri içeren tahsilat dosyasının (TXT) oluşturulması için kullanılan butondur. Butona basıldıktan sonra, dosyanın kaydedileceği yer belirlenir. Oluşan dosya, bankaya iletilir. |
