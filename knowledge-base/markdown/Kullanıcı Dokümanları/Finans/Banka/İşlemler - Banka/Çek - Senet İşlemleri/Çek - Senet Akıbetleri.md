# Çek - Senet Akıbetleri

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Çek/Senet akıbetleri, bu bölümden kontrol edilerek, bankadan alınan akıbet dosyasının seçilmesiyle işlem başlatılır. Dosya içeriği incelendikten sonra ilgili çeklerin/senetlerin banka tarafında işlem gördüğü neticeler görüntülenir. Dosya kontrol sürecinde tespit edilen durumlar, kullanıcı bilgilendirme ekranında görüntülenir. Entegrasyon işlemi ile görüntülenen ve başarılı şekilde tahsil edilen çekler/senetler için sistemde dekont oluşturulması sağlanır.

![](../../../../../_assets/70b0c28ea2f877865947.png)

Çek/Senet Akıbetleri ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Çek/Senet Banka Entegrasyonu Ekranı |  |
| --- | --- |
| Hesap Kodu | Çek/Senet akıbeti için hesap kodu seçilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Banka İsmi/Şube İsmi/IBAN | "Hesap Kodu" alanında girilen hesaba ait banka ismi, şube ismi ve IBAN bilgilerinin izlenmesini sağlayan alanlardır. |
| ![](../../../../../_assets/2371f29deb9fb9434ca2.png) Dosya Seç | Bankadan alınan akıbet dosyasının seçilmesi için kullanılan butondur. Seçilen dosyanın içeriği, grid alanın altında görüntülenir. |
| Dosya Adı | Dosya Seç ![](../../../../../_assets/2371f29deb9fb9434ca2.png) butonu ile seçilen dosyaya ait isim bilgisinin izlendiği alandır. |
| Desen Kodu | "Hesap Kodu" girildikten sonra aktif hale gelen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, desen kodları arasından seçim yapılır. |
