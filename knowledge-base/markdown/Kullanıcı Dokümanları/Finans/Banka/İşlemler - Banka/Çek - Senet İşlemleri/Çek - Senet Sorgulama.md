# Çek - Senet Sorgulama

Finans Bölümü'nde, "İşlemler/Banka" menüsünün altında yer alır. Çek-Senet Sorgulama, bankaya iletilen çek/senet bilgilerinin izlendiği bölümdür. Sorgulama seçenekleri kullanılarak daha önce bankaya aktarılan çek/senet listelerinin görüntülenmesi sağlanır. Görüntülenen listenin içinde, banka gönderimi iptal edilmesi istenen çeklerde/senetlerde isteğe bağlı değişiklik yapılabilir.

![](../../../../../_assets/1cc50aee13f4069d36e8.png)

Çek/Senet Sorgulama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Çek/Senet Banka Entegrasyonu Ekranı |  |
| --- | --- |
| Çek/Senet | Sorgulaması yapılacak belgenin seçildiği alandır. Çek sorgulaması yapılacaksa "Çek", Senet sorgulaması yapılacaksa "Senet" seçeneği seçilir. |
| Numara Aralığı | Sorgulaması yapılacak belge numara/numaralarının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, çekler/senetler arasından seçim yapılır. |
| Vade Tarih Aralığı | Sorgulaması yapılacak belgeler için vade tarih aralığı kısıdı verilen alandır. |
| Cari Kodu | Sorgulaması yapılacak fatura için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Banka | Grid ekranda listelenen belgeye ait banka bilgisinin izlendiği alandır. |
| Cari Kodu/Cari İsmi | Grid ekranda listelenen belgeye ait cari kod ve ismin izlendiği alandır. |
| Fatura No | Grid ekranda listelenen belgeye ait çek/senet numarasının izlendiği alandır. |
| Tutar | Grid ekranda listelenen belgeye ait çek/senet tutarının izlendiği alandır. |
| Gönderildi | Grid ekranda listelenen belgelerin içinde, banka gönderimi iptal edilmesi istenen çeklerde/senetlerde isteğe bağlı değişiklik yapılmasını sağlayan seçenektir. **Örneğin:** Grid ekranda listelenen çekin/senedin üzerinde fare ile çift tıklandığında; "Gönderildi" seçeneği işaretli ise, çekin/senedin bankaya gönderildiği anlaşılır. Seçenekteki işaret kaldırılarak banka gönderimi iptal edilir. |
| ![](../../../../../_assets/8fc04e715a062a675b8e.png) Listele | Ekranın ön sorgulama bölümündeki alanlara kısıt verildikten sonra, çeklerin/senetlerin grid alanda listelenmesini sağlayan butondur. |
| ![](../../../../../_assets/605a968d1ae355d77063.png) Temizle | Girilen kısıtların temizlenmesi için kullanılan butondur. |
