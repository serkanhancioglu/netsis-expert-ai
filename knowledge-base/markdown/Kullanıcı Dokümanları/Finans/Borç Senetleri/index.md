# Borç Senetleri

Alacaklı kişinin borcuna istinaden kesilen senede "Borç Senedi" denir. Borç senetleri sadece cari hesaplara ciro edilir. "Borç Senetleri" modülü, cari hesaplara ciro edilen senetlere ait kayıt ve raporlama gibi işlemlerin yapılmasını sağlar.
