# Toplu Ödeme Bildirimi / Borç Senetleri

Borç Senetleri modülü Toplu Ödeme Bildirimi bölümü, Finans Bölümü'nde, "İşlemler/Borç Senetleri" menüsünün altında yer alır. Borç Senetleri modülü Toplu Ödeme Bildirimi bölümü, müşteri ya da satıcıya ciro edilen, bankaya tahsil veya teminata çıkan senetlerin içinden ödeme günü geçenlere toplu olarak "Ödenmiş" kaşesi vurmak için kullanılan bölümdür.

![](../../../../_assets/bde9b081fb4aef85c477.png)

Borç Senetleri modülü Toplu Ödeme Bildirimi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Toplu Ödeme Bildirimi Ekranı |  |
| --- | --- |
| Baz Tarihi | Senetlerin vade tarihi ile aynı anlama gelir. Vade tarihleri, baz tarihi girilen tarihten küçük olan, ciro edilmiş veya tahsile/teminata çıkılmış senetlerin "Beklemede" olanlarının “Ödendi” olarak işaretlenmesini sağlar. |
| Yer Kodu | Durum kodu bilgisi "Ödendi" olarak değiştirilecek senetlerin yer kodları için kısıt verilmesini sağlayan alandır. Ciro, Tahsil, Teminat ve Hepsi seçeneklerinden oluşur. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
