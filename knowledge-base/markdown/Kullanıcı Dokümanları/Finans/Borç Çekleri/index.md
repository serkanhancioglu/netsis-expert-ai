# Borç Çekleri

Firmanın, borcuna istinaden, alacaklılarına kestiği (bankanın firma adına tahsis ettiği çek defterinden kesilen) çeklere **"Borç Çekleri"** denir. Bu çekler sadece cari hesaplara ciro edilir. "Borç Çekleri" modülü, cari hesaplara ciro edilen çeklere ait kayıt ve raporlama gibi işlemlerin yapılmasını sağlar.
