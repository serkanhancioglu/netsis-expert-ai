# Kur Farkı Kayıtları Silme / Borç Çekleri

Borç Çekleri modülü Kur Farkı Kayıtları Silme bölümü, Finans Bölümü'nde İşlemler/Borç Çekleri menüsünün altında yer alır. Borç Çekleri modülü Kur Farkı Kayıtları Silme bölümü, dövizli borç çeklerinden oluşan kur farkı kayıtlarının silinmesini sağlayan bölümdür.

![](../../../../_assets/a753a3ad7aeb12862fbb.png)

Borç Çekleri modülü Kur Farkı Kayıtları Silme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kur Farkı Kayıtları Silme Ekranı |  |
| --- | --- |
| Yeniden Değerleme Tarihi | Kur farkı kayıtları silinecek tarihin girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
