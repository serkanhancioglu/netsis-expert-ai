# Cari Özel Parametreleri

Özel parametrelerinin tanımlanması için "[Özel Parametre Tanımlamaları](<../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Özel Parametre Tanımları.md>)" ekranı kullanılır.

Akbank İçin Cari İsim Bilgisinin Gönderilmesinin Sağlanması için tanımlanması gereken parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | CARI |
| Anahtar | ODEACIKLAMACARIISIMKULLANILSIN |

Cari Hareket Kayıtları Ekranında, Gride Tanımlanan Filtrenin Bir Sonraki Kayda Geçildiğinde de Tanımlı Kalmasının Sağlanması için tanımlanması gereken parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | CARI |
| Anahtar | GRIDFILTRE |

İlgili özel parametre tanımlandığında, Grid'deki filtreler sonraki veya önceki kayda geçerken sıfırlanmaz.
