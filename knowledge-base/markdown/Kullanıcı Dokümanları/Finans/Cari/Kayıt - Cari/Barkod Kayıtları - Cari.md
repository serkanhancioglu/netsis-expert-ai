# Barkod Kayıtları / Cari

Barkod Kayıtları Cari, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. Cari hesaplar için barkod tanımlamalarının yapıldığı bölümdür. Bu alanda tanımlanan barkodlar cari hesap ile ilişkilendirildikten sonra, Cari → İşlemler → Cari Barkod İşlemleri bölümünden barkod dizaynı yapılarak, yazıcıdan basımı yapılır.

Barkod Kayıtları Cari ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Barkod Kayıtları Ekranı |  |
| --- | --- |
| Cari Kod | Barkod tanımlanacak cari hesaba ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlar arasından seçim yapılır. |
| Barkod | Cariye ait barkod numarasının girildiği alandır. |
| Kayıt Tarihi | Günün tarihinin otomatik olarak ekrana geldiği alandır. Üzerinde değişiklik yapılamaz. |
| Barkod Tipi | Barkod tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok tuşu ile barkod tipleri arasından seçim yapılır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
