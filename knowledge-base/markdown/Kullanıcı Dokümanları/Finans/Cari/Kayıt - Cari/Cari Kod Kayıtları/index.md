# Cari Kod Kayıtları

Cari Kod Kayıtları, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. Cari Hesap Kayıtları menüsünde rapor amaçlı kullanılan Kod1, Kod2, Kod3, Kod4, Kod5, Grup Kodu ve Cari-Grup Kod alanlarına ait kod ve isim tanımlamalarının yapıldığı bölümdür.
