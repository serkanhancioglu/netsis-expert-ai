# Cari İrtibat Bilgileri

Cari İrtibat Bilgileri, Finans Bölümü'nde, "Kayıt/Cari " menüsünün altında yer alır. Cari hesap kayıtlarında tanımlı olan müşteri ve satıcılarla ilgili işlemler yapıldıkça, işlemlerle ilgili haber verilmesini sağlayacak e-posta bilgilerinin girildiği bölümdür. "Cari İrtibat Bilgileri" ekranı, İrtibat Bilgileri ve E-Posta/SMS Tanımlamaları olmak üzere iki sekmeden oluşur.

"Cari İrtibat Bilgileri" bölümünün menüde yer alması için, Yardımcı Programlar → Kayıt → Şirket/Şube Parametre Tanımları → "E-Posta Uygulaması Var" parametresinin veya Yardımcı Programlar → Kayıt → Netsis SMS Servisi → "SMS Uygulaması Var" parametresinin işaretlenmesi gerekir.

**İrtibat Bilgileri**

Cari İrtibat Bilgileri ekranı İrtibat Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Cari İrtibat Bilgileri Ekranı |  |
| --- | --- |
| Cari Kod | İşlem yapıldıkça kendisine e-posta veya SMS yoluyla haber verilmesini isteyen cariye ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlar arasından seçim yapılır. Bir cari için birden fazla irtibat bilgisi tanımlanabilir. |
| İsim Soyadı | Cari kodu girilen firmada, irtibat sağlanacak yetkili isminin girildiği alandır. |
| Görev | Cari kodu girilen firmada, irtibat sağlanacak yetkilinin görevinin girildiği alandır. |
| Unvan | Firmadaki yetkili kişinin unvan bilgisinin girildiği alandır. |
| Telefon, Telefon 2 ve Dahili Tel | Yetkili kişinin sabit telefon numarasının ve dahili telefon numarasının girildiği alanlardır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile tanımlanmış ülke alan kodları arasından kod seçimi yapılır. |
| Direkt Tel | Yetkili kişinin direkt telefon numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile tanımlanmış ülke alan kodları arasından kod seçimi yapılır. |
| Cep Tel, Cep Tel 2 | Yetkili kişinin cep telefonu numarasının girildiği alanlardır. |
| Adres | Cari kodu girilen firmanın adres bilgisinin girildiği alandır. |
| Duyuru Kodu | "Cari E-Posta Duyuru Kayıtları" bölümünden daha önce kaydedilmiş bir duyuru kodunun girildiği alandır. Cari → İşlemler → "Duyuru E-Posta Gönderme" bölümünde, duyuru kodlarına göre her cari hesaba ayrı e-posta gönderilir. Dolayısıyla bu alana girilen duyuru kodu, e-posta gönderme bölümünde de kullanıldığında, aynı duyuru koduna sahip bütün cari hesaplara aynı duyuru gönderilir. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, duyuru kodları arasından seçim yapılır. |
| E-Posta | Firmanın e-posta adresinin girildiği alandır. Firmaya ait işlemler yapıldıkça, bu adrese e-posta gönderilir. Birden fazla adres yazılması için, ekranın sağ tarafında bulunan ekle (\>) işaretine tıklanarak adres eklenir. Alanın sağ tarafına eklenen bir adresin iptal edilmesi için, ilgili adres işaretlendikten sonra çıkar (\<) tuşuna tıklanarak iptal edilir. |
| Cc-Posta | Firmaya ait işlemler yapıldıkça E-posta alanına girilen adresle beraber "CC" olarak ikinci bir adrese de bilgi gönderilmesi istendiğinde ilgili adresin girildiği alandır. Bu durumda, firma ile ilgili bilgilendirme aynı anda iki adrese de yapılır. |
| Kişisel E-Posta | Yetkili kişinin e-posta bilgisinin girildiği alandır. Bu alan sadece bilgi amaçlı olup, e-posta gönderimi yapılmaz. |
| Ek Bilgiler | Eklenmesi istenen ek bilgilerin girildiği alandır. |
| Aktif | İrtibat bilgisinin aktifliğini gösterir. E-Posta gönderimi sadece aktif olarak seçili irtibat bilgileri için yapılır. |
| İrtibat Bilgisini Taşı | Seçili irtibat bilgilerinin başka cari koda kopyalanmasını sağlayan butondur. Butona tıklandığında açılan "Cari İrtibat Bilgisini Taşıma" ekranı car kod alanında, bilginin hangi cariye kopyalanacağı seçilir. "Kaynak İrtibat Bilgisi Kapatılsın" seçeneği işaretlendiğinde, kopyalanan irtibat bilgisi aktif ise pasif hale gelir. Cari kod aktif olarak taşınır. ![](../../../../_assets/a30a0f02ec1ef23925f2.png) |

**E-Posta/SMS Tanımlamaları**

e-Posta ile gönderilmesi istenen işlemlerin belirlendiği sekmedir. e-Posta gönderimi yapıldığı halde dizayn seçilmemiş olan işlemler, Logo Netsis programının standart formatlarına göre gönderilir.

| Cari İrtibat Bilgileri Ekranı |  |
| --- | --- |
| İşlem Tipi | Firmanın haberdar olmak istediği işlemlerin seçildiği sütundur. İşlem Tipi alanı ile, işlemlerden hangisi için e-posta/SMS gönderileceği belirlenir. |
| SMS Gönder | Hangi işlem için SMS gönderimi yapılacağının seçildiği sütundur. SMS gönder sütununun aktif hale gelmesi için Yardımcı Programlar → Kayıt → Netsis SMS Servisi → "SMS Uygulaması Var" parametresinin işaretlenmesi gerekir. |
| E-Posta Gönder | Hangi işlem tipi için e-posta gönderimi yapılacağının seçildiği sütundur. |
| E-Posta/Dizayn | E-postanın özel dizayn ile gönderilmesi istendiğinde seçim yapılacak sütundur. Tercih yapılmaması halinde, Logo-Netsis programının varsayılan dizaynı ile gönderim yapılır. |
| Dizayn | E-posta gönderimi sırasında hangi dizaynın kullanılacağının seçildiği sütundur. **Örneğin:** Faturanın e-posta olarak gönderilmesi sırasında hep aynı dizayn kullanılacaksa, ilgili dizayn rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçilerek kaydedilir. Bir işlem için birden fazla dizayn kullanılacaksa bu bölüm boş bırakılır. |
| Sorulsun | İlgili işlem yapılırken, hangi dizayna göre e-posta gönderileceği program tarafından sorgulanır. Eğer dizayn sütununda bir dizayn belirlenmişse, dizayn adı alanına bu bilgi ön değer olarak gelir. Bu alan işaretlenmediğinde ise, dizayn bölümünde seçilen dizayna göre e-posta gönderilir ve gönderim sırasında herhangi bir sorgulama yapılamaz. |
| Ek Olarak Gönderilsin | Gönderilen e-postanın ek (attachment) olarak gönderilmesinin istendiği durumlarda işaretlenmesi gereken sütundur. |

Sütunlarda yer alan ![(error)](../../../../_assets/1ba848ff48d1f78bde03.svg) çarpı ikonları çift tıklandığında ![(tick)](../../../../_assets/72b3afd8b2fe319fbd82.svg) onay ikonuna dönüşür. Değişiklikleri Kaydet ![](../../../../_assets/bab49ecd68dcaf1bac4b.png) butonuna basılarak, sütunlar üzerinde yapılmış olan değişiklikler kaydedilir. SMS işlemlerinin hepsinin işaretlenmesi/kaldırılması istendiğinde, Tüm SMSleri İşaretle/Kaldır ![](../../../../_assets/ca8d9802fcd95c8b12c7.png) butonu kullanılır. e-Posta işlemlerinin hepsinin işaretlenmesi/kaldırılması istendiğinde ise, Tüm e-Postaları İşaretle/Kaldır butonu kullanılır.
