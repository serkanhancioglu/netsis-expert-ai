# Ciro Prim Hak Ediş Tablosu

Ciro Prim Hak Ediş Tablosu, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. "Ciro Prim Hak Ediş Tablosu", "Ciro Pirimi Uygulaması" ile ilgili bir bölümdür.

Ciro Primi Uygulaması ile ilgili detaylı bilgi için; Finans → Cari → Kayıt → Ek-4 (Ciro Primi Uygulaması).

Ciro Prim Hak Ediş Tablosu ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ciro Prim Hak Ediş Tablosu Ekranı |  |
| --- | --- |
| Grup Kodu | Bu alanın başlığı, "Cari Parametreleri" bölümünde seçilen "Cari Rapor Kodu" alanına göre değişir. **Örneğin:** Grup Kodu "G01" olan cari hesaplar için "Ciro Primi Hak Ediş Bilgisi" girilecekse, parametrelerdeki cari rapor kodu alanı olarak "Grup Kodu" seçilmeli. Böylece, "Ciro Primi Hak Ediş Bilgileri" ekranında "Grup Kodu" başlıklı alana "G01" kodu girilebilir. |
| ![](../../../../../_assets/01f73cfbb2326416f085.png) Önceki | Grup kodu alanındaki koddan bir önceki koda geçmek için kullanılan butondur. |
| ![](../../../../../_assets/cffd65e6b02640a2242e.png) Sonraki | Grup kodu alanındaki koddan bir sonraki koda geçmek için kullanılan butondur. |
| Başlangıç Ciro | Ciro primi uygulanacak miktar veya ciro tutarı için başlangıç değerinin bulunduğu alandır. Bu alan program tarafından otomatik olarak ekrana getirilir. Ciro aralığı ilk kez tanımlanırken, program tarafından otomatik olarak 0 (sıfır) değeri ekrana getirilir. Diğer aralıklarda ise, kendisinden bir önceki aralığın bitiş cirosundan bir fazlası ekrana gelir. Kullanıcı tarafından elle giriş yapılamaz. |
| Bitiş Ciro | Ciro primi uygulanacak miktar veya ciro tutarı için bitiş değerinin girildiği alandır. |
| İskonto (%) | Müşterilerin, belirtilen aralık içindeki alımları sonrası, hak ettikleri ciro iskonto oranının girildiği alandır. |
| Ciro/Miktar | Mal fazlası iskontosunun hangi değer üzerinden hesaplanacağının belirlendiği alandır. Ciro aralığına tutar girildiğinde **Ciro,** stok miktarı girildiğinde ise **Miktar** seçeneği işaretlenir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
