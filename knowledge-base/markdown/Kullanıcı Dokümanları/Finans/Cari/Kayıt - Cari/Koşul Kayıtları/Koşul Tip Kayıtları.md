# Koşul Tip Kayıtları

Koşul Tip Kayıtları, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. Koşul Tip Kayıtları, "Koşul Sabit Kayıtları" üstünde bir gruplama oluşturulması ve "Koşul Politika Tanımlamasında" burada belirlenen önceliklere göre politika tanımlanmasını sağlayan bölümdür.

Koşul Tip Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Koşul Tip Kayıtları Ekranı |  |
| --- | --- |
| Koşul Tipi | Tanımlanan tipe ait kodun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, koşul tipleri arasından seçim yapılabilir. |
| Açıklama | Tanımlanan koşul tipine ait açıklamanın girildiği alandır. |
| Önceliği | Tanımlanan koşul tipinin önceliğinin girildiği alandır. Bu bölümde tanımlanan koşul tiplerinin "Koşul Sabit Kayıtlarında" sorgulanan "Koşul Tipi" alanına girilmesi ile, hangi koşulun hangi önceliğe sahip olduğu belirlenir. |
| Birden fazla koşul olduğunda sorulsun | "Koşul Politika Tanımlamaları" bölümünde belirlenen politikaya göre (önceliği aynı olan birden fazla koşul geçerli olduğunda) fatura kayıtlarında koşul sorgulamasının yer alması için kullanılan seçenektir. |
| İşletmelerde Ortak | Tanımlanan "Koşul Tip Kayıtlarının" işletmelerde geçerli olması istendiğinde kullanılan alandır. Tüm işletmelerde geçerli olması isteniyorsa, -1 değerinin girilmesi gerekir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlanan "Koşul Tip Kayıtlarının" şubelerde geçerli olması istendiğinde kullanılan alandır. Tüm şubelerde geçerli olması isteniyorsa, -1 değerinin girilmesi gerekir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodları arasından seçim yapılır. |
| Hariç Tutulacak Şube Tanımlamaları | Tanımlaması yapılan Koşul Tip Kayıtlarının hangi şubelerde hariç tutulacağının belirtildiği alandır. "Ek Koşul Kayıtları" bölümünde bulunan politikalardan farklı olarak, belirlenen önceliklere göre tanımlama yapılması için Cari → Kayıt → Cari Parametreleri → “Koşul Politika Tanımlaması Yapılsın” parametresinin işaretlenmesi gerekir. Böylece "Koşul Kayıtları" bölümünün altına "Koşul Politika Tanımlamaları" bölümü eklenir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
