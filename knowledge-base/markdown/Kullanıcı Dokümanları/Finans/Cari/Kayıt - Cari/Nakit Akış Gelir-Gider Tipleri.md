# Nakit Akış Gelir/Gider Tipleri

Nakit Akış Gelir Gider Tipleri, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. Nakit Akış Gelir/Gider Tipleri, kullanıcı bazında firmaya özel olarak gelir/gider tiplerinin tanımlanmasını ve bu tipler için tahmini veri girişi yapılarak nakit akış raporuna dahil edilmesi için kullanılan bölümdür.

Nakit Akış Gelir Gider Tipleri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Nakit Akış Gelir/Gider Tipleri Ekranı |  |
| --- | --- |
| Kod | Tanımlanacak gelir/gider tipi için kod tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Açıklama | Gelir/Gider tipinin nakit akış raporunda gösterilecek açıklamasının girildiği alandır. |
| Gelir/Gider | Tanımlanan gelir/gider tipinin hangi hareketler için kullanılacağı bilgisi için, alanın sağ tarafında yer alan aşağı ok butonu ile "Gelir" veya "Gider" seçenekleri arasından seçim yapılır. |
| Aktif | Herhangi bir anda kullanımdan vazgeçilen ve raporlara dahil edilmek istenmeyen gelir/gider tipleri için bu seçeneğin işareti kaldırılabilir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
