# Kayıt / Cari

Cariler için Kayıt, çalışılan şirkete ait Cari Hesapların, Müşteri, Satıcı, Banka vb. kayıtlarının yapıldığı bölümdür. "Cari Modülde" sabit bilgi kayıtları oluşturulmadan, fatura, sipariş, çek, senet vb cari hesapla bağlantılı olan diğer modüllerde çalışma yapılamaz. Sabit bilgi kayıtları tamamlandıktan sonra programın fatura, kasa, çek/senet, dekont vb. modülleri cari hesaplarla entegre çalışır.
