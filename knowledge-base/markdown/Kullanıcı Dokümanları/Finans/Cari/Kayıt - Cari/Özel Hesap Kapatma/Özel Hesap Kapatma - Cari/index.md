# Özel Hesap Kapatma / Cari

Cariler için Özel Hesap Kapatma, Finans Bölümü'nde Kayıt/Cari menüsünün altında yer alır. Özel Hesap Kapatma/Cari bölümü, daha önce Özel Hesap Kapatma işlemi yapılan kayıtların yeniden düzenlenmesi/izlenmesi amacıyla kullanılan bölümdür. Özel hesap kapatma ekranından, hem başka modüllerden yapılmış olan kapatmaların izlenmesi hem de yapılan kapatma işlemlerinin iptal edilerek tekrar bu ekrandan kapatma işleminin yapılması sağlanır.

"Özel Hesap Kapatma" işleminde farklı döviz tiplerindeki hareketler birbirini kapatabilir.

Özel hesap kapatma uygulaması, "Cari Hesap Kayıtları" ekranındaki "Hesap Tipi" alanı "Özel Hesap Kapatma" olarak işaretlenen cari hesaplarda kullanılır. Bu tür cari hesaplar kullanılarak yapılan işlemlerde, henüz kapatılmamış borç ve alacak kayıtları ekrana gelir ve kayıtlarla ilgili kapatma kararı kullanıcıya bırakılır. Böylece kullanıcı, bir faturaya ait borç hareketini hangi alacak hareketi ile kapatacağını seçebilir. Özel hesap kapatma işlemine geçilmeden önce, "Cari Bilgisi" sekmesindeki alanların doldurulması gerekir.

**Borçlar/Alacaklar**

Özel Hesap Kapatma ekranının üst kısmında borç, alt kısmında alacak hareketleri yer alır. Burada hangi borç/alacak hareketi ile hangi alacak/borç hareketinin kapatılacağı seçilir. Özel Hesap Kapatma Borçlar Alacaklar ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Borçlar / Alacaklar Ekranı |  |
| --- | --- |
| Cari Kod | Özel hesap kapatması yapılacak cariye ait kod bilgisinin ve isminin izlendiği alandır. |
| ![](../../../../../../_assets/86bb575f446b6ff6f8d4.png) Yenile | Cari kodun yenilenmesi/değiştirilmesi istendiğinde, Cari Bilgiler" sekmesine dönmek için kullanılan butondur. |
| Borç No/Alacak No | Özel hesap kapatma ekranında listelenen her bir harekete program tarafından borç/alacak numarası verilir. Böylece, hangi numaraya ait kayıtların hangi numara ile kapatıldığı bilgisinin izlenmesi sağlanır. Borç No/Alacak No alanlarında, üzerinde bulunulan kaydın numarası izlenir. |
| Açıklama | İlgili hareketin, cari hareket kayıtları ekranındaki açıklamasının izlendiği alandır. |
| Açık Bakiye | Kapatma işlemi sırasında, üzerinde bulunulan hareketin tutarını gösteren alandır. Kapatma işlemi tamamlandıktan sonra da, üzerinde bulunulan hareketin ne kadar kapatılmamış açık kalmış bakiyesi varsa bu alandan izlenmesi mümkündür. |
| Proje Kodu | Eğer proje takibi yapılıyorsa ilgili cari harekete ait proje kodunun izlenebildiği alandır. |
| ![](../../../../../../_assets/e9e7e44ca1968aa7cbba.png) Kaydet | Kapatma işleminin yapılması için kullanılan butondur. |
| ![](../../../../../../_assets/3b7f9a10b6b12eb5cbcb.png) Sil | Yapılan kapatma işleminin iptal edilmesi için, ilgili cari hareketin üzerine fare ile çift tıklandıktan sonra kullanılması gereken butondur. Böylece kapatma işlemi geri alınır. |
| **![](../../../../../../_assets/4cd332c42b60e8c1b22b.png)** Vazgeç | İşlemlerden vazgeçilip mevcut ekrandan çıkılması istendiğinde kullanılması gereken butondur. |
| Borç Toplamı | İlgili cari hesaba ait borç toplamının izlendiği alandır. |
| Alacak Toplamı | İlgili cari hesaba ait alacak toplamının izlendiği alandır. |
| Bakiye | İlgili cari hesaba ait bakiye bilgisinin izlendiği alandır. |

Özel Hesap Kapatma yöntemi ile cari hareketlerin kapatılması işlemi Cari → Kayıt → Özel Hesap Kapatma menüsünden manuel yapıldığı gibi (ilgili cari hesabın hesap tipi "Özel Hesap Kapatma" ise), modüllerde yapılan işlemler bittikten sonra "Özel Hesap Kapatma" ekranı gelir ve kullanıcı kayıt anında hareketleri kapatabilir. İşlemler bittikten sonra "Özel Hesap Kapatma" ekranı gelmesi istenmediğinde, Yardımcı Programlar → Şirket/Şube/ Parametre Tanımları → "Özel Hesap Penceresi Gösterilmesin" parametresinin seçilmesi gerekir.

![](../../../../../../_assets/832dbff340ef1b956123.png)

Ekranın üst kısmında çıkan bilgiler, o anda yapılan kayda ait tutarları gösterir. Normalde yapılan kayıt tutarı tek olacağı için bir tek kayıt izlenir. Yapılan kayıt borç kaydı ise, ekranın alt bölümünde henüz tamamı kapatılmamış alacak hareketleri izlenir. Yapılan kayıt bir alacak kaydı ise, aşağıda kapatılmamış borç hareketleri izlenir. Ekranın üst kısmında izlenen satırların birden fazla olması iki koşulda mümkündür. Bunlardan biri, firma genelinde "Proje Uygulamasının" kullanılıyor olması. Bu durumda özel hesap kapatma ekranından yapılan kayda ait farklı proje kodları kullanılmışsa, kayıtlar proje kodu kırılımında gelir.

**Örneğin:** Kaydedilen bir alış faturasında, kalem kayıtları kaydedilirken farklı proje koduyla işlem yapılmışsa, özel hesap kapatma ekranının üst kısmında proje kodları bazında kümüle edilmiş tutarlar izlenir. Eğer Cari → Kayıt → [Parametre Kayıtları](<../../../../../Genel/Sene Sonu Devir/Kayıt - Sene Sonu Devir/Denetim Listeleri - Sene Sonu Devir/Parametre Kayıtları.md>) → "Özel Hesapta Proje Kodu Kontrol Edilsin" parametresi işaretlenmişse, farklı proje koduna sahip kayıtlar birbiriyle kapatılamaz. Kapatılmak istendiğinde "Seçilen Kayıtlar Uyumsuz" şeklinde uyarı ekrana gelir. Proje uygulaması kullanıldığı halde Cari → Kayıt → [Parametre Kayıtları](<../../../../../Genel/Sene Sonu Devir/Kayıt - Sene Sonu Devir/Denetim Listeleri - Sene Sonu Devir/Parametre Kayıtları.md>) → "Özel Hesapta Proje Kodu Kontrolü" işaretlenmemişse, özel hesap kapatma ekranında proje kodu bazında yine detay izlenir ve proje kodları farklı kayıtlar birbiriyle kapatılabilir. Özel Hesap Kapatma ekranı ile cari hesaba ait kayıtlar vadelere bölünerek aktarılsa bile, özel hesap kapatma yapabilir.
