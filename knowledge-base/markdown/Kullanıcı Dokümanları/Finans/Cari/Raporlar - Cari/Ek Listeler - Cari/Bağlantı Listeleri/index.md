# Bağlantı Listeleri

Finans Bölümü'nde, "Raporlar/Cari" menüsünün altında yer alır. Bağlantı Listeleri, Cari → Kayıt → "Bağlantı Sipariş Kayıtları" bölümünden kaydedilen işlemlerle ilgili rapor alınmasını sağlayan bölümdür.
