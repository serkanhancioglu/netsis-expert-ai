# Dövizli Listeler

Dövizli Listeler, Finans Bölümü'nde Raporlar/Cari menüsünün altında yer alır. Bu bölümün menüde yer alması için; Yardımcı Programlar → Kayıt → Şirket - Şube Parametre Tanımları → “Döviz Uygulaması Var” parametresinin işaretlenmesi gerekir. Böylece, dövizli takip edilen cari hesaplar ile ilgili listeler alınabilir.
