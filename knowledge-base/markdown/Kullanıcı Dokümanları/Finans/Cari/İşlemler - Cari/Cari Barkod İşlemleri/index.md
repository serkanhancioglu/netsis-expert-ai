# Cari Barkod İşlemleri

Cari Barkod İşlemleri, Finans Bölümü'nde İşlemler/Cari menüsünün altında yer alır. Cari hesaplar için barkod tanımlandığı durumlarda, cari hesaba ait barkod basımının barkod yazıcısından yapılmasını sağlayan bölümdür. Bu bölümde barkod yazıcısından basım için dizayn yapılabilir.

Barkod işlemleri ile ilgili detaylı bilgi için; Stok → İşlemler → Stokbar İşlemleri → Barkod Dizayn.
