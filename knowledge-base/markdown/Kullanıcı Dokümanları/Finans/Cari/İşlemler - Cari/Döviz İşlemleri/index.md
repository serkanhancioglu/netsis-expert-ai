# Döviz İşlemleri

Döviz İşlemleri, Finans Bölümü'nde İşlemler/Cari menüsünün altında yer alır. "Cari Hesap Kayıtları" bölümünde "Döviz Uygulaması" kullanıldığında, dövizle ilgili işlemlerin yapılmasında kullanılan bölümdür.
