# Ödeme Emri Akıbetleri

Ödeme Emri Akıbetleri işlemi, Finans Bölümü'nde İşlemler/Cari menüsünün altında yer alır. Ödeme emirleri, Toplu Ödeme Sistemi (TÖS) öncesinde bankaya iletildikten sonra herhangi bir akıbet bilgisi sorgulanmadan, sistemdeki "Ödeme Emri Entegrasyonu" bölümünden entegre edilir. TÖS, firmaların bankaya göndermiş olduğu ödeme talimatlarının akıbetlerinin sorgulanmasını sağlar.

Ödeme Emri Akıbetleri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ödeme Emri Akıbetleri Ekranı |  |
| --- | --- |
| Hesap No | Ödeme emri akıbetini görüntülemek için banka hesap kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, banka hesap kodları arasından seçim yapılır. |
| Banka Hesap | "Hesap No" alanında seçilen bankanın hesap numarasının izlendiği alandır. |
| Banka | "Hesap No" alanında seçilen banka hesabına ait banka bilgisinin otomatik olarak aktarıldığı alandır. |
| Dosya Adı | Seçilen dosya adının izlendiği alandır. |
| Dosya Seç | Bankadan alınan akıbet dosyasının seçilmesi için kullanılan butondur. |
| Desen Kodu | Bu alanda seçilen dosya, Finans → Banka → İşlemler → Dosya Desen Oluşturma bölümü ile oluşturulan akıbet dosya deseni ise, ilgili desen kodu girilir ve görüntüleme işlemi bu desen bilgilerine göre yapılır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, dosya desen kodları arasından seçim yapılır. Bazı bankaların kendilerine ait dosya desenleri olduğu için bu alan pasif hale gelir. Örneğin: Banka olarak Vakıfbank seçildiğinde "Desen Kodu" alanı pasif haldedir. |
| Görüntüle | Dosya Seç butonu ile dosya seçimi yapıldıktan sonra Görüntüle butonuna tıklandığında, dosya içeriği incelenerek, ilgili ödeme emirlerinin banka tarafında gördüğü işlem sonuçları görüntülenir. Görüntülenen dosya ile programda uyuşmazlık çıkarsa veya seçilen dosyada hatalar varsa, "TÖS Dosya Kontrol Sonuçları" ekranı açılır. Burada ilgili kayıtlar incelenip dosyada gerekli düzenlemeler yapılabilir. ![](../../../../../_assets/24a8d0b6d7c576e1afca.png) |
| Entegrasyon | Görüntüleme sonuç durumu ödeme yapılmış veya başarılı olan kayıtlar entegrasyona aktarılması için kullanılan butondur. |
