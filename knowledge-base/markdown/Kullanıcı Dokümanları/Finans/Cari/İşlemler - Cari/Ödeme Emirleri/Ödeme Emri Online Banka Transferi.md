# Ödeme Emri Online Banka Transferi

Ödeme Emri Online Banka Transferi işlemi, Finans Bölümü'nde İşlemler/Cari menüsünün altında yer alır. Ödeme Emri Online Banka Transferi; Hesap Seçimi, Ödeme Emri Gönder ve Ödeme Emri Sorgula olmak üzere üç sekmeden oluşur.

**Hesap Seçimi**

Ödeme Emri Online Banka Transferi ekranı Hesap Seçimi sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ödeme Emirleri Online Bankacılık Ekranı |  |
| --- | --- |
| Hesap Kodu | Ödeme emri için banka hesap kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| İşlemlere Geç | Banka hesap kodu seçildikten sonra online bankacılık işlemlerine geçmek için kullanılan butondur. |

**Ödeme Emri Gönder**

Ödeme Emri Online Banka Transferi ekranı Ödeme Emri Gönder sekmesi sayesinde, "Ödeme Emri Oluşturma" ile oluşturulan ödemeler online olarak bankaya gönderilir. Banka tanımlamalarının doğru olarak yapılması önemlidir.

| Ödeme Emirleri Online Bankacılık Ekranı |  |
| --- | --- |
| Ödeme Emri Yükle | Sistemde kayıtlı olan ödeme emirlerinin, çalışılan bankaya gönderilecek XML dosyasında görüntülenmesini sağlayan butondur. ![](../../../../../_assets/f770ebe790878b3a649f.png) |
| Online İşlem Başlat | Ödeme emirlerinin bankaya gönderilmesi için kullanılan butondur. |
| Cevap Dosyası Alanı | Ödeme Emirleri online olarak gönderildiğinde, gelen cevabın izlendiği alandır. Böylece, gönderilen ödeme emrinde herhangi bir yanlışlık/eksiklik durumu ile ilgili bilgi edinilir. |
| Cevap İçerik Değiştir | Cevap dosyasının tipinin XML ya da TXT olarak belirlenmesini sağlayan butondur. |
| Sakla | Gönderilen XML/Cevap dosyasının kaydedilmesini sağlayan butondur. "Ödeme Emirleri Online Bankacılık" işlemini gerçekleştirmek için, "Banka Modülünde" bazı düzenlemelerin yapılması gerekir. Banka modülünde yapılması gereken tanımlamalar ile ilgili detay bilgi için; Banka → Kayıt → T.C.M.B Kayıtları → [Online Bankacılık İşlem Seçimi](<../../../Banka/Kayıt - Banka/TCMB Kayıtları/Online Bankacılık İşlem Seçimi.md>) |

**Ödeme Emri Sorgula**

Ödeme Emri Online Banka Transferi ekranı Ödeme Emri Sorgula sekmesi ödeme emirlerinin sonuçlarının izlendiği ve entegrasyon kayıtlarının yapıldığı sekmedir.

| Ödeme Emirleri Online Bankacılık Ekranı |  |
| --- | --- |
| Tarih1 | Programdaki tarihin otomatik olarak aktarıldığı alandır. |
| Hesap No | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait tanımlanmış kod bilgisinin otomatik olarak aktarıldığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, banka hesapları incelenebilir. |
| Banka Hesap | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait numara bilgisinin otomatik olarak aktarıldığı alandır. |
| Banka | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait banka bilgisinin otomatik olarak aktarıldığı alandır. |
| Şube | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait şube bilgisinin otomatik olarak aktarıldığı alandır. |
| IBAN | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait IBAN bilgisinin otomatik olarak aktarıldığı alandır. |
| Online Getir | Bankaya gönderilen ödeme emirlerinin durumunu online sorgulamak için kullanılan butondur. Belirtilen tarih aralığındaki ödemelerin, bankadan gelen ödeme durumlarının izlenmesini sağlar. Ödeme durumları; ödendi, beklemede ve red (kırmızı renk ile belirtilir) durum açıklamaları ile gösterilir. **Örneğin:** Durumu beklemede olan, bankaya ulaşmış ancak bankadan henüz cari hesabın bankasına (alacaklı bankaya) ulaşmamış durumdaki işlemler bu bölümden izlenebilir. |
| Sistemdeki Ödeme Emirleri |  |
| Cari Kodu | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait ödeme emri yapılan cari kodun izlendiği alandır. |
| Cari İsim | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait ödeme emri yapılan cari ismin izlendiği alandır. |
| Fatura Numarası | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait ödeme emri yapılan fatura numarasının izlendiği alandır. |
| Havale Tutarı | "Hesap Seçimi" sekmesinde belirlenen banka hesabına ait ödeme emri yapılan havale tutarının izlendiği alandır. |
| Gönderildi | Grid ekranındaki listeden ödeme emri durumları izlenir. Sağ klik tuşu ile çift tıklanarak seçilen ödeme emrine ait bilgiler (cari kod, fatura numarası, havale tutarı), ekranda yer alan "Sistemdeki Ödeme Emirleri" bölümünden izlenir. Seçilen kayda ait ödeme emri gönderilmişse, "Gönderildi" kutucuğu seçili olarak ekranda görüntülenir. |
| Entegre Edilmiş Ödemeleri Sil | Verilen tarih aralığında gerçekleşmiş ödemelerin silinmesi için kullanılan butondur. |
| Onaylanmamış Ödemeleri Sil | Onaylanmamış ödemelerin silinmesi için kullanılan butondur. Onaylanmamış ödemelerin (reddedilen ödemeler) bir sonraki aktarımda soruna neden olmaması için silinmesi gerekir. Silme işleminden önce istenirse, Rapor → Raporlar → [Serbest Rapor](<../../../../Genel/Rapor/Serbest Rapor.md>) → BNKODEEMIR view seçilerek rapor alınabilir. ![](../../../../../_assets/0d70800ad174551c054f.png) |
| Ödeme Emri Entegrasyonu | Uygun olan tüm ödemelerin "Ödeme Emirleri Entegrasyonu" işlemindeki altyapı kullanılarak sisteme aktarılmasını sağlayan butondur. |
