# Özel Kayıt

Özel Kayıt işlemi, Finans Bölümü'nde İşlemler/Cari menüsünün altında yer alır. Özel Kayıt, iki ayrı cari koda aynı anda hızlı hareket girişi yapılmasını sağlar. 1.Hareket ve 2.Hareket alanlarının altında yer alan "Cari Kod" alanına girilen cari kayıtlara, fiş numaraları farklı olan, Tarih, Vade Tarihi, Açıklama, Plasiyer Kodu, Borç/Alacak Tutarı ve Miktarları aynı olan birer hareket işlenir. Özel Kayıt ile seçime göre, cari hesaplardan birine borç diğerine ise alacak hareketi aktarılır.

Cari Özel Kayıt ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Cari Özel Kayıt Ekranı | 1.Hareket |
| --- | --- |
| Cari Kod | Hızlı hareket girişi yapılması istenen ilk cariye ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile kodlar arasından seçim yapılır. |
| Fiş No | Harekete ait fiş numarasının girildiği alandır. |
| Tarih | Tarih bilgisinin girildiği alandır. |
| Vade Tarihi | Harekete ait vade tarihi bilgisinin girildiği alandır. |
| Açıklama | Özel kaydı oluşturulacak cariye ait açıklama bilgisinin girildiği alandır. |
| Döviz/TL | Döviz tipinin seçildiği alandır. |
| Döviz Tutar | İşlemin dövizli olması halinde, döviz tutarını girmek için kullanılan alandır. |
| Tutar | İşlem tutarının girildiği alandır. "Döviz/TL" alanında "Döviz" seçeneği işaretlenmişse, "Tutar" alanına tıklandığında kur bilgisinin girileceği bir ekran görüntülenir. Kur ve döviz bilgisi girişi yapıldıktan sonra, işleme ait döviz tutarı ile girilen kur değeri çarpılarak bulunan değer, "Tutar" alanına otomatik olarak aktarılır. |
| Borç/Alacak | 1.Hareket için girilen cari koda ait "Borç/Alacak" hareketinin belirlendiği alandır. |
| Miktar | Miktar bilgisinin izlendiği alandır. |
| Plasiyer Kodu | Girilen cari kod ile ilgili, yapılan işleme ait plasiyer kodu bilgisinin girildiği alandır. |
