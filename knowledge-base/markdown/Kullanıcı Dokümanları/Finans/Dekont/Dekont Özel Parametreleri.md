# Dekont Özel Parametreleri

Dekont özel parametrelerinin tanımlanması için "[Özel Parametre Tanımlamaları](<../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Özel Parametre Tanımları.md>)" ekranı kullanılır.

İrsaliye Birleştikten Sonra Eski İrsaliye Hareketlerinin Silinmesinin Sağlanması için kullanılan özel parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | DEKONT |
| Anahtar | BIRIRSCAHARSIL |

Portföydeki Senet-Çek Karşılıksız İşleminin Sağlanması için kullanılan özel parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | DEKONT |
| Anahtar | DOVIZEKRAN |
