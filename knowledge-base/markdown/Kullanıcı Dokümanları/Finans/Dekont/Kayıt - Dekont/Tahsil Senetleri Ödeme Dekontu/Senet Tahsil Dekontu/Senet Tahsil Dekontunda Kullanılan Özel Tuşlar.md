# Senet Tahsil Dekontunda Kullanılan Özel Tuşlar

"Senet Tahsil Dekontu" ekranında kullanılan yardımcı tuşlar, ekran üzerinde iken farenin sağ tuşu ile ekrana gelir.

![](../../../../../../_assets/6810bd9ff4d81718e657.png)

Senet Tahsil Dekontu Özel Tuşları menüsündeki alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Senet Tahsil Dekontu Özel Tuşları |  |
| --- | --- |
| Senet Detayı Görme | Senedin alış bilgileri ve güncel durumu ile ilgili detaylı bilgi verilmesini sağlayan seçenektir. ![](../../../../../../_assets/84346c40e53d628e946f.png) |
| Tarihsel Senet/Çek Hareketleri İzleme | Müşteri senetlerinin, portföye alındığı günden itibaren gördüğü hareketlerin (satıcıya ciro edilmesi, tahsil veya teminata verilmesi, ödenmesi, karşılıksız çıkması veya iade alınması/verilmesi) işlem tarihi sırasıyla izlenmesini sağlayan seçenektir. |
