# Toplu Senet Tahsil Dekontu İptali

Toplu Senet Dekontu İptali, Finans Bölümü'nde, "Kayıt/Dekont" menüsünün altında yer alır. Toplu Senet Tahsil Dekontu İptali, bankaya tahsile çıkan ve aynı tarihte ödenen birden fazla senedin tahsilat kaydının iptal edilmesi için kullanılan bölümdür.

![](../../../../../_assets/d945a502057e4e0fc034.png)

Toplu Senet Tahsil Dekontu İptali alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Senet Tahsil Dekontu İptali Ekranı |  |
| --- | --- |
| Vade Tarihi Aralığı | Toplu senet tahsil dekontu iptali için vade tarihi aralığı kısıdı verilen alandır. |
| İşlem Tarihi | Toplu senet tahsil dekontu iptali için baz alınacak tarihin girildiği alandır. Girilen tarih hem cari hem de entegrasyon kayıtlarında kullanılır. |
| Tutar | Toplu senet tahsil dekontu iptali için tutar kısıdı verilen alandır. |
| Döviz Tipi | İptal edilmesi istenen senetler için döviz tipi girilen alandır. Herhangi bir döviz tipi girildiğinde, iptal edilecek senetlerdeki döviz tipinin, girilen döviz tipi ile eşit olması gerekir. |
| Tahsil/Teminat Hesap Kodu | Senetlerin tahsile verildiği banka (bankalar cari hesaplarda tanımlanmışsa cari, muhasebede tanımlanmışsa muhasebe) hesap kodunun girildiği alandır. Bu alana girilen banka/cari/muhasebe kodu ile ciro edilen senetler bulunarak iptal işlemi yapılır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. Boş bırakılmaz. |
| Tüm Senetler Getirilsin | Girilen bilgiler doğrultusunda, grid ekrana tüm senetlerin getirilmesi için kullanılan seçenektir. |
| **![](../../../../../_assets/39d77b8716226638d9ce.jpg)**Tamam | Girilen koşullara uygun senetlerin, grid ekranda listelenmesi için kullanılan butondur. |
| ![](../../../../../_assets/73338e68dece433f7f5d.png) Tahsil Dekontu İptal Et | Listelenen senetler içinde iptal edilecek olanların üzerinde iken fare ile çift tıklanarak, oluşacak kayıtların ilgili modüllere aktarılması için kullanılan butondur. Butona tıklanması ile, ekrana gelen uyarı onaylanarak işlem tamamlanır. ![](../../../../../_assets/31310bb4c9c55d25469c.png) |
| ![](../../../../../_assets/ab9047f06dcf17f8b154.png) Tümünü Seç | Grid alana aktarılan tüm satırların seçilmesi için kullanılan butondur. |
| ![](../../../../../_assets/ca4e3e18d9df15206767.png) Tümünü Kaldır | Grid alanda seçilen satırların tümünün seçimini kaldırmak için kullanılan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Toplu senet tahsil iptal dekontu için girilen kaydın iptal edilmesi için kullanılan butondur. |
