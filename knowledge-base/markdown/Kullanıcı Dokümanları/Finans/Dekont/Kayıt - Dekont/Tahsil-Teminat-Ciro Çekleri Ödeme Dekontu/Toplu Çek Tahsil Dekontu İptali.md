# Toplu Çek Tahsil Dekontu İptali

Toplu Çek Tahsil Dekontu İptali, Finans Bölümü'nde, "Kayıt/Dekont" menüsünün altında yer alır. Toplu Çek Tahsil Dekontu İptali, bankaya tahsile çıkan ve aynı tarihte ödenen birden fazla çekin tahsilat kaydının iptal edilmesi için kullanılan bölümdür.

![](../../../../../_assets/2553af5a282d9e43ef0f.png)

Toplu Çek Tahsil Dekontu İptali alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Çek Tahsil Dekontu İptali Ekranı |  |
| --- | --- |
| Vade Tarihi Aralığı | Toplu çek tahsil dekontu iptali için vade tarihi aralığı kısıdı verilen alandır. |
| İşlem Tarihi | Toplu çek tahsil dekontu iptali için baz alınacak tarihin girildiği alandır. Girilen tarih hem cari hem de entegrasyon kayıtlarında kullanılır. |
| Tutar | Toplu çek tahsil dekontu iptali için tutar kısıdı verilen alandır. |
| Döviz Tipi | İptal edilmesi istenen çekler için döviz tipi girilen alandır. Herhangi bir döviz tipi girildiğinde, iptal edilecek çeklerdeki döviz tipinin, girilen döviz tipi ile eşit olması gerekir. |
| Tahsil/Teminat Hesap Kodu | Çeklerin tahsile verildiği banka (bankalar cari hesaplarda tanımlanmışsa cari, muhasebede tanımlanmışsa muhasebe) hesap kodunun girildiği alandır. Bu alana girilen banka/cari/muhasebe kodu ile ciro edilen çekler bulunarak iptal işlemi yapılır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. Boş bırakılmaz. |
| Tüm Senetler Getirilsin | Girilen bilgiler doğrultusunda, grid ekrana tüm çeklerin getirilmesi için kullanılan seçenektir. |
| Çek Seri No | İptal edilmesi istenen çekin üzerinde yer alan seri numaranın girildiği alandır. |
| **![](../../../../../_assets/39d77b8716226638d9ce.jpg)**Tamam | Girilen koşullara uygun çeklerin, grid ekranda listelenmesi için kullanılan butondur. |
| ![](../../../../../_assets/73338e68dece433f7f5d.png) Tahsil Dekontu İptal Et | Listelenen çekler içinde iptal edilecek olanların üzerinde iken fare ile çift tıklanarak, oluşacak kayıtların ilgili modüllere aktarılması için kullanılan butondur. Butona tıklanması ile, ekrana gelen uyarı onaylanarak işlem tamamlanır. ![](../../../../../_assets/31310bb4c9c55d25469c.png) |
| ![](../../../../../_assets/ab9047f06dcf17f8b154.png) Hepsini Seç | Grid alana aktarılan tüm satırların seçilmesi için kullanılan butondur. |
| ![](../../../../../_assets/ca4e3e18d9df15206767.png) Hepsini Sil | Grid alanda seçilen satırların tümünün seçimini kaldırmak için kullanılan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Toplu çek tahsil iptal dekontu için girilen kaydın iptal edilmesi için kullanılan butondur. |
