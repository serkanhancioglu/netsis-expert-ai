# Çek Tahsil Dekontunda Kullanılan Özel Tuşlar

"Çek Tahsil Dekontu" ekranında kullanılan yardımcı tuşlar, ekran üzerinde iken farenin sağ tuşu ile ekrana gelir.

![](../../../../../../_assets/45b3d23d5d8388625473.png)

Çek Tahsil Dekontunda Kullanılan Özel Tuşlar menüsünün alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Çek Tahsil Dekontu Özel Tuşları |  |
| --- | --- |
| Çek Detayı Görme | Çekin alış bilgileri ve güncel durumu ile ilgili detaylı bilgi verilmesini sağlayan seçenektir. ![](../../../../../../_assets/796382f0f469e2b4af43.png) |
| Tarihsel Senet/Çek Hareketleri İzleme | Müşteri çeklerinin, portföye alındığı günden itibaren gördüğü hareketlerin (satıcıya ciro edilmesi, tahsil veya teminata verilmesi, ödenmesi, karşılıksız çıkması veya iade alınması/verilmesi) işlem tarihi sırasıyla izlenmesini sağlayan seçenektir. ![](../../../../../../_assets/db741d637d6943b1a79e.png) |
