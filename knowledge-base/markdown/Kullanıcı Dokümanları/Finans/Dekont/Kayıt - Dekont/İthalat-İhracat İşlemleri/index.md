# İthalat/İhracat İşlemleri

İthalat/İhracat İşlemleri; ithalat/ihracat işlemlerinin sonlandırılması (kapatma işleminin gerçekleştirilmesi), ithalat/ihracat kapatma işleminin iptal edilmesi ve ithalat/ihracat işlemleri ile ilgili raporların alınması için kullanılan bölümdür.

İthalat/İhracat işlemlerinin kapatma aşamasına gelmesi için programın bazı bölümlerinden yapılacak kayıtların tamamlanması gerekir.
