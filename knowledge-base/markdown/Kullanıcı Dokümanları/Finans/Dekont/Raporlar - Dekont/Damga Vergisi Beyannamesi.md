# Damga Vergisi Beyannamesi

Damga Vergisi Beyannamesi, Finans Bölümü'nde, "Raporlar/Dekont" menüsünün altında yer alır. Damga Vergisi Beyannamesi, damga vergisi beyannamesinin basımı için kullanılan bölümdür.

![](../../../../_assets/fb99b4a962ad19285248.png)

Damga Vergisi Beyannamesi ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Damga Vergisi Beyannamesi Ekranı |  |
| --- | --- |
| Ay Kodu | Beyanname basımı yapılacak ay kodunun girildiği alandır. |
| Yıl Kodu | Beyanname basımı yapılacak yıl kodunun girildiği alandır. |
| Vergi Dairesi Adı | Beyanname basımında yer alacak vergi dairesi adının girildiği alandır. |
| İl | Beyanname basımında yer alacak ilin girildiği alandır. |
| Tahakkuk Fişi Tarihi | Beyanname için tahakkuk fişi tarihi girilen alandır. |
| Tahakkuk Fişi No | Beyanname için tahakkuk fiş numarası girilen alandır. |
| Sicil No | Beyanname için sicil no girilen alandır. |
| Adı Soyadı | Beyanname için mükellefin ad ve soyadının girildiği alandır. |
| Mesleği | Beyanname için mükellefin mesleğinin girildiği alandır. |
| İş Adresi | Beyanname için mükellefin iş adresinin girildiği alandır. |
| Vergi Dairesi | Beyanname için mükellefin vergi dairesinin girildiği alandır. |
| Gelir Ve Kurum Yönünden | Beyanname için mükellefin gelir ve kurum yönünden bağlı bulunduğu vergi dairesinin girildiği alandır. |
| ![](../../../../_assets/ec18e7b64a3ad2dcc877.png) Basım | Girilen bilgilerin onaylanması halinde basım yapılması için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
