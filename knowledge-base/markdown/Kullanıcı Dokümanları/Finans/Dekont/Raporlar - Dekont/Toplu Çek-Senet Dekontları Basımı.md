# Toplu Çek/Senet Dekontları Basımı

Toplu Çek/Senet Dekontları Basımı, Finans Bölümü'nde, "Raporlar/Dekont" menüsünün altında yer alır. Toplu Çek/Senet Dekontları Basımı, Dekont Modülünden kaydı yapılan dekontların toplu basımının yapıldığı bölümdür.

![](../../../../_assets/aec174d0a9062e380841.png)

Toplu Çek/Senet Dekontları Basımı ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Çek/Senet Dekontları Basımı Ekranı |  |
| --- | --- |
| Dekont Tipi | Basım yapılacak dekont tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile dekont tipleri arasından seçim yapılır. "Dekont Tipi" seçildikten sonra Müşteri Çekleri/Borç Çekleri/Müşteri Senetleri/Borç Senetleri seçeneği program tarafından otomatik olarak işaretlenir. **Örneğin:** "Dekont Tipi" alanında "Senet Tahsil Dekontu" seçildiği varsayıldığında, "Müşteri Senetleri" seçeneği işaretli olarak ekrana gelir. Çünkü, "Senet Tahsil" işlemi "Müşteri Senetleri" modülü ile ilgili bir dekonttur. |
| Tarih Aralığı | Toplu çek/senet dekont basımı için tarih aralığı kısıdı verilen alandır. |
| Seri Kodu | Toplu çek/senet dekont basımı için seri kodu kısıdı verilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, seri kodları arasından seçim yapılır. |
| Dekont No Aralığı | Toplu çek/senet dekont basımı için dekont numara aralığı kısıdı verilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, dekont numaraları arasından seçim yapılır. |
| Çek/Senet No | Tek bir çek ya da senet için dekont basımı yapılması istendiğinde çek/senet numarası girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, çek/senet numaraları arasından seçim yapılır. |
| Özel Basım | Basımı yapılması istenen dekont için dizayn adı sorgulanarak, "Dizayn" modülünde ilgili dekont için tanımlanan dizaynın basımı için kullanılan seçenektir. İşaretlenmediğinde, dekont için standart basım yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
