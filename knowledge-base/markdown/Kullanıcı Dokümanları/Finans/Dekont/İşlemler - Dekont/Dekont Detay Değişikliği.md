# Dekont Detay Değişikliği

Dekont Detay Değişikliği, Finans Bölümü'nde, "İşlemler/Dekont" menüsünün altında yer alır. Dekont Detay Değişikliği, kaydı yapılan dekontlara kısıt verilerek, toplu halde detay değişikliği yapılmasını sağlayan bölümdür.

![](../../../../_assets/8c7daa013d23e1b06abb.png)

Dekont Detay Değişikliği ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Dekont Detay Değişikliği Ekranı |  |
| --- | --- |
| Tarih Aralığı | Detay değişikliği yapılacak dekontlar için tarih aralığı kısıdı verilen alandır. |
| Seri Kodu | Detay değişikliği yapılacak dekontlar için seri kodu kısıdı verilen alandır. |
| Dekont No Aralığı | Detay değişikliği yapılacak dekontlar için numara aralığı kısıdı verilen alandır. |
| Borç/Alacak | Detay değişikliği yapılacak dekontlar için borç/alacak kısıdı verilen alandır. |
| Hesap Tipi | Detay değişikliği yapılacak dekontlar için hesap tipi kısıdı verilen alandır. Cari, Muhasebe, Banka, Stok ve Hepsi olmak üzere beş seçenekten oluşur. Seçim yapıldıktan sonra, klavyede yer alan \<tab\> tuşu ile ilerlendiğinde "Hesap Kodu" alanı aktif hale gelir. Yapılan seçime göre, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile ilgili hesap kodlarına tıklanarak kısıt verilir. |
| Sıralama | Detay değişikliği yapılacak dekontlar için sıralama belirlenen alandır. Seri No-Dekont No, Tarih veya Vade Tarihi seçenekleri arasından sıralama şekli seçilir. |
| Proje Kodu Aralığı | Detay değişikliği yapılacak dekontlar için proje kodu aralığı kısıdı verilen alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanması için kullanılan butondur. Butona basıldığında, verilen kısıtlara uygun dekont detay değişikliği yapılacak dekontlar listelenir. Listelenen dekontlar içinden değişiklik yapılması istenen dekont detayının üzerine gelerek fare ile çift tıklandığında; Açıklama, Plasiyer Kodu, Proje Kodu, B Formu, Cari Kod, Durum, Belge Türü, Fiş No, Valör Başlangıç Tarihi, Ödeme Türü gibi alanlara girilen bilgiler değiştirilebilir. Ekranın sol üst köşesinde bulunan Değişen Bilgileri Sakla ![](../../../../_assets/3d2f85f156d8993577ca.png) butonu ile yapılan değişikliklerin kaydedilmesi sağlanır. ![](../../../../_assets/fade2fd4987c42ab1981.png) Değişiklikleri kaydetmeden çıkmak için ekranın sağ üst köşesinde bulunan (X) simgesine tıklanır. Uyarı ekranına onay verilerek çıkış yapılır. ![](../../../../_assets/6125c65e6511ee65321d.png) |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Kısıt için girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
