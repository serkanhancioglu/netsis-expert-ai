# Dekont Numarası Düzenleme

Dekont Numarası Düzenleme, Finans Bölümü'nde, "İşlemler/Dekont" menüsünün altında yer alır. Dekont Numarası Düzenleme, farklı serilere ait dekont numaraları için başlangıç numarası girilmesini ya da kullanılan numaranın değiştirilmesini sağlayan bölümdür. Yapılan seçime göre dekont kayıtlarındaki başlangıç numaraları, "Dekont No" alanına girilen numara ile başlar.

![](../../../../_assets/54c39f858cf097059cb1.png)

Dekont Numarası Düzenleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dekont Numarası Düzenleme Ekranı |  |
| --- | --- |
| Seri Kodu | Dekont kaydı için kullanılacak seri kod bilgisi tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlı seri kodlara ulaşılır. |
| Dekont No | "Seri Kodu" alanında tanımlanan seriye ait başlangıç numarası tanımlanan alandır. |
| Son Kullanılan Dekont No | İlgili seri için son kullanılan dekont numarasının izlendiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra "Kaydet" ![](../../../../_assets/865524a70e225c89c107.jpg) butonuna basılarak kayıt oluşturulur. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
