# Dekont Silme

Dekont Silme, Finans Bölümü'nde, "İşlemler/Dekont" menüsünün altında yer alır. Dekont Silme, Dekont modülü kullanılarak kaydedilen dekont kayıtlarının silinmesini (iptal edilmesini) sağlayan bölümdür. Hatalı veya yanlış kaydedilen dekontlar için kullanılır.

![](../../../../_assets/2a202fbdbbab7b57e606.png)

Dekont Silme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dekont Silme Ekranı |  |
| --- | --- |
| Seri Kodu | Silinmesi istenen dekontun kaydı sırasında belirlenen seri kodunun girildiği alandır. Boş bırakılmaz. |
| Dekont Numarası | Silinmesi istenen dekont numarasının girildiği alandır. Boş bırakılmaz. |
| İşlem Tarihi | Seri kodu ve dekont numarası doğru girildiğinde, program ilgili kaydı bularak işlem tarihini otomatik olarak ekrana getirir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanması için kullanılan butondur. Butona basıldığında, daha önce kaydedilen kayıtlar silinir. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
