# Otomatik Ödeme Talimatları Sorgulama

Otomatik Ödeme Talimatları Sorgulama, Finans Bölümü'nde, "İşlemler/Dekont" menüsünün altında yer alır.

![](../../../../../_assets/356ab498c0f24cfb56d6.png)

Otomatik Ödeme Talimatları Sorgulama ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Otomatik Ödeme Talimatları Sorgulama Ekranı |  |
| --- | --- |
| Sorgu | Otomatik ödeme talimatı verilen ödemelerin grid ekrana aktarılması için tarih kısıdı girilen alandır. |
| Hesap No | Otomatik ödeme talimatı verilen ödemelerin grid ekrana aktarılması için hesap numarası kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap numaraları arasından seçim yapılır. |
| Banka Hesap | "Hesap No" alanına girilen banka isminin otomatik olarak aktarıldığı alandır. |
| Banka | "Hesap No" alanına girilen bankaya ait kod bilgisinin otomatik olarak aktarıldığı alandır. |
| Şube | "Hesap No" alanına girilen bankaya ait şube kodu bilgisinin otomatik olarak aktarıldığı alandır. |
| Online Getir | Sisteme tanıtılan ödeme talimatları doğrultusunda, bankada ödenmeyi bekleyen veya ödemesi yapılan talimatların grid ekranda listelenmesi için kullanılan butondur. Böylece, normal ödeme talimatları için durumu "Ödendi" ve ön ödemeliler için durumu "Ödenmedi" olan kayıtlar arasından istenenler grid alan üzerinde iken fare ile çift tıklanarak seçilir. |
| Entegrasyon | Grid ekranda listelenen talimatlar arasında seçim yapıldıktan sonra, sisteme entegre edilmesi için kullanılan butondur. Entegre edilen kayıtlar, "Bankadan Gelen Otomatik Ödeme Talimatları" alanından silinerek "Sistemdeki Otomatik Ödemeler" alanından izlenir. Ön ödemeli kayıtlar entegre edildiğinde, bu kayıtların sistemdeki durumu “ilk ödeme yapıldı” olarak değişir. |

Online Gelen (XML) kısmında, bankadan XML paketleri halinde gelen ödeme talimatları ile ilgili bilgiler XML formatında izlenebilir.
