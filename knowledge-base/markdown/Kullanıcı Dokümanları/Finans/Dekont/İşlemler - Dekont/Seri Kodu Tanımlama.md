# Seri Kodu Tanımlama

Seri Kodu Tanımlama, Finans Bölümü'nde "İşlemler/Dekont" menüsünün altında yer alır. Dekont modülündeki hiçbir dekont kaydı seri kodu olmadan kaydedilmez. Farklı dekont kayıtlarını birbirinden ayırmak için seri kodlarından yararlanılır.

![](../../../../_assets/012fa1d0b20604eacaba.png)

Seri Kodu Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Seri Kodu Tanımlama Ekranı |  |
| --- | --- |
| Seri Kodu | En fazla 2 karakter uzunluğunda kod tanımlaması yapılan alandır. |
| Açıklama | Tanımlanan seri koduna ait açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra "Kaydet" ![](../../../../_assets/865524a70e225c89c107.jpg) butonuna basılarak kayıt oluşturulur. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
