# Toplu Dekont Silme

Toplu Dekont Silme, Finans Bölümü'nde, "İşlemler/Dekont" menüsünün altında yer alır. Toplu Dekont Silme, Dekont modülü kullanılarak kaydedilen dekont kayıtlarının toplu halde silinmesini (iptal edilmesini) sağlayan bölümdür. Girilen seri kodu, dekont no aralığı ve tarih aralığı içindeki tüm dekontlar silinir.

![](../../../../_assets/e5e0695649a83fbb2c25.png)

Toplu Dekont Silme ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Dekont Silme Ekranı |  |
| --- | --- |
| Seri Kodu | Toplu dekont silme için seri kodu kısıdı verilen alandır. |
| Dekont No Aralığı | Toplu dekont silme için numara aralığı kısıdı verilen alandır. |
| Tarih Aralığı | Toplu dekont silme için tarih aralığı kısıdı verilen alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanması için kullanılan butondur. Butona basılması ile, verilen kısıtlara uygun tüm dekontlar silinir. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
