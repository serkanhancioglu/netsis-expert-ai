# Hızlı Kasa - Banka Kayıtları

Merkez şubeden, içinde bulunulan şubeye ve diğer şubelere Kasa/Banka kaydı yapılmasını sağlayan bölümdür. Hızlı Kasa-Banka Kayıtları, Finans Bölümü'nde, "Kayıt/Kasa" menüsünün altında yer alır. "Tarih ve Tip Belirleme" ekranındaki alanlar cevaplandıktan sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak Hızlı Kasa - Banka Kayıtları Gelir/Gider tipli kayıt ekranına geçilir.

"Hızlı Kasa - Banka Kayıtları" ekranı, Banka → Kayıt → Banka Genel Parametreleri → Banka Entegre parametresinin işaretlenmesi ile Kasa → Kayıt menüsünde yer alır.

![](../../../../_assets/61b27a9920faa9b68eb0.png)

![](../../../../_assets/578e7f95375f6e23ecc2.png)

Hızlı Kasa-Banka Kayıtları ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Hızlı Kasa - Banka Kayıtları Gelir/Gider Tipli Kayıt Ekranı |  |
| --- | --- |
| Şube Kodu | İşlem yapılacak şube kodunun rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçildiği alandır. |
| Kasa Kodu | İşlem yapılacak kasa kodunun rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçildiği alandır. |
| Toplam Gelir | Seçilen kasanın toplam gelirinin izlendiği alandır. |
| Toplam Gider | Seçilen kasanın toplam giderinin izlendiği alandır. |
| Devreden | Seçilen kasanın devreden tutarının izlendiği alandır. |
| Banka Hesap Kodu | Hızlı Kasa-Banka kaydı yapılacak banka hesap kodunun girildiği alandır. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla hesap kodları arasından seçim yapılabilir. |
| Banka Ana Kodu/Banka Şube Kodu/Banka Hesap No | "Banka Hesap Kodu" ilgili alana girildiğinde, Banka Ana Kodu, Banka Şube Kodu ve Banka Hesap Numarası program tarafından otomatik olarak ekrana getirilir. |
| Fiş No | Yapılacak Hızlı Kasa-Banka kaydıyla ilgili fiş numarasının girildiği alandır. |
| Döviz Tutarı | Dövizli takip edilen banka hesapları ve kasalarda döviz tutarının girildiği alandır. Banka hesabının sabit kayıtlarında döviz tipi tanımlı ise, banka hesabı için oluşturulan kayıtların da aynı döviz birimi ile girilmesi gerekir. |
| Tutar | Hızlı Kasa-Banka kaydı yapılacak tutar bilgisinin girildiği alandır. |
| Kasa Açıklaması | Kasa hareketlerine aktarılacak açıklamanın izlendiği alandır. Kullanıcı, bu alana otomatik aktarılan açıklama üzerinde değişiklik yapabilir. |
| Banka Açıklaması | Banka hareketlerine aktarılacak açıklamanın izlendiği alandır. Kullanıcı, bu alana otomatik aktarılan açıklama üzerinde değişiklik yapabilir. |
| Efektif Tarihi | Kayıt ile ilgili efektif tarihin girildiği alandır. Bu alana yazılan tarih, banka hareket kayıtlarındaki efektif tarih alanında izlenebilir. |
| Plasiyer Kodu | Tanımlanan plasiyer kodları arasından,![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu ile seçim yapılarak, ilgili müşteriye ait plasiyer kodunun girildiği alandır. Ekrana bu alanın eklenmesi için, [Yardımcı Programlar](<../../../Genel/Yardımcı Programlar/index.md>) → Kayıt → Şirket/Şube Parametre Tanımları → "Plasiyer Uygulaması Var" parametresinin işaretli olması gerekir. |
| Proje Kodu | Tanımlanan plasiyer kodları arasından,![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu ile seçim yapılarak, ilgili müşteriye ait plasiyer kodunun girildiği alandır. Ekrana bu alanın eklenmesi için, [Yardımcı Programlar](<../../../Genel/Yardımcı Programlar/index.md>) → Kayıt → Şirket/Şube Parametre Tanımları → "Proje Uygulaması Var" parametresinin işaretli olması gerekir. |
| Yevmiye Açıklaması | Kayıt yapılırken bu alana standart açıklama program tarafından otomatik olarak aktarılır. İstendiğinde kullanıcı tarafından değişiklik yapılabilir. Girilen açıklama, "Muhasebe Modülünde" yevmiye fiş kayıtlarında yer alan "Açıklama - 1" alanından izlenebilir. |
| ![](../../../../_assets/79cc58589ff168df2cf7.png) Kasa Kayıtlarını Oluştur | İlgili alanlara bilgi girişi yapıldıktan sonra alt ekrana aktarılan işlem/işlemlerin kasa kayıtlarını oluşturmak için kullanılan butondur. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
