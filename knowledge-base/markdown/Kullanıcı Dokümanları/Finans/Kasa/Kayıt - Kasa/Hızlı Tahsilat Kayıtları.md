# Hızlı Tahsilat Kayıtları

Kasa kayıtları, Finans Bölümü'nde, "Kayıt/Kasa" menüsünün altında yer alır. Hızlı Tahsilat Kayıtları, cari hesap tahsilat ve ödeme işlemlerinin yapıldığı bölümdür.

![](../../../../_assets/b12ff6e0a2d503080e38.png)

Hızlı Tahsilat Kayıtları sekmesinin alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Hızlı Tahsilat Kayıtları Ekranı |  |
| --- | --- |
| Belge No | Tahsilat işlemine ait belge numarasının rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak girildiği alandır. |
| Cari Kodu | Tahsilat işlemi yapılacak cari kodun rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak girildiği alandır. |
| Hesap Bakiyesi | İşlem yapılan cari hesaba ait bakiye bilgisinin izlendiği alandır. |
| İşlem Tarihi | Kasa tarihinden farklı bir işlem tarihinin girilmesini sağlayan alandır. |
| Tahsilat Şekli | Tahsilat şeklinin rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile sözleşme rehberinden seçim yapılarak girildiği alandır. |
| Taksit Sayısı | Tahsilat işlemine ait taksit sayısının girildiği alandır. |
| Döviz Tipi | Tahsilat işlemine ait döviz tipinin rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçilerek girildiği alandır. Dövizli çalışan cari girildiğinde aktif hale gelir. |
| Döviz Tutarı | Tahsilat işlemine ait döviz tutarının girildiği alandır. Döviz tipi seçildiğinde aktif hale gelir. |
| Kur | Döviz Takibi/Günlük Kur Girişi Bölümü’nden girilen kur tutarı, Kur alanına yansır. İsteğe göre değişiklik yapılabilir. Döviz tipi seçildiğinde aktif hale gelir. |
| Tutar | Kur tutarı ile döviz fiyatı alanındaki değerlerin çarpımı sonucu çıkan rakam, tutar alanına yansır. |
| Kart Numarası | Tahsilatın yapıldığı karta ait numaranın girildiği alandır. |
| Cari Rapor Kodu | Cari hesap ödeme ve tahsilat işlemlerini özel kriterlere göre raporlamak için kullanılan kodlama alanıdır. |
| Cari Rapor Kodu 2 | Cari hesap ödeme ve tahsilat işlemlerini özel kriterlere göre raporlamak için kullanılan ikinci bir kodlama alanıdır. |
| Proje Kodu | Tahsilatın proje bazında izlenmesini sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile proje kodları arasından seçim yapılır. |
| Plasiyer Kodu | Tanımlanan plasiyer kodları arasından, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak, ilgili tahsilata ait plasiyer kodunun girildiği alandır. |
| Referans Kodu | Tanımlanan referans kodları arasından, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak, ilgili tahsilata ait referans kodunun girildiği alandır. |
| Basım Yap | İlgili tahsilat için “Dizayn Modülünde” hazırlanan bir ayara göre basım yapılması amacıyla kullanılan seçenektir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Tahsilata ait işlemin kaydedilmesini sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi durumunda ekrandan çıkmak için kullanılan butondur. |
