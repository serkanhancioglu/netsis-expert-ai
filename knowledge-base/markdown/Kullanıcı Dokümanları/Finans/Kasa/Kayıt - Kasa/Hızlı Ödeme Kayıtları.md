# Hızlı Ödeme Kayıtları

Hızlı Ödeme Kayıtları, Finans Bölümü'nde, "Kayıt/Kasa" menüsünün altında yer alır. "Kasa Belirleme" ekranındaki alanlar cevaplandıktan sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak Kasa Ödeme Kayıtları ekranına geçilir.

Hızlı Ödeme Kayıtları, tanımlanan firma kredi kartları veya nakit olarak kendi ödeme kayıtlarının girilmesini sağlayan bölümdür. Taksit sayısı ve tutar bilgilerini kullanıcının girmesi gerekmekte, Kart Numarası alanına rehberde seçilen firma kredi kartının numarasını getirebiliriz.

Hızlı Ödeme Kayıtları ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Hızlı Ödeme Kayıtları Ekranı |  |
| --- | --- |
| Belge No | Ödeme işlemine ait belge numarasının rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak girildiği alandır. |
| Cari Kodu | Ödeme işlemi yapılacak cari kodun rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak girildiği alandır. |
| Hesap Bakiyesi | İşlem yapılan cari hesaba ait bakiye bilgisinin izlendiği alandır. |
| İşlem Tarihi | Kasa tarihinden farklı bir işlem tarihinin girilmesini sağlayan alandır. |
| Ödeme | Ödeme şeklinin rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile firma kredi kartı kodları arasından seçim yapılarak girildiği alandır. |
| Taksit Sayısı | Ödeme işlemine ait taksit sayısının girildiği alandır. |
| Döviz Tipi | Ödeme işlemine ait döviz tipinin rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçilerek girildiği alandır. Dövizli çalışan cari girildiğinde aktif hale gelir. |
| Döviz Tutarı | Ödeme işlemine ait döviz tutarının girildiği alandır. Döviz tipi seçildiğinde aktif hale gelir. |
| Kur | Döviz Takibi/Günlük Kur Girişi Bölümü’nden girilen kur tutarı, **Kur** alanına yansır. İsteğe göre değişiklik yapılabilir. Döviz tipi seçildiğinde aktif hale gelir. |
| Tutar | Kur tutarı ile döviz fiyatı alanındaki değerlerin çarpımı sonucu çıkan rakam, tutar alanına yansır. |
| Kart Numarası | Ödemenin yapıldığı karta ait numaranın girildiği alandır. |
| Cari Rapor Kodu | Cari hesap ödeme işlemlerini özel kriterlere göre raporlamak için kullanılan kodlama alanıdır. |
| Cari Rapor Kodu 2 | Cari hesap ödeme işlemlerini özel kriterlere göre raporlamak için kullanılan ikinci bir kodlama alanıdır. |
| Proje Kodu | Tahsilatın proje bazında izlenmesini sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile proje kodları arasından seçim yapılır. |
| Plasiyer Kodu | Tanımlanan plasiyer kodları arasından, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak, ilgili ödemeye ait plasiyer kodunun girildiği alandır. |
| Referans Kodu | Tanımlanan referans kodları arasından, rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile seçim yapılarak, ilgili ödemeye ait referans kodunun girildiği alandır. |
| Basım Yap | İlgili ödeme için “Dizayn Modülünde” hazırlanan bir ayara göre basım yapılması amacıyla kullanılan seçenektir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Ödemeye ait işlemin kaydedilmesini sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi durumunda ekrandan çıkmak için kullanılan butondur. |
