# Kasa

Kasa Modülü nakit işlemlerin takibinin yapılmasını ve raporlanmasını sağlar. Kapalı fatura işlemleri haricinde, işletmeyi ilgilendiren tüm nakit hareketleri Kasa bölümden yapılır. Kasa Modülü ile ilgili işlemlere başlamadan önce, takip edilecek kasalara ait tanımlamaların yapılması gerekir. Kasalar tanımlandıktan sonra ilgili kayıt işlemlerine geçilir.
