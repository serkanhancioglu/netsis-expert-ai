# Kasa Tarihi / Kodu Değiştirme

Kasa Tarihi/Kodu Değiştirme, Finans Bölümü'nde, "İşlemler/Kasa" menüsünün altındaki "Ek İşlemler" bölümünde yer alır. Kaydedilecek kayıtların hangi kasa koduna ve hangi tarihe ait olduğu "Kasa Modülüne" girişte belirlenir. Sadece "Kasa Belirleme" ekranından girilen bilgilere ait kayıtlar oluşturulduktan sonra, diğer bir kasanın veya diğer bir günün kayıtlarını oluşturmak için Kasa Tarihi/Kodu değişikliği ekranı kullanılır.

![](../../../../../_assets/f382f52449c91b115958.png)

Kasa Belirleme ekranının alanları ve içerdiği bilgiler aşağıdaki şekildedir:

| Kasa Belirleme Ekranı |  |
| --- | --- |
| Kasa Kodu | İşlem yapılması istenen kasa kodunun belirlendiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile kasa kodları arasından seçim yapılabilir. |
| Tarih | İşlem yapılması istenen tarihin girildiği alandır. |
| Son Devir Tarihi | Son devir tarihinin izlendiği alandır. |
| Son Devir Tutarı | Devir tarihindeki bakiye tutarının izlendiği alandır. |
| Son Döviz Devir Tutarı | Devir tarihindeki dövizli bakiye tutarının izlendiği alandır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Kasa Tarihi/Kodu değişikliğine ait işlemin kaydedilmesini sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi durumunda ekrandan çıkmak için kullanılan butondur. |
