# Avukat Senet İşlemleri

Avukat Senet İşlemleri bölümü, "Karşılıksız" kaydı olan senetleri avukata göndermek veya avukattaki senetleri portföye/tahsile geri göndermek için kullanılan bölümdür.

Avukat Senet İşlemleri ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Avukat Çek İşlemleri Ekranı |  |
| --- | --- |
| İşlem Tipi | Yapılması istenen işlem tipinin seçildiği alandır. İşlem Tipi alanının sağ tarafında yer alan aşağı ok butonu ile; Avukata Gönder, Avukattan Portföye Gönder ve Avukattan Tahsile Gönder seçenekleri arasından seçim yapılır. |
| Kayıtlar Getir | Karşılıksız kaydı girilmiş ve hali hazırda avukata gönderilecek durumda olan senetlerin listelenmesi için kullanılan butondur. |
| Tümünü Seç | Grid ekranda listelenen kayıtların hepsinin seçilmesi için kullanılan butondur. |
| Tümünü Kaldır | Grid ekranda listelenen kayıtlar arasından seçimi yapılan kayıtların hepsinin seçiminin kaldırılmasını sağlayan butondur. |
| Belge Detayı | Grid ekrandan seçilen kaydın belge detayının görüntülenmesini sağlayan butondur. Devir Senet Girişi ekranı açılarak ilgili çekin izlenmesini sağlar. |
| Hareket Detayı | Grid ekrandan seçilen kaydın geçmiş tarihlerdeki hareketlerinin izlenmesini sağlayan butondur. |
| Gönder | Grid ekrandan seçilen kaydın avukata gönderilmesi için kullanılan butondur. Butona tıklandığında ekrana gelen İşlem Tarihi alanına tarih bilgisi girilerek ve ilgili avukat seçilerek "Tamam" butonuna tıklandığında, gönderme işlemi gerçekleşir. |
