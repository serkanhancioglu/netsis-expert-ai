# Senet Tahsil

Senet Tahsil, Finans Bölümü'nde, "Kayıt/Müşteri Senetleri" menüsünün altında yer alır. Senet Tahsil, "Senet Tanzim" bölümünden veya diğer bölümlerden kaydedilen senetlerin tahsilat kayıtlarının girildiği bölümdür.

![](../../../../../_assets/6e3fe9e329d47687ab50.png)

Senet Tahsil İşlemleri ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Senet Tahsil İşlemleri Ekranı |  |
| --- | --- |
| Cari Kodu | Senet tahsilatı yapılacak cari hesaba ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| R.Kod (Rapor Kodu) | Kaydedilen senetlerin, raporlamaya yönelik bir kod altında toplanması için, 1 karakter uzunluğunda isteğe göre kayıt oluşturulmasını sağlayan alandır. **Örneğin;** normal belirlenen senetlerin rapor kodu için (N), devir senetlerinin rapor kodu için (D) karakterleri kullanılabilir, senetlerin bankasına göre gruplamalar yaparak daha sonra toplu çıkış bölümünden rapor koduna göre hızlı ciro edilebilir ya da, rapor koduna göre listeler alınabilir. |
| Kasa Kodu | Senet tahsilatı yapıldığında, senet tutarının hangi kasaya gelir olarak işleneceği ile ilgili kod bilgisi girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Adı | Senet tahsilatı yapılacak cari hesap seçildiğinde, bu hesap için "Cari Hesap Kayıtları" bölümünde girilen isim bilgisinin program tarafından otomatik olarak ekrana getirildiği alandır. |
| Adres | Senet tahsilatı yapılacak cari hesap seçildiğinde, bu hesap için "Cari Hesap Kayıtları" bölümünde girilen adres bilgisinin program tarafından otomatik olarak ekrana getirildiği alandır. |
| Tahsil Edilecek Senet Numarası | Tahsil edilmesi istenen senet numarasının girilmesiyle ya da rehber butonundan ![](../../../../../_assets/088477bb321d1b20c939.jpg) seçilmesiyle işlem yapılan alandır. Tahsil edilmesi istenen senet grid ekrandan da seçilebilir. |
| Senet No | Cari hesap kodu girildikten sonra, bu hesaba ait senet bilgileri grid alanda listelenir. İşlem yapılacak senet üzerinde farenin sol klik tuşu ile çift tıklandığında, seçilen senede ait numara bilgisi "Senet No" alanında izlenir. |
| Döviz Tutarı | Seçilen senedin dövizli olması halinde, döviz tutarının izlendiği alandır. |
| Döviz Tipi | Seçilen senedin dövizli olması halinde, döviz tipinin izlendiği alandır. |
| Vade Tarihi | Seçilen senede ait vade tarihinin program tarafından ekrana getirildiği alandır. |
| Cari Rapor Kodu | Seçilen senedin kaydı sırasında girilen "Cari Rapor Kodu" bilgisinin program tarafından otomatik olarak ekrana getirildiği alandır. |
| Proje Kodu | Senet tahsilatı yapılacak cari hesap seçildiğinde, bu hesap için "Cari Hesap Kayıtları" bölümünde girilen proje kodunun program tarafından otomatik olarak ekrana getirildiği alandır. |
| Plasiyer Kodu | Senet tahsilatı yapılacak cari hesap seçildiğinde, bu hesap için "Cari Hesap Kayıtları" bölümünde girilen plasiyer kodunun program tarafından otomatik olarak ekrana getirildiği alandır. |
| Ödendi/Eksik/Kalan İlave | Seçilen senede ait ödeme şeklinin belirlendiği alandır. Seçilen senede ait tutarın tamamı ödeneceği zaman "Ödendi", seçilen senede ait tutarın bir kısmı ödeneceği zaman "Eksik", ödenmeyen (kalan tutarın) bir sonraki senet tutarına eklenmesi istendiğinde ise "Kalan İlave" seçeneğinin işaretlenmesi gerekir. |
| Ödeme Tarihi | Ödemenin yapıldığı tarihin girildiği alandır. Program, içinde bulunulan günün tarihini otomatik olarak ekrana getirir. Kullanıcı isterse tarih bilgisini değiştirebilir. |
| Tutar | "Eksik" ve "Kalan İlave" seçenekleri işaretlendiğinde aktif olan alandır. Senet tutarının ne kadarının tahsil edileceği ile ilgili tutar girilmesini sağlar. |
| Cari Alacak Bakiye | Seçilen cari hesaba ait alacak bakiyesinin izlendiği alandır. |
| Ödenen | Seçilen cari hesaba ait toplam senet ödeme tutarının izlendiği alandır. |
| Kalan | Seçilen cari hesabın ödeme yapacağı kalan toplam tutarın izlendiği alandır. |
