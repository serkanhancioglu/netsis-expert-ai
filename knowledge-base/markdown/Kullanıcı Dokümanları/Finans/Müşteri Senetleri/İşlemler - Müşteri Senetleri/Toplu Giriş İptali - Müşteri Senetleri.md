# Toplu Giriş İptali / Müşteri Senetleri

Müşteri Senetleri Toplu Giriş İptali, Finans Bölümü'nde, "İşlemler/Müşteri Senetleri" menüsünün altında yer alır. Müşteri Senetleri Toplu Giriş İptali, senetlerin "Cari Hesap Senet Alındı Kaydı" bölümünden sisteme kaydedilmesi ile oluşturulan alındı bordrolarında, yapılan hatalar nedeniyle düzenleme yapılması gerektiğinde, tek bir bordronun tamamının iptal edilmesini sağlayan bölümdür.

![](../../../../_assets/cd121916167b97a789de.png)

Toplu Giriş İptali ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Giriş İptali Ekranı |  |
| --- | --- |
| Alındı Bordro No | İptal edilmesi istenen alındı bordro numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, bordro rehberinden seçim yapılır. |
| Tarih | İptal edilmesi için seçilen alındı bordrosunun, kayıt tarihinin program tarafından otomatik olarak ekrana getirildiği alandır. |
| Veren kodu | İptal edilmesi için seçilen alındı bordrosunda bulunan senetleri veren cari hesabın program tarafından otomatik olarak ekrana getirildiği alandır. İlk olarak silinmesi istenen alındı bordro numarasının yazılması gerekir. Yazılan bordro numarası içinde kaç adet çek kaydı bulunduğu ekrana gelir ve bu kayıtların silinmesi ile ilgili onay ekranı görüntülenir. ![](../../../../_assets/91d59786dc832765d9df.png) Burada "Hayır" butonuna basılarak işlemden vazgeçilir veya "Evet" butonuna basılarak senet kayıtları iptal edilir. İşlem tamamlandığında iptal edilen senet kayıtlarının yeniden tek tek girilmesi gerekir. Bordro numarası ile alınan senetlerin herhangi bir yere çıkışı yapıldıysa, program senetlerin kullanılmasından dolayı silme işlemini gerçekleştirmeyeceğine dair uyarı verir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
