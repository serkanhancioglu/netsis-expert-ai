# Toplu Plasiyer Kodu Atama

Toplu Plasiyer Kodu Atama, Finans Bölümü'nde, "İşlemler/Müşteri Senetleri " menüsünün altında yer alır. Toplu Plasiyer Kodu Atama, seçimi yapılan senetlere, toplu olarak plasiyer bilgisi atanmasını sağlayan bölümdür.

![](../../../../_assets/5360cd3b4f12cdae5911.png)

Toplu Plasiyer Kodu Atama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Plasiyer Kodu Atama Ekranı |  |
| --- | --- |
| Plasiyer Kodu | Seçilen senetlere atanacak plasiyer kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, plasiyer kodları arasından seçim yapılır. |
| **![](../../../../_assets/da2be21b85e05ba1c4f6.png)**Çek Seçimi | Plasiyer kodu atanacak senetlerin belirlenmesi için kullanılan butondur. Butona basılmasıyla ekrana gelen "Senet Seçimi" ekranında, girilen kısıtlara uyan senetler "Toplu Plasiyer Atama" ekranının grid alanında listelenir. |
| **![](../../../../_assets/ab9047f06dcf17f8b154.png)**Tümünü Seç | Grid alanında bulunan senetlerin tamamının seçilmesi için kullanılan butondur. Seçilen senetler gri renkte görüntülenir. |
| **![](../../../../_assets/ca4e3e18d9df15206767.png)**Tümünü Sil | Grid alanında seçilen tüm senetlerin, seçiminin kaldırılması için kullanılan butondur. |
| **![](../../../../_assets/e7b0642c0eec2cd6a91e.png)**Kaydet | Seçilen senetlere "Plasiyer Kodu" alanında belirlenen plasiyerin atanması için kullanılan butondur. |
| **![](../../../../_assets/973111d004995dca0113.jpg)**İptal | Toplu plasiyer atama işleminden vazgeçildiğinde, ekrandan çıkmak için kullanılan butondur. |
| Senet No | Listelenen senet sayısının fazla olduğu durumlarda, bazı senetlerin seçilmesi ya da seçiminin kaldırılması için senet numarası kısıdı verilerek arama yapılmasını sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, senet numaraları arasından seçim yapılır. |
| ![](../../../../_assets/f4283ef0f57ef07dc291.png) Onayla/Onay Kaldır | "Senet No" alanında belirlenen senetin seçilmesi ya da seçiminin kaldırılması için kullanılan butondur. "Senet No" alanına girilen senet seçili iken bu butona basıldığında seçim kaldırılır, seçili değil iken basıldığında ise seçim onaylanır. |
