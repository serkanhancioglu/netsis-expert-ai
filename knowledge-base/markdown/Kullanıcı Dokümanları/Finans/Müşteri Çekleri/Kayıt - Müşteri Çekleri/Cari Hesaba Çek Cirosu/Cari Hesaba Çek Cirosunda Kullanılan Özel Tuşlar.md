# Cari Hesaba Çek Cirosunda Kullanılan Özel Tuşlar

Cari Hesaba Çek Cirosu ekranında kullanılan yardımcı tuşlar, ekran üzerinde iken farenin sağ tuşu ile görüntülenir.

![](../../../../../_assets/f681773ac491cfedc65d.png)

Cari hesaba çek cirosu ekranında kullanılan özel tuşlar şunlardır:

| Cari Hesaba Çek Cirosu Ekranı Özel Tuşlar |  |
| --- | --- |
| Tarihsel Senet/Çek Hareketleri İzleme | Müşteri çeklerinin, şirket bünyesine girmesinden itibaren görmüş olduğu hareketlerin kısa yoldan görüntülenmesini sağlar. İçinde bulunulan çek ile ilgili, tüm geçmiş hareketler ve çekin son durumu izlenir. Bu fonksiyon çeklerin işlem gördüğü tüm modüllerde (Müşteri Çekleri, Kasa, Dekont) kullanılabilir. ![](../../../../../_assets/968a93f7bc1a96f2af92.png) |
| Toplu Çek Seçimi | Girilecek kısıtlara uygun olan çeklerin kombinasyonu yapılarak, aynı kombinasyona dahil olan birden fazla çekin verildi bordrosuna aktarılmasını sağlar. Toplu Çek Seçimi uygulaması ile ilgili detaylı bilgi için; Müşteri Çekleri → [Ek-2 (Toplu Çek Seçimi)](<../../Ekler - Müşteri Çekleri/Ek-2 (Toplu Çek Seçimi).md>). |
| Verilen Kodun Değişikliği | Çekin ciro edildiği cari hesabın kod bilgisinde değişiklik yapılmasını sağlar. Yeni kod yazıldıktan sonra Tamam butonuna basılır. Böylece çekin verildiği cari hesap kodu değiştirilmiş olur. Bordro Tamamlama butonu ile ciro işlemi kaydedilir. ![](../../../../../_assets/e95d684b93e561721703.png) |
| Toplu Proje Kodu Değişikliği | Verildi bordrosuna eklenen çeklerin proje kodlarının değiştirilmesini sağlar. ![](../../../../../_assets/9044cd7168613982d7a7.png) |
| Gönder | "Gönder" seçeneği ile, çek bilgileri Excel’e aktarılabilir, grafik hazırlanabilir ve akıllı gride gönderilebilir. |
