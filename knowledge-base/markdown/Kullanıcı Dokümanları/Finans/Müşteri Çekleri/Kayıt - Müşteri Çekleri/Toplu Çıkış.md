# Toplu Çıkış

Toplu çıkış, Finans Bölümü'nde Kayıt/Müşteri Çekleri menüsünün altında yer alır. Portföydeki çeklerin cari, tahsil veya teminat hesabına toplu olarak ciro edildiği bölümdür. Toplu çıkış işlemi ile kullanıcının verdiği kısıtlara uyan tüm çekler listelenir. Daha sonra bu listeden seçilen çekler toplu olarak cari hesaba, tahsil hesabına ya da teminat hesabına ciro edilir. Toplu Çıkış bölümüne girildiğinde Çek Seçimi ekranı görüntülenir. Bu ekran, toplu çıkışı yapılacak çeklere ait listede bulunması istenen çekler için kısıt verilmesini sağlar. Girilen kısıtlara uymayan çekler ciro edilemez. Hiçbir kısıt verilmeden devam edilmesi istendiğinde, Tamam butonuna basılarak Toplu Çıkış İşlemi ekranına geçilir.

![](../../../../_assets/c8b2370594050c7ba794.png)

Toplu çıkış çek seçimi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Çek Seçimi Ekranı |  |
| --- | --- |
| Veren Kodu | Sadece belirlenen aralıktaki cari hesaptan alınan çeklerin toplu olarak ciro edilmesi için kısıt verilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlara ulaşılır. |
| Vade Tarihi Aralığı | Vadesi belli bir tarih aralığında olan çeklerin toplu olarak ciro edilmesi için kullanılan alandır |
| Tutar Aralığı | Belli bir tutar aralığındaki çeklerin toplu olarak ciro edilmesi için kullanılan alandır. |
| Çek No Aralığı | Toplu çıkış işlemindeki listeye getirilecek çekler için numara aralığı verilmesini sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile çek rehberine ulaşılır. |
| Alındı Bordro No Aralığı | Toplu çıkış işlemindeki listeye getirilecek çeklerin bulunduğu alındı bordroları için numara aralığı verilmesini sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile alındı bordro numaralarına ulaşılır. |
| R.K. (Rapor Kodu) | Toplu çıkış işlemindeki listeye getirilecek çeklerin sahip oldukları rapor koduna kısıt verilmesi için kullanılan alandır. |
| Bankası | Toplu çıkış işlemindeki listeye getirilecek çeklerin bankalarına kısıt verilmesi için kullanılan alandır. |
| Dövizli Çekler/TL Çekler/Hepsi | Toplu çıkış işleminde sadece Dövizli Çeklerin ya da TL Çeklerin listelenerek ciro edilmesi için kullanılan alandır. Bu aşamada döviz tipi fark etmeden, dövizli ya da TL olarak tüm çeklerin listelenmesi istendiğinde Hepsi seçeneğinin işaretlenmesi gerekir. |
| Döviz Tipi | Dövizli Çekler seçeneğinin işaretlenmesi halinde, hangi döviz tipine sahip çeklerin listeleneceği ile ilgili kod girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile döviz tiplerine ulaşılır. |
| Durum Kodu | Sadece belirli bir durum koduna sahip çeklerin listelenmesi için kullanılan alandır. Tüm çeklerin listelenmesi istendiğinde Hepsi seçeneğinin işaretlenmesi gerekir. |
| Yer Kodu | Sadece belirli bir yer koduna sahip çeklerin listelenmesi için kullanılan alandır. Tüm çeklerin listelenmesi istendiğinde Hepsi seçeneğinin işaretlenmesi gerekir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen kısıtların onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen kısıtlardan vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |

**Toplu Çıkış İşlemi**

Çek Seçimi ekranında verilen çeklerin listelendiği ve toplu olarak ciro edildiği bölümdür.

![](../../../../_assets/a7ec96901a7c85baa4b7.png)

Toplu çıkış işlemi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Toplu Çıkış İşlemi Ekranı |  |
| --- | --- |
| Yer kodu | İlgili çekin/çeklerin nereye ciro edileceği ile ilgili seçim yapılan alandır. Ciro, Tahsil veya Teminat seçeneklerinden biri seçilir. |
| Verilen Kodu | Yer Kodu alanında Ciro seçeneğinin işaretlenmesi ile cari hesap kodunun, Tahsil/Teminat seçeneğinin işaretlenmesi ile parametre girişindeki seçime göre banka için açılan cari hesap kodu, banka veya muhasebe kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlara ulaşılır. |
| Çıkış Tarihi | Çeklerin portföyden çıkış tarihinin girildiği alandır. Günün tarihi, program tarafından otomatik olarak aktarılır. Kullanıcı tarafından değiştirilebilir. |
| Rapor Kodu | Ciro edilecek çeklere ait rapor kodunun girildiği alandır. |
| Proje Kodu | Ciro edilecek çeklere ait proje kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile proje kodlarına ulaşılır. |
| Sıralama | Girilen kısıtlara uyan çeklerin listelenmesi aşamasında, neye göre sıralanacağı ile ilgili seçim yapılan alandır. Çekler, numaralarına ya da vade tarihlerine göre sıralanabilir. |
| Kayıtlar Tek Tek Onaylansın | Ön sorgulamada verilen kriterlere göre seçilen tüm çeklerin seçili olarak gelmesi istendiğinde Kayıtlar Tek Tek Onaylansın seçeneğinin **işaretlenmemesi** gerekir. İşaretlendiğinde, listelenen çeklerden ciro edileceklerin üzerinde fare ile iki kez tıklanarak seçilmesi gerekir. |
| Toplu Çek Seçimi | Toplu Çek Seçimi uygulaması ile ilgili detaylı bilgi için; Müşteri Çekleri → [Ek-2 (Toplu Çek Seçimi)](<../Ekler - Müşteri Çekleri/Ek-2 (Toplu Çek Seçimi).md>). |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen kısıtlara uyan çeklerin listelenmesi için kullanılan butondur. |
| ![](../../../../_assets/c96e2b0d2c19eb0d52cc.png) Bordro Tamamlama | Girilen bilgilere göre çeklerin ciro edilmesi için kullanılan butondur. İşlem tamamlandığında, işaretlenen çekler çıkış olarak verilen hesaba aktarılır. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Toplu Çıkış işleminden çıkmak için kullanılan butondur. |
| Verildi Bordro No | Seçilen çeklerin ciro edildiği verildi bordro numarasının izlendiği alandır. |
