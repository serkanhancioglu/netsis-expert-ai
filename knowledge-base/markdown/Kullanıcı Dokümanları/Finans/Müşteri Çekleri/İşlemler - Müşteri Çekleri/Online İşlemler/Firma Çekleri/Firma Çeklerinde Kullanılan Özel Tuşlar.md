# Firma Çeklerinde Kullanılan Özel Tuşlar

"Firma Çekleri" ekranında kullanılan yardımcı tuşlar, "Çekler" sekmesi ekranının üzerinde iken farenin sağ tuşu ile ekrana gelir.

![](../../../../../../_assets/c25e86b03927a06779d7.png)

Firma Çekleri ekranındaki özel tuşlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Firma Çekleri Ekranı Özel Tuşlar |  |
| --- | --- |
| Bordro Tamamlama | Seçilen tahsil bilgilerinin program içine aktarılmasını sağlar. |
| Tüm Tahsiller İçin Bordro Tamamlama | Bankadan gelen tüm tahsil bilgilerinin program içine aktarılmasını sağlar. |
| Gönder | "Gönder" seçeneği ile, çek bilgileri Excel’e aktarılabilir, grafik hazırlanabilir ve akıllı gride gönderilebilir. |

Çekler, "Bordro Tamamlama" işlemlerinin çalıştırılması ile bankadan gelen bilgiler doğrultusunda, alındı bordro numarası ile portföye giriş yapar ve aynı zamanda verildi bordro numarası ile otomatik olarak tahsile çıkar. Bordro numaraları sistemdeki son numaranın bir fazlası olarak otomatik şekilde oluşur. Daha önceden program içine aktarılan çeklerin durumlarında “Var” açıklaması yer alır.
