# Tahsil Çekleri Gönder

Tahsil Çekleri Gönder, Finans Bölümü'nde, "İşlemler/Müşteri Çekleri " menüsünün altında yer alır. Tahsil Çekleri Gönder, portföyde bulunan müşteri çeklerinin tahsil edilmesi için, çek bilgilerinin bankadaki tahsil hesabına online gönderilmesi için kullanılır. Tahsil Çekleri Gönder uygulaması, şu an için sadece TEB, HSBC, Akbank, ICBC, Finansbank, Ziraat Bankası bankaları için destek verir.

![](../../../../../_assets/0258961924fbc947e256.png)

Tahsil Çekleri Online Bankacılık ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Tahsil Çekleri Online Bankacılık Ekranı |  |
| --- | --- |
| Gönderilen Banka Hesap No | Çeklerin gönderileceği banka hesap numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, banka hesap kodları arasından seçim yapılır. |
| Banka | "Gönderilen Banka Hesap No" alanında seçilen hesap kodunun ait olduğu banka ana kodunun program tarafından otomatik olarak ekrana getirildiği alandır. |
| Şube | "Gönderilen Banka Hesap No" alanında seçilen hesap kodunun ait olduğu banka şube kodunun program tarafından otomatik olarak ekrana getirildiği alandır. |
| IBAN | "Gönderilen Banka Hesap No" alanında seçilen hesap kodunun ait olduğu IBAN numarasının program tarafından otomatik olarak ekrana getirildiği alandır. |
| Verildi Bordro No | Tahsile gönderilecek çeklerin seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, verildi bordroları arasından seçim yapılır. |
| **![](../../../../../_assets/c33647cb9f05828bed16.png)**Tahsil Çekleri Yükle (XML) | Tahsile gönderilecek çeklerin "Gönderilecek XML Dosyası" alanında oluşması için kullanılan butondur. Sadece tek bir bordro gönderimi için kullanılır. |
| **![](../../../../../_assets/d94090ff208c8e5de731.png)**Online İşlem Başlat | XML bilgilerinin bankaya gönderilmesi için kullanılan butondur. Gönderim sırasında ekrana bilgilendirme penceresi gelir. ![](../../../../../_assets/11c7da3bcd70ffe13712.png) |
| Cevap Dosyası | Bankadan gelen cevap içeriğinin XML formatında oluştuğu alandır. |
| **![](../../../../../_assets/fdb12335bfb04361fb0d.png)**Cevap İçeri Değiştir | Cevap içeriğinin XML formatı dışında, kullanıcının anlayacağı bir ifade ile ekranda oluşmasını sağlayan butondur. |
| **![](../../../../../_assets/665bdda4effaf0ad0cc7.png)**Sakla | "Gönderilen XML Dosyası" ya da "Cevap" seçenekleri arasından tercih edilen seçimin yedekleme amaçlı saklanmasını sağlayan butondur. |
