# Toplu Giriş İptali

Toplu Giriş İptali, Finans Bölümü'nde, "İşlemler/Müşteri Çekleri " menüsünün altında yer alır. Toplu Giriş İptali, çeklerin "Cari Hesap Çek Alındı Kaydı" bölümünden sisteme kaydedilmesi ile oluşturulan alındı bordrolarında, yapılan hatalar nedeniyle düzenleme yapılması gerektiğinde, tek bir bordronun tamamının iptal edilmesini sağlayan bölümdür.

![](../../../../_assets/6539eb5e4f0ac1a7bbd1.png)

Toplu Giriş İptali ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Giriş İptali Ekranı |  |
| --- | --- |
| Alındı Bordro No | İptal edilmesi istenen alındı bordro numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, bordro rehberinden seçim yapılır. |
| Tarih | İptal edilmesi için seçilen alındı bordrosunun, kayıt tarihinin program tarafından otomatik olarak ekrana getirildiği alandır. |
| Veren kodu | İptal edilmesi için seçilen alındı bordrosunda bulunan çekleri veren cari hesabın program tarafından otomatik olarak ekrana getirildiği alandır. İlk olarak silinmesi istenen alındı bordro numarasının yazılması gerekir. Yazılan bordro numarası içinde kaç adet çek kaydı bulunduğu ekrana gelir ve bu kayıtların silinmesi ile ilgili onay ekranı görüntülenir. ![](../../../../_assets/91d59786dc832765d9df.png) Burada "Hayır" butonuna basılarak işlemden vazgeçilir veya "Evet" butonuna basılarak çek kayıtları iptal edilir. İşlem tamamlandığında iptal edilen çek kayıtlarının yeniden tek tek girilmesi gerekir. Bordro numarası ile alınan çeklerin herhangi bir yere çıkışı yapıldıysa, program çeklerin kullanılmasından dolayı silme işlemini gerçekleştirmeyeceğine dair uyarı verir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
