# Toplu Plasiyer Atama

Toplu Plasiyer Atama, Finans Bölümü'nde, "İşlemler/Müşteri Çekleri " menüsünün altında yer alır. Toplu Plasiyer Atama, seçimi yapılan çeklere, toplu olarak plasiyer bilgisi atanmasını sağlayan bölümdür.

![](../../../../_assets/24f39325a2b7a51b6ad2.png)

Toplu Plasiyer Atama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Toplu Plasiyer Atama Ekranı |  |
| --- | --- |
| Plasiyer Kodu | Seçilen çeklere atanacak plasiyer kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, plasiyer kodları arasından seçim yapılır. |
| **![](../../../../_assets/da2be21b85e05ba1c4f6.png)**Çek Seçimi | Plasiyer kodu atanacak çeklerin belirlenmesi için kullanılan butondur. Butona basılmasıyla ekrana gelen "Çek Seçimi" ekranında, girilen kısıtlara uyan çekler "Toplu Plasiyer Atama" ekranının grid alanında listelenir. |
| **![](../../../../_assets/ab9047f06dcf17f8b154.png)**Hepsini Seç | Grid alanında bulunan çeklerin tamamının seçilmesi için kullanılan butondur. Seçilen çekler gri renkte görüntülenir. |
| **![](../../../../_assets/ca4e3e18d9df15206767.png)** Hepsini Kaldır | Grid alanında seçilen tüm çeklerin, seçiminin kaldırılması için kullanılan butondur. |
| **![](../../../../_assets/e7b0642c0eec2cd6a91e.png)**Kaydet | Seçilen çeklere "Plasiyer Kodu" alanında belirlenen plasiyerin atanması için kullanılan butondur. |
| **![](../../../../_assets/973111d004995dca0113.jpg)**İptal | Toplu plasiyer atama işleminden vazgeçildiğinde, ekrandan çıkmak için kullanılan butondur. |
| Çek No | Listelenen çek sayısının fazla olduğu durumlarda, bazı çeklerin seçilmesi ya da seçiminin kaldırılması için çek numarası kısıtı verilerek arama yapılmasını sağlayan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, çek numaraları arasından seçim yapılır. |
| ![](../../../../_assets/f4283ef0f57ef07dc291.png) Onayla/Onay Kaldır | "Çek No" alanında belirlenen çekin seçilmesi ya da seçiminin kaldırılması için kullanılan butondur. "Çek No" alanına girilen çek seçili iken bu butona basıldığında seçim kaldırılır, seçili değil iken basıldığında ise seçim onaylanır. |
