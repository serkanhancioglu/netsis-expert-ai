# Dizayn Sakla / Dizayn

Dizayn Sakla işlemi, Genel Bölümü'nde İşlemler/Dizayn Modül menüsünün altında yer alır. Dizayn modülünde yer alan Dizayn Sakla ekranı; dizayn tanımlamalarını, başka bir firmaya kopyalamak ya da destek firmasına ulaştırmak için belli bir dosyaya saklanmasını sağlayan bölümdür.

![](../../../../_assets/e07fcf0e666edb123ffb.png)

Dizayn Saklama işlem ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dizayn Saklama Ekranı |  |
| --- | --- |
| Dizayn Adı | Saklanması istenen dizaynın girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, dizayn adları arasından seçim yapılır. |
| Dosya Adı | Saklanacak dosyanın girildiği alandır. Yükle butonu ![](../../../../_assets/4405f44b9131d916091d.png) ile, saklanması istenen dosya seçilir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Dizayn saklama işleminin gerçekleşmesi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
