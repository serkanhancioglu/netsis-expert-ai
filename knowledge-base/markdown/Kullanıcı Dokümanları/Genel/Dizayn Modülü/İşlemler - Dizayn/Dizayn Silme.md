# Dizayn Silme

Dizayn Silme işlemi, Genel Bölümü'nde İşlemler/Dizayn Modülü menüsünün altında yer alır. Dizayn Silme, önceden tanımlanan bir Windows dizaynının silinmesi için kullanılan bölümdür. Bu bölümden silinen bir dizayn, daha önce kullanıldığı modülden seçilerek basılamaz.

![](../../../../_assets/28270e94fc9e35546c2b.png)

Dizayn Silme işlem ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dizayn Sil Ekranı |  |
| --- | --- |
| Dizayn Adı | Silinecek dizaynın girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, dizayn adları arasından seçim yapılır. |
| ![](../../../../_assets/8983580a379aff0c4678.png) Sil | Önceden tanımlanan bir dizaynın silinmesi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
