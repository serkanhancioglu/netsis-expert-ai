# Dizayn Yükle / Dizayn

Dizayn Yükle işlemi, Genel Bölümü'nde İşlemler/Dizayn Modülü menüsünün altında yer alır. Dizayn Sakla işlemi ile belli bir dosyaya saklanan dizayn tanımlamalarının geri yüklenmesini sağlayan bölümdür.

![](../../../../_assets/46a52fb30f7bb5fed609.png)

Dizayn Yükle ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dizayn Yükleme Ekranı |  |
| --- | --- |
| Dosya Adı | "Dizayn Sakla" işlemi ile saklanan dosya adının girildiği alandır. Yükle butonu ![](../../../../_assets/4405f44b9131d916091d.png) ile, saklanan dosya seçilir. |
| Dizayn Adı | Dizayn tanımlaması geri yüklenecek dizaynın seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, dizayn adları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Dizayn yükleme işleminin gerçekleşmesi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
