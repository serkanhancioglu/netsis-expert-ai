# Dos’dan Çeviri

Dos'tan Çeviri işlemi, Genel Bölümü'nde İşlemler/Dizayn Modülü menüsünün altında yer alır. Dos’dan Çeviri bölümü, DOS tabanlı programda yapılmış dizaynların, Windows programına uygun hale getirilerek çevrilmesini sağlayan bölümdür. Daha önce Logo Netsis’in DOS tabanlı programlarını kullanan ve bu programlardan yapılan dizaynları basan firmaların, var olan dizayn basımını sağlamak için Windows programına çevrilmesini sağlar.

![](../../../../_assets/6c24013e72c6413a759a.png)

DOS Dizayn Çeviri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| DOS Dizayn Çevir Ekranı |  |
| --- | --- |
| DOS Program Dizini | DOS programının, program dizininin girildiği alandır. **Örneğin;** F:\\PROFPRG |
| DOS Data Dizini | DOS programında bilgilerin bulunduğu data dizininin girildiği alandır. Data dizinin girilmesinden sonra, ilgili dizinde var olan dizaynlar ekranın alt kısmında listelenir. Çevrilmesi istenen dizaynın, farenin sol klik tuşu ile işaretlenmesi gerekir. |
| Dizayn Tipi | DOS programından çevrilecek olan dizayn tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile dizayn tipleri arasından seçim yapılır. **Örneğin;** Satış İrsaliyesi dizaynı çevrilecek ise, "3 Satış İrsaliyeleri" seçeneğinin tercih edilmesi gerekir. |
| Açıklama | Windows programına çevrilecek olan dizayn için açıklama bilgisi girilen alandır. |
| **![](../../../../_assets/cc5b0b1dad5236580ee7.png)**Çevir | Seçilen DOS dizaynının Windows programına çevrilmesi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
