# Windows’dan Çeviri

Windows'dan Çeviri, Genel Bölümü'nde İşlemler/Dizayn Modülü menüsünün altında yer alır. Windows’dan Çeviri; Windows programında kullanması için, eski dizayn modülü ile yapılmış Windows dizaynlarının yeni dizayn modülüne çevrilmesini sağlayan bölümdür.

![](../../../../_assets/70b57e0548ac262f79ea.png)

Windows'dan Dizayn Çevirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Windows'dan Dizayn Çevirme Ekranı |  |
| --- | --- |
| Dizayn Tipi | Yeni dizayn modülüne çevrilecek olan dizayn tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile dizayn tipleri arasından seçim yapılır. **Örneğin;** Satış İrsaliyesi dizaynı çevrilecek ise, "3 Satış İrsaliyeleri" seçeneğinin tercih edilmesi gerekir. |
| Açıklama | Windows'dan çevrilecek dizayn için açıklama bilgisi girilen alandır. |
| ![](../../../../_assets/6a2bdcb8b226f80db25a.png) Çevir | Windows dizaynlarının yeni dizayn modülüne çevrilmesi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
