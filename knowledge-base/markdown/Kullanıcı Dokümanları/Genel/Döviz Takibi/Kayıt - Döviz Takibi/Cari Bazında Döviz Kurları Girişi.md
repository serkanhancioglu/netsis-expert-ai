# Cari Bazında Döviz Kurları Girişi

Cari Bazında Döviz Kurları Girişi, Genel Bölümü'nde, "Kayıt/Döviz Takibi" menüsünün altında yer alır. Cari Bazında Döviz Kurları Girişi, cari bazında döviz kurlarının tanımlanmasını sağlayan bölümdür.

Cari Bazında Döviz Kurları Girişi ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Cari Bazında Döviz Kurları Girişi Ekranı |  |
| --- | --- |
| Cari Kodu | Döviz kuru tanımlanacak cari kodun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlar arasından seçim yapılır. |
| Döviz Tipi | Seçilen cari kod için döviz tipi tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tipleri arasından seçim yapılır. |
| Başlangıç/Bitiş Tarihi | Seçilen cari kod ve döviz tipi için başlangıç ve bitiş tarihi belirlenen alandır. Girilen tarih aralığı ile, Döviz Alış/Satış, Efektif Alış/Satış kurlarının sabitlenmesi sağlanır. Satış Kurlarının Sabitlenmesi bölümünden girilen kurların kullanıcılar tarafından değiştirilmemesi için Cari → Kayıt → Cari Parametreleri → "Cari Bazında Tanımlanan Döviz Kurları Belgede Değiştirilemesin" parametresinin seçilmesi gerekir. |

Cari Bazında Döviz Kurları Girişi ekranında ilgili kayıtlar girildikten sonra “Kaydet” ![](../../../../_assets/865524a70e225c89c107.jpg) butonu ile kayıt tamamlanır. Açılan bir kayıt, kayıt sil ![](../../../../_assets/2df4b343310bcd16b01e.jpg)butonu ile iptal edilir veya üzerinde değişiklik yapılması için kaydet tuşu kullanılarak düzeltilir.
