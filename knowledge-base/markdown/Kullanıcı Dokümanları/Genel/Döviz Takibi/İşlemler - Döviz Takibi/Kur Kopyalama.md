# Kur Kopyalama

Kur Kopyalama, Genel Bölümü'nde, "İşlemler/Döviz Takibi" menüsünün altında yer alır. Kur Kopyalama, bir tarihteki kur değerlerinin başka bir tarihteki kur değerlerine kopyalanmasını sağlayan bölümdür.

![](../../../../_assets/c3aa2fb7bf571e72c323.png)

Kur Kopyalama ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Kur Kopyalama Ekranı |  |
| --- | --- |
| Döviz Başlangıç | Kur kopyalama işlemi için döviz başlangıç kısıdı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tipleri arasından seçim yapılır. |
| Döviz Bitiş | Kur kopyalama işlemi için döviz bitiş kısıdı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tipleri arasından seçim yapılır. |
| Kaynak Tarih | Kopyalanması istenen kur tarihinin girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile takvim kullanılarak seçim yapılır. |
| Hedef Tarih | Kopyalanacak kur tarihinin girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile takvim kullanılarak seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
