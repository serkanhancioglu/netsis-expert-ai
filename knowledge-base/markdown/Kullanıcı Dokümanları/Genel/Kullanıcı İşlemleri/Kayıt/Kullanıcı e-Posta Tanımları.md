# Kullanıcı e-Posta Tanımları

Kullanıcı e-Posta Tanımları, Genel Bölümü'nde Kayıt/Kullanıcı İşlemleri menüsünün altında yer alır. Şirket içinde yapılan bazı işlemlerin, istenen kullanıcılara e-Mail ile anında bildirilmesi ve Netsis bildirimleri için tanımlama yapılan bölümdür. Bu bölüm ile bazı kullanıcılar, önemli işlemlerden anlık haberdar olur. Üst düzey yöneticilerin de gelişmeleri takip etmesini sağlar.

Kullanıcı e-Posta Tanımlamaları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kullanıcı e-Posta Tanımlamaları Ekranı |  |
| --- | --- |
| İşlemler | Kullanıcıların bilgilendirileceği işlemlerin seçildiği alandır. Seçilen işlemlere bağlı olarak ilgili iş kullanıcı tarafından yapıldığında otomatik olarak e-Posta gönderimi sağlanır. Alanın sağ tarafında yer alan aşağı ok butonu ile işlemler arasından seçim yapılır. Grid üzerinden işlem yapılacak kullanıcılar için bilgilendirme yöntemi seçilerek Kaydet butonu ile tanımlama yapılması sağlanır. |
| Şube Kodu | Mevcut kayıtların şube bazlı kullanılması için şube kodu girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodları arasından seçim yapılır. > [!NOTE]<br>> Aynı kullanıcı numarası ile, farklı şubelerde farklı kullanıcılara ait kayıtların kontrollü olarak düzeltilmesi gerekir. |
| Bildirim | Kullanıcılara program üzerinden bildirim gitmesi için kullanılır. |
| ![](../../../../_assets/d15ca1ad68365b9a1a84.png) Tümünü Seç | Grid üzerinde listelenen kullanıcıların hepsinin seçilmesini sağlayan butondur. |
| ![](../../../../_assets/f5ffb212771284b3d8d5.png) Tümünü Kaldır | Grid üzerinde yapılan seçimlerin hepsinin kaldırılması için kullanılan butondur. |
| ![](../../../../_assets/3209ce7010ce46965fa5.png) Satır Seç | Grid üzerindeki herhangi bir satırı toplu şekilde seçmek için kullanılan butondur. |
| ![](../../../../_assets/5b52a72ade51d4fe2e7d.png) Satır Kaldır | Grid üzerinden seçilen satıra ait seçimlerin kaldırılması için kullanılan butondur. |
| ![](../../../../_assets/dcafc30ba4f2dfd78cef.png) Sütun Seç | Grid üzerindeki herhangi bir sütunu toplu şekilde seçmek için kullanılan butondur. |
| ![](../../../../_assets/d554123fce5c0c2c635a.png) Sütun Kaldır | Grid üzerinden seçilen sütuna ait seçimlerin kaldırılması için kullanılan butondur. |
| Kaydet | Grid üzerinden yapılan seçimlerin kaydedilmesi için kullanılan butondur. |

Grid üzerinde daha fazla bilgilendirme görülmesi için sol tarafta yer alan yıldız sembolüne tıklanarak görünür sütunlar seçilir. "Filtrelemek için buraya tıklayın." cümlesinin üzerine tıklandığında sadece görülmesi istenen kullanıcıların listesinin grid ekrana gelmesi sağlanır.
