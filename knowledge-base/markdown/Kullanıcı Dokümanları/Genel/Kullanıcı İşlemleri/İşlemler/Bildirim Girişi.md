# Bildirim Girişi

Bildirim Girişi işlemi, Genel Bölümü'nde İşlemler/Kullanıcı İşlemleri menüsünün altında yer alır. Kullanıcılara bildirim gönderilmesi için kullanılan bölümdür.

![](../../../../_assets/563294b69ea951b1a684.png)

Giden Bildirimler ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Giden Bildirimler Ekranı |  |
| --- | --- |
| ![](../../../../_assets/d15ca1ad68365b9a1a84.png) Tümünü Seç | Tüm bildirimlerin seçilmesi için kullanılan butondur. |
| ![](../../../../_assets/f5ffb212771284b3d8d5.png) Tümünü Kaldır | Seçilen bildirimlerin işaretinin kaldırılması için kullanılan butondur. |
| ![](../../../../_assets/8983580a379aff0c4678.png) Sil | Seçilen bildirimin silinmesi için kullanılan butondur. Kullanıcılar tarafından okunmuş mesajlar silinemez. |
| ![](../../../../_assets/8cb895af6381dc952774.png) Yani Bildirim | Kullanıcılara gönderilecek yeni bildirimin eklenmesi için kullanılan butondur. "Bildirim Mesajı" ekranına Alıcı, Başlık, Mesaj, Gönderim Tarihi ve Dosya eklenerek mesaj gönderilmesi sağlanır. **![](../../../../_assets/572726f528877c626ce9.png)** |
