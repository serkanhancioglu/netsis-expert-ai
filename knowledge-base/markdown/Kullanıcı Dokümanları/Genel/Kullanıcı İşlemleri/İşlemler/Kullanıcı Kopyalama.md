# Kullanıcı Kopyalama

Kullanıcı Kopyalama, Genel Bölümü'nde İşlemler/Kullanıcı İşlemleri menüsünün altında yer alır. Kullanıcı bilgilerini şubeye kopyalamak için kullanılan bölümdür.

![](../../../../_assets/596a8d6bb3e99af6e1c5.png)

Kullanıcı Kopyalama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kullanıcı Kopyalama Ekranı |  |
| --- | --- |
| Baz Alınacak Kullanıcı No | Kopyalanması istenen kullanıcı numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kullanıcı numaraları arasından seçim yapılır. |
| Kopyalanacak Şube | Girilen kullanıcı numarasının kopyalanacağı şubenin belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, şube kodları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
