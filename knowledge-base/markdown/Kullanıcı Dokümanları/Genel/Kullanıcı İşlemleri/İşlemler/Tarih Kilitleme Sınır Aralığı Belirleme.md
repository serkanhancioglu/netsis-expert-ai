# Tarih Kilitleme Sınır Aralığı Belirleme

Tarih Kilitleme Sınır Aralığı Belirleme, Genel Bölümü'nde İşlemler/Kullanıcı İşlemleri menüsünün altında yer alır. Tarih kilitleme için tarih aralığının belirlenmesi için kullanılan bölümdür.

![](../../../../_assets/419f2fa5b9f941dedfdb.png)

Tarih Kilitleme Sınır Aralığı Belirleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Tarih Kilitleme Sınır Aralığı Belirleme Ekranı |  |
| --- | --- |
| Tarih Kilitleme Şifresi | Tarih kilitleme şifresinin girildiği alandır. |
| Açık Tarih Aralığı Başlangıcı/Açık Tarih Aralığı Bitişi | Tarih kilitleme yapılacak başlangıç ve bitiş tarih aralığının girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
