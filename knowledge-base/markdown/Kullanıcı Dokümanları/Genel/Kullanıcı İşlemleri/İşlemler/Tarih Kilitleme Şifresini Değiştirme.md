# Tarih Kilitleme Şifresini Değiştirme

Tarih Kilitleme Şifresini Değiştirme, Genel Bölümü'nde İşlemler/Kullanıcı İşlemleri menüsünün altında yer alır. Tarih kilitleme şifresini değiştirmek için kullanılan bölümdür.

![](../../../../_assets/ca0a4084df469fc2c56c.png)

Tarih Kilitleme Şifresini Değiştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Tarih Kilitleme Şifresini Değiştirme Ekranı |  |
| --- | --- |
| Eski Şifre | Değiştirilmesi istenen eski şifrenin girildiği alandır. |
| Yeni Şifre | Yeni şifrenin girildiği alandır. |
| Onay Şifre | Yeni şifre tekrarının girildiği alandır |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
