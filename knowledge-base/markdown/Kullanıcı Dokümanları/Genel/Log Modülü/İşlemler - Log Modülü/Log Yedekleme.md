# Log Yedekleme

Log Yedekleme; Genel Bölümü'nde, "İşlemler/Log Modülü" menüsünün altında yer alır. Log bilgileri, NETSIS isimli veri tabanında saklanır ve istendiği zaman veri tabanına bağlanılarak rapor alınabilir. Çok uzun süre log tutularak işlem yapılmış olması, yani NETSIS veri tabanına ait data dosyasının boyutunun çok fazla olması halinde, bu datada bulunan log bilgilerinin başka bir dosyada yedeklenmesi ve yedeklenen bilgilerin NETSIS veri tabanından silinmesi için kullanılan işlemdir.

![](../../../../_assets/bfaf372903a4eee1dd23.png)

Log Yedekleme ekranında yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Log Yedekleme Ekranı |  |
| --- | --- |
| Tarih | Log yedeklemesi için tarih aralığı girilen alandır. |
| Yedekleme Dizini | Log yedeklemesi için dizin seçimi yapılan alandır. Alanın sağ tarafında yer alan Yükle ![](../../../../_assets/f5494a9691693fdb71d7.png) butonu ile, yedekleme yapılacak dizin yüklenir. |
| Dosya Boyutu | Log yedeklemesi için (MB cinsinden) dosya boyutu seçilen alandır. Alanın sağ tarafında yer alan ikonlar yardımı ile boyut artırımı/azaltımı yapılır. |
| ![](../../../../_assets/8664255e091ee51c850f.png) Yedekleme Başlat | Yedeklemenin başlatılması için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Yedekleme yapılmasından vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
