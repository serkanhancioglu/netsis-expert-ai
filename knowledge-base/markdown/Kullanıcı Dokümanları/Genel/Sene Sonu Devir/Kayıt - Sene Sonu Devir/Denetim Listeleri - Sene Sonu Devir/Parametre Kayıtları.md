# Parametre Kayıtları

Parametre Kayıtları, Genel Bölümü'nde, "Kayıt/Sene Sonu Devir" menüsünün altında yer alır. Devir işlemlerine yeni eklenen VBscript özelliği ile firmalara özel devir uygulamalarının yazılması mümkündür. Bunun için, ekrandaki “Dinamik Kodlama ile "Firmaya Özel Devir Yapılsın” parametresinin işaretli olması gerekir.

![](../../../../../_assets/66caefea6d1c52345ddc.png)

Parametre Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Parametre Kayıtları Ekranı |  |
| --- | --- |
| Dinamik Kodlama İle Firmaya Özel Devir Yapılsın | Devir işlemlerine yeni eklenen VBscript özelliği ile firmalara özel devir uygulamalarının yazılması için kullanılan seçenektir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/249197106fa4d90d9fe9.png) Çıkış | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
