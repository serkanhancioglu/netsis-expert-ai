# Denetim Listeleri / Sene Sonu Devir

Sene Sonu Devir Denetim Listeleri bölümü, modül bazında devir sonucunda; yeni sene şirketinde cari hesap, stok, çek/senet ve banka hareketlerinde oluşan devir kayıtları ile yine yeni sene şirketinde oluşan muhasebe açılış fişi arasındaki farkları, modüllerdeki denetim listeleri mantığında raporlayan bölümdür.

Burada bulunan raporlar, devir işlemleri sırasında oluşacak farkların program tarafından kapatılmasına yönelik kullanılabilir.
