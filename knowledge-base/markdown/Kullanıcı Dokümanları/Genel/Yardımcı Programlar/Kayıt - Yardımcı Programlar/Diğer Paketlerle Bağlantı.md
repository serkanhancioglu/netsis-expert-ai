# Diğer Paketlerle Bağlantı

Diğer Paketlerle Bağlantı, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Diğer Paketlerle Bağlantı, Ticari pakette çalışırken, içinde bulunulan modülden Personel ve Demirbaş paketlerinin verilerine ulaşmak için bağlantı kurulmasını sağlayan bölümdür.

**Örneğin**

"Diğer Paketlerle Bağlantı" bölümünden tanımlama yapıldıktan sonra MRP → Kayıt → "Makine Tanımlama" bölümünde Demirbaş, "Personel Tanımlama" bölümünde ise Personel paketlerindeki bilgilere ulaşılır.

![](../../../../_assets/5fa13ddde4b0202144fb.png)

Diğer Paketlerle Bağlantı ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Diğer Paketlerle Bağlantı Ekranı |  |
| --- | --- |
| İsim | Bağlantı kurulacak paketin veri tabanı adının girildiği alandır. |
| Kullanıcı | Bağlantı kurulacak paketin veri tabanı kullanıcısının girildiği alandır. Kullanıcı adının, "Personel" paketi için PERSONEL, "Demirbaş" paketi için DEMIRBAS olarak girilmesi gerekir. |
| Şifre | Bağlantı kurulacak paketin veri tabanı şifresinin girildiği alandır. İlgili veri tabanı için bir şifre yoksa boş bırakılabilir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
