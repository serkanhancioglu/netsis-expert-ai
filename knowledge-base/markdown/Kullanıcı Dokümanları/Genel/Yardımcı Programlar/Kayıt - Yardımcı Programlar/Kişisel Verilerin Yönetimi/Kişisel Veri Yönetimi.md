# Kişisel Veri Yönetimi

Kişisel Veri Yönetimi, kullanıcı veya cari hesaplarla ilgili olarak izin alınması gereken, kişisel verilerin tanımlandığı ekrandır. Kişisel Veri Yönetimi, cari veya kullanıcıdan izin alınması istenen alan belirlenerek iznin alındığı tarihin kaydedilmesini sağlar.

Kişisel Veri Yönetimi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kişisel Veri Yönetimi Ekranı |  |
| --- | --- |
| Kayıt Tipi | İzin alınması gereken kayıt tipinin belirlendiği alandır. Alanın sağ tarafında yer alan Kullanıcı veya Cari Hesap seçeneği arasından seçim yapılır. |
| Kullanıcı No/Cari Hesap Kodu | "Kayıt Tipi" alanında yapılan seçime göre ilgili kullanıcı numarası veya cari hesap kodunun seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kullanıcı numaraları/cari hesap kodları arasından seçim yapılır. |
| Program Adı | Program üzerinde izin alınması gereken bölümün seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile izin alınması gereken bölüm seçilir. |
| Alan Adı | "Program Adı" alanında seçilen bölüme ait alan seçiminin yapılmasını sağlayan alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile izin alınması gereken alan seçilir. |
| Veri İşleme Amacı | Veri işleme amacının girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu, önceden tanımlı amacın seçilmesi sağlar. |
| Anonimleştirme Tarihi | İlgili veriler anonimleştirildiği zaman güncel bir şekilde tarihin izlendiği alandır. |
| Başlangıç Tarihi | İzinin alındığı tarihin girildiği alandır |
| Geçerlilik Tarihi | İznin geçerlilik tarihinin girildiği alandır. |
| İptal Tarihi | İznin iptal tarihinin girildiği alandır. |
| ![](../../../../../_assets/753bdb121842810c0adc.png) Hızlı Alan Ekleme | Kişisel veri yönetimi ile ilgili yapılan tanımlamalar doğrultusunda grid ekrana hızlı alan ekleme yapılarak kayıt aktarılmasını sağlayan butondur. Görüntülenen "Hızlı Alan Ekleme" ekranından seçim yapılabilir. ![](../../../../../_assets/5be7ac05afdbcecb36bb.png) |
| ![](../../../../../_assets/262f3465098c8af20dfc.png) Alan Kopyalama | Kişisel veri yönetimi ile ilgili yapılan tanımlamalar doğrultusunda grid ekrana alan kopyalama yapılarak kayıt aktarılmasını sağlayan butondur. Görüntülenen "Alan Kopyalama" ekranından seçim yapıldıktan sonra "Tanımlı Alanlar" ekranından da seçim yapılarak alan kopyalama işlemi gerçekleştirilir. |
| ![](../../../../../_assets/59b76b2c422da3926289.png) Belge Ekleme | Grid ekrana gelen kaydın üzerine fare ile çift tıklanarak ilgili kayıt için belge eklenmesini sağlar. ![](../../../../../_assets/477fe7e289eba8d9e0f9.png) |
| ![](../../../../../_assets/e2319b11ac4b94830879.png) Mail İle Onay Al | Grid üzerinden seçilen belge için mail ile onay alınmasını sağlayan butondur. İlgili dizaynın tanımlanması için, "Dizayn" modülünden "KVKK Onay Basımı" dizayn tipinin seçilmesi ve ilgili dizaynın "Görsel Dizayn" olması zorunludur. Bu şekilde tanımlanan dizaynlar "Mail İle Onay Al" sistemi için kullanılır. "Mail İle Onay Al" butonuna tıklanması ile ekrana gelen "Dizayn Sorgulama" ekranından "Dizayn Adı" seçilerek "Tamam" butonuna tıklandığında, ilgili Cari'ye/Kullanıcı'ya mail gönderilerek online onay alınması sağlanır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kişisel Veri Yönetimi kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
