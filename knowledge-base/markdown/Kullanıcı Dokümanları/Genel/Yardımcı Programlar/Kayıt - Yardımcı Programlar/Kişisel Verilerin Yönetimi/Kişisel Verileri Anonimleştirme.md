# Kişisel Verileri Anonimleştirme

Kişisel Verileri Anonimleştirme, "Kişisel verilerin Yönetimi" ekranında kaydedilen cari veya kullanıcı kişisel kayıtlarının, geçerlilik tarihi baz alınarak anonimleştirildiği bölümdür. Kişisel Verileri Anonimleştirme; izin tarihi geçmiş (alınan iznin geçerlilik süresi bitmiş) alanlarla ilgili olarak cari veya kullanıcı bazında, ilgili alanların veritabanı seviyesinde geri dönüşü mümkün olmayacak şekilde güncellenmesi - yok edilmesi - için kullanılır.

Kişisel Verileri Anonimleştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kişisel Verilerin Anonimleştirilmesi Ekranı |  |
| --- | --- |
| Kayıt Tipi | İşlem yapılması istenen kayıt tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile kayıt tipleri arasından seçim yapılır. |
| Tip | Kişisel verileri anonimleştirmek için tip kısıdının verildiği alandır. Hepsi, Satıcı, Toptancı, Alıcı , Kefil, Müstahsil veya Diğer seçenekleri arasından seçim yapılır. |
| Cari Kodu | Anonimleştirme yapılacak kayıt tipi için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |

| İlçe/İl | Anonimleştirme yapılacak kayıt tipi için ilçe ve il kısıtlarının verildiği alanlardır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, ilçe/il kodları arasından seçim yapılır. |
