# İletişim İzin Kayıtları

İletişim İzin Kayıtları; Cari Hesap, Kullanıcı, Diğer e-Posta ve Diğer Cep Telefonu kayıt tiplerine istinaden izin kod tanımlamalarının yapıldığı bölümdür. İletişim İzin Kayıtları, geçerlilik durumları dikkate alınarak iletişim kontrollerinin yapılmasını sağlar.

İletişim İzin Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İletişim İzin Kayıtları Ekranı |  |
| --- | --- |
| Kayıt Tipi | İletişim izin kaydı yapılan kayıt tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile Cari Hesap, Kullanıcı, Diğer e-Posta ve Diğer Cep Telefonu seçenekleri arasından seçim yapılır. |
| Cari Hesap Kodu | "Kayıt Tipi" alanında "Cari Hesap" seçildiğinde aktif hale gelen alandır. İlgili cari hesap kodunun girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıtlı cari hesap kodlarına ulaşılır. |
| Kullanıcı Kodu | "Kayıt Tipi" alanında "Kullanıcı" seçildiğinde aktif hale gelen alandır. İlgili kullanıcı kodunun girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıtlı kullanıcı kodlarına ulaşılır. |
| Diğer e-Posta | "Kayıt Tipi" alanında "Diğer e-Posta" seçildiğinde aktif hale gelen alandır. İlgili mail adresinin girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıtlı mail adreslerine ulaşılır. |
| Diğer Cep Telefonu | "Kayıt Tipi" alanında "Diğer Cep Telefonu" seçildiğinde aktif hale gelen alandır. İlgili telefon numarasının girilmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıtlı telefon numaralarına ulaşılır. |
| İzin Kodu | İletişim izin kaydı için izin kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kayıtlı izin kodlarına ulaşılır. |
| İzin Durumu | İletişim izin kaydı için izin durumu bilgisi girilen alandır. Alanın sağ tarafında yer alan "Var" veya "Yok" seçenekleri arasından seçim yapılır. |
| İzin Alma Tarihi | İznin alındığı tarihin girildiği alandır. |
| İzin Alma Şekli | İzin alma şeklinin girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile izin alma şekilleri arasından seçim yapılır. |
| Başlangıç/Bitiş Tarihi | İznin başlangıç ve bitiş tarihinin girildiği alandır. |
| Açıklama | İletişim izin kaydı için açıklama bilgisi girilen alandır. |
| İzin Alan Kullanıcı | İzni alan kullanıcı kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kullanıcı kodları arasından seçim yapılır. |
| ![](../../../../../_assets/d6cbb20d49ea57fae10a.png) Hızlı İzin Ekleme | İletişim izin kaydı ile yapılan tanımlamalar doğrultusunda grid ekrana hızlı izin ekleme yapılarak kayıt aktarılmasını sağlayan butondur. Görüntülenen "Hızlı İzin Ekleme" ekranından seçim yapılabilir. ![](../../../../../_assets/c321fda606b53706cbe3.png) |
| ![](../../../../../_assets/8c4d1a98ddd3a2aae366.png) İzin Kopyala | İletişim izin kaydı ile ilgili yapılan tanımlamalar doğrultusunda grid ekrana alan kopyalama yapılarak kayıt aktarılmasını sağlayan butondur. Görüntülenen "İzin Kopyalama" ekranından seçim yapılır. |
| ![](../../../../../_assets/edcac381092e0ea52663.png) Belge Ekle | Grid ekrana gelen kaydın üzerine fare ile çift tıklanarak ilgili kayıt için belge eklenmesini sağlar. ![](../../../../../_assets/c27def087598845d801d.png) |
| ![](../../../../../_assets/e2319b11ac4b94830879.png) Mail İle Onay Al | Grid üzerinden seçilen iletişim izin kaydı için mail ile onay alınmasını sağlayan butondur. İlgili dizaynın tanımlanması için, "Dizayn" modülünden "KVKK Onay Basımı" dizayn tipinin seçilmesi ve ilgili dizaynın "Görsel Dizayn" olması zorunludur. Bu şekilde tanımlanan dizaynlar "Mail İle Onay Al" sistemi için kullanılır. "Mail İle Onay Al" butonuna tıklanması ile ekrana gelen "Dizayn Sorgulama" ekranından "Dizayn Adı" seçilerek "Tamam" butonuna tıklandığında, ilgili Cari'ye/Kullanıcı'ya mail gönderilerek online onay alınması sağlanır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydedilen cari kod işletme ve şubelerde ortak bir cari ise, yapılan tanımlamaların tüm işletme ve şubelerde geçerli olup olmayacağı, gelen uyarı ekranında "Evet" yanıtına tıklanarak seçilir. "Hayır" butonuna tıklanması halinde, tanımlama yapılan şube için iletişim izin kaydı oluşturulur. İletişim izin kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
