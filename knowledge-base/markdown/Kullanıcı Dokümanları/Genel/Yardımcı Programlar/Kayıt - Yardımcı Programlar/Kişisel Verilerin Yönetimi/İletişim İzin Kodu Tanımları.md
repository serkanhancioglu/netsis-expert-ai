# İletişim İzin Kodu Tanımları

İletişim İzin Kodu Tanımları, izin kod tanımlamalarının yapılmasını sağlayan bölümdür. Önceden belirlenen izin kod tanımlamaları program tarafından grid ekrana otomatik olarak getirilir.

"S" ile başlayan kodlar kullanıcı tarafından silinemez.

İletişim İzin Kodu Tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İletişim İzin Kodu Tanımları Ekranı |  |
| --- | --- |
| İzin Kodu | Tanımlaması yapılacak izin kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, önceden tanımlanan izin kodlarına ulaşılır. |
| İzin Açıklama | İzin kodu açıklamasının girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. İletişim İzin Kodu Tanımları kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
