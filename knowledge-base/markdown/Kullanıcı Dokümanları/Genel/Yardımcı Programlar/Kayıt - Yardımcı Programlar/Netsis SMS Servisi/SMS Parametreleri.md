# SMS Parametreleri

SMS Parametreleri, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. SMS Parametreleri, SMS uygulamasının kullanılması için gerekli tanımlamaların yapıldığı bölümdür.

![](../../../../../_assets/ec705d0c997b100d6f02.png)

SMS Parametreleri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| SMS Parametreleri Ekranı |  |
| --- | --- |
| SMS Uygulaması Var | SMS uygulamasının aktif hale gelmesi için kullanılan parametredir. |
| SMS Kullanıcı Adı | e-Logo’dan alınan kullanıcı adının girildiği alandır. |
| SMS Şifre | e-Logo’dan alınan şifrenin girildiği alandır. |
| Gönderen (Originator) | SMS gönderenin tanımlandığı alandır. |
| Gönderen Tel No | SMS’in gönderilecek telefon numarasının tanımlandığı alandır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. Gerekli tanımlamalar yapılıp Tamam ![](../../../../../_assets/39d77b8716226638d9ce.jpg) butonuna basıldığında, SMS uygulaması ile ilgili olarak, Yardımcı Programlar → Kayıt → Netsis SMS Servisi → "Serbest SMS Gönderme" ve "SMS Durum İzleme" bölümleri ile Cari → Kayıt → Cari İrtibat Bilgileri → "SMS Gönder" seçeneği aktif hale gelir. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
