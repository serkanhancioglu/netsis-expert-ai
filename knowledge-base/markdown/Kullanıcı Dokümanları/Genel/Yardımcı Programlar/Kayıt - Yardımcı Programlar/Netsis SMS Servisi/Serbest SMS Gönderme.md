# Serbest SMS Gönderme

Serbest SMS Gönderme, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Serbest SMS Gönderme, istenen herhangi bir metnin serbest olarak girilmesini ve burada belirlenen telefonlara gönderilmesini sağlayan işlemdir.

![](../../../../../_assets/2c730eb783a6c0225afe.png)

Serbest SMS Gönderme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Serbest SMS Gönderme Ekranı |  |
| --- | --- |
| ![](../../../../../_assets/b5e5eba18802c1e53d95.png) Bakiye Sorgula | [SMS Parametreleri](<SMS Parametreleri.md>) bölümünde tanımlanan hesap bilgilerinin ve kalan kontör sayısının gösterilmesini sağlayan butondur. ![](../../../../../_assets/f8206e233a72924ee153.png) |
| Mesajınızı Giriniz | Mesaj olarak gönderilmesi istenen metnin girildiği bölümdür. |
| Gönderim Zamanını Belirtiniz | Mesajın gönderileceği zamanın seçildiği alandır. "Hemen Gönder" veya "İleri Tarihte Gönder" seçenekleri arasından seçim yapılır. |
| Mesaj Gönderilecek Numaraları Giriniz | Gönderim yapılacak bilgilerin girildiği bölümdür. Bu bilgiler elle, hazır bir Excel dosyası ile, önceden kaydedilen bir şablon ile veya Cari İrtibat Bilgileri ekranından aktarılabilir. |
| Şablon Adı | Cep telefonu rehberi kullanılarak şablon adının girilmesini sağlayan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cep telefonu rehberine ulaşılır. |
| ![](../../../../../_assets/bbefb7feb27e5da5e733.png) Yeni Şablon | Gönderim yapılacak telefon numaralarının gruplanarak kaydedilmesini sağlayan butondur. Bir sonraki gönderimde bu şablon seçilerek, daha önceden kaydedilen bu numaraların ekrana otomatik olarak getirilmesini sağlar. Böylece, aynı tip mesajlar için aynı gruptaki numaraların tekrar tekrar girilmesine gerek kalmaz. |
| ![](../../../../../_assets/d6b5bb93dc33d1bf7f7d.png) Sil | Girilen telefon kaydının silinmesini sağlayan butondur. |
| ![](../../../../../_assets/2a46b7fe64e9fa18f7f7.png) Güncelle | Girilen telefon kaydının güncellenmesini sağlayan butondur. |
| ![](../../../../../_assets/0ecafa078c592e03d863.png) Listeyi Temizle | Girilen tüm telefon kayıtlarının listeden silinmesini sağlayan butondur. |
| ![](../../../../../_assets/94e744e886995781ecae.png) Dosyadan Al | Telefon kayıtlarının hazır bir dosyadan aktarılması için kullanılan butondur. |
| Telefon | SMS gönderilecek telefon numarasının girildiği alandır. Telefon numarası, başında sıfır olmadan 10 karakter uzunluğunda girilir. Yanlış şekilde girildiğinde program uyarı verir. ![](../../../../../_assets/0b7399e1405e5dfc8040.png) |
| ![](../../../../../_assets/aeb6028385a65e5a0ca2.png) Gönder | Girilen bilgilere göre SMS gönderilmesi için kullanılan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
