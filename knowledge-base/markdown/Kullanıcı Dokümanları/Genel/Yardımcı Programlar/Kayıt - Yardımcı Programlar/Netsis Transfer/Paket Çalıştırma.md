# Paket Çalıştırma

Paket Çalıştırma, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. "Şablon Hazırlama" bölümünden hazırlanan şablonun çalıştırılması için kullanılan bölümdür. "Şablon Hazırlama" bölümünde yapılan "Sakla/Yükle" seçimine göre oluşturulan şablon ile, bilgilerin program içine aktarılması veya program dışına gönderilmesi sağlanır.

![](../../../../../_assets/011dc00839bff0742c92.png)

Paket Çalıştırma ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Paket Çalıştırma Ekranı |  |
| --- | --- |
| Şablon Adı | Paket çalıştırma işlemi için şablon adı girilen alandır. Şablon adı direkt girileceği gibi, Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) kullanılarak da seçilebilir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
