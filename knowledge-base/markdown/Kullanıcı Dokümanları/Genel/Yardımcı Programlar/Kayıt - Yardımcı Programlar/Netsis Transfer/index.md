# Netsis Transfer

Netsis Transfer, Netsis veritabanlarındaki nesneler -tablo, view- için şablonlar tanımlayarak bilgi yüklenmesi veya şablonları kullanarak bilgileri dışarıya alınması, veritabanındaki tablolara ait bilgilerin başka bir veritabanına kopyalanması gibi işlemlerin SQL bilgisi gerekmeden yapılmasını sağlayan bölümdür.

Netsis Transfer; Şablon Hazırlama, Paket Çalıştırma, Tablodan Tabloya Kopyalama, Şablon Sakla/Yükle alt menülerinden oluşur.
