# e-Posta Başlık Bilgileri

e-Posta Başlık Bilgileri, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır.

![](../../../../_assets/388c4b209f1b891a33db.png)

e-Posta Başlık Bilgileri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| e-Posta Başlık Bilgileri Ekranı |  |
| --- | --- |
| Firma Unvanı | "E-Posta Uygulamasının" kullanıldığı yerlerde, yapılan işlemler sonucu gönderilen e-Postalarda, görünmesi istenen firma unvanının girildiği alandır. Girilen unvan, gönderilen tüm e-Postalarda başlık olarak kullanılır. "e-Posta Uygulaması" ile ilgili detaylı bilgi için; Cari → Kayıt → [Cari İrtibat Bilgileri](<../../../Finans/Cari/Kayıt - Cari/Cari İrtibat Bilgileri.md>) ve Kullanıcı İşlemleri → Kayıt → [Kullanıcı e-Posta Tanımları](<../../Kullanıcı İşlemleri/Kayıt/Kullanıcı e-Posta Tanımları.md>) dokümanına bakılabilir. |
| Link Adresi | Kullanıcıya gönderilen e-Postadan, ilgili maili gönderen firmanın web sayfasına bağlanmasını sağlayacak link adresinin girildiği alandır. Boş bırakılabilir. |
| Link Başlığı | Link adresi girilmişse, giden e-Postada link adresinin başlığı olarak görülecek bilginin girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
