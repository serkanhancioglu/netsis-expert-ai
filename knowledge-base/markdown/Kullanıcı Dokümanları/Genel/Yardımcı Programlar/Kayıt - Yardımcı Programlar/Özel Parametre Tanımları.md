# Özel Parametre Tanımları

Özel Parametre Tanımları, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Özel Parametre Tanımları, programda parametreye bağlı özel işlemlerin yapılması için tanımlama yapılmasını sağlayan bölümdür. Özel Parametre Tanımları bölümünde girilen değerlere göre aktif hale gelen bazı uygulamalar için, girilen değerlerin büyük ya da küçük harfle girilmesi önem taşır. Çünkü, tanımlamada yapılan bir yanlışlık, uygulamanın çalışmayacağı anlamına gelir.

![](../../../../_assets/04b44d569d8978562adc.png)

Özel Parametre Tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | Özel parametre için grup kodu tanımlaması yapılan alandır. |
| Anahtar | Özel parametre için anahtar tanımlaması yapılan alandır. |
| Değer | Özel parametre için değer girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Özel Parametre Tanımları kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
