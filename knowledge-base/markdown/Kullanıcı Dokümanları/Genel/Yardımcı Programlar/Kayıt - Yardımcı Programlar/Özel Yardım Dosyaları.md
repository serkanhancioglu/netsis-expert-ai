# Özel Yardım Dosyaları

Özel Yardım Dosyaları, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Özel Yardım Dosyaları ekranında girilen Modül No, Program No ve Yardım Dosyası alanları sayesinde, ilgili bölüm içinde - klavyedeki CTRL tuşu ile beraber F1 tuşuna basıldığında - kullanıcı tarafından yazılan ve eklenen yardım dosyasının ekrana gelmesini sağlar.

![](../../../../_assets/25932e8a6664723d77a7.png)

Özel Yardım Dosyaları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Özel Yardım Dosyaları Ekranı |  |
| --- | --- |
| Modül No | Özel yardım dosyasının ilişkili olduğu modül numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile modüller arasından seçim yapılır. |
| Program No | "Modül No" alanında seçilen modüle bağlı bölüm seçiminin yapıldığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, bölümler arasından seçim yapılır. |
| Yardım Dosyası | Özel hazırlanan doküman dosyasının yüklendiği alandır. Yükle ![](../../../../_assets/f5494a9691693fdb71d7.png) butonu ile hazırlanan dosya yüklenir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Özel Yardım Dosyaları kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
