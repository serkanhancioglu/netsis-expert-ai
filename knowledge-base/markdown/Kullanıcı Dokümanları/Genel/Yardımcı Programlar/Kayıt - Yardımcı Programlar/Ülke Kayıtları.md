# Ülke Kayıtları

Ülke Kayıtları, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Ülke Kayıtları, Cari → Kayıt → Cari Hesap Kayıtları, Banka → Kayıt → Banka Şube Kayıtları, Yardımcı Programlar → Kayıt → Şirket/Şube/Parametre Tanımları gibi bazı bölümlerde sorgulanan ülke kayıtlarının girilmesini ve izlenmesini sağlayan bölümdür. Ülke Kayıtları bölümünden girilen ülke kodları, modül menülerinde sorgulanan "Ülke Kodu" rehberinde ekrana gelir ve kullanıcı, bu rehber yardımıyla ülke kodlarını listeleyerek seçim yapar. Yeni bir şirket tanımlandığı zaman, ülke kodları program tarafından tanımlı halde gelir. Kullanıcı, istediği zaman aşağıdaki ekran yardımı ile, olmayan ülke kodlarını ekleyebilir.

![](../../../../_assets/a3a084d671e6e77496cb.png)

Ülke Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ülke Kayıtları Ekranı |  |
| --- | --- |
| Ülke Kodu | Kaydı yapılacak ülke için kod bilgisi girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, ülke kodlarına ulaşılır. |
| Telefon Kodu | Kaydı yapılacak ülkenin telefon kodunun girildiği alandır. |
| Ülke İsmi | Kaydı yapılacak ülke isminin girildiği alandır. |
| İngilizce Ülke Adı | Kaydı yapılacak ülkenin ingilizce adının girildiği alandır. |
| Beyanname Kodu | Kaydı yapılacak ülke için beyanname kodu tanımlanan alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Ülke kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
