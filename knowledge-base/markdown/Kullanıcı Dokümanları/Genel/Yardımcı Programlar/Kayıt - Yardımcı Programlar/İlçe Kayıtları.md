# İlçe Kayıtları

İlçe Kayıtları, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. İlçe Kayıtları, Cari → Kayıt → Cari Hesap Kayıtları gibi bazı bölümlerde sorgulanan ilçe kayıtlarının girilmesini ve izlenmesini sağlayan bölümdür. İlçe Kayıtları bölümünden girilen ilçe kodları, modül menülerinde sorgulanan ilçe kodu rehberinde ekrana gelir ve kullanıcı bu rehber yardımıyla ilçe kodlarını listeleyerek seçim yapar. Yeni bir şirket tanımlandığı zaman, ilçe kodları program tarafından tanımlı halde gelir. Kullanıcı, istediği zaman aşağıdaki ekran yardımı ile, olmayan ilçe kodlarını ekleyebilir.

"İlçe Kayıtları" ekranından, "İlçe Kodu" dışında Ülke Kodu, Şehir Kodu ve İlçe Adı bilgileri izlenebilir.

![](../../../../_assets/d1320bea4c46b251a9cf.png)

İlçe Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İlçe Kayıtları Ekranı |  |
| --- | --- |
| İlçe Kodu | Kaydı yapılacak ilçe için kod bilgisi girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, ilçe kodlarına ulaşılır. |
| Ülke Kodu | Kaydı yapılacak ilçenin bulunduğu ülkenin kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, ülke kodlarına ulaşılır. |
| Şehir Kodu | Kaydı yapılacak ilçenin bulunduğu şehrin kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, şehir kodlarına ulaşılır. |
| İlçe Adı | Kaydı yapılacak ülke isminin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. İlçe kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
