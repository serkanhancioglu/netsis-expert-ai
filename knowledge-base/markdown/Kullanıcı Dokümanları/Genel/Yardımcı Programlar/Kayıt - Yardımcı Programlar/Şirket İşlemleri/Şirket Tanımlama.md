# Şirket Tanımlama

Şirket Tanımlama, Genel Bölümü'nde, "Kayıt/Yardımcı Programlar" menüsünün altında yer alır. Şirket Tanımlama, yeni bir şirket açmak için kullanılan bölümdür. Şirket Tanımlama, yeni açılan şirkette bilgi dosyalarının bir kısmının (kullanıcılar ve hakları) kopyalanmasını sağlar. Fakat, bir çok bilgi dosyası yeni açılan şirkete girilerek yapılan tanımlamalar sonucu oluşur. "Şirket Tanımlama" işlemi tamamlandıktan sonra, programın ana araç çubuğu bölümünde bulunan "Şirket Değişikliği" seçeneği kullanılarak yeni açılan şirkete geçilmesi sağlanır.

![](../../../../../_assets/0622cdbef71bee4220da.png)

Şirket Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Şirket Tanımlama Ekranı |  |
| --- | --- |
| Şirket Adı | Tanımlanacak yeni şirket için isim girilen alandır. Açılan şirkete bu isim ile ulaşılır. Şirket açılırken tanımlanan şirket kodu içinde Türkçe Ç,Ğ,İ,Ö,Ü harfleri, özel karakterler (\*,/,vb.) ve boşluk kullanılmaması gerekir. Boşluk yerine (\_) alt çizgi kullanılabilir. |
| MSSQL Data Dizini | Tanımlanan yeni şirket datalarının fiziksel olarak hangi dizinde oluşacağının görülmesini sağlayan alandır. Datanın oluşacağı dizin, program tarafından otomatik olarak aktarılır. Sunucu üzerinde, ilgili diskte yer kalmaması gibi zorunlu olmayan durumlar dışında, program tarafından getirilen dizine müdahale edilmemesi gerekir. |
| NT Server Adı | Program üzerinde çalışan sunucu adının izlendiği alandır. Sunucu ismi program tarafından otomatik olarak aktarılır. |
| Yıl | İçinde bulunulan cari yılın program tarafından otomatik olarak aktarıldığı alandır. Gerekli olmadıkça müdahale edilmemesi gerekir. Şirket yılı 2005 ve daha büyük olduğu durumlarda tüm hesaplamalar YTL’ye göre yapılır. 2005 yılında iken, daha önceki yıllara ait bir şirket tanımlanması için, hesaplamaların YTL’ye göre değil TL’ye göre yapılması sebebi ile "Yıl" alanının eski yıl bilgisi ile değiştirilmesi gerekir. |
| DB Update Dizini | DB Update dosyalarının bulunduğu dizinin izlendiği alandır. Program tarafından otomatik olarak aktarılır. Şirket açma işlemi tamamlandıktan sonra Db Update işlemi program tarafından otomatik olarak yapılır. Db Update dosyaları gösterilen dizinden başka bir yere taşınmışsa veya değiştirilmesi isteniyorsa, alanın sağ tarafında yer alan Yükle/Sakla ![](../../../../../_assets/4405f44b9131d916091d.png) butonuna tıklanarak Db Update dizini değiştirilebilir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
