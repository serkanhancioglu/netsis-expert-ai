# Diğer

Diğer menüsü; Yardım, Program Bilgisi, Logo Portal Giriş, Netsis Çözümlerine Ulaşın, Logo Fırsatlar Dünyası, Dosya Sürümleri, Tanıtım Turu, Ön Tanımlı Masaüstleri ve Klavye Kısayolları Listesi seçeneklerinden oluşur.

Diğer menüsünde yer alan seçenekler ve içerdiği bilgiler şunlardır:

| Diğer Menüsünde Yer Alan Seçenekler |  |
| --- | --- |
| Yardım | Kullanıcı dokümanına ulaşılmasını sağlayan genel yardım seçeneğidir. Modül menülerinde ilgili modülü içeren bilgilere ulaşılmasını sağlar. Geliştirilmiş kullanım imkanı ile yardım ekranında modül bazında bilgi arama ya da kelime arama yapılabilir. Yardım bilgilerine, modüllerin alt menü ekranlarında F1 yardım tuşu ve [https://polaris.logo.cloud/](https://polaris.logo.cloud/) adresinden erişim sağlanır. Ayrıca, tüm modüllerin rapor ekranlarında F1 tuşu dışında, rapor ekranlarında bulunan Yardım ![](../../../_assets/4ad6cc61ca2c42a19c85.jpg) butonlarına tıklanarak da erişim sağlanabilir. |
| Program Bilgisi | Program sürümü ve diğer program bilgilerinin alınmasını ve lisans sözleşmesinin görüntülenmesini sağlayan seçenektir. İçinde bulunulan şirketin ismi, dizini, veritabanı adı ve tipi, şube sayısı, şube kodu, program sürümü, Logo Netsis kullanıcısı ve diğer bazı ek bilgilerin izlenmesi için kullanılır. |
| Logo Portal Giriş | Kullanıcıların, mevcut lisanslarını ve LEM sözleşme detaylarını izlemesini, Logo'daki yenilikleri takip etmesini, yeni destek talebi oluşturmasını ve önceden oluşturulan taleplerin sonucunu takip etmesini sağlayan seçenektir. |
| Netsis Çözümlerine Ulaşın | Logo Netsis’in İstek-Cevap servisine bağlanarak program ile ilgili istek girişi yapılmasını ve Logo Netsis’e bildirilen istek bilgilerine ulaşılmasını sağlayan seçenektir. Girilen isteklerin tamamlanıp tamamlanmadığı buradan takip edilir. Seçeneğin aktif olarak gelmesi için, programa giriş yapan kullanıcının "Admin" olarak belirlenmesi ve istek girişi yapılacak bilgisayarın internet bağlantısının olması, firma istek girişi yapacak şekilde yetkilendirilmesi gerekir. İstek-Cevap servisi ile ilgili yetkilendirme için, servis aldığınız Logo Netsis iş ortağına başvurulması gerekir.<br>Kullanıcının "Admin" olarak tanımlanması ile ilgili detaylı bilgi için; Kullanıcı İşlemleri → Kayıt → [Kullanıcı Grup Kayıtları](<../../Genel/Kullanıcı İşlemleri/Kayıt/Kullanıcı Grup Kayıtları.md>) |
| Logo Fırsatlar Dünyası | Logo müşterilerinin faydalanacağı [https://www.logofirsatlardunyasi.com.tr/](https://www.logofirsatlardunyasi.com.tr/) linkine erişilmesini sağlayan seçenektir. |
| Dosya Sürümleri | Kullanılan paketin dosya sürümlerine ulaşılmasını sağlayan seçenektir. |
| Tanıtım Turu | Masaüstü kullanımının kısa bir tanıtımı yapılarak kullanıcının bilgilendirilmesini sağlayan seçenektir. |
| Ön Tanımlı Masaüstleri | Öndeğer masaüstü seçiminin yapılmasını sağlayan seçenektir. Kullanıcının rolüne uygun masaüstü seçilir. |
| Klavye Kısayolları Listesi | Sistemde kullanılan klavye kısayolları listesinin görüntülenmesini sağlayan seçenektir. ![](../../../_assets/eef3d770c720f9ec662a.png) |
