# Bilgi Gönderimi

Grid ekranlarındaki bilgiler, özel çalışmalara gerek kalmadan Excel, Word, Writer programlarına aktarılabilir.

Logo Netsis programının tüm modüllerindeki grid ekranlardan Excel programına veri aktarımı yapılabilir.

![](../../../../../_assets/9e45d735d66cea903fcd.png)

Her grid ekranda "Excel" programına aktarma işlemi, farenin sağ tuşuile ekrana gelen özel seçenekler arasında yer alır. “Gönder” seçeneği ile ekrana gelen uygulama ile veriler "Excel" tablosuna aktarılır. Böylece bilgiler üzerinde, diğer uygulamanın özelliklerinden faydalanılarak istenen düzenlemenin yapılması sağlanır.
