# Dinamik Depo-Sayım Girişi

Sayım Girişi, hücrelerdeki ürünlerin sayım sonuçlarının girildiği bölümdür.

![](../../../../../_assets/5374b0dfbb45283866fd.png)

Hücre Sayım Girişi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Hücre Sayım Girişi Ekranı |  |
| --- | --- |
| Tarih | Sayımın yapıldığı tarihin girildiği alandır. Sayımlar, tarih bazında saklandığı için farklı tarihli pek çok sayım girilebilir. |
| Hücre Kodu | Sayım yapılan hücre kodunun girildiği alandır. Rehber butonu ile hücre kodlarına ulaşılır. |
| Stok Kodu | Belirlenen hücre kodunda, sayımı yapılan stok kodunun girildiği alandır. Rehber butonu ile stok kodlarına ulaşılır. |
| Sayım Miktarı | İlgili stokun sayım sonucunun girildiği alanadır. |
| Proje Kodu | Sayım miktarlarının proje kodu bazında girilmesi için kullanılan alandır. Yardımcı Programlar → Kayıt → Şirket - Şube Parametreleri → “Proje Uygulaması Var” parametresini işaretlenmesiyle aktif hale gelen alandır. Boş bırakılmaz. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
