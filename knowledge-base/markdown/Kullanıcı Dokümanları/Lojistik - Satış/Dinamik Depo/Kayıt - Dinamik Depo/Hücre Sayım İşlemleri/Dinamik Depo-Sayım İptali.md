# Dinamik Depo-Sayım İptali

Sayım İptali, belli bir tarihte girilmiş olan sayım bilgilerinin silinmesi amacıyla kullanılan bölümdür.

![](../../../../../_assets/da6f61b830cc225a7268.png)

Hücre Sayım İptali ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Sayım İptali Ekranı |  |
| --- | --- |
| Sayım Tarihi | Sayım bilgileri silinecek olan sayım tarihinin girildiği alandır. |
| Hücre Kodu | Sayım bilgisi silinecek olan hücreler için, aralık tanımlaması yapılan alandır. Rehber butonu ile hücre kodlarına ulaşılır. Boş bırakılırsa, hücre koduna bakılmaksızın girilen tarihteki tüm sayımlar silinir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
