# Hücre Sayım İşlemleri

Hücre Sayım İşlemleri, Dinamik Depo-Kayıt menüsünün altında yer alır. Hücre Sayım İşlemleri, depolardaki hücrelere ait sayım işlemlerinin yapıldığı bölümdür. Stok parametrelerinde "Detaylı sayım sistemi kullanılsın" parametresi işaretli ise, Stok modülü altındaki Sayım Girişi ekranından hücre sayım girişleri yapılabilir. "Detaylı sayım sistemi kullanılsın" parametresi kullanıldığında, Dinamik Depo modülünde sadece Sayım Bağlantısız Bakiye Sıfırlama işlemi çalıştırılabilir. Detaylı stok sayım parametresi kullanılmıyorsa, hücre sayım işlemleri Dinamik Depo modülü altından gerçekleştirilir.
