# Hücre Toplama

Hücre Toplama, Dinamik Depo-Kayıt menüsünün altında yer alır. Hücre Toplama, satış veya ambardan çıkış durumunda, hücrelerden toplama işleminin yapıldığı bölümdür. Hücre Toplama bölümde yapılan işlemler, ekran üzerinde yer alan alanlar ve içerdiği bilgiler Hücre Yerleştirme bölümüyle aynıdır.
