# Hücreler Arası Transfer

Hücreler Arası Transfer, Dinamik Depo-Kayıt menüsünün altında yer alır. Hücreler Arası Transfer, herhangi bir hücredeki ürünün, bir başka hücreye transferi amacıyla kullanılır.

![](../../../../_assets/e0ed1c4c87571ef27287.png)

Hücreler Arası Transfer ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Hücreler Arası Transfer Ekranı |  |
| --- | --- |
| Stok Kodu | Başka bir hücreye transfer edilecek stok kodunun girildiği alandır. |
| Kaynak Hücre Kodu | Transferi yapılacak stokun, yerleştirilmiş olduğu hücre kodunun girildiği alandır. |
| Virman İşlemi Yapılsın | Virman işleminin yapılması istendiğinde işaretlenmesi gereken seçenektir. |
| Kaynak Belge | Belirli bir belge kaydı için işlem gerçekleştirileceği zaman kullanılan alandır. |
| Miktar | Belirlenen stokun, transfer edilecek miktarının girildiği alandır. |
| Hedef Hücre Kodu | Belirlenen stokun, transfer edileceği hücre kodunun girildiği alandır. |
| Tarih | İşlemin gerçekleşeceği tarih bilgisinin girildiği alandır. |

Tamam butonu ile girilen bilgiler kaydedilir. İptal butonu, girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur.
