# Depo Kontrol Raporu

Depo Kontrol Raporu, Dinamik Depo-Raporlar menüsünün altında yer alır. Depo Kontrol Raporu, yerleştirme veya toplama işlemleri sırasında yapılan kayıtların, belge detayı ile listelerinin alınmasını sağlayan rapordur. Depo Kontrol Raporu; belge numarası, cari kodu, stok kodu, stok adı, miktar, hücre kodu, hücre giriş miktarı ve hücre çıkış miktarı başlıkları ile listelenir. Depo Kontrol Raporu; Genel Kısıtlar, Ölçekleme ve Yazıcı Seçenekleri sekmelerinden oluşur.

Depo Kontrol Raporu ekranı Genel Kısıtlar sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Depo Kontrol Raporu |  |
| --- | --- |
| Yerleştirme/Toplama | Raporun, yerleştirme mi yoksa toplama mı alınacağının belirlendiği alandır. |
| Belge No Aralığı | Raporun alınacağı belge numaralarına kısıt verilmesini sağlayan alandır. Rehber butonu ile belge numaralarına ulaşılabilir. |
| Cari Kod Aralığı | Raporun alınacağı cari hesaplara kısıt verilmesini sağlayan alandır. Rehber butonu ile cari kodlara ulaşılabilir. |
| Tarih Aralığı | Raporun alınacağı tarih için kısıt verilmesini sağlayan alandır. |
| ![](../../../../_assets/7ba39f9046a578093326.png) Rapor | Yukarıdaki alanlara girilen bilgiler doğrultusunda, rapor almak için kullanılan butondur. Butonun sağ tarafında yer alan aşağı ok tuşu, "Gelişmiş Rapor" seçeneğinin kullanılmasını sağlar. Kullanıcı, "Gelişmiş Rapor" seçeneği ile ekrana gelen tablo üzerinde hesaplama yapabilir. Bu seçenek sayesinde, 13684 satırın üstündeki raporlamaların da tek sayfa üzerinden raporlanması sağlanır. "Rapor" seçeneği Text Dosya, Excel Dosya, VTS Format, HTML kayıt türlerini desteklerken, "Gelişmiş Rapor" seçeneği Excel Workbook, Excel Template, Excel 97-2003 Workbook, Excel 97-2003 Template, Comma Delimited, Text Document, Web Page, XML Document, PDF Document kayıt türlerini destekler. |
| ![](../../../../_assets/e3223333470668512f5f.jpg) Oku | Daha önceden saklanan kısıtların aynısının ekrana getirilmesini sağlayan butondur. **Oku** butonu ile sadece "en son saklanan kısıtlar" ekrana getirilir. |
| ![](../../../../_assets/53859e19eb2737b88a17.jpg) Sakla | Verilen kısıtlar ve işaretlenen tüm seçeneklerin saklanması için kullanılan butondur. Rapor almak için kısıt verildikten sonra bu butona basıldığında, onaylama ekranı görüntülenir. Onaylama ekranında "Evet" butonuna basılması ile belirlenen kısıtlar bir sonraki stok hareket dökümü alma işleminde kullanılmak üzere saklanır. |
| ![](../../../../_assets/4ad6cc61ca2c42a19c85.jpg) Yardım | Rapor hakkında standart yardım bilgisi için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Rapor almak için verilen kısıtların iptal edildiği butondur. |

Ekranda yer alan diğer sekmelerin kullanımı, diğer modüllerin Raporlar menüsünde yer alan sekmeler ile aynıdır.
