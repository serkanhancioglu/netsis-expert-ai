# Yerleştirme/Toplama İptali

Yerleştirme/Toplama İptali, Dinamik Depo-İşlemler menüsünün altında yer alır. Yerleştirme/Toplama İptali, Kayıt menüsünde yer alan Hücre Yerleştirme veya Hücre Toplama adımlarıyla yapılan kayıtların iptal edilmesi için kullanılan bölümdür.

Yerleştirme/Toplama İptali ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Yerleştirme/Toplama İptali Ekranı |  |
| --- | --- |
| Yerleştirme/Toplama | İptal edilecek kaydın, yerleştirme mi yoksa toplama mı olduğunun belirlendiği alandır. |
| Kalemleri Getir | Verilen kısıtlara uygun kalem bilgilerinin, grid ekranına getirilmesi için kullanılan butondur. |
| Hepsini Seç | Grid ekranındaki kalemlerin işaretlenmesi için kullanılan butondur. Herhangi bir kalem seçilmeden işlem yapılamayacağı için; öncelikle Hepsini Seç butonu kullanılarak veya Satır Seç butonu ile tek tek seçerek, ya da fare ile iptal edilecek satır çift tıklanarak kalemlerin seçilmesi gerekir. |
| Hepsini Kapat | Daha önceden seçilmiş olan satırların iptal edilmesinden vazgeçilmesi durumunda kullanılan butondur. Seçilmiş olan tüm satırların işaretini kaldırır. |
| Satır Seç | Grid ekranında, üzerinde bulunulan bir satırın iptal edilmesi için kullanılan butondur. |
| Satır Kapat | Daha önceden seçilmiş ve grid ekranda üzerinde bulunulan bir satırın iptal edilmesinden vazgeçilmesi halinde kullanılan butondur. |
