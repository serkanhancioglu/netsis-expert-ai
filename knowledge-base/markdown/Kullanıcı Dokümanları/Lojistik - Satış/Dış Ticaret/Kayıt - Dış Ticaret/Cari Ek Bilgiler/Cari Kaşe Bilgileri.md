# Cari Kaşe Bilgileri

Cari Kaşe Bilgileri, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. İhracat belgeleri basımında, ilgili cari için kaşe bilgisi yazılması istendiği zaman cari kaşe bilgilerinin döviz tipi bazında kaydedilmesi için kullanılan bölümdür.

Cari Kaşe Bilgileri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Cari Kaşe Bilgileri Ekranı |  |
| --- | --- |
| Cari Kodu | Kaşe bilgisi girilecek cari kodun seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlara ulaşılır. |
| Döviz Tipi | Kaydedilen kaşe bilgisi için döviz tipinin girildiği alandır. Döviz Tipi alanına, Döviz Takibi → Döviz İsimleri Tanımlama bölümünde girilen Döviz Sıra Numarası'nın girilmesi gerekir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tiplerine ulaşılır. |
| Kaşe Bilgisi | Kaşe açıklamasının girildiği alandır. Kaydedilen kaşe bilgisi için istenen uzunlukta açıklama girişi yapılabilir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
