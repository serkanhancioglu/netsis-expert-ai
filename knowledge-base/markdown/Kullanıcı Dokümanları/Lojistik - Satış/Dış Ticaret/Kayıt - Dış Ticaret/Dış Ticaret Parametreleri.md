# Dış Ticaret Parametreleri

Dış Ticaret Parametreleri, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. Dış Ticaret modülü ile ilgili parametre tanımlarının yapıldığı bölümdür.

Dış Ticaret Parametreleri ekranı; İhracat Parametreleri ve İthalat Parametreleri olmak üzere iki sekmeden oluşur.

**İhracat Parametreleri**

Dış Ticaret Parametreleri ekranı İhracat Parametreleri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Dış Ticaret Parametreleri Ekranı |  |
| --- | --- |
| İhracat Uygulaması Tekliften Başlasın | İhracat uygulamasında takip edilecek sürecin satış teklif belgesinden başlaması için kullanılan parametredir. |
| İhracat Uygulaması Siparişten Başlasın | İhracat uygulamasında takip edilecek sürecin müşteri siparişinden başlaması için kullanılan parametredir. |
| İhracat Uygulaması İrsaliyeden Başlasın | İhracat uygulamasında takip edilecek sürecin satış irsaliyesinden başlaması için kullanılan parametredir. |
| Navlun Muhasebe Kodu | İhracat işlemlerinde girilen navlun tutarının muhasebeye yansıtılması için, ilgili muhasebe kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Sigorta Muhasebe Kodu | İhracat İşlemlerinde girilen sigorta tutarının muhasebeye yansıtılması için, ilgili muhasebe kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Masraf Dekont Seri | İhracat işlemlerinden sonra, program tarafından oluşturulacak genel dekont kayıtlarının seri numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, seri numaralarına ulaşılır. |
| Döviz Takibi Hangi Değerden Yapılsın | Dış Ticaret ile ilgili işlemlerde döviz takibinin yapılacağı değerin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile Fatura Parametrelerini Uygula, Döviz Alış, Döviz Satış, Efektif Alış ve Efektif Satış seçenekleri arasından seçim yapılır. |
| Dosya No Prefix | İhracat İşlemleri → Dosya İşlemleri bölümünde, her ihracat işlemi için bir dosya numarası verilir. Dosya numarası, bu alanda verilen Ön Kısım'dan (Prefix'den) türetilerek, program tarafından otomatik olarak ekrana getirilir. |
| Tekliften Ön Çeki Listesi Oluşturulsun | Parametre işaretlendiğinde, siparişte olduğu gibi, teklif oluşturulurken çeki listesi de oluşturulur. İhracat Dosya İşlemleri → Tekliflerim sekmesindeki "Tanımlı Çeki Listesini Aktar" seçeneği işaretlendiğinde, satış teklif girilirken oluşturulan çeki listesinin siparişe aktarılması sağlanır. |
| Siparişten Ön Çeki Listesi Oluşturulsun | Siparişten ön çeki listesi oluşturulması için kullanılan parametredir. |
| Çeki Listesinden İrsaliye Oluşturulsun | Çeki listesi oluşturulması adımında, çeki listesine bağlı olarak satış irsaliyesinin oluşturulması kullanılan parametredir. |
| İrsaliyeler Sevk Kontrol Numarasına Göre Oluşturulsun | İrsaliyelerin sevk kontrol numarasına göre oluşturulması için kullanılan parametredir. |
| Çeki Listesinde Hacim Kontrolü Yapılsın | Çeki listesinde hacim kontrolünün yapılması için kullanılan seçenektir. |
| Hacim Kontrolü İçin Kullanılacak Alan | Hacim kontrolü için kullanılacak alanın belirlendiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile seçim yapılır. |
| İptal Edilen İhracat Belgeleri İçin Log Tutulsun | İptal edilen proforma (Taslak) faturaların iptal edildi bilgisinin, dosya genel ekranında gösterilmesi için kullanılan parametredir. |
| Çoklu DİİB Uygulaması | Parametre işaretlendiğinde, Dış Ticaret → İşlemler → İhracat İşlemleri → Dosya İşlemleri ekranındaki "Detay Gösterme" ekranı üzerinde iken farenin sağ tuşu ile ekrana gelen menüden "DİİB Bilgi Girişi" ve "Kalem Detay Bilgileri" seçenekleri kullanılarak, bir kaleme birden fazla DİİB Numarası aktarılmasını sağlar. Parametre işaretli olduğunda, ilgili ekranlarda DİİB No rehberi yerine "Çoklu DİİB Girişi" ekranı açılarak birden fazla DİİB No seçimi yapılması sağlanır. |
| DİİB Bakiye Kontrolü Yapılsın | DİİB bakiye kontrolünün yapılması için kullanılan seçenektir. |
| Çeki Listesinden İrsaliye Oluşumunda Kümüle Edilsin | Çeki listesinden irsaliye oluşturulurken kümüle edilmesi için kullanılan parametredir. |
| Masraf Dekont Kayıtları Kümüle Edilsin | Cari Kodu, Vade Tarihi, Döviz Tipi, Referans Kodu, Proje Kodu ve Belge Türü aynı olan cari hareket kayıtlarının kümüle edilmesi için kullanılan parametredir. Dekont ve cari hareket kayıtlarına kümüle olarak atılır. |
| Kaynak Belge Kur Bilgileri Saklansın | Müşteri siparişinde otomatik olarak gelen kur bilgisi değiştirildiğinde ve dosya işlemlerinde siparişten proforma oluşturulduğunda, belgedeki kur bilgisinin aynı gelmesi için kullanılan parametredir. |
| Cari İhracat Bilgilerinde Komisyoncu Tip Kısıtları Kullanılsın | Parametre işaretlendiğinde, "Cari İhracat Bilgileri" ekranındaki cari rehberleri, "Komisyoncu Tanımları" ekranında belirtilen tiplere göre kısıtlanır. |
| İhracat Kapatmada Navlun ve Sigorta İçin Fiili Kur Kullanılsın | Parametre işaretlendiğinde; "İhracat Kapatma" işleminde sigorta ve nakliye tutarları, kapatma sırasında girilen fiili kur üzerinden hesaplanarak oluşturulur. |
| İhracat Kapatması Yapılan Dosyaların Durumu Kapalı Olsun | Parametre işaretlendiğinde; ihracat dosyasının içindeki tüm belgelerin kapatması yapıldığında, dosyanın durumu "Kapalı" olarak güncellenir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
