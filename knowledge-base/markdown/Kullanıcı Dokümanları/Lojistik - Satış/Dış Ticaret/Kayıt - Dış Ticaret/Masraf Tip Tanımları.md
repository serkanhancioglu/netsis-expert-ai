# Masraf Tip Tanımları

Masraf Tip Tanımları, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. Dış Ticaret modülünde kullanılacak masraf tiplerinin tanımlandığı bölümdür.

Masraf Tip Tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Masraf Tip Tanımları Ekranı |  |
| --- | --- |
| Masraf Kodu | Dış Ticaret giderleri için oluşturulacak masraflara ait kodun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, masraf kodlarına ulaşılır. |
| Masraf Grup Kodu | Masraf Kodu alanında girilen masraf kodlarını gruplamak için kullanılan alandır. |
| Muhasebe Kodu | Tanımlanan masraf koduna ait giderin aktarılacağı muhasebe kodunun tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodlarına ulaşılır. |
| Mal Bedeli Hesabı | Oluşan ithalat giderine ait, tanımlanan masraf kodunun mal bedeli olarak kullanılmasını sağlayan seçenektir. |
| Beyanname Masraflarında Gösterilsin | Tanımlanan masraf kodunun beyanname masraflarında gösterilmesi için kullanılan seçenektir. |
| KDV Oran | Tanımlanan masraf kodu için KDV oranının tanımlandığı alandır. |
| İndirilecek KDV'de Kullanılsın | Tanımlanan masraf kodunun indirilecek KDV'de kullanılması için işaretlenen alandır. |
| Açıklama | Tanımlanan masraf koduna ait açıklama bilgisinin girildiği alandır. |
| İthalat ve İhracat Ortak, Sadece İhracat, Sadece İthalat | Tanımlanan masraf kodunun kullanılacağı yerin belirlendiği alandır. İthalat ve İhracat Ortak, Sadece İhracat ve Sadece İthalat seçenekleri arasından seçim yapılır. |
| İşletmelerde Ortak | Tanımlaması yapılan masraf tiplerinin hangi işletmede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlaması yapılan masraf tiplerinin hangi şubede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile şube kodları arasından seçim yapılır. |
| Hariç Tutulacak Şube Tanımlamaları | "Hariç Tutulacak Şube Tanımlamaları" yazısının üzerine tıklandığında, mevcut şubeler içinde, hariç tutulması istenen şubeler için sol fare tuşu ile çift tıklanarak seçim yapılan alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
