# Paket Tanımları

Paket Tanımları, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. İthalat ve ihracat işlemleri sırasında sevk edilecek stokların nakliyesinde kullanılacak paket ve ambalaj tiplerinin tanımlandığı bölümdür. Paketler tanımlandıktan sonra paketler stoklarla çeki listesi üzerinde eşleştirilir.

Paket Tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Paket Tanımları Ekranı |  |
| --- | --- |
| Paket Kodu | Tanımlanan paket için programda kullanılacak kodun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile kodlara ulaşılır. |
| Açıklama | Tanımlanan paket için açıklama bilgisinin girildiği alandır. |
| Boş Ağırlık | Paketin boş ağırlığının girildiği alandır. |
| Grup Kodu | Tanımlanan paketlerin, sahip olduğu özellik bazında gruplanması için 10 karakter uzunluğunda, serbest kadının yapıldığı alandır. |
| Paket Markası | Tanımlanan paketin markasının girildiği alandır. |
| Paket Cinsi | Tanımlanan paketin cinsinin girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile, paket cinsleri arasından seçim yapılır. |
| Maksimum Ağırlık | Paketin taşıyabileceği maksimum ağırlık bilgisinin girildiği alandır. |
| Hacim | Paket hacminin tanımlandığı alandır. |
| Maksimum Adet | Pakete yerleştirilebilecek maksimum stok miktarının girildiği alandır. |
| İşletmelerde Ortak | Tanımlaması yapılan paketin hangi işletmede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlaması yapılan paketin hangi şubede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile şube kodları arasından seçim yapılır. |
| Hariç Tutulacak Şube Tanımlamaları | "Hariç Tutulacak Şube Tanımlamaları" yazısının üzerine tıklandığında, mevcut şubeler içinde, hariç tutulması istenen şubeler için sol fare tuşu ile çift tıklanarak seçim yapılan alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
