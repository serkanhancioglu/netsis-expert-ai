# Teşvik Bilgileri (DİİB)

Teşvik Bilgileri DİİB, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. Dahilde İşleme İzin Belgesine sahip firmaların, bu belge bilgilerini Gümrük Tarife Kodu ve DİİB numarası bazında tanımlama yapmaları için kullanılan bölümdür. Girilen bilgiler raporlama amaçlı kullanılır. Kullanıcılar DİİB kaydını; Grup kayıtları ile Grup-1 ve Grup-2 alanlarını kullanarak ilişkilendirebilir.

Teşvik Bilgileri DİİB ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Teşvik Bilgileri (DİİB) Ekranı |  |
| --- | --- |
| DİİB No | Dahilde İşleme İzin Belgesi numarasının tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, DİİB numaralarına ulaşılır. |
| Gümrük Tarife Kodu | Dahilde İşleme İzin Belgesi'ne sahip firmanın gümrük tarife kodunu tanımladığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, GTİP numaralarına ulaşılır. |
| Başlangıç/Bitiş Tarihi | DİİB'in başlangıç ve bitiş tarihinin girildiği alanlardır. |
| Belge Alış Tarihi | DİİB'in alış tarihinin girildiği alandır. |
| Miktar | DİİB miktarının tanımlandığı alandır. |
| Kullanılan Miktar | DİİB'in kullanılan miktarının tanımlandığı alandır. |
| Grup-1, Grup-2 | DİİB kaydı için Grup-1 ve Grup-2 tanımlaması yapılan alandır. |
| Açıklama | DİİB kaydı için açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
