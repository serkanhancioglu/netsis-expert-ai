# Teşvik Bilgileri (Yatırım)

Teşvik Bilgileri Yatırım, Lojistik/Satış Bölümü'nde, "Kayıt/Dış Ticaret Modülü" menüsünün altında yer alır.

Teşvik Bilgileri Yatırım ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Teşvik Bilgileri (Yatırım) Ekranı |  |
| --- | --- |
| Yatırım Teşvik No | Yatırım teşvik numarasının tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, yatırım teşvik numaralarına ulaşılır. |
| Gümrük Tarife Kodu | Gümrük tarife kodunun tanımladığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, GTİP numaralarına ulaşılır. |
| Başlangıç Tarihi/Bitiş Tarihi | Teşvik bilgilerinin başlangıç ve bitiş tarihinin girildiği alanlardır. |
| Belge Alış Tarihi | Teşvik bilgilerinin alındığı tarihin girildiği alandır. |
| Miktar | Teşvik bilgileri kaydı için miktar tanımlanan alandır. |
| Kullanılan Miktar | Teşvik bilgileri kaydı için kullanılan miktarın tanımlandığı alandır. |
| Grup-1, Grup-2 | Teşvik bilgileri kaydı için Grup-1 ve Grup-2 tanımlaması yapılan alandır. |
| Açıklama | Teşvik bilgileri kaydı için açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
