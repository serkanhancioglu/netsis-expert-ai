# Ödeme Açıklamaları

Ödeme Açıklamaları, Lojistik/Satış Bölümü'nde Kayıt/Dış Ticaret Modülü menüsünün altında yer alır. İthalat ve ihracat işlemlerinde kullanılacak olan ödeme tiplerinin ve bu tiplere ilişkin standart ödeme açıklamalarının tanımlandığı bölümdür. Kaydedilen ödeme açıklamaları dizayn ve evrak basımlarında kullanılır.

Ödeme Açıklamaları ekranı; Ödeme Tipleri ve Ödeme Açıklamaları olmak üzere iki sekmeden oluşur.

**Ödeme Tipleri**

Ödeme Açıklamaları ekranı Ödeme Tipleri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ödeme Açıklamaları Ekranı |  |
| --- | --- |
| Ödeme Tip | Ödeme tipi için kullanıcı tarafından belirlenen kodun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, ödeme tiplerine ulaşılır. |
| Açıklama | Ödeme tipine ait açıklamanın girildiği alandır. |
| Akreditif Tipli | Akreditif ödeme tipi için yapılan tanımlamada işaretlenmesi gereken seçenektir. Her bir ödeme tipi için açıklamalar, "Ödeme Açıklamaları" sekmesinden tanımlanır. |
| Uluslararası Ödeme Kodu | Ödeme tipi için uluslararası ödeme kodu tanımlanan alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile seçim yapılır. |
| İşletmelerde Ortak | Tanımlaması yapılan ödeme tipinin hangi işletmede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlaması yapılan ödeme tipinin hangi şubede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile şube kodları arasından seçim yapılır. |
| Hariç Tutulacak Şube Tanımlamaları | "Hariç Tutulacak Şube Tanımlamaları" yazısının üzerine tıklandığında, mevcut şubeler içinde, hariç tutulması istenen şubeler için sol fare tuşu ile çift tıklanarak seçim yapılan alandır. |

**Ödeme Açıklamaları**

Ödeme Açıklamaları sekmesi bilgileri aşağıdaki şekildedir:

| Ödeme Açıklamaları Ekranı |  |
| --- | --- |
| Ödeme Açıklama (TR) | Ödemeye ait Türkçe açıklamanın girildiği alandır. |
| Ödeme Açıklama (EN) | Ödemeye ait İngilizce açıklamanın girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
