# İhraç Kayıtlı Fatura Listesi Birim Eşleştirme

İhraç Kayıtlı Fatura Listesi Birim Eşleştirme, Lojistik/Satış Bölümü'nde, "Kayıt/Dış Ticaret Modülü" menüsünün altında yer alır. İhraç Kayıtlı Fatura Listesi Birim Eşleştirme; ihraç kayıtlı faturalarda kullanılacak temel ölçü birimlerinin, uluslararası ölçü birimleri ile eşleştirilerek kaydedilmesini sağlayan bölümdür. Grid ekranda yer alan ölçü birimlerinin içinden kullanılacak ölçü biriminin eşleştirileceği "Uluslar Arası Ölçü Birim Kodu" alanının üzerine gelerek çift tıklandığında, alanın sağ tarafında yer alan aşağı ok butonu ile, eşleştirilecek birim kodu seçilir. Seçilen kodun kaydedilmesi için Değişiklikleri Kaydet ![](../../../../_assets/f1c02c7398b15457bb27.png) butonuna tıklandıktan sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak değişiklik kaydedilir. Yapılan eşleştirmeyi iptal etmek için, iptal edilmesi istenen ölçü biriminin üzerine gelerek fare ile çift tıklandıktan sonra Eşleştirme İptali ![](../../../../_assets/82ad521f3f802f1adf31.png) butonuna tıklanır. Butona tıklanması ile ekrana gelen uyarı ekranına onay verildikten sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak iptal işlemi kaydedilir. Eşleştirme iptalinden veya yapılan eşleştirme kaydından vazgeçilmesi halinde ekrandan çıkmak için İptal ![](../../../../_assets/973111d004995dca0113.jpg) butonu kullanılır.
