# Eklenmiş Belgeleri Çıkar

Eklenmiş Belgeleri Çıkar, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. Dosya üzerine eklenmiş - Word, PDF, JPEG gibi - Ek Sertifika, Akreditif, Sözleşme gibi dosyaların toplu bir biçimde istenen klasöre aktarılması (Export edilmesi) için kullanılan bölümdür.

Eklenmiş Belgeleri Çıkar ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Eklenmiş Belgeleri Çıkar Ekranı |  |
| --- | --- |
| Cari kodu | Eklenmiş belgelerin çıkarılması için cari kod girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Dosya No | Eklenmiş belgelerin çıkarılması için dosya numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, dosya numaraları arasından seçim yapılır. |
| Açıklama | Aktarılacak belgeler için açıklama bilgisi girilen alandır. |
| Klasör Adı | Belgelerin aktarılacağı klasöre isim verilmesi için kullanılan alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Dosyaların dışarı aktarılmasını sağlayan butondur. |
