# Proforma Birleştirme

Proforma Birleştirme, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. Cari Kodu ve Dosya Numarası kısıtları verildiğinde, listelenen faturaların arasından seçim yapılarak yeni Dosya ve Fatura Numarası bilgileri ile, seçilen proformaların birleştirilmesini sağlayan bölümdür.

Proforma Birleştirme ekranı; Ön Sorgu ve Proforma Fatura Listesi sekmesinden oluşur.

**Ön Sorgu**

Proforma Birleştirme ekranı Ön Sorgu sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Proforma Birleştirme Ekranı |  |
| --- | --- |
| Cari Kodu | Proforma Fatura Birleştirme işlemi için cari kod kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Dosya No | Proforma Fatura Birleştirme işlemi için dosya numarası kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, dosya numaraları arasından seçim yapılır. |

**Proforma Fatura Listesi**

Proforma Birleştirme ekranı Proforma Fatura Listesi sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Proforma Birleştirme Ekranı |  |
| --- | --- |
| Dosya No | Proforma Fatura Birleştirme işleminin yapılacağı dosya numarasının tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, dosya numaraları arasından seçim yapılır. |
| Yeni Fatura Numarası | Proforma Fatura Birleştirme işleminin yapılacağı yeni fatura numarasının tanımlandığı alandır. |
| Fatura Tarihi | Proforma Fatura Birleştirme işleminin yapılacağı faturaya ait tarihin girildiği alandır. |
| Resmi Fatura Numarası | Proforma Fatura Birleştirme işleminin yapılacağı resmi fatura numarasının girildiği alandır. |
| Birleştirilen Proformalar Saklansın | Proforma Fatura Birleştirme işleminde, birleştirilen faturaların saklanması için kullanılan seçenektir. |
| ![](../../../../../_assets/8ee100bb345e8fa5da90.png) Seçili Proformaları Birleştir | Liste üzerinden seçilen proformaların birleştirilmesi için kullanılan butondur. |
