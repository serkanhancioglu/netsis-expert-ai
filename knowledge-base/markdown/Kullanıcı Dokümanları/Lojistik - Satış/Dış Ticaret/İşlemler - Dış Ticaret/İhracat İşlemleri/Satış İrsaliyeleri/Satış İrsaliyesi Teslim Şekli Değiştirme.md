# Satış İrsaliyesi Teslim Şekli Değiştirme

Satış irsaliyesinin teslim şeklinin hızlı bir şekilde değiştirilmesini sağlamak için kullanılan bölümdür.

Satış İrsaliyesi Teslim Şekli Değiştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Satış İrsaliyesi Teslim Şekli Değiştirme Ekranı |  |
| --- | --- |
| Cari Kod | Teslim şeklinin değiştirilmesi istenen satış irsaliyesinin bağlı bulunduğu cari kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Export Tipi | Grid ekran üzerinde listelenen irsaliyeler arasından seçim yapılarak, Export Tipi seçiminin yapıldığı alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile tipler arasından seçim yapılır. |
| ![](../../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Satış İrsaliyesi Teslim Şekli Değiştirme işleminin gerçekleştirilmesi için kullanılan butondur. |
