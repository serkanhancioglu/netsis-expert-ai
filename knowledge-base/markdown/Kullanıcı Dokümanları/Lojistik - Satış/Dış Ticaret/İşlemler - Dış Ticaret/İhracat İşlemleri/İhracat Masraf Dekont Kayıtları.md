# İhracat Masraf Dekont Kayıtları

İhracat Masraf Dekont Kayıtları, ihracatın kapatılması sürecinde oluşan masrafların sisteme hızlı girişinin sağlıklı şekilde yapılması için kullanılan bölümdür. Tanımlanmış olan masraf tipleri kullanılarak, ilgili ihracat faturalarına gelen ihracat masraflarının sisteme girilip dekontunun oluşturulduğu ekrandır. Bu ekran kullanılarak, bir ihracat işleminde oluşan - Örneğin; Gümrük Komisyoncu Faturaları - ihracat kaydı eşleştirilerek sisteme girilebilir. Dekontun üzerindeki "Export Ref. No." alanı üzerinden ilişkilendirilme işlemi gerçekleştirilir. Yeni dekont girmek için artı ![(plus)](../../../../../_assets/8bc1079dc378a6219e99.svg) butonuna tıklanır. Yeni dekont kaydı için ekran hazırlanır ve aynı şekilde eksi ![(minus)](../../../../../_assets/1b0d15e570bf80d3a5bb.svg) butonu ile, mevcut dekont kaydı sistemden silinir.

Muhasebe Parametreleri ekranında "İndirilecek KDV" uygulamasının açık olması durumunda; girilen masraf tipleri için İndirilecek KDV kullanımına göre dekont tamamlandıktan sonra, İndirilecek KDV uygulaması devreye girer.

İhracat Masraf Dekont Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İhracat Masraf Dekont Kayıtları Ekranı |  |
| --- | --- |
| Cari/Banka Kod | İhracat masrafına ait cari/banka kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Masraf Kodu | Tanımlanan masraf kodları arasından ihracata ait masraf kodunun seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, masraf kodları arasından seçim yapılır. |
| B Formu Cari Kodu | İhracat masrafı B formu kapsamında ise, masrafa ait cari kodun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Tarih | İhracat masraf belgesine ait tarihin girildiği alandır. |
| Vade Tarihi | İhracat masrafına ait vade tarihinin girildiği alandır. |
| Masraf Fatura No | İhracat masraf faturasına ait numaranın girildiği alandır. |
| Export Referans No | İhracat masraf dekontuna ait Export Referans Numarası'nın girildiği alandır. |
| Fatura No | Fatura numarasının girildiği alandır. |
| Döviz/TL | İhracat masraf dekontu Döviz cinsinden ise Döviz seçeneğini, TL cinsinden ise TL seçeneğinin seçilmesi gerekir. |
| Döviz Tutarı | "Döviz" seçeneği seçildiğinde - masraf dekontunun döviz cinsinden olması sebebi ile - tutarın girildiği alandır. |
| Tutar | "TL" seçeneği seçildiğinde - masraf dekontunun TL cinsinden olması sebebi ile - tutarın girildiği alandır. |
| KDV Oranı | İhracat masrafına ait KDV oranının girildiği alandır. |
| KDV Tutarı | İhracat masrafına ait KDV tutarının girildiği alandır. |
| Referans Kodu | İhracat masrafına ait referans kodunun tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket-Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) → "Proje Uygulaması Var" parametresinin işaretlenmesi ile aktif hale gelen alandır. Masraf yerlerine ait kayıtlarda proje kodunun kullanıldığı durumlarda, proje koduna göre ayrım yapılması için kullanılır. |
| Belge Türü | İhracat masraf belgesinin türünün seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile belge türleri arasından seçim yapılır. |
| Açıklama | İhracat masraf dekontu için açıklama bilgisi girilen alandır. Rapor amaçlı kullanılır. |

| ![](../../../../../_assets/497019a04de4920fad54.png) Satır Sil | Grid ekrana eklenen bir ihracat masraf dekontu satırının silinmesi için kullanılan butondur. |
