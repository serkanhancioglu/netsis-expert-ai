# Satıcı Siparişleri - Dış Ticaret

Dış Ticaret bölümü Satıcı Siparişleri, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. Yurtdışı tipli satıcı siparişlerinin kaydedilmesi, daha önce kaydedilen müşteri siparişlerinin izlenmesi, üzerinde değişiklik yapılması veya iptal edilmesi için kullanılan bölümdür. İşlemler → İthalat İşlemleri → Dosya İşlemleri → Satınalma Teklifleri menüsünden oluşturulan teklif kayıtları da buradan izlenebilir, değiştirilebilir ya da iptal edilebilir.

Satıcı Siparişleri bölümünün kullanımı Fatura → [Satıcı Siparişleri](<../../../Fatura/Kayıt - Fatura/Satıcı Siparişleri.md>) bölümü ile aynıdır.

Yurtdışı tipli Satıcı Siparişleri buradan kaydedileceği gibi, Fatura → Satıcı Siparişleri ekranından da oluşturulabilir. Bu işlem ile oluşturulan yurtdışı Satıcı Siparişleri yine bu ekran üzerinden izlenebilir/değiştirilebilir. Buradan kaydedilen Satıcı Siparişlerinin "Tipi" alanına müdahale edilemeyip, program tarafından otomatik olarak “Yurtdışı” tipinde getirilir. İhr/İth Tipi'nin kullanıcı tarafından seçilmesi gerekir. Exp. Ref. No alanının ise boş bırakılması gerekir. Exp.Ref.No daha sonra program tarafından atanır.
