# Satıcı İrsaliyeleri

Satıcı İrsaliyeleri, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. Yurtdışı tipli satıcı irsaliyelerinin kaydedilmesi, daha önce kaydedilen müşteri siparişlerinin izlenmesi, üzerinde değişiklik yapılması veya iptal edilmesi için kullanılan bölümdür.

Satıcı İrsaliyeleri bölümünün kullanımı, Fatura → [Alış İrsaliyesi](<../../../Fatura/Kayıt - Fatura/Alış İrsaliyesi.md>) bölümü ile aynıdır.
