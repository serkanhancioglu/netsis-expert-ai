# Satınalma Teklifleri

Satınalma Teklifleri, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. Yurtdışı tipli satınalma teklif belgelerinin kaydedilmesi, daha önce kaydedilen teklif kayıtlarının izlenmesi, teklif kaydı üzerinde değişiklik yapılması veya iptal edilmesi için kullanılan bölümdür.

Satınalma Teklif Kaydı'nın kullanımı Talep/Teklif modülünde yer alan "Satış Teklif" bölümünün aynısıdır.

Satınalma Teklif Oluşturma bölümünden, teklif kaydında "Tipi" alanına müdahale edilemez ve bu alan program tarafından "Yurtdışı" tipi olarak otomatik gelir. İhracat/İthalat tipinin kullanıcı tarafından seçilmesi gerekir. Export Referans No alanının boş bırakılması gerekir. Export Referans No alanı daha sonra program tarafından otomatik atanır.

Girilen satınalma tekliflerinin sipariş haline getirilmesi işlemi, İşlemler → İthalat İşlemleri → Dosya İşlemleri menüsünün Satınalma Teklifleri bölümünden yapılır.
