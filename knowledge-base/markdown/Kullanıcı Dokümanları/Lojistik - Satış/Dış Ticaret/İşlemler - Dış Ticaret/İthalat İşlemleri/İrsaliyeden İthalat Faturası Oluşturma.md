# İrsaliyeden İthalat Faturası Oluşturma

İrsaliyeden İthalat Faturası Oluşturma, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. İrsaliyeden fatura oluşturulması için kullanılan bölümdür. Cari Kod kısıdı girilerek, ilgili irsaliyelerin grid ekranda listelenmesi sağlanır. "Tamam" butonu kullanılarak, Grid üzerinden seçilen irsaliyenin ithalat faturası oluşturulur.
