# İthalat Mal Kabul

İthalat Mal Kabul, Lojistik/Satış Bölümü'nde İşlemler/Dış Ticaret Modülü menüsünün altında yer alır. İthalat faturaları üzerinden alış irsaliyesi oluşturmak için kullanılan ekrandır.

İthalat Mal Kabul ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İthalat Mal Kabul Ekranı |  |
| --- | --- |
| Cari Kodu | İthalat faturalarının listelenmesi için cari kod kısıdının verildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Dosya No | Dosya numarasına göre kısıt verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, dosya numaraları arasından seçim yapılır. |
| Tarih | İthalat faturalarının listelenmesi için tarih kısıdı verilen alandır. |
| İthalat Fatura No | Dosya içinde oluşan fatura numarasına göre kısıt verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, fatura numaraları arasından seçim yapılır. |
| Tarih | Oluşturulacak irsaliyeler için tarih girilen alandır. |
| Depo Kodu | Oluşturulacak irsaliyeler için depo kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, depo kodları arasından seçim yapılır. |
| Tümünü Seç ![](../../../../../_assets/d15ca1ad68365b9a1a84.png) | Girilen kısıtlar doğrultusunda Grid ekranda listelenen ithalat faturalarının hepsinin seçilmesini sağlayan butondur. |
| Tümünü Kaldır ![](../../../../../_assets/f5ffb212771284b3d8d5.png) | Grid ekran üzerinden seçimi yapılan ithalat faturalarının hepsinin seçiminin kaldırılmasını sağlayan butondur. |
| İrsaliye Oluştur ![](../../../../../_assets/1a5ffb2f3419937210cb.png) | İthalat faturaları üzerinden alış irsaliyesi oluşturmak için kullanılan butondur. İthalat mal kabul sonrası, ilgili belge satırında belge tipi Alış İrsaliyesi'ne döner. Alış İrsaliyesi ile ilgili detaylı bilgi için tıklayınız. |
