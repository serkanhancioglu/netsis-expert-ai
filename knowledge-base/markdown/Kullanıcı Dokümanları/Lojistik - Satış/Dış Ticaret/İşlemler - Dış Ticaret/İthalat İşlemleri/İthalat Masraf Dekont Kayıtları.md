# İthalat Masraf Dekont Kayıtları

İthalat Masraf Dekont Kayıtları, tanımlanan masraf tipleri kullanılarak ilgili ithalat faturalarına gelen ithalat masraflarının girilerek dekont haline getirilmesi için kullanılan bölümdür. İthalat Masraf Dekont Kayıtları ekranı kullanılarak, bir ithalat işleminde oluşan - Örneğin; Gümrük Komisyoncu Faturaları - ihracat kaydı eşleştirilerek sisteme girilebilir. Dekontun üzerindeki "Export Ref. No." alanı üzerinden ilişkilendirilme işlemi gerçekleştirilir. Yeni dekont girmek için artı ![(plus)](../../../../../_assets/8bc1079dc378a6219e99.svg) butonuna tıklanır. Yeni dekont kaydı için ekran hazırlanır ve aynı şekilde eksi ![(minus)](../../../../../_assets/1b0d15e570bf80d3a5bb.svg) butonu ile, mevcut dekont kaydı sistemden silinir.

İthalat Masraf Dekont Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İthalat Masraf Dekont Kayıtları Ekranı |  |
| --- | --- |
| Cari/Banka Kod | İthalat masrafına ait cari/banka kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Masraf Kodu | Tanımlanan masraf kodları arasından ithalata ait masraf kodunun seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, masraf kodları arasından seçim yapılır. |
| B Formu Cari Kodu | İthalat masrafı B formu kapsamında ise, masrafa ait cari kodun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Tarih | İthalat masraf belgesine ait tarihin girildiği alandır. |
| Vade Tarihi | İthalat masrafına ait vade tarihinin girildiği alandır. |
| Masraf Fatura No | İthalat masraf faturasına ait numaranın girildiği alandır. |
| Export Referans No | İthalat masraf dekontuna ait Export Referans Numarası'nın girildiği alandır. |
| Fatura No | Fatura numarasının girildiği alandır. |
| Döviz/TL | İthalat masraf dekontu Döviz cinsinden ise Döviz seçeneğini, TL cinsinden ise TL seçeneğinin seçilmesi gerekir. |
| Döviz Tutarı | "Döviz" seçeneği seçildiğinde - masraf dekontunun döviz cinsinden olması sebebi ile - tutarın girildiği alandır. |
| Tutar | "TL" seçeneği seçildiğinde - masraf dekontunun TL cinsinden olması sebebi ile - tutarın girildiği alandır. |
| KDV Oranı | İthalat masrafına ait KDV oranının girildiği alandır. |
| KDV Tutarı | İthalat masrafına ait KDV tutarının girildiği alandır. |
| Referans Kodu | İthalat masrafına ait referans kodunun tanımlandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → Şirket-Şube Parametre Tanımları → "Proje Uygulaması Var" parametresinin işaretlenmesi ile aktif hale gelen alandır. Masraf yerlerine ait kayıtlarda proje kodunun kullanıldığı durumlarda, proje koduna göre ayrım yapılması için kullanılır. |
| Belge Türü | İthalat masraf belgesinin türünün seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile belge türleri arasından seçim yapılır. |
| Açıklama | İthalat masraf dekontu için açıklama bilgisi girilen alandır. Rapor amaçlı kullanılır. |

| Satır Sil ![](../../../../../_assets/497019a04de4920fad54.png) | Grid ekrana eklenen bir İthalat masraf dekontu satırının silinmesi için kullanılan butondur. |
| Seçili Satırı Kopyala ![](../../../../../_assets/e13cad734cfe9b1e182a.png) | Grid ekrandan seçilen bir İthalat masraf dekontunun aynısını alt satıra kopyalamak için kullanılan butondur. |
