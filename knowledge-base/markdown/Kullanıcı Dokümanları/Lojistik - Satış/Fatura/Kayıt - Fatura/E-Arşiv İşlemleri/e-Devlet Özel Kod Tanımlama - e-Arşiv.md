# e-Devlet Özel Kod Tanımlama / e-Arşiv

e-Arşiv e-Devlet özel kod tanımlamalarının yapılmasını sağlayan bölüm, e-Devlet Özel Kod Tanımlama bölümüdür. e-Devlet Özel Kod Tanımlama, GİB'in hazırladığı kod listesinde belirtilen kodların tanımlanmasını sağlar. e-Devlet Özel Kod Tanımlama ekranından tanımlanan kodlar e-Arşiv oluşturulan belgeye program tarafından eklenir.

e-Devlet Özel Kod Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| e-Devlet Özel Kod Tanımlama Ekranı |  |
| --- | --- |
| Kod | e-Devlet işlemlerinde kullanılması için, GİB'in belirlediği kodların tanımlandığı alandır. |
| Tip | Tanımlanan koda ait tipin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile tipler arasından seçim yapılır. |
| Açıklama | Tanımlanan Kod ve Tip ile ilgili açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
