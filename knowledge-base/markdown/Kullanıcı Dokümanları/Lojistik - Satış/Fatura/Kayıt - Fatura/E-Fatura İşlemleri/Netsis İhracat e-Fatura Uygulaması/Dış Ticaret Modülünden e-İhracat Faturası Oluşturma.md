# Dış Ticaret Modülünden e-İhracat Faturası Oluşturma

İhracat e-Fatura süreci, proforma fatura oluşturma ile başlar.

Dış Ticaret Modülünden e-İhracat Faturası Oluşturmak için Lojistik–Satış → Dış Ticaret → İşlemler → İhracat İşlemleri → Dosya İşlemleri → Siparişlerim → Proforma Oluştur yolu izlenir.

Proforma fatura numarası girilirken ihracat e-Fatura serisi kullanılır. Oluşturulan proforma faturanın "Detay Gösterme" ekranında, “Gümrük Tarife Kodu (GTİP)”, “Nakliye Tipi”, “Ödeme Şekli” ve “Paket Tipi” tanımlamalarının yapılması zorunludur.

**Gümrük Tarife Kodu (GTİP):** Stoklara ait gümrük tarife kodları stok kartından gelir. Stok kartında tanımlı değilse, “Detay Gösterme → Kalem Bilgileri → Sağ Tuş → Gümrük Tarife Kodu Değişikliği” ile mevcut GTİP değiştirilebilir ya da yeni atama yapılabilir.

**Nakliye Tipi,** Detay Gösterme → Nakliye → "Nakliye Tipi" alanından tanımlanır.

**Ödeme Şekli,** Detay Gösterme → Ödeme Bilgileri → "Ödeme Şekli" alanından tanımlanır.

**Paket Tipi,** Detay Gösterme → Çeki Listesi → "Paket Tipi" alanından tanımlanır.
