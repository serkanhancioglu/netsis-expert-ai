# Paket Tanımları/e-İhracat

e-İhracat paket tanımları için, Netsis "Entegre" paketini kullanan firmanın "Dekont" modülünde “İthalat – İhracat İşlemleri Lisansı” bulunması gerekir. "Netsis Standard" veya "Enterprise" paketi kullanan firmaların, "Dış Ticaret" modülü lisansının bulunması gerekir. İthalat – İhracat İşlemleri Lisansı ve Dış Ticaret" modülü lisansı ile beraber e-Fatura Parametreleri → “İhracat Faturaları e-Fatura Olarak Oluşturulsun” parametresi işaretlendiğinde "Paket Tanımları" bölümü menüye eklenir. "Paket Tanımları" bölümünde çeki listesinde kullanılan paketler tanımlanır.

Paket Tanımları/e-İhracat ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Paket Tanımları Ekranı |  |
| --- | --- |
| Paket Kodu | Çeki listesinde kullanılan paketler için paket kodu tanımlanan alandır. |
| Paket Markası | Paket markasının tanımlandığı alandır. |
| Açıklama | Paket Kodu alanından tanımlanan koda ait açıklama bilgisinin girildiği alandır. |
| Paket Cinsi | Paket cinsinin tanımlandığı alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile aynı uluslararası belge kodlarında olduğu gibi, uluslararası paket cinsleri arasından seçim yapılır. |
| Boş Ağırlık | Paketin boş ağırlığının tanımlandığı alandır. |
| Maksimum Ağırlık | Paketin maksimum ağırlığının tanımlandığı alandır. |
| Grup Kodu | Paket için grup kodu tanımlanan alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile önceden tanımlanan grup kodları görüntülenir. |
| Hacim | Paket hacminin tanımlandığı alandır. |
| Maksimum Adet | Maksimum paket adetinin tanımlandığı alandır. |
| İşletmelerde Ortak | Tanımlaması yapılan paket kodunun hangi işletmede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlaması yapılan paket kodunun hangi şubede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile şube kodları arasından seçim yapılır. |
| Hariç Tutulacak Şube Tanımlamaları | "Hariç Tutulacak Şube Tanımlamaları" yazısının üzerine tıklandığında, mevcut şubeler içinde, hariç tutulması istenen şubeler için sol fare tuşu ile çift tıklanarak seçim yapılan alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
