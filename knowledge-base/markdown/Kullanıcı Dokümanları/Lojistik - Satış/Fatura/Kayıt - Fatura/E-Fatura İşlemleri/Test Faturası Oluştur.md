# Test Faturası Oluştur

Test Faturası Oluştur, Online e-Fatura lisansına sahip firmaların GİB'deki testlerden geçmesi için kullanılan bölümdür.

Test Faturası Oluştur ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Test Faturası Oluştur Ekranı |  |
| --- | --- |
| Numara | Oluşturulacak test faturası için fatura numarası girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile fatura numaraları arasından seçim yapılır. |
| Cari Kodu | Girilen fatura numarasına ait cari kod ve isim bilgisinin otomatik olarak getirildiği alandır. |
| Tarih | Girilen fatura numarasına göre ait tarihin otomatik olarak getirildiği alandır. |
| Test Fatura Adet | Oluşturulacak test faturası adetinin girildiği alandır. |
| ![](../../../../../_assets/8d1bbc508500253005e2.png) Test Faturası Oluştur Butonu | Test faturası oluşturmak için kullanılan butondur. |
