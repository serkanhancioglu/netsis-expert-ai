# Toplu e-Fatura XML Aktarımı

Toplu e-Fatura XML Aktarımı, oluşturulan e-faturaların, toplu halde XML olarak klasöre aktarılmasını sağlayan bölümdür.

Toplu e-Fatura XML Aktarımı ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Toplu e-Fatura XML Aktarımı Ekranı |  |
| --- | --- |
| Fatura Tipi | XML olarak aktarılacak fatura tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile alış veya satış faturası seçilir. |
| Tarih Kısıt Türü | XML olarak aktarılacak faturalar için tarih kısıt türü seçilen alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile kayıt tarihine veya fatura tarihine göre seçim yapılır. |
| Başlangıç/Bitiş Tarihi | XML olarak aktarılması istenen faturalar için başlangıç ve bitiş tarihinin girildiği alandır. Verilen tarih aralığındaki faturaların XML olarak aktarılmasını sağlar. |
