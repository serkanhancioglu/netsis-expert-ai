# Fatura Bazında Gelen e-Fatura

Fatura Bazında Gelen e-Fatura, fatura bazlı liste almak için kullanılan bölümdür.

Fatura Bazında Gelen e-Fatura ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fatura Bazında Gelen e-Fatura Ekranı |  |
| --- | --- |
| Tarih Kısıt Türü | Listeye tarih kısıtlaması vermek amacıyla kullanılan alandır. Kayıt tarihine göre ve fatura tarihine göre olmak üzere iki türden oluşur. |
| Fatura Başlangıç Tarihi | Listeye fatura kısıtlaması vermek amacıyla kullanılan alandır. |
| Fatura Bitiş Tarihi | Listeye fatura kısıtlaması vermek amacıyla kullanılan alandır. |
| Senaryo | Hepsi, Temel, Ticari ve İhracat faturası olmak üzere dört türden oluşur. Hangi tür/türlerdeki faturaların listelenmesi isteniyorsa o türün seçimi yapılır. |
| Basım Durumu | Hepsi, Basım Yapılmış, Basım Yapılmamış olmak üzere üç türden oluşur. Hangi tür/türlerdeki faturaların listelenmesi isteniyorsa o türün seçimi yapılır. |
| Onay Durumu | Listelenecek faturaların onay durumuna göre kısıtlama yapılarak listelenmesini sağlayan alandır. Onay Durumu; Hepsi, Kabul, Red, Yanıt Bekliyor, Şartlı Kabul (8 gün) olmak üzere beş durumdan oluşur. |
| GİB Belge No | Listelenecek belgelerin Gelir İdaresi Başkanlığı belge numarasına göre kısıtlama yapılarak listelenmesini sağlayan alandır. |
| Şubeler Dahil Edilsin | Diğer şube kullanıcılarının bilgilendirilmesi için kullanılan seçenektir. |
| ![](../../../../../../_assets/f16dee424bd46abd13a9.png) Butonu | Girilen kısıtlara uygun durum sorgulamasının yapılması için kullanılan butondur. İşlem; online çalışma varsa merkezden, offline çalışma varsa kullanıcı tarafından manuel olarak yürütülür. |
| ![](../../../../../../_assets/9e217205331c4a276282.png) Butonu | Fatura bazlı listenin Excel olarak oluşturulması için kullanılan butondur. |

Gelen fatura üzerinde iken farenin sağ tuşu ile ekrana gelen "Uygulama Yanıt" seçeneği ile fatura kabul veya reddedilebilir.

Fatura Bazında Gelen e-Fatura ekranı özel tuşlar, üst ekran üzerinde iken sağ klik tuşuna basılması ile ekrana gelen kısayol seçenekleridir.

Fatura Bazında Gelen e-Fatura ekranı özel tuşlar ve içerdiği bilgiler şunlardır:

| Fatura Bazında Gelen e-Fatura Ekranı Özel Tuşlar |  |
| --- | --- |
| Kullanıcı Bilgilendirme | "Netsis Kullanıcı Bilgilendirme" ekranına erişmek için kullanılan kısayol seçeneğidir. Erişilen ekrandan "Kullanıcı Numarası" seçilerek "Bilgilendirme" butonu ile veya "e-Posta Gönder" seçeneği ile ilgili kullanıcının bilgilendirilmesini sağlar. |
| Kontrol Durumu | Gelen e-Faturaların kontrol durumuna erişmek için kullanılan kısayol seçeneğidir. |
| e-Faturadan Alış Faturası Oluşturma | e-Faturadan Alış Faturası oluşturmak için kullanılan kısayol seçeneğidir. Seçeneğin görünmesi için e-Faturanın başarı ile gelmesi gerekir. Aynı işlem "e-Fatura İşlemleri" menüsünün altında bulunan "[e-Faturadan Alış Faturası Oluşturma](<../e-Faturadan Alış Faturası Oluşturma.md>)" ekranından da yapılabilir. |
| Dekont Oluşturma | e-Faturadan Genel Dekont Oluşturma ekranına erişmek için kullanılan kısayol seçeneğidir. XML içinden okunan bilgileri, cari olarak işlenecek bilgileri, KDV hesabına gidecek bilgileri, Dövizli ise döviz bilgilerini gösterir. Geriye kalan bilgiler (Seri Kodu, Proje Kodu, Plasiyer Kodu, Export Ref. No, Export İşlem Tipi) kullanıcı tarafından girildikten sonra "Kaydet" butonu ile kaydedilir. "Kaydet" butonu, bakiye sıfırlandıktan ve hesap kodları girildikten sonra aktif hale gelir. "e-Faturadan Genel Dekont Oluşturma" ekranından B Form'a dahil etme, Satır Ekleme, Satır Silme gibi işlemler de yapılabilir. |
| Ara Tabloda Kayıt Oluştur | Ara tabloda kayıt oluşturulmasını sağlayan kısayol seçeneğidir. e-Fatura tablosuna göre EFATMAS (Üst Bilgiler) ve EFATKALEM (Kalem Bilgileri) kayıtlarını silip tekrar oluşturur. |
| Gruplama | Gruplama yapılmasını sağlayan kısayol seçeneğidir. |
| Görünüm Ayarları | Görünümü Sakla ve Standart Görünüm olarak görünüm ayarlarının yapılması için kullanılan kısayol seçeneğidir. |
| Kolonları Sığdır | Kolonların sığdırılmasını sağlayan kısayol seçeneğidir. |
