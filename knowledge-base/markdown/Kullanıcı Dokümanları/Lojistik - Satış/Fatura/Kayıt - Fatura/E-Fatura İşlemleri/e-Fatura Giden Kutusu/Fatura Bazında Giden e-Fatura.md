# Fatura Bazında Giden e-Fatura

Fatura Bazında Giden e-Fatura, fatura bazlı liste almak için kullanılan bölümdür.

Fatura Bazında Giden e-Fatura ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fatura Bazlı Liste (Giden) Ekranı |  |
| --- | --- |
| Tarih Kısıt Türü | Listeye tarih kısıtlaması vermek amacıyla kullanılan alandır. Kayıt tarihine göre ve fatura tarihine göre olmak üzere iki türden oluşur. |
| Fatura Başlangıç Tarihi | Listeye fatura kısıtlaması vermek amacıyla kullanılan alandır. |
| Fatura Bitiş Tarihi | Listeye fatura kısıtlaması vermek amacıyla kullanılan alandır. |
| Senaryo | Hepsi, Temel, Ticari ve İhracat Faturası olmak üzere dört türden oluşur. Hangi tür/türlerdeki faturaların listelenmesi isteniyorsa o türün seçimi yapılır. |
| Basım Durumu | Hepsi, Basım Yapılmış, Basım Yapılmamış olmak üzere üç türden oluşur. Hangi tür/türlerdeki faturaların listelenmesi isteniyorsa o türün seçimi yapılır. |
| Onay Durumu | Listelenecek faturaların onay durumuna göre kısıtlama yapılarak listelenmesini sağlayan alandır. Onay Durumu alanı; Hepsi, Kabul, Red, Yanıt Bekliyor, Şartlı Kabul (8 gün) olmak üzere beş durumdan oluşur. |
| GİB Belge No | Listelenecek belgelerin Gelir İdaresi Başkanlığı belge numarasına göre kısıtlama yapılarak listelenmesini sağlayan alandır. |
| ![](../../../../../../_assets/f16dee424bd46abd13a9.png) Sorgula Butonu | Girilen kısıtlara uygun durum sorgulamasının yapılması için kullanılan butondur. İşlem; online çalışma varsa merkezden, offline çalışma varsa kullanıcı tarafından manuel olarak yürütülür. |
| ![](../../../../../../_assets/9e217205331c4a276282.png) Excel Oluştur Butonu | Fatura bazlı listenin Excel olarak oluşturulması için kullanılan butondur. |

"Fatura Bazında Giden Kutusu" bölümünde sağ klik ile ekrana gelen özel seçeneklerde "Harici Yolla Fatura İptali" seçeneği yer alır. Harici Yolla Fatura İptali seçeneği sayesinde, zarf durumu 1300 olan yurt içi e-Fatura belgelerinde fatura iptalinin yapılması sağlanır.

e-Fatura belgelerinde fatura iptal işlemin yapılması için öncelikle, kullanıcılara "Merkezi Kimlik Yönetimi" ekranından "Fatura/Harici Yolla Fatura İptali" yetkisinin verilmesi gerekir.
