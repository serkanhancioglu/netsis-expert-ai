# Zarf Bazında Giden e-Fatura

Zarf Bazında Giden e-Fatura, e-Fatura sistemine entegre olan alıcı birimlere gönderilen e-faturalar ve sistem yanıtlarının, tarih aralığı kısıtlaması verilerek görüntülenmesini sağlayan bölümdür.

Zarf Bazında Giden e-Fatura ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Giden Kutusu (Gönderilenler) Ekranı |  |
| --- | --- |
| Başlangıç ve Bitiş Tarihi | Giden kutusu listesine tarih kısıdı verilmesi için kullanılan alandır. |
| Şubeler Dahil Edilsin | Zarf bazında giden e-Fatura listesine şubelerin de dahil edilmesi için kullanılan seçenektir. |
| ![](../../../../../../_assets/4a26da57f42af6c6397d.png) Sorgula Butonu | Girilen kısıtlara uygun durum sorgulamasının yapılması için kullanılan butondur. İşlem; online çalışma varsa merkezden, offline çalışma varsa kullanıcı tarafından manuel olarak yürütülür. |

Giden Kutusu (Gönderilenler) Ekranı Özel Tuşlar, üst ekran üzerinde iken sağ klik tuşuna basılması ile ekrana gelen kısayol seçenekleridir.

Giden Kutusu (Gönderilenler) Ekranı özel tuşlar ve içerdiği bilgiler şunlardır:

| Giden Kutusu (Gönderilenler) Ekranı Özel Tuşlar |  |
| --- | --- |
| Zarf Sil | Ekranda yer alan listedeki zarflardan seçili olanın silinmesini sağlayan kısayol seçeneğidir. |
| Ara Tabloda Kayıt Oluştur | Ara tabloda kayıt oluşturulmasını sağlayan kısayol seçeneğidir. e-Fatura tablosuna göre EFATMAS (Üst Bilgiler) ve EFATKALEM (Kalem Bilgileri) kayıtlarını silip tekrar oluşturur. |
| Şube Değiştir | Gönderilen zarfın şube bilgisinin değiştirilmesini sağlayan kısayol seçeneğidir. ![](../../../../../../_assets/7c4c6d2c9e64fe3b1911.png) |
| Gruplama | Gruplama yapılmasını sağlayan kısayol seçeneğidir. |
| Kolonları Sığdır | Kolonların sığdırılmasını sağlayan kısayol seçeneğidir. |
