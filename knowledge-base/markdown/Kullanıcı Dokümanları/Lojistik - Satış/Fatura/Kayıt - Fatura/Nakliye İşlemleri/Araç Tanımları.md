# Araç Tanımları

Araç Tanımları bölümünde, nakliye için kullanılan araçlar tanımlanır.

Araç Tanımları ekranında yer alan alanlar ve içerdiği bilgileri şunlardır:

| Araç Tanımları Ekranı |  |
| --- | --- |
| Araç Kodu | Tanımlanacak araca ait kod bilgisinin girileceği alandır. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla araç kodu seçilir. |
| Plaka | Tanımlanan aracın plakasının girildiği alandır. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla plaka seçilir. |
| Kamyon Modeli | Tanımlanan aracın modelinin bilgi amaçlı olarak girildiği alandır. |
| Darası | Aracın darasının girildiği alandır. |
| Cari Kodu | Tanımlanan araç, bir nakliye firmasına ait ise ve bu nakliye firması da Cari/Cari Hesap Kayıtları bölümünde tanımlı ise, bilgi amaçlı olarak nakliye firmasının cari kodunun girildiği alandır. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla cari kod seçilir. |
| Araç Tipi | Aracın tipinin girildiği alandır. Araç tipleri öncelikle Fatura/Nakliye İşlemleri/Araç Tip Tanımları bölümünden tanımlanmalıdır. Girilen araç tipine ait Açıklama, İstiap Haddi ve Birim Maliyet burada bulunan alanlara otomatik olarak gelir. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla araç tipi seçilir. |
| Açıklama | Seçilen araç tipine ait açıklamanın program tarafından ekrana getirildiği alandır. |
| İşletmelerde Ortak | ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla işletme seçimi yapılan alandır. |
| Şubelerde Ortak | ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla şube seçimi yapılan alandır. |
| Ehliyet No | Şoförün ehliyet numarasının girildiği alandır. |
| Ehliyet Tarihi | Şoförün ehliyet tarihinin girildiği alandır. |
| Ehliyet İl | Ehliyetin alındığı ilin girildiği alandır. |
| Ruhsat No | Araç ruhsat numarasının girildiği alandır. |
| Ruhsat Tarihi | Araç ruhsat tarihinin girildiği alandır. |
| Teslim Eden | Rapor amaçlı olarak nakliyeyi teslim edenin bilgisinin girildiği alandır. |
| İstiap Haddi | Seçilen araç tipi için girilen istiap haddinin program tarafından ekrana getirildiği alandır, istendiğinde değiştirilebilir. |
| Birim Maliyet | Seçilen araç tipi için girilen birim maliyet bilgisinin program tarafından ekrana getirildiği alandır, istendiğinde değiştirilebilir. |
| ![](../../../../../_assets/f758e4242a272dafbbdd.jpg) Çoklu Şoför Atama | Plakası seçilen araca ait birden fazla şoför bilgisi girilmesi istendiğinde kullanılan butondur. Çoklu Şoför Atama butonuna basıldığında "..... plakalı kamyona çoklu şoför atama" penceresi ekrana gelir. Şoför adı, ehliyet numarası, ehliyet tarihi ve ehliyet ili kaydedilerek ekrandan çıkılır. Araç tanımları penceresinin üst tarafında bulunan ![](../../../../../_assets/865524a70e225c89c107.jpg) kaydet tuşuna veya klavyeden f5 tuşuna basılarak kayıt işlemi tamamlanır. |
