# Araç Tip Tanımları

Araç Tip Tanımları, stokların nakliyesinde kullanılan araçların birim maliyet ve istiap hadlerine göre gruplandırılması için kullanılan bölümdür. Burada tanımlanan araç tipleri, "Araç Tanımlamaları" bölümünde sorgulanır.

Araç Tip Tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Araç Tip Tanımları Ekranı |  |
| --- | --- |
| Tip Kodu | Araç tiplerinin belirlenmesinde kullanılan alandır. Maksimum 8 karakterden oluşan alfa sayısal kod girişi yapılabilir. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber tuşu yardımıyla tip kodların arasından seçim yapılır. |
| Açıklama | Tanımlanan araç tipine ait açıklamanın girildiği alandır. Boş geçilebilir. |
| Birim Maliyet | Tanımlanan araç tipine ait araçlar ile nakliyesi yapılan stoklar için, birim başına yüklenilen maliyetin girildiği alandır. Bu alana girilen maliyet tutarı, bazı durumlarda nakliye maliyetinin hesaplanmasında dikkate alınabilir. (Bu koşulların neler olduğu, Nakliye Bilgi Girişinde açıklanmıştır.) |
| İstiap Haddi | Tanımlanan araç tiplerinin yükleme kapasitesinin girildiği alandır. Buraya girilen istiap haddi bilgi amaçlıdır. Tanımlanan araç tipine ait bir araca, istiap haddini aşacak şekilde yükleme yapılması program tarafından kontrol edilmez. |
