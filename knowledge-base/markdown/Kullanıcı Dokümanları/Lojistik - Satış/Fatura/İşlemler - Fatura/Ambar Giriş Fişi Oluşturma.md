# Ambar Giriş Fişi Oluşturma

Ambar Giriş Fişi Oluşturma, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Ambar Giriş Fişi Oluşturma, daha önce kaydı yapılmış olan ambar çıkış fişlerinin, aynı bilgiler ile ambar giriş fişi haline getirilmesi için kullanılan bölümdür.

Ambar Giriş Fişi Oluşturma ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Ambar Giriş Fişi Oluşturma Ekranı |  |
| --- | --- |
| Numara | Ambar Giriş Fişi numarasının girildiği alandır. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımı ile belge numaraları arasından seçim yapılarak "Ambar Giriş Fişi" numarası oluşturulur. |
| Tarih | Numara alanında seçilen ambar çıkış fişinin tarihi bu alana otomatik olarak gelir. Bu alandaki tarih değiştirilemez. |
| Ambar Giriş No | Oluşturulacak "Ambar Giriş Fişi" için son girilen ambar giriş numarasının bir fazlası "Ambar Giriş Numarası" olarak bu alana program tarafından otomatik gelir. Kullanıcı bu numarayı değiştirebilir. |
| Ambar Giriş Tarihi | Oluşturulacak "Ambar Giriş Fişi" tarihinin girileceği alandır. Bu alana girilen tarih dikkate alınarak "Ambar Giriş Fişi" oluşturulur. |
| Proje Kodu | Proje uygulamasının kullanıldığı durumlarda, ambar çıkış fişinde girilen proje kodu bu alana program tarafından otomatik olarak getirilir. Farklı bir proje kodunun girilmesi istendiğinde ![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımı ile proje kodları arasından seçim yapılır. |
| Depo Kodu | Lokal Depo uygulamasının kullanıldığı durumlarda, ambar çıkış fişinde girilen lokal depo kodu bu alana program tarafından otomatik olarak getirilir. Farklı bir lokal depo kodunun girilmesi istendiğinde ![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımı ile depo kodları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | "Ambar Giriş Fişi" oluşturulması için basılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | "Ambar Giriş Fişi" oluştururken girilen bilgilerin iptal edildiği butondur. |
