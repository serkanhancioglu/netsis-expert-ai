# Açıklama Düzenleme

Açıklama Düzenleme, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Açıklama Düzenleme; müşteri siparişleri, satış irsaliyesi ve satış faturalarının sadece açıklama alanlarının düzenlenmesini sağlayan bölümdür. Belge numarası verilerek ekrana yansıtılan açıklama bölümü üzerinde düzenleme yapılır.

Açıklama Düzenleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Açıklama Düzenleme Ekranı |  |
| --- | --- |
| Alış/Satış | Düzenlenecek açıklamanın hangi işleme ait olduğunun seçildiği alandır. Alış ve satış olarak iki seçenekten oluşur. |
| Sipariş/İrsaliye/Fatura | Düzenlenecek açıklamanın hangi işleme ait olduğunun seçildiği alandır. Sipariş, irsaliye ve fatura olarak üç seçenekten oluşur. |
| Cari Kodu | Düzenlenecek açıklamaya ait cari kodun ![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımıyla seçildiği alandır. |
| Belge No | Düzenlenecek açıklamaya ait belgenin ![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımıyla seçildiği alandır. |
| Eski Açıklama | Belgedeki eski açıklama bilgisinin girildiği alandır. |
| Açıklama | Belgeye yeni açıklama bilgisinin girildiği alandır. |

Yukarıdaki bilgiler girildikten sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna basılarak kaydedilir.
