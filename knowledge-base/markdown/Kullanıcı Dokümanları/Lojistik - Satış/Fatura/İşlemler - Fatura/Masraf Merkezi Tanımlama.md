# Masraf Merkezi Tanımlama

Masraf Merkezi Tanımlama, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Masraf Merkezi Tanımlama, cari hesaplarla ilgisi olmayan, faturasız ve muhasebeye genel gelir/gider kayıtlarının yapılması istenen stoklarla bağlantılı "Ambar Giriş/Çıkış" fişlerinin kaydı sırasında sorgulanan masraf kodlarının tanımlamasının yapıldığı bölümdür. Maliyet muhasebesi kullananlar masraf merkezlerine giriş/çıkış yapabilmek için, masraf merkezlerini tanımlamaları gerekir.

Masraf Merkezi Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Masraf Merkezi Tanımlama Ekranı |  |
| --- | --- |
| Masraf Kodu | Fiş kaydı sırasında belirlenmesi gereken masraf kodlarının, alfabetik veya sayısal olarak belirlendiği sekiz karakterlik alandır. Belirlenen yeni masraf kodunun veya önceden girilmiş masraf kodlarından birinin açıklamasının daha sonra izlenmesi için masraf kodlarının tanımlanması gerekir. |
| Masraf Açıklama | Ambar giriş/çıkış fişlerinden tanımlanan masraf hesaplarına kayıt yapılırken, muhasebe hareketlerinin açıklama alanlarına, aktarılması istenen açıklamanın girildiği alandır. |
| Muhasebe Kodu | Tanımlanan masraf kodunun, muhasebe hesap planında girilmiş olan karşılık hesap kodudur. Masraf koduyla ilgili giriş/çıkış kayıtlarının, muhasebede hangi hesaba işleneceği bu alanda belirlenir. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu ile muhasebe kodları arasından seçim yapılır. Ambar giriş/çıkış fişi kayıtlarının muhasebe bağlantılı çalışması istenmediğinde bu alan boş bırakılır ve \<tab\> tuşu ile ilerlenir. Girilecek hesap kodlarının "Muhasebe Hesap Planı" girişi bölümünden tanımlanması gerekir. |
| Satış Hesap Kodu | Masraf merkezi için satış hesap kodu tanımlanan alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| İşletmelerde Ortak | Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) yardımıyla işletme seçimi yapılan alandır. |
| Şubelerde Ortak | Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) yardımıyla şube seçimi yapılan alandır. |
