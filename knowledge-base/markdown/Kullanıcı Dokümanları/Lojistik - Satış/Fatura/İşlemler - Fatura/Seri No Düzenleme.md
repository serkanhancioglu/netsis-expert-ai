# Seri No Düzenleme

Seri No Düzenleme, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Seri No Düzenleme; Genel Parametre Kayıtları bölümünden “Seri Uygulaması” parametresini işaretleyerek işlem yapan firmaların kullanacağı bölümdür. Seri No Düzenleme; Seri kayıtlarına yeni başlayanlar için yeni başlayan kullanıcılar için başlangıç numaralarının girilmesini, eski kullanıcılar için kalan numaraların (daha önceden girilen kayıtlara zarar vermeden) değiştirilmesini sağlar.

Seri No Düzenleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Seri No Düzenleme Ekranı |  |
| --- | --- |
| Seri | Düzenleme yapılması istenen seri numarasının girildiği alandır. Başlangıç serisi kullanılmıyorsa bu alan boş geçilebilir. |
| Numara | Girilen serinin son kalan numarası otomatik olarak ekrana gelir. Bu alana başlangıç olarak belirlenmesi istenen seri numarası girilir. |

Yukarıdaki bilgiler girildikten sonra Tamam ![](../../../../_assets/39d77b8716226638d9ce.jpg) butonuna basılarak kaydedilir. Böylece, yapılacak yeni kayıtlarda belirlenen numaradan devam edilmesi sağlanır.
