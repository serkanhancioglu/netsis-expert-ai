# Sevk Emri Açma - Kapama

Sevk Emri Açma-Kapama, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Sevk Emri Açma-Kapama, verilen kısıtlara uyan siparişlerin tamamının açılması ya da açık olanların kapatılması için kullanılan bölümdür.

Sevk Emri Açma-Kapama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Otomatik Sevk Açma / Kapama Ekranı |  |
| --- | --- |
| Açma/Kapama | Kapalı durumda olan sevk emirlerinin açılmasını veya açık durumda olan sevk emirlerinin kapatılmasını sağlayan alandır. |
| Sevk No | Açma/Kapama yapılacak sevk emirleri için numara aralığı verilen alandır. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla sevk numaraları arasından seçim yapılır. |
| Sevk Tarihi | Açma/Kapama yapılacak sevk emirleri için tarih aralığı verilen alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Otomatik sevk emri açma/kapama işleminin gerçekleştirilmesini sağlayan butondur. |
| ![](../../../../_assets/21b5276f2871a4221e55.png) Çıkış | Otomatik sevk emri açma/kapama işleminden vazgeçilmesi durumunda ekrandan çıkmak için kullanılan butondur. |
