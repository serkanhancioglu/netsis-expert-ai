# Otomatik Sipariş Açma / Kapama

Otomatik Sipariş Açma/Kapama, Lojistik-Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Otomatik Sipariş Açma/Kapama, verilen kısıtlara uyan siparişlerin tamamının açılması ya da açık olan siparişlerin kapatılması için kullanılan bölümdür.

Otomatik Sipariş Açma/Kapama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Otomatik Sipariş Açma / Kapama Ekranı |  |
| --- | --- |
| Açma/Kapama | Açık olan bir siparişin kapatılması veya kapalı olan bir siparişin otomatik olarak açılması için kullanılan alandır. |
| Belge Tipi | Açma/Kapama yapılacak belge tipinin belirlendiği alandır. "Müşteri Siparişleri" ve "Satıcı Siparişleri" olarak iki seçenekten oluşur. |
| Cari Kodu | Cariye ait kod aralığı ![](../../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımı ile seçilerek, otomatik sipariş açma/kapama için kısıt verilmesini sağlayan alandır. |
| Stok Kodu | Stoka ait kod aralığı ![](../../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımı ile seçilerek, otomatik sipariş açma/kapama için kısıt verilmesini sağlayan alandır. |
| Özellikler | Stoka ait özellikler, üç nokta ![](../../../../../_assets/5098b020c5e814c92501.png) butonu ile esnek yapılandırma özellik rehberinden belirlenerek, açma/kapama için kısıt verilmesini sağlar. "İleri seviyede kısıt vermek için burayı kullanabilirsiniz." yazısının üzerine sağ klik tuşu ile tıklandığında, aşağıdaki ekranda belirtilen alanlar doldurularak detaylı kısıt verilmesi sağlanır. ![](../../../../../_assets/a2e7cc0c6d72a689603c.png) |
| Sipariş Tarihi | Açma/kapama yapılacak siparişin tarih aralığının girildiği alandır. |
| Teslim Tarihi | Açma/kapama yapılacak siparişin teslim tarih aralığının girildiği alandır. |
| Sipariş Bakiyesi | Açma/kapama yapılacak siparişin bakiye aralığının girildiği alandır. |
| Plasiyer Kodu | Açma/kapama yapılacak siparişin plasiyer kod aralığının ![](../../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımıyla seçilerek girildiği alandır. |
| Sipariş Bakiyesi Stok Bakiyesinden Küçük Olanlar | Sipariş bakiyesi stok bakiyesinden küçük olan siparişlerin açma/kapama işlemi yapılması istendiğinde işaretlenmesi gereken parametredir. |
| Şubeler Dahil | Otomatik sipariş açma/kapama işlemine şubelerin de dahil edilmesi istendiğinde işaretlenmesi gereken parametredir. |
| DAT Kayıtlı Siparişleri Dahil Olmasın | "Depolar Arası Transfer" kaydı yapılan siparişlerin açma/kapama işlemine dahil edilmesi istenmediğinde işaretlenmesi gereken parametredir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Açma/kapama yapılacak işlemin gerçekleştirilmesini sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Açma/kapama yapılması istenen işlemden vazgeçilmesi durumunda kullanılan butondur. |
