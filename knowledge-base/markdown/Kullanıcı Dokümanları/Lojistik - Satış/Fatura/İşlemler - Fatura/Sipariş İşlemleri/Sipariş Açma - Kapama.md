# Sipariş Açma / Kapama

Sipariş Açma/Kapama, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Sipariş Açma/Kapama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Sipariş Açma / Kapama Ekranı |  |
| --- | --- |
| Açma/Kapama | Açma seçeneği, kapalı olan siparişin açılması için kullanılır. Açma işlemi yapıldığında, bakiye sipariş miktarları kümüle değer alan bilgilerine eklenerek sipariş miktarı ve teslimat bilgileri alanları tekrar güncellenir. Kapama seçeneği, müşteri/satıcı siparişlerinin bir kısmı teslim edilip bir kısmı bakiye olarak kaldığı zaman, bakiye sipariş teslimatı yapılamadığı durumlarda siparişin kapatılması için kullanılır. Kapatılan sipariş, ilgili hiçbir liste ve rehberde izlenemez. Siparişlerin kapatılması sipariş numarasına göre yapılır ve kapatma işlemi yapılan sipariş miktarları, stok sabit kayıtlarındaki kümüle bilgilerinden azaltılarak düşülür. |
| Belge Tipi | Açma/Kapama yapılacak belge tipinin belirlendiği alandır. "Müşteri Siparişleri" ve "Satıcı Siparişleri" olarak iki seçenekten oluşur. |
| DAT Kayıtlı Siparişleri Dahil Olmasın | "Depolar Arası Transfer" kaydı yapılan siparişlerin açma/kapama işlemine dahil edilmesi istenmediğinde işaretlenmesi gereken parametredir. |
| Tüm Siparişler Getirilsin | "Depolar Arası Transfer" kaydı yapılan siparişler dahil tüm siparişlerin açma/kapama işlemi için ekrana gelmesini sağlayan parametredir. |
| Sipariş Numarası | Açma/Kapama işlemi yapılacak sipariş numarasının girildiği alandır. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla sipariş numaraları arasından seçim yapılır. Bakiyeli olan sipariş numarası girildiğinde, program kapalı ibaresi atar ve bu sipariş irsaliye şekline getirilemez. |
| Sipariş Tarihi | Sipariş numarası seçilen açma/kapama işleminin sipariş tarih bilgisinin program tarafından ekrana getirildiği alandır. |
| Teslim Tarihi | Sipariş numarası seçilen açma/kapama işleminin teslim tarih bilgisinin program tarafından ekrana getirildiği alandır. |
| Cari Kodu | Sipariş numarası seçilen açma/kapama işleminin cari kod bilgisinin program tarafından ekrana getirildiği alandır. |
| Cari İsim | Sipariş numarası seçilen açma/kapama işleminin cari isim bilgisinin program tarafından ekrana getirildiği alandır. |
| ![](../../../../../_assets/cc246386ceb7a02f7428.png) Detay İzleme | Girilen sipariş numarasına ait detaylı bilginin izlenmesini sağlayan butondur. ![](../../../../../_assets/25fd22395dcea485fbe6.png) |
| ![](../../../../../_assets/0b25cfdb1ff3e0d6a72e.png) Tüm Sipariş | Girilen sipariş numarasına ait tüm siparişlerin getirilmesini sağlayan butondur. |
