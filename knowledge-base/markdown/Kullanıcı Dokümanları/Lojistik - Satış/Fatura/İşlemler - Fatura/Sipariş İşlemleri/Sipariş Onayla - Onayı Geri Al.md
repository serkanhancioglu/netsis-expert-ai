# Sipariş Onayla - Onayı Geri Al

Sipariş Onayla-Onayı Geri Al, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Sipariş Onayla-Onayı Geri Al, sistemdeki onaysız siparişlerin onaylanması ve onaylı siparişlerin onayının geri alınmasını sağlayan bölümdür.

Sipariş Onayla-Onayı Geri Al Bölümü, Fatura → Kayıt → Alış Parametreleri/[Satış Parametreleri](<../../Kayıt - Fatura/Satış Parametreleri.md>) → Fatura Sipariş → Sipariş Onay Açılsın parametresinin işaretli olduğu durumlarda kullanılır.

Sipariş Onayla-Onayı Geri Al ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Sipariş Onayla / Onayı Geri Al Ekranı |  |
| --- | --- |
| Onayla/Onayı Geri Al | Onaysız siparişlerin onaylanması veya onaylanmış siparişlerin onayının geri alınması için kullanılan alandır. |
| Belge Tipi | Onaylanacak/onayı geri alınacak belge tipinin belirlendiği alandır. "Müşteri Siparişleri" ve "Satıcı Siparişleri" olarak iki seçenekten oluşur. |
| Sipariş Numarası | Onaylanacak/onayı geri alınacak sipariş numarasının girildiği alandır. ![](../../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla sipariş numaraları arasından seçim yapılır. |
| Sipariş Tarihi | Sipariş numarası seçildikten sonra, onaylanacak/onayı geri alınacak belgenin sipariş tarih bilgisinin program tarafından ekrana getirildiği alandır. |
| Teslim Tarihi | Sipariş numarası seçildikten sonra, onaylanacak/onayı geri alınacak belgenin teslim tarih bilgisinin program tarafından ekrana getirildiği alandır. |
| Cari Kodu | Sipariş numarası seçildikten sonra, onaylanacak/onayı geri alınacak belgenin cari kod bilgisinin program tarafından ekrana getirildiği alandır. |
| Cari İsim | Sipariş numarası seçildikten sonra, onaylanacak/onayı geri alınacak belgenin cari isim bilgisinin program tarafından ekrana getirildiği alandır. |
| ![](../../../../../_assets/cc246386ceb7a02f7428.png) Detay İzleme | Girilen sipariş numarasına ait detaylı bilginin izlenmesini sağlayan butondur. ![](../../../../../_assets/897f719cf7e4a37efe0a.png) |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Sipariş numarasına ait belgenin onaylanması/onayının geri alınması işleminin gerçekleşmesini sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Sipariş numarasına ait belgenin onaylanması/onayının geri alınması işleminden vazgeçilmesi halinde kullanılan butondur. |
