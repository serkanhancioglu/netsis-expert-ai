# Siparişleri Dönemsel Silme

Siparişleri Dönemsel Silme, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Siparişleri Dönemsel Silme, girilen sınır tarihine kadar teslimatı yapılmış tüm siparişlerin -"Müşteri Siparişleri", "Satıcı Siparişleri" ya da "Hepsi" seçeneklerinden biri seçildiğinde - silindiği bölümdür.
