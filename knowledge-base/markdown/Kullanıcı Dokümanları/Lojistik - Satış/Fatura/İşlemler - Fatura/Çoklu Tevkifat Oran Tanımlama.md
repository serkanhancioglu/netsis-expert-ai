# Çoklu Tevkifat Oran Tanımlama

Çoklu Tevkifat Oran Tanımlama, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Çoklu Tevkifat Oran Tanımlama bölümünde fatura belgeleri kaydederken girilecek Özel Kod-2 bazında farklı tevkifat oranları için pay/payda değerleri ve bu oranlara ait alışta/satışta geçerli olacak muhasebe hesap kodlarının tanımlaması yapılır.

Çoklu Tevkifat Oran Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Çoklu Tevkifat Oran Tanımlama Ekranı |  |
| --- | --- |
| Kod | Kullanılacak çoklu tevkifat oranı için belirlenen kod alanıdır. Özel Kod-2 için tanımlanan kodlar arasından seçim yapılır. |
| Açıklama | Girilen tevkifat kodu değerinin açıklamasının kaydedildiği alandır. |
| Alış Hesap Kodu | Fatura belgelerinin kaydı sırasında girilecek Özel Kod-2 bazında farklı tevkifat oranları için, alışta kullanılması istenen hesap kodudur. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla hesap kodları arasından seçim yapılır. |
| Satış Hesap Kodu | Fatura belgelerinin kaydı sırasında girilecek Özel Kod-2 bazında farklı tevkifat oranları için, satışta kullanılması istenen hesap kodudur. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla hesap kodları arasından seçim yapılır. |
| İşletmelerde Ortak | Tanımlaması yapılan çoklu tevkifat oran kodunun hangi işletmede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işletme kodları arasından seçim yapılır. |
| Şubelerde Ortak | Tanımlaması yapılan çoklu tevkifat oran kodunun hangi şubede kullanılacağının belirlendiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile şube kodları arasından seçim yapılır. |
| Pay | Tevkifat oranları için pay tanımlanan alandır. |
| Payda | Tevkifat oranları için payda tanımlanan alandır. |
| Geç. Bitiş Tarihi | Tevkifat oranları geçerlilik bitiş tarihinin belirlendiği alandır. |
| E-Devlet Tevkifat Kodu | Tevkifat oranları için e-Devlet tevkifat kodunun tanımlandığı alandır. |
