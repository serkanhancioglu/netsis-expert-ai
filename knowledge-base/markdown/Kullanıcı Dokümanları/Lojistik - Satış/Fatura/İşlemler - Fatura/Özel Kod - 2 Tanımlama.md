# Özel Kod - 2 Tanımlama

Özel Kod-2 Tanımlama, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Özel Kod-2 Tanımlama, Alış/Satış parametrelerinde "Özel Kod-2" parametresini işaretleyerek işlem yapan firmaların, Kod-2 tanımlamalarını kaydedecekleri bölümdür. Özel Kod-2 Tanımlama bölümünden kaydedilen Kod-2 tanımlamalarının fatura modülü işlemlerinde kullanılabilmesi için, fatura parametrelerindeki “Özel Kod-2 değeri tablodan kontrol edilsin“ parametresinin işaretlenmesi gerekir. Böylece, girilen Kod-2 değerinin bu bölümde kayıtlı olup olmadığı program tarafından kontrol edilir ve kayıtlı olmayan Kod-2 değeri kullanılamaz.

Özel Kod-2 Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Özel Kod-2 Tanımlama Ekranı |  |
| --- | --- |
| Kod | Kullanılacak Kod-2 değerinin girildiği alandır. En fazla bir karakterlik Kod-2 değeri girilir. |
| Açıklama | Girilen Kod-2 değerinin açıklamasının kaydedildiği alandır. |
| Hesap Kodu | İlgili Kod-2 değeri için girilmesi gereken muhasebe hesap kodudur. "Ambar Fişi Muhasebeleştirme" çalıştırıldığında, sarflar için oluşturulan muhasebe kaydı aşamasında bu alana girilen hesap kodu kullanılır. ![](../../../../_assets/088477bb321d1b20c939.jpg) Rehber butonu yardımıyla hesap kodları arasından seçim yapılır. |
| Referans Kodu | İlgili Kod-2 değeri için girilmesi gereken referans kodudur. Muhasebe → Kayıt → Referans Kodu Kayıtlarında tanımlanmış olan kodlar, ![](../../../../_assets/088477bb321d1b20c939.jpg) rehber butonu yardımıyla seçilir. |
