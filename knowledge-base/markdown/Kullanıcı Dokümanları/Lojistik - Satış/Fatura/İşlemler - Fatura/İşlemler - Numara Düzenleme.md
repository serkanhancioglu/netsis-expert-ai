# İşlemler / Numara Düzenleme

Numara Düzenleme; Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Numara Düzenleme, "Fatura, İrsaliye, Sipariş ve Depolar Arası Transfer kayıtlarına" yeni başlayan kullanıcılar için başlangıç numaralarının girilmesini, eski kullanıcılar için kalan numaraların (daha önceden girilen kayıtlara zarar vermeden) değiştirilmesini sağlar.

Numara Düzenleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Numara Düzenleme Ekranı |  |
| --- | --- |
| Satış Faturası | Satış faturası başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Satış İrsaliyesi | Satış irsaliyesi başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Müşteri Siparişleri | Müşteri sipariş başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Satıcı Siparişleri | Satıcı sipariş başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Depolar Arası Transfer | Depolar arası transfer başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Ambar Giriş Fişi | Ambar giriş fişi başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
| Ambar Çıkış Fişi | Ambar çıkış fişi başlangıç numarasının girildiği veya önceden girilmiş olan numaranın değiştirildiği alandır. |
