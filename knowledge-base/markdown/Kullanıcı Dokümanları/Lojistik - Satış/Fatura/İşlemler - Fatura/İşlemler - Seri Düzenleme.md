# İşlemler / Seri Düzenleme

Seri Düzenleme, Lojistik - Satış Bölümü'nde, "İşlemler/Fatura" menüsünün altında yer alır.

Seri Düzenleme, fatura belgelerindeki numaraların, başlangıç karakteri için şube bazında tanımlama yapılması için kullanılan bölümdür. Seri Düzenleme, belirlenen seri numarası ile son numaranın program tarafından ekrana getirilmesini sağlar. Seri Düzenleme ekranında yapılan tanımlamalara göre numaraların program tarafından ekrana getirilmesi için, fatura parametrelerinde bulunan “İrsaliye/faturalarda seri no takibi yapılsın” parametresinin işaretli olması gerekir.
