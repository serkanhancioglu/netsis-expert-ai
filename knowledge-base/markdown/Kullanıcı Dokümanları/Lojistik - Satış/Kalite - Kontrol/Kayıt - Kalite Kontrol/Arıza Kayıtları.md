# Arıza Kayıtları

Arıza Kayıtları, kalite kontrol işlemleri sonucu, malların reddedilmesine neden olacak arızaların, ölçüm tipi bazında tanımlandığı bölümdür.

![](../../../../_assets/128bc7442305bdf92fd8.png)

Arıza Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Arıza Kaydı Ekranı |  |
| --- | --- |
| Arıza Kodu | Tanımlanan arızaya ait, en fazla 8 karakterlik, sayısal ya da alfa sayısal kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, arıza kodları arasından seçim yapılabilir. |
| Ölçüm Tipi | Arıza kaydının hangi ölçüme ait olduğunun belirlendiği alandır. Seçilecek ölçüm tiplerinin, “[Kalite Ölçüm Bilgileri](<Grup Ölçüm Kayıtları/Kalite Ölçüm Bilgileri.md>)” bölümünden kaydedilmiş olması gerekir. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, ölçüm tipleri arasından seçim yapılabilir. |
| Açıklama | Arıza kaydına ait açıklama bilgisinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
