# Kabul/Red Kodları

Kalite kontrol kayıtlarına ait kabul/red nedenlerinin girildiği bölümdür. Kabul/Red Kodları, Lojistik-Satış Bölümü'nde, "Kayıt/Kalite Kontrol" menüsünün altında yer alır.

Kabul/Red kodları, kalite kontrol kayıtları sırasında kullanılır. Böylece kayıtların, kabul/red nedenlerine göre raporlanması sağlanır.

![](../../../../_assets/72ce1fc4e2e9e181cddb.png)

Kabul/Red kodları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kabul / Red Kodları Ekranı |  |
| --- | --- |
| Kabul/Red Kodu | Kabul/Red durumu için belirlenen sayısal ya da alfa sayısal kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile kabul/red kodları izlenebilir. |
| Kabul/Red | Tanımlaması yapılan kodun kabul/red durumunun belirlendiği alandır. Aşağı ok butonu ile seçim yapılabilir. |
| Açıklama | Kabul/red nedeni ile ilgili en fazla 50 karakterlik açıklamanın girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
