# Personel Tanımlama

Personel Tanımlama, Netsis Personel programıyla bağlantılı ya da serbest kodlama ile, personellerin bulunduğu iş istasyonları, görevi, saat maliyeti, grup kodu ve durumunun tanımlanmasını sağlayan bölümdür. Lojistik - Satış Bölümü'nde, "Kayıt/Kalite Kontrol" menüsünün altında yer alır.

Netsis Personel Paketi ile bağlantı kurmak için Yardımcı Programlar → Kayıt → Diğer Paketlerle Bağlantı seçeneğinde gerekli düzenlemelerin yapılması gerekir. Düzenlemeler yapıldıktan sonra, Personel Tanımlama ekranında yer alan "Rehber Paketi" alanında “Rehber” seçeneği seçilerek, “İşyeri” alanına Personel paketinde oluşturulmuş, veri alınacak personel şirketinin ismi yazılması gerekir.

Personel Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Personel Tanımlama Ekranı |  |
| --- | --- |
| İşyeri | Personelin çalıştığı işyerinin kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işyeri kodları arasından seçim yapılabilir. |
| Sicil Numarası | Personel sicil numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile sicil numaraları arasından seçim yapılabilir. |
| Personel İsmi | Personel isminin girildiği alandır. |
| Grup Kodu | Personelin bağlı bulunduğu kalite kontrol grubu kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile grup kodları arasından seçim yapılabilir. |
| İstasyon Kodu | Personelin bulunduğu iş istasyonu kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile istasyon kodları arasından seçim yapılabilir. |
| Durum | Personelin durumunun belirlendiği alandır. Aktif ve Pasif olmak üzere iki seçenekten oluşur. |
| Birim Maliyet | Personel birim maliyetinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
