# Cari / Stok - Grup Eşleştirme

Cari Stok Grup Eşleştirme, stokların satıcı bazında hangi kalite grubuna bağlı olduğunun belirlendiği bölümdür. Farklı satıcılardan alınan ürünlerin farklı ölçümlerden geçmesini sağlar.

![](../../../../../_assets/bec18a39d242c40536c5.png)

Cari Stok Grup Eşleştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Cari/Stok - Grup Eşleştirme Ekranı |  |
| --- | --- |
| Cari Kodu | Kalite grubuna bağlanacak satıcı kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlar arasından seçim yapılabilir. |
| Stok Kodu | Kalite grubuna bağlanacak stok kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile stok kodları arasından seçim yapılabilir. |
| Departman Kodu | Kalite departmanı ile ilgili kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile departman kodları arasından seçim yapılabilir. |
| Grup Kodu | Satıcı bazında stokun bağlı olduğu kalite grubunun belirlendiği bölümdür. Satıcıdan alınan mallar, kalite grubunun özelliklerine göre ilgili ölçümlerden geçer. Bu alanda seçilen grup kodlarının “[Kalite Grup Tanımları](<../Grup Ölçüm Kayıtları/Kalite Grup Tanımları.md>)” bölümünden tanımlanmış olması gerekir. |
| Revizyon No | Kalite grubuna bağlanacak revizyon numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile revizyon numaraları arasından seçim yapılabilir. |
| Aktif | Cari/Stok-Grup eşleştirme için girilen kaydın aktif olup olmadığını belirtmek için kullanılan seçenektir. |
| Açıklama | Kalite grubu ile ilgili açıklama bilgisinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
