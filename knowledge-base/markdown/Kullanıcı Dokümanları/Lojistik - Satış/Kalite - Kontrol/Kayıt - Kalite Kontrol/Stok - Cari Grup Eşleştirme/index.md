# Stok / Cari Grup Eşleştirme

Stok Cari Grup Eşleştirme, stokların veya satıcıların, bağlanacağı kalite grubunun belirlendiği bölümdür. Yapılacak tanımlamalar kalite kontrol kayıtları sırasında kullanılarak, stoklara uygulanacak kalite ölçüm türünün belirlenmesini sağlar.
