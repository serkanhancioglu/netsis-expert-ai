# Cari - Muayene Eşleştirme

Cari Muayene Eşleştirme, Lojistik-Satış Bölümü'nde Kayıt/Kalite Kontrol menüsünün altında yer alır.

![](../../../../../_assets/c95b64ed56bfd645092e.png)

Cari Muayene Eşleştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Cari - Muayene Eşleştirme Ekranı |  |
| --- | --- |
| Cari Kodu | Muayene eşleştirmesi yapılacak cari kodun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılabilir. |
| Departman Kodu | Muayene eşleştirmesi için departman kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, departman kodları arasından seçim yapılabilir. |
| Muayene Kodu | Cari - Muayene eşleştirmesi için muayene kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muayene kodları arasından seçim yapılabilir. |
| Geçerlilik Tarihi | Muayene koduna ait geçerlilik tarihinin girildiği alandır. |
| Aktif | Cari-Muayene eşleştirmesi için yapılan kaydın aktif olup olmadığının belirtilmesi için kullanılan seçenektir. |
| Açıklama | İşleme ait açıklama bilgisinin girildiği alandır. |
| Kalite Kontrol Yapılmayacak | Kalite kontrol yapılmasının istenmediği durumlarda işaretlenmesi gereken seçenektir. |
| PPM Değeri | PPM, kalite performansını ölçmek için kullanılan ölçümdür. Ölçüm sonucu tespit edilen PPM değerinin girildiği alandır. **Örneğin:** Satın alınan 1 milyon parça içerisinden 1 adet hatalı parça tespit edilirse PPM değeri 1 olarak belirtilir. 1 PPM değeri, bir milyon içerisinde 1 hata olduğunu ifade eder. Formül olarak ifade edilirse PPM = (Hatalı Parça Sayısı / Toplam Parça Sayısı) \* 1.000.000 şeklindedir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
