# Grup Bilgileri Kopyalama

Grup Bilgileri Kopyalama, Lojistik - Satış Bölümü'nde, "İşlemler/Kalite Kontrol" menüsünün altında yer alır. Kalite kontrol işlemleri ile ilgili yeni bir grup oluşturulması istendiğinde, daha önceden tanımlanan başka bir grubun bilgilerinin yeni gruba kopyalanmasını sağlayan bölümdür.

![](../../../../_assets/e01f68d015fc962ef696.png)

Grup Bilgileri Kopyalama işlem ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Grup Bilgileri Kopyalama Ekranı |  |
| --- | --- |
| Yeni Grup Kodu | Kalite kontrol işlemleri için yeni oluşturulacak grup kodunun belirlendiği alandır. |
| Revizyon No | Grupla ilgili revizyon numarasının girildiği alandır. |
| Yeni Grup Açıklama | Grup kodunun isim açıklamasının girildiği alandır. |
| Kaynak Grup | Kalite kontrol işlemleri için daha önceden tanımlanan ve bilgilerinin kopyalanması istenen grup kodudur. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kaynak grup kodları arasından seçim yapılır. |
| Revizyon No | Kaynak grup kodunun revizyon bilgisinin seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, revizyon numaraları arasından seçim yapılır. |
| Ölçüm Bilgileri Kopyalansın | Kopyalanması istenen grubun ölçüm bilgilerinin de kopyalanması istendiğinde kullanılması gereken seçenektir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin kaydedilmesini sağlayan butondur. |
| ![](../../../../_assets/21b5276f2871a4221e55.png) Çıkış | Grup bilgilerini kopyalamak için girilen tüm bilgilerden vazgeçilmesi halinde kullanılan butondur. |
