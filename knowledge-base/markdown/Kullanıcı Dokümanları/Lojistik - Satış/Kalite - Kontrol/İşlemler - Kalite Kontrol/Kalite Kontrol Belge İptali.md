# Kalite Kontrol Belge İptali

Kalite Kontrol Belge İptali, Lojistik-Satış Bölümü'nde İşlemler/Kalite Kontrol menüsünün altında yer alır. Kalite kontrol numarası ile belge iptalini gerçekleştirmek için kullanılan bölümdür.

![](../../../../_assets/a9c3153372e7bf538fba.png)

Kalite Kontrol Belge İptali ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kalite Kontrol Belge İptali Ekranı |  |
| --- | --- |
| Kalite Kontrol Numarası | İptal edilmesi istenen belge numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kalite kontrol numaraları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Belge iptali işleminin gerçekleşmesi için kullanılan butondur. |
| ![](../../../../_assets/21b5276f2871a4221e55.png) Çıkış | Belge iptali ile ilgili işlemden vazgeçilmesi halinde kullanılan butondur. |
