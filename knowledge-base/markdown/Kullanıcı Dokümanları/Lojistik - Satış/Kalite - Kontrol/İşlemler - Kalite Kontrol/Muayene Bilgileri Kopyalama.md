# Muayene Bilgileri Kopyalama

Muayene Bilgileri Kopyalama, Lojistik - Satış Bölümü'nde İşlemler/Kalite Kontrol menüsünün altında yer alır. Kalite kontrol işlemleri ile ilgili yeni bir muayene oluşturulması istendiğinde, daha önceden tanımlanan başka bir muayene bilgisinin yeni muayene koduna kopyalanmasını sağlayan bölümdür.

![](../../../../_assets/164d6dc66b5bbaddc5b1.png)

Muayene Bilgileri Kopyalama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Muayene Bilgileri Kopyalama Ekranı |  |
| --- | --- |
| Yeni Muayene Kodu | Kalite kontrol işlemleri için yeni oluşturulacak muayene kodunun belirlendiği alandır. |
| Yeni Muayene Açıklama | Muayene kodunun isim açıklamasının girildiği alandır. |
| Kaynak Muayene Kodu | Kalite kontrol işlemleri için daha önceden tanımlanan ve bilgilerinin kopyalanması istenen muayenenin grup kodudur. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kaynak muayene grup kodları arasından seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin kaydedilmesini sağlayan butondur. |
| ![](../../../../_assets/21b5276f2871a4221e55.png) Çıkış | Muayene bilgilerini kopyalamak için girilen tüm bilgilerden vazgeçilmesi halinde kullanılan butondur. |
