# Hareket Düzeltme

Kantar Tartım Hareket Düzeltme, Lojistik - Satış Bölümü'nde, "Kayıt/Kantar-Tartım" menüsünün altında yer alır. Girilen tartım bilgilerinin, tartım numarası alanından eski numaraları girilerek, tekrar çağrılması ve üzerinde düzeltme/iptal işleminin yapılmasını sağlayan bölümdür. İrsaliyesi oluşturulmuş olan tartım kayıtlarının üzerinde herhangi bir düzeltme/iptal işlemi yapılamaz.

Kantar Tartım Hareket Düzeltme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Hareket Düzeltme Ekranı |  |
| --- | --- |
| Tartım Numarası | Hareketi düzeltilmesi istenen tartımın, numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile tartım numaraları arasından seçim yapılır. |
| Geliş Tarih/Saat | Tartım numarasının girilmesiyle birlikte geliş tarih ve saat bilgileri otomatik olarak ekrana gelir. Üzerinde değişiklik yapılabilir. |
| Gidiş Tarih/Saat | Tartım numarasının girilmesiyle birlikte gidiş tarih ve saat bilgileri otomatik olarak ekrana gelir. Üzerinde değişiklik yapılabilir. |
| İlk Tartım Değeri | Tartım numarasının girilmesiyle birlikte ilk tartım değeri bilgileri otomatik olarak ekrana gelir. Üzerinde değişiklik yapılabilir. |
| Son Tartım Değeri | Tartım numarasının girilmesiyle birlikte son tartım değeri bilgileri otomatik olarak ekrana gelir. Üzerinde değişiklik yapılabilir. |
| İrsaliye Kesilmiş | İrsaliye kesilmişse işaretlenmesi gereken seçenektir. |
| Kantardaki Sayı | Kantardaki sayının belirtildiği alandır. |
| Kamyonun Plakası | Tartım numarasının girilmesiyle birlikte kamyonun plakası otomatik olarak ekrana gelir. |
| Dara Aktarılsın | Hareket düzeltme işlemi yaparken kamyonun darasının aktarılması istendiğinde kullanılması gereken seçenektir. |
| Basım Yapılsın | Hareket düzeltme işleminin basımının yapılması istendiğinde kullanılması gereken seçenektir. |
| Farklı Mal/Cari Teslimat | Farklı mal/cari teslimat olması durumunda işaretlenmesi gereken seçenektir. |
| Cari Kodu | Tartım numarasının girilmesiyle birlikte cari kod otomatik olarak ekrana gelir. Üzerinde değişiklik yapılabilir. |
| Stok Kodu | Hareket düzeltme işlemine ait stok kodunun girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile stok kodları arasından seçim yapılır. |
| Kamyonun Modeli | Hareket düzeltme işlemine ait kamyon modelinin girildiği alandır. |
| Şoförün Adı | Hareket düzeltme işlemine ait şoför adının girildiği alandır. |
| Açıklama 1/2/3 | Hareket düzeltme işlemine ait açıklama bilgisinin girildiği alanlardır. |
| İlk Operatör Adı | Tartım numarasının girilmesiyle birlikte ilk operatör adı otomatik olarak ekrana gelir. |
| İlk Kantar Kodu | Tartım numarasının girilmesiyle birlikte ilk kantar kodu otomatik olarak ekrana gelir. |
| Son Operatör Adı | Son operatör adının girildiği alandır. |
| Son Kantar Kodu | Son kantar kodunun girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
