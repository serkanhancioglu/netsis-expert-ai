# Kamyon Sabit Bilgileri

Kamyon Sabit Bilgileri, Lojistik - Satış Bölümü'nde Kayıt/Kantar-Tartım menüsünün altında yer alır. "Hareket Girişi" bölümünde sorgulanan kamyon bilgilerinin girildiği bölümdür. "Kamyon Sabit Bilgileri" kartının hangi işletme/işletmelerde kullanılacağı, işletmelerde ortak alanına girilen değere göre belirlenir.

Kamyon Sabit Bilgileri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kamyon Sabit Bilgileri Ekranı |  |
| --- | --- |
| Plaka | Kamyona ait plaka numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile daha önce tanımlanmış plakalar arasından seçim yapılarak kamyona ait cari kod, model gibi düzeltmeler yapılabilir. |
| Kamyon Model | Kamyon modelinin girildiği alandır. |
| Darası | Kamyonun darasının girildiği alandır. Dara=Kamyonun Brüt Kütlesi-Net Kütlesidir. Yani içinde mal varken gelen ağırlığından, mal yokken gelen ağırlığı çıkartıldığında ortaya çıkan rakam kamyonun darasıdır. |
| Cari Kodu | Kamyona ait cari kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile cari kodlar arasından seçim yapılır. |
| Ruhsat No | Kamyonun ruhsat numarasının girildiği alandır. |
| Ruhsat Tarihi | Kamyonun ruhsat tarihinin girildiği alandır. |
| Teslim Eden | Kamyonu teslim eden kişinin isminin girildiği alandır. |
| Araç Tanımlarına Eklensin-Araç Kodu | Kamyon sabit bilgilerinde tanımlanan alanların araç tanımlarına eklenmesi istendiğinde kullanılması gereken seçenektir. Bu seçenek işaretlendiğinde sağ tarafta yer alan "Araç Kodu" alanı aktif hale gelir. Araç kodu bilgisi girildiğinde, kamyon sabit bilgilerine girilen tanımlamalar, belirlenen araç kodu için de tanımlanır. |
| ![](../../../../_assets/c90dd39eb807cd5e0c34.png) Çoklu Şoför Atama | Tanımlaması yapılan plaka numarasına birden fazla şoför atanması istendiğinde kullanılması gereken butondur. ![](../../../../_assets/c535bc9d384b6b3e6417.png) |
| İşletmelerde Ortak | Tanımlanan kamyon bilgileri için işletme bilgisinin seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile işletmeler arasından seçim yapılabilir. |
| Şubelerde Ortak | Tanımlanan kamyon bilgileri için şube bilgisinin seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile şubeler arasından seçim yapılabilir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
