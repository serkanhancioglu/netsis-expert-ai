# Tartım Fiş Basımı

Tartım Fiş Basımı, Lojistik-Satış Bölümü'nde Kayıt/Kantar-Tartım menüsünün altında yer alır. Tartım fiş numarası verilerek, yapılan tartımların fişlerinin basılması amacıyla kullanılan bölümdür.

Tartım Fiş Basımı ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Tartım Fiş Basımı Ekranı |  |
| --- | --- |
| Tartım No | Basım için, tartım fiş numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile tartım numaraları arasından seçim yapılabilir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Belirlenen tartım numarasına fişin basımı için kullanılan butondur. Ekrana gelen dizayn sorgulama alanlarına bilgi girişi yapıldıktan sonra basım gerçekleşir. |
