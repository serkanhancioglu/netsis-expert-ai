# Operatör Girişi

Operatör Girişi, Lojistik-Satış Bölümü'nde İşlemler/Kantar-Tartım menüsünün altında yer alır. Programı kullanacak, tartımları girecek operatör isimlerinin, tanımlanan kantarlar bazında girildiği bölümdür.

Operatör Girişi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Operatör Girişi Ekranı |  |
| --- | --- |
| Kantar Kodu | Kantar kodunun tanımlandığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kantar kodları arasından seçim yapılarak, belirlenen kantar kodları için operatör ismi girilebilir. |
| Operatör İsmi | Programı kullanan, tartımları giren kişinin isminin girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Operatör girişi alanlarına girilen bilgilerin kaydedilmesini sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Operatör girişi alanlarına girilen bilgilerden vazgeçilmesi durumunda ekrandan çıkmak için kullanılan butondur. |
