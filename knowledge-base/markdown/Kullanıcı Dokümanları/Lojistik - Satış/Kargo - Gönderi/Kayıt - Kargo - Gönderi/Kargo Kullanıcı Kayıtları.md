# Kargo Kullanıcı Kayıtları

Kargo Kullanıcı Kayıtları, Lojistik - Satış Bölümü'nde Kayıt/Kargo-Gönderi menüsünün altında yer alır. Logo Netsis-Kargo Kullanıcı Tanımları ekranında, kargo şirketlerine yapılacak işlemlerde kullanılmak üzere kargo şirketi tarafından verilen kullanıcı adı ve şifre bilgileri, Netsis kullanıcısı ile eşleştirilir. Bu sayede işlem anında, kargo şirketinde tanımlanan kullanıcı bilgileri kullanıcıya sunulur.

Kargo Kullanıcı Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Netsis-Kargo Kullanıcı Tanımlamaları Ekranı |  |
| --- | --- |
| Netsis Kullanıcı Bilgileri |  |
| Kullanıcı No | Kargo kullanıcısı ile eşleştirilecek olan Netsis kullanıcı numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) yardımı ile kullanıcı numaraları arasından seçim yapılır. |
| Kargo Kullanıcı Bilgileri |  |
| Kargo Şirketi | Kargo şirketinin seçildiği alandır. Yurtiçi ve Ups olmak üzere iki seçenek bulunur. Alanın sağ tarafında yer alan aşağı ok tuşu ile seçim yapılır. |
| Kullanıcı Bilgileri |  |
| Kullanıcı Adı | Kargo şirketi tarafından verilen kullanıcı adının girildiği alandır. |
| Şifre | Kargo şirketi tarafından verilen kullanıcıya ait şifrenin girildiği alandır. |
| Karakterleri Göster | Girilen şifrenin doğruluğunun kontrolü için, karakterlerin gösterilmesini sağlayan seçenektir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
