# Gönderi Oluştur

Kargo Gönderi Oluştur, Lojistik - Satış Bölümü'nde İşlemler/Kargo-Gönderi menüsünün altında yer alır. Fatura Modülünden girilen "Satış Faturası" veya "Satış İrsaliyesi" belgelerinin kargo şirketlerine gönderiminin yapılmasını sağlar.

Kargo Gönderi Oluştur işlemi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kargo Gönderimi Ekranı |  |
| --- | --- |
| Kargo Şirketi | Kargo şirketinin seçildiği alandır. Yurtiçi ve Ups olmak üzere iki seçenek bulunur. Alanın sağ tarafında yer alan aşağı ok tuşu ile seçim yapılır. |
| İrsaliye/Fatura | Kargo gönderilecek belge tipinin seçildiği alandır. |
| Fatura No | Seçilen belge tipine göre kargo gönderilecek irsaliye/fatura numarasının girildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile fatura numaraları arasından seçim yapılır. |
| Cari Kodu | Fatura/İrsaliye numarası seçildiğinde, belgeye ait cari kodun otomatik olarak ekrana geldiği alandır. |
| ![](../../../../_assets/a667e013c29b394cc0cf.png) Kargo Gönder | Kargo şirket seçimi, belge tipi ve numarası girildikten sonra, kargo bilgilerinin yurtiçi/ups kargo portalına gitmesi için kullanılan butondur. Kargo gönderimi işleminin yapılmasından sonra kullanıcı ve mevcut kargo bilgilerinin sorgulandığı Yurt İçi Kargo/Ups Kargo Login Ekranı açılır. Kargo kullanıcı bilgileri sistemde yapılan tanımlama mevcut ise otomatik olarak tespit edilir. ![](../../../../_assets/22bc6802378868e9b6c6.png)<br>Bu ekranda "Kargo Bilgileri" kısmına kargo sayısı girilir. **Örneğin:** Belgedeki stok kalem sayısı 1 adet düşünüldüğünde, kargonun 2 paket halinde gitmesi durumunda kargo sayısının 2 adet girilmesi gerekir. |
| Yanıt XML | Kargo gönderimi sonrasında, kargo şirketi tarafından gönderi ile ilgili gelen yanıtın xml olarak gösterildiği kısımdır. |
| Sonuç Açıklama | Kargo şirketinden gelen cevabı gösteren alandır. Gönderim sırasında herhangi bir hata söz konusu değilse “Başarılı” cevabı gelir. Gönderim sırasında hata oluşmuşsa hata ile ilgili açıklama görünür. |
