# Müstahsil Makbuzu Girişi Ekranında Kullanılan Özel Tuşlar

Müstahsil Makbuzu Girişi ekranında sağ fare tuşu ile görüntülenen kısayol seçenekleri şunlardır:

| Müstahsil Makbuzu Girişi Ekranı Özel Tuşlar |  |
| --- | --- |
| Numara Değişikliği | Kaydedilmiş bir müstahsil faturasının numara değişikliğini sağlayan seçenektir. Herhangi bir müstahsil faturasının “Üst Bilgiler” ekranında iken, farenin sağ butonuna tıklayarak “Numara Değişikliği” seçeneği ile veya klavyeden “Ctrl+N” kısa yolunu kullanarak müstahsil numarası değişikliği yapılabilir. Ekranda açılan “Numara Değiştirme” penceresinden yeni fatura numarası girilerek “Tamam” butonuna basıldığında numara değişikliği işlemi gerçekleşir. |
| Stok Kartı İzleme | Müstahsil Makbuzu Girişi-Müstahsil Kalemleri sekmesinde iken, girişi yapılacak stok kodu girildikten sonra, girilen stokun sabit kartındaki bilgilerin izlenmesini sağlayan seçenektir. |
| Cari Kartı İzleme | Müstahsil Makbuzu Girişi ekranından Cari Kod bilgisi girildikten sonra, girilen carinin sabit kartındaki bilgilerin izlenmesini sağlayan seçenektir. |
