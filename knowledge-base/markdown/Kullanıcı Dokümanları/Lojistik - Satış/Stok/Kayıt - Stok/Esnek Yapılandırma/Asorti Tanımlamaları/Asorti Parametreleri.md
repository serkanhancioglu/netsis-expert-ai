# Asorti Parametreleri

Asorti uygulamasının program içinde desteklenmesi için; Stok → Kayıt → [Stok Parametreleri](<../../Stok Parametreleri.md>) → "Esnek Yapılandırma" parametresinin işaretlenmesi, Yardımcı Programlar → Kayıt → [Özel Parametre Tanımları](<../../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Özel Parametre Tanımları.md>) bölümünden aşağıdaki tanımlamanın yapılması, belgedeki stok kalemleri için, asorti kodunun saklanacağı alan seçiminin yapılması gerekir. Asorti kodunun saklanacağı alanın seçimi, [Satış Parametreleri](<../../../../Fatura/Kayıt - Fatura/Satış Parametreleri.md>) bölümünden yapılır.
