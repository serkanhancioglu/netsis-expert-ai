# Özellik Fiyat Tanımlamaları

Özellik Fiyat Tanımlamaları, Lojistik - Satış Bölümü'nde, "Kayıt/Stok" menüsünün altında yer alır. Özellik Fiyat Tanımlamaları, esnek yapılandırılan stoklar için, özellik bazında ve tarihsel fiyat listesi hazırlamak amacıyla kullanılan bölümdür.

Özellik Fiyat Tanımlamaları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Özellik Fiyat Tanımlamaları Ekranı |  |
| --- | --- |
| Alış/Satış | Fiyat tanımlamasının alış/satış seçeneklerinden hangisi için belirleneceği ile ilgili seçim yapılan alandır. |
| Fiyat Listesi | Fiyat tanımlaması yapmak için fiyat listesi girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlı fiyat listeleri arasından seçim yapılır. Yeni bir fiyat listesi tanımlamak için, rehber butonunun yanında yer alan "Ekle" butonu ![](../../../../../_assets/8bdec5cfc988b475eada.png) kullanılır. ![](../../../../../_assets/dd55c9822dde5bfc3a9c.png) |
| Başlangıç Tarihi | Fiyat listesinin başlangıç tarihinin girildiği alandır. |
| Bitiş Tarihi | Fiyat listesinin bitiş tarihinin girildiği alandır. |
| Döviz Tipi | Fiyat listesinin tanımlanacağı döviz tipinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, döviz tipleri arasından seçim yapılır. Bu alanın boş bırakılması, fiyat listesinin TL olarak tanımlanacağı anlamına gelir. TL dışında fiyat listesi tanımlanması için ilgili para biriminin, Döviz Takibi → Kayıt → [Döviz İsimleri Tanımlama](<../../../../Genel/Döviz Takibi/Kayıt - Döviz Takibi/Döviz İsimleri Tanımlama.md>) bölümünden tanımlanmış olması gerekir. |
| Fiyat Grubu | Farklı carilere farklı liste fiyatları ile satış yapılması ve/veya bir malın farklı satıcılardan alınması durumunda, alıcılara/satıcılara göre farklı fiyat listelerinin oluşturulması amacıyla kullanılan alandır. Bu alanda "Fiyat Grup Tanımları" bölümünden tanımlanan kodlar listelenir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, listelenen kodlar arasından seçim yapılır. |
| Stok Kodu | Fiyat listesi tanımlanacak stoka ait kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, "Stok Kartı Kayıtları" bölümünün Ek Bilgi sekmesinde yer alan "Esnek Yapılandır" seçeneği işaretli olan stok kod listesi ekrana gelir. Burada listelenen stokların dışında farklı bir stok kodunun girilmesi gerektiğinde, fiyat tanımlamaları Stok → Kayıt → "Stok Fiyat İşlemleri" menüsünde yer alan bölümlerin kullanılması gerekir. |
| Özellik Kodu | Stokun sahip olduğu özelliklerden hangisi için fiyat listesi tanımlanması isteniyorsa, ilgili özellik kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, özellik kodları arasından seçim yapılır. |
| Özellik Değer Kodu | Seçilen özellik için "Özellik Tanımlamaları" bölümünden girilen değerlerin listelendiği alandır. İlgili stokun hangi özelliği için fiyat listesi tanımlanması isteniyorsa, ilgili özellik değer kodu bu bölümden seçilir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, özellik değer kodları arasından seçim yapılır. |
| Fiyat-1, Fiyat-2, Fiyat-3, Fiyat-4 | Fiyat listesinde bulunması istenen fiyatların girildiği alanlardır. |
| ![](../../../../../_assets/2df964a627562a183bcb.png) Hızlı Değişiklik | Hazırlanan fiyat listelerindeki alış/satış fiyatlarının baz alınarak farklı fiyat listelerinin hızlı bir şekilde oluşturulmasını sağlayan butondur. ![](../../../../../_assets/118c39a1e8ed70ae83fd.png) Hızlı fiyat değişikliği ekranı ile ilgili detaylı bilgi için, Stok → Kayıt → Stok Fiyat İşlemleri → "[Hızlı Fiyat Değişikliği](<../Stok Fiyat İşlemleri/Hızlı Fiyat Değişikliği.md>)" |
| ![](../../../../../_assets/f2a25dc9bb7b26033fa8.png) Fiyat Listesi İptali | Tanımlı fiyat listesinin silinmesi için kullanılan butondur. ![](../../../../../_assets/0f5e2bb0e5ad51184abf.png) Fiyat Listesi iptal ekranı ile ilgili detaylı bilgi için, Stok → Kayıt → Stok Fiyat İşlemleri → [Fiyat Listesi İptali](<../Stok Fiyat İşlemleri/Fiyat Listesi İptali.md>) |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yapılan kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
