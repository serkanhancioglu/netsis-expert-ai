# Seri Numarası Değişikliği

Seri Numarası Değişikliği, Lojistik - Satış Bölümü'nde, "Kayıt/Stok" menüsünün altında yer alır. Seri Numarası Değişikliği, "Eski Seri No" ve "Yeni Seri No" alanları kullanılarak seri numaralarında değişiklik yapılmasını sağlayan bölümdür.

Seri Numarası Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Seri Numarası Değişikliği Ekranı |  |
| --- | --- |
| Eski Seri No | Seri numarası değişikliği için eski seri numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, seri numaraları arasından seçim yapılır. |
| Yeni Seri No | Seri numarası değişikliği için yeni seri numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, seri numaraları arasından seçim yapılır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
