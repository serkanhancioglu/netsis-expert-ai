# Seri Takibi Kayıtları

Seri Takibi Kayıtları, Lojistik - Satış Bölümü'nde, "Kayıt/Stok" menüsünün altında yer alır. Seri Takibi Kayıtları, belli bir tarihte başlayan firmaların, daha önce kullandıkları seri numaralarının kaydedilmesini sağlayan bölümdür.

Seri Takibi uygulamasının program menüsünde yer alması için; Yardımcı Programlar → Kayıt → [Şirket - Şube Parametre](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) Tanımları → “Seri Takibi Var” parametresinin işaretlenmesi gerekir.

Bu bölümden girilen seri numaraları devir kabul edilir ve sadece raporlarda baz alınır.

"Stok Hareket Kayıtlarına" yansıtılmaz, kontrolü kullanıcılara bırakılır. Yani, stok giriş/çıkış hareketlerinde bu seriler için parametre kontrolü yapılmaz.

Seri Takibi Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Stok Takibi Kayıtları Ekranı |  |
| --- | --- |
| Stok Kodu | Seri takibi kaydı için stok kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, stok kodları arasından seçim yapılır. |
| Seri No | Seri takibi kaydı için numara girilen alandır. |
| Seri No-2 | Seri takibi kaydı için ikinci seri numarasının girildiği alandır. |
| Giriş/Çıkış | Seri takibi kaydı stok giriş/çıkış seçeneklerinden hangisi için yapılacaksa, ilgili tercihin yapıldığı alandır. |
| Miktar | Seri takibi kaydı için miktar girilen alandır. |
| Belge No | Seri takibi kaydı için belge numarası girilen alandır. |
| Tarih | Günün tarihi otomatik olarak ekrana gelir. Tarih üzerinde değişiklik yapılabilir. |
| Depo Kodu | Seri takibi kaydı için depom kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, depo kodları arasından seçim yapılır. |
| Son Kullanma Tarihi | Son kullanma tarihi opsiyonel sahasına girilecek tarih, "Seri Girişi" ekranında kullanılır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
