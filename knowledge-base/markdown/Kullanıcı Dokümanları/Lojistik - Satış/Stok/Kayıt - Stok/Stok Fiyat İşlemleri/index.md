# Stok Fiyat İşlemleri

Stok Fiyat İşlemleri, Lojistik - Satış Bölümü'nde, "Kayıt/Stok" menüsünün altında yer alır.

"Stok Fiyat İşlemleri" menüsünün altında yer alan alt menü seçenekleri ile; stok kartlarında tanımlı olan fiyatlar kullanılmadan farklı amaçlı fiyat listelerinin oluşturulması, oluşturulan fiyat listelerindeki fiyatların sorumlu gruplar tanımlanarak değiştirilmesi, girilen fiyatların "Fatura Modülünde" kullanılması sağlanır.

"Stok Fiyat İşlemleri" menüsünün programda yer alması için, Stok → Kayıt → [Stok Parametreleri](<../Stok Parametreleri.md>) → "Özel Fiyat Sistemi" parametresinin işaretlenmesi gerekir.
