# Stok Hareket Kayıtları Özel Tuşlar

Stok hareket kayıtları bölümündeki yardımcı tuşlar, grid ekranı üzerinde sağ fare tuşu ile ekrana gelir. Stok hareketlerine ait bilgilere ulaşmak için önce hareketin olduğu satır üzerine fare ile çift tıklanır, ardından farenin sağ tuşuyla izlenmesi istenen seçeneğe tıklanır.

Stok Hareket Kayıtları özel tuşları ve içerdiği bilgiler şunlardır:

| Stok Hareket Kayıtları Özel Tuşlar |  |
| --- | --- |
| Stok Hareket Diğer Bilgiler | Grid ekranından seçilen harekete ait döviz tipi, döviz fiyatı, net fiyat, brüt fiyat, maliyet fiyatı gibi detay bilgilere ulaşılmasını sağlar. ![](../../../../../_assets/1a2c149e504dc0aa0874.png) |
| Stok Kartı | Grid ekranından seçilen harekete ait stok kartı bilgisine ulaşılmasını sağlar. ![](../../../../../_assets/1cae96a2c69fd3f6d422.png) |
| Seri Bilgisi İzleme | Stok hareket kaydının herhangi bir hareketine ait seri detayının izlenmesini sağlar. Harekete ait seri bilgisi varsa, izleme ekranı açılır. ![](../../../../../_assets/30b12e40091268179244.png) |
| Yevmiye Detay | Stok modülü ile entegre olan bir modülden yapılan kaydın (hareket muhasebeye aktarılmış ise) ilgili yevmiye fişine ait detayın izlenmesini sağlar. Hareket henüz entegrasyonda ise veya farklı bir ay muhasebe fişine aktarılmışsa, program ilgili yevmiye fişini bulamaz ve uyarı verir. ![](../../../../../_assets/dc132928d83dbf9aeb3c.png) |
| Hücre Toplama Bilgileri | Grid ekranından seçilen harekete ait hücre toplama bilgisine ulaşılmasını sağlar. **![](../../../../../_assets/de63931acb37369ff74c.png)** |
| Dinamik Depo Yerleştirme/Toplama İptali | Grid ekranından seçilen harekete ait stokun yerleştirme/toplama iptali işleminin yapılmasını sağlar. ![](../../../../../_assets/9e5c64dc37b6699dc564.png) |
| Fatura Detay Göster | Grid ekranından seçilen harekete ait fatura detayının izlenmesini sağlar. ![](../../../../../_assets/5f9282a6951a609c7123.png) |
| Gönder | Ekranda bulunan grid bilgisinin Excel programına aktarılmasını sağlar. Uygulama başladığında, “Bilgiler karşı uygulamaya gönderiliyor “ mesajı ile karşılaşılır ve işlem bittiğinde ilgili uygulamaya geçilir. Böylece, grid ekranında bulunan tüm bilgiler seçilen uygulamaya aktarılır. |
