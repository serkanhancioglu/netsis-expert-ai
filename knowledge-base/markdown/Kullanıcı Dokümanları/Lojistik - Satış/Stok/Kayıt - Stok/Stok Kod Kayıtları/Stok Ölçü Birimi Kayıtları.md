# Stok Ölçü Birimi Kayıtları

Stok Ölçü Birimi Kayıtları, Lojistik - Satış Lojistik - Satış Bölümü'nde, "Kayıt/Stok" menüsünün altında yer alır. Stok Ölçü Birimi Kayıtları, "Stok Ölçü Birimi Kayıtları", Stok ya da ortak özelliklere sahip stok grupları bazında, stok kartında yapılan tanımlamalardan farklı pay/payda değerleri tanımlanması için kullanılan bölümdür.

Stok Ölçü Birimi Kayıtlarının kullanımı ile ilgili detaylı bilgi için; Stok → Ekler → [Ek-2 Ölçü Birimi Uygulamaları](<../../Ekler (Stok)/Ek-2 (Ölçü Birimi Uygulamaları).md>) dokümanına bakılabilir.

Stok Ölçü Birimi Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır.

| Stok Ölçü Birimi Kayıtları Ekranı |  |
| --- | --- |
| Kod Türü | Ölçü birimi kaydı için kod türünün girildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile Stok Kodu, Grup Kodu, Kod-1/2/3/4/5 arasından seçim yapılır. |
| Kod | Ölçü birimi kaydı için kod bilgisinin girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, ölçü kodları arasından seçim yapılır. |
| Ölçü Birimi | Ölçü birimi kaydı için birim seçimi (koli, paket, adet vb.) yapılan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, ölçü birimleri arasından seçim yapılır. |
| Açıklama | "Ölçü Birimi" alanında birim seçimi yapıldıktan sonra, açıklama isminin otomatik olarak aktarıldığı alandır. |
| Pay/Payda | Ölçü birimi kaydı için pay/payda değerlerinin girildiği alandır. |
| Net Ağırlık | Stok ölçü birimi kaydı için, stoka ait net ağırlık bilgisinin girildiği alandır. |
| Brüt Ağırlık | Stok ölçü birimi kaydı için, stoka ait brüt ağırlık bilgisinin girildiği alandır. |
| En/Boy/Yükseklik | Stok ölçü birimi kaydı için, stoka ait en/boy/yükseklik bilgisinin girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
