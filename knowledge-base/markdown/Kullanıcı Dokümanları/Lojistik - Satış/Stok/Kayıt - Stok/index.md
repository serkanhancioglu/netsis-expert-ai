# Kayıt / Stok

Stok modülünün Kayıt bölümü, ticari veya üretimle ilgili, stok faaliyetlerinin takip edildiği bölümdür. Stok modülünün Kayıt bölümü, farklı amaçlarla firma elinde bulunan stoklara ait tanımlamaların yapılmasını ve stokların giriş/çıkış hareketlerinin izlenmesini sağlar.
