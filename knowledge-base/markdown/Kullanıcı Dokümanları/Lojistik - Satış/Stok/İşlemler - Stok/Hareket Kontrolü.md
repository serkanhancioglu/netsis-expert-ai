# Hareket Kontrolü

Hareket Kontrolü, Lojistik - Satış Bölümü'nde, "İşlemler/Stok " menüsünün altında yer alır. Hareket Kontrolü, Stok → Kayıt → [Stok Kartı Kayıtları](<../Kayıt - Stok/Stok Kartı Kayıtları/index.md>) → Tutar/Miktar Bilgileri sekmesinde bulunan Giriş/Çıkış Miktar/Tutarlarının stok hareket kartındaki ile tutmaması ya da "[Stok Hareket Kayıtları](<../Kayıt - Stok/Stok Hareket Kayıtları/index.md>)" bölümündeki grid alanında bulunan giriş, çıkış ve bakiye bilgilerinin dip toplam ile tutmaması durumunda çalıştırılması gereken işlemdir. Hareket Kontrolü, sadece admin yetkisine sahip kullanıcı tarafından çalıştırılır.

Hareket Kontrolü ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Hareket Kontrolü Ekranı |  |
| --- | --- |
| Stok Kodu Aralığı | Stok Kodu Aralığı, hareketleri kontrol edilmesi istenen stoklara ait kısıt verilmesi için kullanılan alandır. Bu alanın boş bırakılması halinde tüm stok kayıtlarının hareketleri kontrol edilir. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, kod aralığı vermek için seçim yapılır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
