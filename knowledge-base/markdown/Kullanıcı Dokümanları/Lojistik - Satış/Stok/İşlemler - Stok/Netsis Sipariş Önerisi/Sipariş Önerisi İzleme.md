# Sipariş Önerisi İzleme

Sipariş Önerisi İzleme, Finans Bölümü'nde, "İşlemler/Stok " menüsünün altında yer alır. Sipariş Önerisi İzleme, "Sipariş Önerisi Hazırlık" bölümünün çalıştırılmasıyla, program tarafından otomatik olarak bulunan sipariş öneri miktarlarının izlendiği ve üzerinde değişiklik yapıldığı bölümdür. Sipariş Önerisi İzleme, Genel Kısıtlar ve Ön Sorgulama sekmelerinden oluşur.

Genel Kısıtlar sayfasında bulunan sahalar yardımıyla, sadece belirli stoklara ait sipariş önerisinin izlenmesi mümkündür. Bunun için, Genel Kısıtlar sayfasındaki sahalar ile, sipariş önerisinin izlenmesi istenen stoklara ait kısıt verilmelidir.

**Genel Kısıtlar**

Sipariş Önerisi İzleme ekranı Genel Kısıtlar sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Netsis Sipariş Önerisi İzleme Ekranı |  |
| --- | --- |
| Netsis Sipariş Önerisi Tarihi | Sipariş önerilerinin izleneceği tarihin girildiği sahadır. Sadece girilen tarihteki sipariş önerileri izlenir. |
| Stok Kodu | Sipariş önerilerinin izlenmesi için stok kodu kısıtının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, stok kodları arasından seçim yapılır. |
| Yapılandırma Kodu | Sipariş önerilerinin izlenmesi için yapılandırma kodu kısıtının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, yapılandırma kodları arasından seçim yapılır. |
| Grup Kodu | Sipariş önerilerinin izlenmesi için grup kodu kısıtının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, grup kodları arasından seçim yapılır. |
| Kod-1/Kod-2 | Sipariş önerilerinin izlenmesi için kod-1/kod-2 kısıtının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kodlar arasından seçim yapılır. |
| Satıcı Kodu | Sipariş önerilerinin izlenmesi için satıcı kodu kısıtının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, satıcı kodları arasından seçim yapılır. Sadece, girilen aralıktaki satıcı kodlarına ait sipariş önerilerinin izlenmesini sağlar. |
| Fiyat Kodu | Sipariş önerilerinin izlenmesi için fiyat kodu kısıtının girildiği alandır. Sadece, girilen fiyat kodu aralığındaki sipariş önerilerinin izlenmesini sağlar. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiyat kodları arasından seçim yapılır. |

**Ön Sorgulama**

Sipariş Önerisi İzleme ekranı Ön Sorgulama sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Netsis Sipariş Önerisi İzleme Ekranı |  |
| --- | --- |
| Stok Kodu | Sipariş önerisi izlenecek stokun kodudur. Grid ekranda yer alan stok kodunun üzerine çift tıklandığında, stoka ait bilgiler ön sorgulama sekmesindeki alanlardan izlenir. Kullanıcı, bu alanlar üzerinde değişiklik yapabilir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, stok kodları listesine ulaşılır. |
| Depo Kodu | Sipariş önerilerinin, lokal depo bazında detaylı hazırlandığı durumlarda, stok depo kodlarının izlenmesini sağlayan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, depo kodları listesine ulaşılır. |
| Proje Kodu | Sipariş önerilerinin, proje bazında detaylı hazırlandığı durumlarda, stok proje kodlarının izlenmesini sağlayan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları listesine ulaşılır. |
| Satıcı Kodu | Sipariş önerileri hazırlanırken, Stok Kartı Kayıtlarında yer alan "Satıcı Kodu" alanındaki cari kodlar baz alınır. Baz alınan cari kodlar, bu alan üzerinden izlenir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, satıcı kodları arasından seçim yapılır. Stok kartlarında cari kodların mutlaka tanımlanmış olması gerekir. Cari satıcı kodu girilmemiş stoklar için sipariş önerisi hazırlanır fakat satıcı siparişleri oluşturulmaz. Bu ekran ile, satıcı kodu boş olan stok kodlarının satıcı kodları girilir ya da girilmiş satıcı kodu üzerinde değişiklik yapılır. Girilen satıcı kodlarına ait satıcı siparişi oluşturulur. |
| Netsis Öneri Miktarı | "Sipariş Öneri Hazırlık" bölümünün çalıştırılması ile oluşan, "Netsis Sipariş Öneri Miktarının" izlendiği alandır. Netsis öneri miktarı, kullanıcı tarafından değiştirilemez. |
| Sipariş Miktarı | Netsis öneri miktarının aktarıldığı alandır. Buradaki miktar, satıcı siparişleri oluşturulurken baz alınacak olan miktardır. Firmalar, bu alandaki sipariş miktarını değiştirme yetkisine sahiptir. Böyle bir durumda, satıcılara ilgili mallar için verilecek sipariş miktarı, üzerinde değişiklik yapılan miktardır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
