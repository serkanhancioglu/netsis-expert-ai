# Sayım İptali

Sayım İptali, Lojistik - Satış Bölümü'nde, "İşlemler/Stok" menüsünün altında yer alır. Sayım İptali, sayım sonuçlarını, girilen sayım tarihi ve lokal depo kodu ile bağlantısı olan cari kod bazında tamamen iptal etmek için kullanılır.

Sayım İptali ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Sayım İptali Ekranı |  |
| --- | --- |
| Sayım Tarihi | Sayım girişinin yapıldığı tarihin girildiği alandır. İptal edilmesi istenen sayım tarihinin girilmesi gerekir. |
| Depo Kodu Başlangıç/Bitiş | İptal edilmesi istenen sayıma ait depo kodu kısıtı verilen alanlardır. Sayım girişinde birden fazla depo için giriş yapıldıysa, sadece belirlenen depo/depolar için kaydedilen sayım girişi iptal edilir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, depo kodları arasından seçim yapılır. |
| Cari Kodu | Lokal depoları cari koda bağlantılı olarak (örneğin; satış noktaları bazında) tanımlayan firmaların kullandığı alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. Sayım bilgilerinin iptali sonuçlandığında, geri dönüş ve ilgili tarih bilgilerini sayım miktarlarına göre raporlama şansı ortadan kalkar. |
| Proje Kodu (Başlangıç) | Sayım iptali için, başlangıç proje kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları arasından seçim yapılır. |
| Proje Kodu (Bitiş) | Sayım iptali için, bitiş proje kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları arasından seçim yapılır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
