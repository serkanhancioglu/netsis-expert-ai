# Talep-Teklif Parametreleri

Talep-Teklif Parametreleri; Lojistik - Satış Bölümünde, "Kayıt/Talep-Teklif" menüsünün altında yer alır. Talep-Teklif Parametreleri, firmaların Talep-Teklif kayıtları sırasında, tercihlerine göre özel uygulamalar yapmasını sağlayan bölümdür.

Satın Alma Talep Parametreleri, Satın Alma Teklif Parametreleri, Satış Talep Parametreleri ve Satış Teklif Parametreleri sekmesinden oluşur.
