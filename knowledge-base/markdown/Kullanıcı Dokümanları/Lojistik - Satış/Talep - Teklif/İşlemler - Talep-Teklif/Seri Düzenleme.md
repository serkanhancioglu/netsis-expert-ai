# Seri Düzenleme

Seri Düzenleme, Lojistik - Satış Bölümünde, "İşlemler/Talep-Teklif" menüsünün altında yer alır. [Talep/Teklif Parametreleri](<../../../Muhasebe/Muhasebe Modülü/Ekler - Muhasebe/Ek-1 Enflasyon Muhasebesi/Genel Tanımlar/Yardımcı Programlar-Şirket-Şube Parametreleri.md>) → “Seri Numarası Takibi” parametresinin işaretlendiği durumlarda talep ve teklif kayıtları belli seri karakterleri ile takip edilir. "Seri Düzenleme" işlemi ile; talep/teklif belgelerinin, belge bazında hangi seri ile takip edileceği belirlenir. Böylece; ilgili belgelerde, burada belirlenen seri karakterleri program tarafından otomatik olarak ekrana getirilir.

Seri Düzenleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Seri Düzenleme Ekranı |  |
| --- | --- |
| Satış Talep | Satış taleplerinin takip edileceği seri numarasının tanımlandığı alandır. |
| Satış Teklif | Satış tekliflerinin takip edileceği seri numarasının tanımlandığı alandır. |
| Satınalma Talep | Satınalma taleplerinin takip edileceği seri numarasının tanımlandığı alandır. |
| Satınalma Teklif | Satınalma tekliflerinin takip edileceği seri numarasının tanımlandığı alandır. |
