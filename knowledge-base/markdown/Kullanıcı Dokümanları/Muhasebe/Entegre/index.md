# Entegre

Entegrasyon Modülü; "Ön Muhasebe" kayıtlarını (kullanıcının tanımlayacağı şekilde) yevmiye fiş kayıtları haline getirilmesini sağlayan bölümdür. Entegrasyon bölümünde, "Ön Muhasebe" bölümlerinden yapılan kayıtların Muhasebe → Kayıt → "Hesap Planı" bölümündeki hesap kodlarıyla bağlantıları kurulur. Bu tanımlamalar sonucu, "Ön Muhasebe" bölümlerinden yapılan kayıtlar, "Entegrasyon" bölümündeki fiş kayıtlarına işlenir. Fişler, tek seferde topluca muhasebeleştirilebilir. Böylece, "Ön Muhasebede" yapılan kayıtların, tekrar "Genel Muhasebe" kayıtlarına işlenmesine gerek kalmaz.

"Ön Muhasebe" ile "Genel Muhasebe" arasında entegrasyon oluşturulması için; Yardımcı Programlar → Kayıt → [Şirket-Şube Parametreleri](<../Muhasebe Modülü/Ekler - Muhasebe/Ek-1 Enflasyon Muhasebesi/Genel Tanımlar/Yardımcı Programlar-Şirket-Şube Parametreleri.md>) → "Muhasebe Entegre” parametresinin işaretlenmesi gerekir. Aksi takdirde; yapılan işlemler, "Ön Muhasebede" modüller arası entegre bağlantısıyla ilgili modüllere işlenir fakat "Entegrasyon" modülünde kayıt oluşmaz.
