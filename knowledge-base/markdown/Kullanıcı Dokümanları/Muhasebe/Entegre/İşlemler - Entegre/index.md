# İşlemler / Entegre

Entegre modülü İşlemler menüsü, "Ön Muhasebe" modüllerinden entegrasyona işlenen kayıtların muhasebe modülüne aktarımının yapıldığı bölümdür. Aktarım; "Seçenekli" ve "Toplu" olmak üzere iki türlü yapılır. "Seçenekli" yada "Toplu Aktarım" seçilerek "Muhasebe" modülüne aktarım yapıldıktan sonra, bu işlem geri alınamaz. Yani, aktarım sonucu entegrasyondaki kayıtlar "Muhasebe" modülünde yevmiye fiş kaydı haline geldikten sonra tekrar entegrasyona geri alınamaz.
