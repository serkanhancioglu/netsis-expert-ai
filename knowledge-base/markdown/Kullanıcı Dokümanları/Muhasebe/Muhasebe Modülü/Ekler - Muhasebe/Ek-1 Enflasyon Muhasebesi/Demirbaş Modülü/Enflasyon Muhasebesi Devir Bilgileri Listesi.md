# Enflasyon Muhasebesi Devir Bilgileri Listesi

Demirbaş-Rapor bölümüne eklenen Enflasyon Muhasebesi Devir Bilgileri Listesi raporu ile, enflasyon muhasebesine başlangıç yapılan tarihler için, mevcut kayıtlarla düzeltilen kayıtlar arasındaki sabit kıymet ve biriken amortisman farkları raporlanır. Bu bilgiler ile, fark fişleri kolaylıkla kaydedilir.
