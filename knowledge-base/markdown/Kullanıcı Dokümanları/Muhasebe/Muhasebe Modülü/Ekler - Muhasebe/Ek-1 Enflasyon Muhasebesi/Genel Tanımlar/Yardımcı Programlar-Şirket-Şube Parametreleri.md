# Yardımcı Programlar/Şirket-Şube Parametreleri

"Enflasyon Muhasebesi" uygulamasının kullanılması için öncelikle, dövizli çalışma parametresinin işaretlenmesi gerekir. "Düzeltme Tipi" alanına, Döviz Modülünde enflasyon endeksleri için tanımlanan döviz tipi girilerek döviz çevrim tipinin belirlenmesi gerekir. Logo Netsis servisleri aracılığıyla yapılan endeks güncellemeleri ile, tüm döviz çevrim sahalarına aynı endeks yazılır. Dolayısı ile, burada hangi çevrim tipinin seçildiği önemsizdir.
