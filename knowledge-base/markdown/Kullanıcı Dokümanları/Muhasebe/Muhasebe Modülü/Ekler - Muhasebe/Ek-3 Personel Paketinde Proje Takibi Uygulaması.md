# Ek-3 Personel Paketinde Proje Takibi Uygulaması

Personel paketinde "Proje Kodu" takibinin yapılması istendiğinde, öncelikle Yardımcı Programlar → Kayıt → [Şirket/Şube Parametreleri](<Ek-1 Enflasyon Muhasebesi/Genel Tanımlar/Yardımcı Programlar-Şirket-Şube Parametreleri.md>)

→ “Proje Uygulaması Var” parametresinin işaretlenmesi gerekir.

> [!NOTE]
> Personellerin proje takibi ile ilgili tanımlamaları Kayıt → Personel Bilgileri → "Personel Devam Bilgileri Girişi" ekranından yapılır. "Personel Devam Bilgileri Girişi" ekranında, personelin ilgili projede çalıştığı ay, gün ve saat bilgileri tanımlanır.
