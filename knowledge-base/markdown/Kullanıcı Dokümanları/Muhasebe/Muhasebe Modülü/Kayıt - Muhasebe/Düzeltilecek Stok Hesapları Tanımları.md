# Düzeltilecek Stok Hesapları Tanımları

Düzeltilecek Stok Hesapları Tanımları, Muhasebe Bölümünde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. Düzeltilecek Stok Hesapları Tanımları bölümü "Enflasyon Muhasebesi" kullanıldığında işlev kazanır.

"Enflasyon Muhasebesi" ile ilgili, bu bölümün kullanımı hakkında detay bilgi için; [Ek-1 Enflasyon Muhasebesi](<../Ekler - Muhasebe/Ek-1 Enflasyon Muhasebesi/index.md>) dokümanına bakılabilir.
