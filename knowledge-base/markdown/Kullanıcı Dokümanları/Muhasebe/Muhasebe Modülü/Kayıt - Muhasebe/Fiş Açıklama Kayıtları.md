# Fiş Açıklama Kayıtları

Fiş Açıklama Kayıtları, Muhasebe Bölümü'nde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. Elde tutulan muhasebe kayıtlarında, bazı yevmiye açıklamaları kalıplaşmış ifadeleri içerebilir. Bu ifadelerin her defasında tekrar yazılması yerine, bu bölümde tanımlanıp daha sonra birden fazla kullanılmasını sağlar. Açıklamalar girildikçe, program tarafından açıklama numarası verilir. Yevmiye fişlerinin kaydı sırasında, açıklama bölümünde bulunan rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) kullanılarak, girilen tanımlamaların listesi ekrana gelir.

![](../../../../_assets/672c3da935509923e037.png)

Fiş Açıklama Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fiş Açıklama Kayıtları Ekranı |  |
| --- | --- |
| Sr | Tanımlanan açıklamaya ait program tarafından otomatik olarak verilen sıra numarasının izlendiği alandır. |
| Açıklama | Yevmiye fişleri için açıklama bilgisi tanımlanan alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Fiş Açıklama Kayıtları kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
