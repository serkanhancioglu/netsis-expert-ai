# Geçici Vergi Beyannamesi Parametreleri

Geçici Vergi Beyannamesi Parametreleri, Muhasebe Bölümü'nde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. Geçici Vergi Beyannamesi Parametreleri, aylık ve üç aylık dönemlerde, geçici vergi beyannamesi basımlarının yapılması için parametre girilen bölümdür. Geçici Vergi Beyannamesi Parametreleri; Yıl/Ay ve Beyanname olmak üzere iki sekmeden oluşur.

**Yıl/Ay**

![](../../../../_assets/d66ed39d64f20be5eace.png)

Geçici Vergi Beyannamesi Parametreleri ekranı Yıl/Ay sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Geçiçi Vergi Beyannamesi Parametreleri Ekranı |  |
| --- | --- |
| Vergi Dairesi Kodu | Beyanname için vergi dairesi kodu girilen zorunlu bir alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, vergi dairesi kodları arasından seçim yapılır. |
| Dönem Tipi | Beyanname dönem tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile, Geçici Vergi Dönemi (Normal Dönem) veya Geçici Vergi Özel Hesap Dönemi seçenekleri arasından tercih yapılır. |
| Dönem | "Dönem Tipi" alanında "Geçici Vergi Dönemi (Normal Dönem)" ve "Geçici Vergi Özel Hesap Dönemi" tipinin seçilmesi ile aktif hale gelen alandır. 1.Dönem, 2.Dönem, 3.Dönem veya 4.Dönem seçeneklerinden biri seçilerek, ilgili dönemin belirtilmesini sağlar. |
| Yılı | "Dönem Tipi" alanında "Geçici Vergi Dönemi (Normal Dönem)" tipinin seçilmesi ile aktif hale gelen alandır. Parametrelerin hangi yıl için tanımlanacağının belirlendiği alandır. |
| Bitiş Yılı | "Dönem Tipi" alanında "Geçici Vergi Özel Hesap Dönemi" tipinin seçilmesi ile aktif hale gelen alandır. Dönemin bitiş yılının girilmesini sağlar. |
| Dönemin Bitiş Ayı | "Dönem Tipi" alanında "Geçici Vergi Özel Hesap Dönemi" tipinin seçilmesi ile aktif hale gelen alandır. Dönemin bitiş ayının girilmesini sağlar. Alanın sağ tarafında yer alan aşağı ok butonu ile aylar arasından seçim yapılır. |
| ![](../../../../_assets/87c754239ff5f9610b77.png) Parametre Kopyala | İlgili beyanname parametrelerinin kopyalanması için kullanılan butondur. Tıklandığında ekrana gelen "Beyanname Parametre Kopyalama" ekranı ile Şirket, İşletmeler, Kaynak Beyanname ve Vergi Dairesi kodu girilerek kopyalama işlemi gerçekleştirilir. ![](../../../../_assets/1d05c7f6554a0a5b2ba3.png) |

**Beyanname**

Beyanname sekmesi, beyanname parametre tanımlamalarının yapıldığı sekmedir.

**![](../../../../_assets/4ee8ef17093c59b2c7cd.png)**

| Geçici Vergi Beyannamesi Parametreleri Ekranı |  |
| --- | --- |
| ![](../../../../_assets/c7275efbddc154ea1579.jpg) Kaydet | Girilen bilgilerin kaydedilmesi için kullanılan butondur. |
| ![](../../../../_assets/bfd25ffa1947d2603b7a.png) Tüm Alanlar İçin Değeri Oku | Beyanname ekranındaki bilgilerin, daha önce saklanan son değerler ile değiştirilmesi istendiğinde kullanılan butondur. |
