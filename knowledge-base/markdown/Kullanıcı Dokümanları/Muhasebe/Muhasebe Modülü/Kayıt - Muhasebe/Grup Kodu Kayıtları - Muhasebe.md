# Grup Kodu Kayıtları / Muhasebe

Grup Kodu Kayıtları, Muhasebe Bölümü'nde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. Grup Kodu Kayıtları; hesap planı kayıtları sırasında, hesapların ilk iki hanesinden oluşan "Muhasebe Gruplarının" kaydedildiği bölümdür. Grup kodlarının mutlaka tanımlanması gerekir. Tanımlanmadığı durumlarda "Gelir Tablosu ve Bilanço Hazırlanması" sırasında sorunla karşılaşılır.

![](../../../../_assets/5e5e859faf7cb880ef9f.png)

Grup Kodu kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Grup Kodu Kayıtları Ekranı |  |
| --- | --- |
| Grup Kodu | Muhasebe grup kodu tanımlamasının yapıldığı alandır. |
| Grup İsmi | Tanımlaması yapılan grup koduna ait isim bilgisi girilen alandır. |
| Yabancı Grup İsmi | Tanımlaması yapılan grup isminin yabancı dildeki karşılığının girildiği alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Grup Kodu kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
