# Hesap Planı Özel Tuşlar

"Hesap Planı" ekranında kullanılan yardımcı tuşlar, ekran üzerinde iken farenin sağ tuşu ile ekrana gelir.

![](../../../../../_assets/4075af20502cbdfdf4e0.png)

Hesap Planı ekranında kullanılan özel tuşlar ve içerdiği bilgiler şunlardır:

| Hesap Planı Ekranı Özel Tuşlar |  |
| --- | --- |
| Diğer Şirkete Hesap Planı Kopyalama | Diğer Şirkete Hesap Planı Kopyalama seçeneği, içinde bulunulan şirkete ait hesap planını, başka bir şirkete kopyalamak için kullanılan seçenektir. Açılan ekranda yer alan "Şirket Kodu" alanına kopyalama yapılacak şirket kodu girilir. ![](../../../../../_assets/21c937d1e904ee598eb5.png) Uyarı ekranına onay verilmesi ile, girilen şirket koduna ilgili hesap planı kopyalanır. ![](../../../../../_assets/92725338e249f25ec9f9.png) |
