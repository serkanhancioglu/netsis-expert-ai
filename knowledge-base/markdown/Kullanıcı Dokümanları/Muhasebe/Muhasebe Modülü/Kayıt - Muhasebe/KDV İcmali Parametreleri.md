# KDV İcmali Parametreleri

KDV İcmali Parametreleri, Muhasebe Bölümü'nde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. KDV İcmali Parametreleri ekranı; Kasa ve Dekont sekmelerinden oluşur. KDV İcmali Parametreleri, KDV İcmal raporu alırken baz alınacak parametrelerin tanımlanmasını sağlar.

**Kasa**

![](../../../../_assets/11a30eb37ad994542a53.png)

KDV İcmali Parametreleri ekranı Kasa sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| KDV İcmali Parametreleri Ekranı |  |
| --- | --- |
| Saha Adı | Kısıt sekmesinde Kısıt düğmesine tıklanması ile görüntülenir. Kasa modülünde, KDV icmal raporu alırken baz alınacak saha adı için kısıt verilen alandır. İlgili hücre üzerinde iken klavyede yer alan **Boşluk Çubuğuna** basılarak aktif hale gelen aşağı ok butonu, kısıt verilmesi istenen sahalara ulaşılmasını sağlar. ![](../../../../_assets/02fe0a13965853a4fbed.png) |
| Sıralama | Kasa kayıtlarının icmal raporuna aktarılma sırasının belirlenmesini sağlayan sekmedir. İlgili sıralama, sadece rapora getirilecek olan sıralamadır. Rapordaki verilerden Excel’e aktarım yapılırken, sıralama tarihe göre yapılır. ![](../../../../_assets/872df554ca6abd1e1d6c.png) |
| Kaydet | Girilen kısıtların kaydedilmesini sağlayan butondur. |

**Dekont**

**![](../../../../_assets/3aedd76b5e2078573c2b.png)**

KDV İcmali Parametreleri ekranı Dekont sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| KDV İcmali Parametreleri Ekranı |  |
| --- | --- |
| Saha Adı | Kısıt sekmesinde Kısıt düğmesine tıklanması ile görüntülenir. Muhasebe modülünde, KDV icmal raporu alırken baz alınacak saha adı için kısıt verilen alandır. İlgili hücre üzerinde iken klavyede yer alan **Boşluk Çubuğuna** basılarak aktif hale gelen aşağı ok butonu, kısıt verilmesi istenen sahalara ulaşılmasını sağlar. ![](../../../../_assets/bf4daa93ef92d8f500d1.png) |
| Sıralama | Dekont kayıtlarının icmal raporuna aktarılma sırasının belirlenmesini sağlayan sekmedir. İlgili sıralama, sadece rapora getirilecek olan sıralamadır. Rapordaki verilerden Excel’e aktarım yapılırken, sıralama tarihe göre yapılır. ![](../../../../_assets/12ce963b044c842138bc.png) |
| KDV Tutar Kısıt | KDV icmal raporu alırken, KDV tutarının hangi satırdan getirileceğinin belirlendiği sekmedir. ![](../../../../_assets/fc2ede01db10b42124b3.png) |
| ![](../../../../_assets/ef5d0483b6b883336c8f.png) Gruplama | Aynı dekont kaydında birden fazla belge olması halinde, tutarların neye göre gruplandırılacağı belirlenir. Hepsini seç butonu ![](../../../../_assets/791c70a62e1a8ade02a1.png) ile, gruplama yapılacak alanların hepsinin işaretlenmesi, hepsini sil butonu ![](../../../../_assets/76e42b0269d9532b9a8d.png) ile de seçilen tüm gruplama alanlarının işaretinin kaldırılması sağlanır. Öncelikli olarak "Dekont No" ve Fiş No alanları işaretli şekilde ekrana gelir. Bunun dışında bir alan kullanılması istendiğinde değişiklik yapılabilir. ![](../../../../_assets/45a1f1ab0ba5156cfea1.png) |
| Kaydet | Girilen kısıtların kaydedilmesini sağlayan butondur. |
