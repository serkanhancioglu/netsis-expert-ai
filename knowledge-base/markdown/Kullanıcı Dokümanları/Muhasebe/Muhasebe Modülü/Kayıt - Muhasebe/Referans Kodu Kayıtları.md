# Referans Kodu Kayıtları

Referans Kodu Kayıtları, Muhasebe Bölümü'nde, "Kayıt/Muhasebe Modülü" menüsünün altında yer alır. Referans Kodu Kayıtları, Muhasebe → Kayıt → [Muhasebe Parametreleri](<Muhasebe Parametreleri.md>) → Genel → “Referans Kodu Sorulsun” parametresinin işaretlendiği ve referans kodları ile kayıt yapıldığı durumlarda referans kodlarının girilmesi için kullanılan bölümdür. Referans Kodu Kayıtları bölümünde tanımlanan referans kodlarının, sorgulandıkları herhangi bir bölümden rehberi alınabilir.

![](../../../../_assets/7177d9bd15b7c8ab0e7d.png)

Referans Kodu Kayıtları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Referans Kodu Kayıtları Ekranı |  |
| --- | --- |
| Referans Kod | Referans kodu tanımlamasının yapıldığı alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlı referans kodlarına ulaşılır. |
| Referans İsmi | Tanımlanan referans koduna ait isim bilgisi girilen alandır. |
| İşletmelerde Ortak | İlgili referans kodunun kullanılacağı işletmenin seçildiği alandır. Referans kodu tüm işletmelerde kullanılacaksa “-1” değeri girilir. |
| Şubelerde Ortak | İlgili referans kodunun kullanılacağı şubenin seçildiği alandır. Referans kodu tüm şubelerde kullanılacaksa “-1” değeri girilir. |
| Hariç Tutulacak Şube Tanımlamaları | İlgili referans kodunun hangi şube/şubelerde hariç tutulacağının tanımlandığı bölümdür. Referans kodları bu bölümden tanımlanmamış ise, referans kodu sorgulanan yerlerde program, “Referans Kod Tanımlı Değil ” şeklinde bir uyarı ile kayıtların tamamlanmasına izin vermez. Bu nedenle, mutlaka kullanılacak referans kodlarının girilmesi gerekir. Ayrıca, bu bölümden tanımlanan referans kodları hatalı referans kodu girişini de engeller. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Referans kodu kayıtlarının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
