# Yevmiye Fiş Girişi Ekranında Kullanılan Özel Tuşlar

"Yevmiye Fiş Girişi" ekranında kullanılan özel tuşlar sadece "Fiş Detay" sekmesinde bulunur. Yevmiye Fiş Girişi ekranı özel tuşları, ekran üzerinde iken farenin sağ tuşu ile görüntülenir.

Yevmiye Fiş Girişi ekranı özel tuşları ve içerdiği bilgiler şunlardır:

| Yevmiye Fiş Girişi Ekranı Özel Tuşlar |  |
| --- | --- |
| Araya Satır Ekleme | Araya Satır Ekleme seçeneğine tıklandığında “Sıra Okuma” ekranı görüntülenir. Araya eklenmesi istenen satırın hangi sırada oluşması isteniyorsa, eklenecek sıra numarası girilir. ![](../../../../../_assets/1d4d9356abb1b8b61bfd.png) |
| Son Satır Kopyalama | Son Satır Kopyalama, "Yevmiye Fiş Girişi" ekranında listelenen kayıtların içinde, en altta bulunan satırı kopyalamak için kullanılan seçenektir. Seçeneğe tıklandığında, girilen son kayıt ekranın üst kısmına kopyalanır. \<tab\> tuşu ile ilerleyerek bu bilgilerin ayrı bir satırda kaydedilmesi sağlanır. |
| Yevmiye Detay İzleme | "Yevmiye Fiş Girişi" ekranında, ilgili yevmiye kayıt satırının üzerinde iken farenin sağ tuşu ile ekrana gelen "Yevmiye Detay İzleme" seçeneği sayesinde, oluşturulan kaydın Döviz Tipi, Döviz Tutarı, Firma Döviz Tipi, Firma Döviz Tutarı, Referans Kodu, Evrak Tarihi, Son İşlem Tarihi vb. detay bilgiler izlenir. ![](../../../../../_assets/e9462b4722d298c812fa.png) |
| Hesap Kartı İzleme | "Hesap Kartı İzleme" seçeneği sayesinde, üzerinde bulunulan hesabın "Hesap Planı Girişi" ekranında belirlenen Hesabın Adı, Hesap Türü, Hesap Tipi, Grup Kodu, Döviz Bilgileri vb. bilgilerin izlenmesi sağlanır. "Tutar/Miktar Bilgileri" sekmesi ile hesabın ait olduğu Ana ve Grup Detay bilgileri ile hesapların toplam olarak şimdiye kadar oluşan "Borç/Alacak Tutarları" görüntülenir. ![](../../../../../_assets/bffbdda42b8d75c9fd2c.png) |
| KDV Oran Tablosu | "KDV Oran Tablosu" seçeneği sayesinde, "Yevmiye Fiş Girişi" ekranında fatura ve KDV kaydı yapılırken, tek fiş bazında oluşan değişik KDV oranlarına göre toplam KDV tutarlarının izlenmesi sağlanır. ![](../../../../../_assets/add0848be4418d63a018.png) |
| Bakiye Kapatma | Bakiye Kapatma seçeneği sayesinde, "Yevmiye Fiş Girişi" ekranında birden fazla borç hareketinin tek bir alacak hareketi ile kapatılması istendiğinde, “Alacak” hareketinin tutarına “Borç” toplamını hesaplayarak getirir. Bu seçenek kullanıldığında, hata yapma olasılığı düşer. |
| Muavin | "Muavin" seçeneği sayesinde, üzerinde bulunulan muavin hesap dökümünün ekrandan/yazıcıdan alınması sağlanır. ![](../../../../../_assets/d3a3fc491690861140c0.png) |
| Klasik Yevmiye Fişi | "Klasik Yevmiye Fişi" seçeneği sayesinde, içinde bulunulan yevmiye fişinin, "Klasik Yevmiye Fişi" formatında dökümünün ekrandan/yazıcıdan alınması sağlanır. ![](../../../../../_assets/0c408d5f9a8ce36676aa.png) |
| Yevmiye Kaynak İzleme | "Yevmiye Kaynak İzleme" seçeneği sayesinde, muhasebeye entegre olan ön muhasebe modüllerinden oluşturulan “Alış/Satış Faturaları”, “Müstahsil Makbuzu Kayıtları”, “Müşteri/Borç Çek/Senet Bordrolarının” izlenmesi sağlanır. **Örneğin,** satış faturasıyla ilgili bir mahsubun içinde iken, bu faturanın herhangi bir hesap kodunda "Kaynak İzleme" bölümü kullanıldığında program, kayıt girilen menü formatında faturanın içeriğini ekrana yansıtarak izleme imkanı verir. |
| Tahsil/Tediye Kasaya Kapat | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../Muhasebe Parametreleri.md>) → Yevmiye → "Kasa Tahsil Muavin" ve "Kasa Tediye Muavin" kodunun tanımlandığı durumlarda kullanılan seçenektir. Tahsil ya da tediye olarak seçilen yevmiye fişlerinde ilk önce, “Tahsil” ya da “Tediye” ile ilgili kayıtlar oluşturulması gerekir. Fiş, kapatılma aşamasına geldiğinde bu seçenek kullanılarak, kasanın muavin kodu, açıklaması ve tutarı otomatik olarak ilgili satıra program tarafından aktarılır. Fişte Borç/Alacak tutarsızlığı yoksa, fiş bakiyesi oluşmadan kapatılır. |
| Fiş Basımı | İçinde bulunulan fişin daha önce dizayn modülünden hazırlanan dizayna göre basımının yapılmasını sağlayan seçenektir. |
| Fiş Kopyala | "Aydan Aya Fiş Aktarımı" ekranın açılarak fiş kopyalama işleminin yapılmasını sağlayan seçenektir. |
| Cari Hesap Kayıtları | İlgili yevmiye fişinin cari hesap kayıtlarına erişmek için kullanılan seçenektir. |
| Gönder | "Gönder" seçeneği ile Grid ekrandaki bilgilerin Excel'e gönderilmesi sağlanır. |
