# Muhasebe Özel Parametreleri

Muhasebe özel parametrelerinin tanımlanması için "[Özel Parametre Tanımlamaları](<Muhasebe Özel Parametreleri.md>)" ekranı kullanılır.

İşletme bilançosunda kar/zarar durumunun raporda görünmemesinin sağlanması için tanımlanacak özel parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | MUHASEBE |
| Anahtar | BILANCO_KARZARAR_GORUNMESIN |

BA-BS raporları oluşturulurken, faturaların fiili tarihe göre raporlanmasının sağlanması için tanımlanacak özel parametre aşağıdaki şekildedir:

| Özel Parametre Tanımlamaları Ekranı |  |
| --- | --- |
| Grup Kodu | MUHASEBE |
| Anahtar | BFORMFIILITARIH |
