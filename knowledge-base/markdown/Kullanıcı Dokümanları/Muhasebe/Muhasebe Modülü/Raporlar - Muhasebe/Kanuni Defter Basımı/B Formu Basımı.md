# B Formu Basımı

B Formu Basımı, Muhasebe Bölümünde, "Raporlar/Muhasebe Modülü" menüsünün altında yer alır. B Formu Basımı, "Bilanço Esasına Göre Defter Tutan Mükelleflerin Mal ve Hizmet Alımlarına İlişkin Bildirim Formunun" alınmasını sağlayan bölümdür. B Formu Basımı; B Formu Parametreleri, B Formu Tanımlamaları ve B Formu Kayıtları olmak üzere üç sekmeden oluşur.

**B Formu Parametreleri**

B Formu Parametreleri, B Formu ile ilgili olarak mükellef ve onaylayan kimlik bilgilerinin tanımlandığı sekmedir.

B Formu Basımı ekranı B Formu Parametreleri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| B Formu Basımı Ekranı |  |
| --- | --- |
| Limit Tutar | B formunda, ilgili vergilendirme döneminde satın alınan mal ve hizmetin KDV hariç tutarlarının toplamı ve resmi kurumlar tarafından belirlenen rakamı geçen alımların bildirilmesi gerekir. Belirlenen rakamın "Limit Tutar" alanına alanına girilmesi gerekir. |
| Başlangıç Tarihi/Bitiş Tarihi | B formu basımı için dönem başlangıç ve bitiş tarihinin girildiği alandır. |
| Faturalardan Getirilmeyecek Kayıtlar İçin Kısıt Girilsin | B formu basımı için faturalardan getirilmeyen kayıtlara kısıt verilmesi için kullanılan seçenektir. İşaretlendiğinde, gridde bulunan alanlar kullanılarak kısıt verilir. |
| Belge Sayısı Getirilirken Dekont Kayıtları Fiş Numarasına Göre Gruplansın | B formu basımı için faturalardan belge sayısı getirilirken dekont kayıtlarının fiş numaralarına göre gruplanması için kullanılan seçenektir. |
| İthalat/İhracat İçin Kullanılacak Tarih | İthalat/İhracat için kullanılacak belgeler için baz alınacak tarihin belirlendiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile; Fatura Tarihi, GÇB Tarihi ve İntaç Tarihi seçenekleri arasından seçim yapılır. "İntaç Tarihi" bilgisi, "Dış Ticaret" modülünde "İhracat Dosya İşlemleri" ekranının "Gümrük Beyanname Bilgileri" sekmesinden getirilir. |

**B Formu Tanımlamaları**

B Formu Basımı ekranı B Formu Tanımlamaları sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| B Formu Basımı Ekranı |  |
| --- | --- |
| Vergi Kimlik No | Mükellefe ait vergi kimlik numarasının girildiği alandır. |
| Vergi Dairesi Kodu | Mükellefin vergi dairesi kodunun girildiği alandır. |
| Soyadı/Unvan | Mükellefin soyadı ya da iş yeri unvan bilgisinin girildiği alandır. |
| Adı | Mükellefin adının girildiği alandır. |
| T.C Kimlik No | Mükellefin T.C Kimlik Numarasının girildiği alandır. |
| Ticaret Sicil No | Mükellefin ticaret sicil numarasının girildiği alandır. |
| E-Posta | Mükellefin e-posta adresinin girildiği alandır. |
| Alan Kodu | Mükellefin bağlı bulunduğu ilin telefon alan kodunun girildiği alandır. |
| Telefon No | Mükellefin telefon numarasının girildiği alandır. |
| HSV Tipi | B formunun ne sıfatla verildiğinin girildiği alandır. Alanın sağ tarafında bulunan aşağı ok butonu ile Mükellef veya Kanuni Temsilci seçenekleri arasından seçim yapılır. |
| Vergi Kimlik No | "HSV Tipi" alanında yapılan seçime göre Mükellef ya da Kanuni Temsilcinin vergi kimlik numarasının girildiği alandır. |
| Soyadı/Unvanı | "HSV Tipi" alanında yapılan seçime göre Mükellef ya da Kanuni Temsilcinin soyadı/iş yeri unvanının girildiği alandır. |
| Adı | "HSV Tipi" alanında yapılan seçime göre Mükellef ya da Kanuni Temsilcinin adının girildiği alandır. |
| T.C Kimlik No | "HSV Tipi" alanında yapılan seçime göre Mükellef ya da Kanuni Temsilcinin T.C Kimlik Numarasının girildiği alandır. B formu parametreleri tanımlanırken, "HSV Tipi" alanında "Mükellef" seçilmişse, buradaki tanımlamalar ile sol tarafta bulunan "Mükellef Kimlik Bilgileri" bölümündeki tanımlamaların aynı olması gerekir. |
| Onaylayan Tipi | Formu kimin onayladığı belirlenir. Alanın sağ tarafında yer alan Serbest Muhasebeci, Yeminli Mali Müşavir veya Serbest Mali Müşavir seçenekleri arasından seçim yapılır. |
| Vergi Kimlik No | "Onaylayan Tipi" alanında yapılan seçime göre ilgili Serbest Muhasebeci, Yeminli Mali Müşavir veya Serbest Mali Müşavir vergi kimlik numarasının girildiği alandır. |
| Soyadı/Unvan | "Onaylayan Tipi" alanında yapılan seçime göre ilgili Serbest Muhasebeci, Yeminli Mali Müşavir veya Serbest Mali Müşavir soyadı/iş yeri unvanının girildiği alandır. |
| Adı | "Onaylayan Tipi" alanında yapılan seçime göre ilgili Serbest Muhasebeci, Yeminli Mali Müşavir veya Serbest Mali Müşavir adının girildiği alandır. |
| T.C Kimlik No | "Onaylayan Tipi" alanında yapılan seçime göre ilgili Serbest Muhasebeci, Yeminli Mali Müşavir veya Serbest Mali Müşavir T.C Kimlik Numarasının girildiği alandır. |

**B Formu Kayıtları**

B Formu Basımı ekranı B Formu Kayıtları sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| B Formu Basımı Ekranı |  |
| --- | --- |
| Tip | Rapora aktarılacak tutarların alınacağı tipin belirlendiği alandır. Alanın sağ tarafında yer alan alış veya satış tipleri arasından seçim yapılır. |
| Sıra No | Elle giriş yapılacak kayıtlar için kullanıcı tarafından sıra numarası verilen alandır. Verilen sıra numarası, kayıtların Faturalardan Oluştur ![](../../../../../_assets/3b10b0988e7d5b9d2337.png) seçeneği ile program tarafından otomatik olarak gride aktarılması istendiğinde, satırlara aktarılan numaradır. |
| Unvan | Raporda listelenecek cari hesap unvanının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, cari isimler arasından seçim yapılır. |
| Vergi Numarası | Raporda listelenecek cari hesap vergi numarasının girildiği alandır. |
| T.C Kimlik No | Raporda listelenecek cari hesap T.C Kimlik Numarasının izlendiği alandır. |
| Belge Sayısı | Raporda listelenecek cari hesaba ait kayıt sayısının izlendiği alandır. |
| Tutar | Raporda listelenecek cari hesaba ait, "Tip alanında alış ya da satış olarak yapılan seçime göre KDV hariç toplam tutarın izlendiği alandır. |
| Ülke Kodu | Raporda listelenecek cari hesabın ülke kodunun izlendiği alandır. Kayıtların B formundan getirtilmesi istendiği zaman, ilgili cari hesaba ait ülke kodunun "Cari Hesap Kayıtları" bölümünden girilmesi gerekir. |
| **![](../../../../../_assets/3b10b0988e7d5b9d2337.png)**Faturalardan Oluştur | "B Formu Parametreleri" sekmesinde yer alan “Limit Tutar” alanında belirlenen tutarı aşan fatura ve dekont hareketleri raporda listelenmesi için kullanılan butondur. Raporda baz alınan değerler KDV hariç tutardır. |
| **![](../../../../../_assets/b50a6bbb66d3be0270f1.png)**Tüm Kayıtları Sil | Faturalardan Oluştur ![](../../../../../_assets/3b10b0988e7d5b9d2337.png) butonuna basılmasıyla veya elle giriş yapılmasıyla gridde listelenen kayıtların tamamının iptal edilmesi için kullanılan butondur. |
| **![](../../../../../_assets/bc74607c8abb23222f13.png)**Rapor | Faturalardan Oluştur ![](../../../../../_assets/3b10b0988e7d5b9d2337.png) butonuna basılmasıyla veya elle giriş yapılmasıyla gridde kayıtlar listelendikten sonra, rapor için XML dosya oluşturulması için kullanılan butondur. XML dosyanın hangi isimle ve hangi dizinde oluşturulacağı işlem sırasında sorgulanır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. B Formu kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
