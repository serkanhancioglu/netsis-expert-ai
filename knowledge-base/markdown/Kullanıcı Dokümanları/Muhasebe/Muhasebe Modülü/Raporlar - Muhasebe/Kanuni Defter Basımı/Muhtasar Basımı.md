# Muhtasar Basımı

Muhtasar Basımı, Muhasebe Bölümünde, "Raporlar/Muhasebe Modülü" menüsünün altında yer alır. Muhtasar Basımı, Muhasebe → Kayıt → [Muhtasar Parametreleri](<../../Kayıt - Muhasebe/Muhtasar Parametreleri.md>) bölümünden girilen bilgiler doğrultusunda, aylık veya üçer aylık dönemler için muhtasar beyanname basımlarının yapılmasını sağlayan bölümdür.

![](../../../../../_assets/e128717e7b51df9dcc73.png)

Muhtasar Beyanname ekranında yer alan butonlar ve içerdiği bilgiler şunlardır:

| Muhtasar Beyanname Ekranı |  |
| --- | --- |
| **![](../../../../../_assets/c7275efbddc154ea1579.jpg)**Sakla | Basım ekranında yapılan değişikliklerin saklanması için kullanılan butondur. Ekrana herhangi bir bilgi girilmesi ya da program tarafından parametrelere göre getirilen bilginin elle değiştirilmesi halinde, bu değişikliklerin daha sonra tekrar ekrana getirilmesi için mutlaka saklanması gerekir. Ekranda girilen bilgilerin saklanması ile, yapılan parametre tanımlamalarında değişiklik olmaz. |
| **![](../../../../../_assets/70b6b570f0f72d53d955.png)**Parametre Oku | "Muhtasar Basımı" ekranında elle değişiklik yapıldıktan sonra, parametrelere göre değerlerin tekrar ekrana getirilmesi için kullanılan butondur. |
| ![](../../../../../_assets/bfd25ffa1947d2603b7a.png) Tüm Alanlar İçin Değeri Oku | Tüm alanlar için değerlerin tekrar ekrana getirilmesi için kullanılan butondur. Butona basılması ile görüntülenen onay ekranına "Evet" yanıtı verilerek işlem gerçekleştirilir. ![](../../../../../_assets/d12e822663d3f88bead0.png) |
| ![](../../../../../_assets/d66ac7619b380a443d0f.png) Son Saklanan Değeri Oku | "Muhtasar Basımı" ekranına girildiğinde, "Muhtasar Parametreleri" bölümünde yapılan tanımlamalara göre, alanların program tarafından otomatik olarak ekrana getirilmesini sağlayan butondur. Daha önce bu değer üzerinde "Muhtasar Basımı" ekranında değişiklik yapılmış ve saklanmış ise, bilgilerin en son saklanan hallerinin getirilmesi için kullanılır. |
| ![](../../../../../_assets/3fdf5cacad8f17aeda01.png) XML | Beyanname ile ilgili tanımlamalar yapıldıktan sonra beyannamenin XML formatında saklanarak internet ortamında gönderilmesini sağlayan butondur. |
| **![](../../../../../_assets/238f4c122c1d1b4bbfa1.png)**Yazdır | Beyannamenin yazıcıdan dökümünün alınmasını sağlayan butondur. |
