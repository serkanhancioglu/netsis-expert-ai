# İndirilecek KDV Listesi

İndirilecek KDV Listesi, Muhasebe Bölümünde, "Raporlar/Muhasebe Modülü" menüsünün altında yer alır. İndirilecek KDV Listesi, İndirilecek KDV listesinin alınmasını sağlar. Fatura, Muhasebe, Kasa veya Dekont Kayıtları için farenin sağ tuşu ile sekmelere tıklandığında, istenen kayıtlar ile ilgili liste gride aktarılır.

![](../../../../../_assets/c204ac56499b75077709.png)

İndirilecek KDV Listesi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İndirilecek KDV Listesi Ekranı |  |
| --- | --- |
| Başlangıç Tarihi/Bitiş Tarihi | İndirilecek KDV listesi için başlangıç ve bitiş tarih aralığı kısıtı verilen alandır. |
| Kayıt Getir | Tarih aralığı girildikten sonra kayıtların gridde listelenmesi için kullanılan butondur. Sadece aktif sekmeye ait indirilecek KDV kayıtlarının getirilmesini sağlar. |
| Tüm Kayıtları Getir | Tarih aralığı girildikten sonra tüm kayıtların gridde listelenmesi için kullanılan butondur. Tüm sekmelere ait indirilecek KDV kayıtlarının getirilmesini sağlar. |
| Parametre Değiştir | [İndirilecek KDV Listesi Parametreleri](<../../Kayıt - Muhasebe/İndirilecek KDV Listesi Parametreleri.md>) ekranına erişilerek parametre değişikliği yapılmasını sağlayan butondur. |
| Kaydet | Aktif sekmeye ait indirilecek KDV kayıtlarının kaydedilmesi için kullanılan butondur. |
| Hepsini Kaydet | Tüm sekmelere ait indirilecek KDV kayıtlarının kaydedilmesi için kullanılan butondur. |
| Excel Oluştur | İndirilecek KDV listesinin Excel tablosuna aktarılması için kullanılan butondur. |
