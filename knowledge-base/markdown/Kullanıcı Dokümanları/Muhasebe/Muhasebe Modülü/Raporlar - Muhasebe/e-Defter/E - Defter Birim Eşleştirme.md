# E - Defter Birim Eşleştirme

e-Defter Birim Eşleştirme bölümü, e-Defter'de kullanılacak dövizlerin, uluslararası para birimleri ile eşleştirilerek kaydedilmesini sağlayan bölümdür. Grid ekranda yer alan döviz birimlerinin içinden kullanılacak uluşlararası para biriminin eşleştirileceği "Uluslararası Para Birim Kodu" alanının üzerine gelerek çift tıklandığında, alanın sağ tarafında yer alan aşağı ok butonu ile, eşleştirilecek birim kodu seçilir. Seçilen kodun kaydedilmesi için Değişiklikleri Kaydet ![](../../../../../_assets/f1c02c7398b15457bb27.png) butonuna tıklandıktan sonra Tamam ![](../../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak değişiklik kaydedilir. Yapılan kaydın iptal edilmesi için, iptal edilmesi istenen para biriminin üzerine gelerek fare ile çift tıklandıktan sonra ![](../../../../../_assets/b773bfa72d2790fad350.png) Kayıt İptal butonuna tıklanır. Butona tıklanması ile ekrana gelen uyarı ekranına onay verildikten sonra Tamam ![](../../../../../_assets/39d77b8716226638d9ce.jpg) butonuna tıklanarak iptal işlemi kaydedilir. Eşleştirme iptalinden veya yapılan eşleştirme kaydından vazgeçilmesi halinde ekrandan çıkmak için İptal ![](../../../../../_assets/973111d004995dca0113.jpg) butonu kullanılır.
