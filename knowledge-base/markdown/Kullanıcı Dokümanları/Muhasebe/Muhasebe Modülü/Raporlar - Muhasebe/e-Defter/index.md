# e-Defter

e-Defter, Yevmiye Defteri'nin GİB'e (Gelir İdaresi Birliği) elektronik ortamda iletildiği defterdir.

Yevmiye Defteri ve Büyük Defter (Defter-i Kebir) olmak üzere iki türlü defter vardır.

e-Defter Modülünün programda yer alması için öncelikle e-Defter lisansının satın alınması gerekir. Lisans satın alındıktan sonra Muhasebe → Raporlar menüsünün altında "e-Defter" bölümü aktif hale gelir.

e-Defter menüsünün içinde; e-Defter Hazırlık, e-Defter Onaylama ve Birim Eşleştirme bölümleri yer alır.
