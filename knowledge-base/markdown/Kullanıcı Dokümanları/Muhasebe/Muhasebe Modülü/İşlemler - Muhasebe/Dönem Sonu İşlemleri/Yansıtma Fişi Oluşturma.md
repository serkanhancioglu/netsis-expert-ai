# Yansıtma Fişi Oluşturma

Yansıtma Fişi Oluşturma, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Yansıtma Fişi Oluşturma, "Yansıtma Girişi" bölümünden girilen yansıtma hesaplarına göre, yansıtma fişinin otomatik olarak oluşturulmasını sağlar. Yansıtma fişi oluşturulmadan önce, 710 hesaplara sarf fişlerinin, diğer gider hesaplarının da ilgili hesaplara yansıtılması gerekir. Yansıtma yapılacak ayla ilgili tüm kayıtların, dağıtımların ve yansıtma fişi ekranından tüm tanımlamaların yapılması gerekir.

"Kar/Zarar Devir Fişi" oluşturulmadan önce “Yansıtma Girişi” bölümünde anlatıldığı gibi 7 rakamı ile başlayan hesap kodlarının yansıtılacağı ilgili muavinlerin girilmesi gerekir.

![](../../../../../_assets/ba6154bc53fca725fc33.png)

Yansıtma Fişi Oluşturma ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Yansıtma Fişi Ekranı |  |
| --- | --- |
| Fiş Tarihi | Oluşturulacak yansıtma fişi için tarih belirlenen alandır. Fiş tarihi, sistem tarihinden okunarak getirilir ve üzerinde istenen değişiklik yapılabilir. |
| Fiş No | Girilen ayın son fiş numarasının bir fazlasının otomatik olarak aktarıldığı alandır. Kullanıcı, fiş numarasında değişiklik yapabilir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Açıklama | Yansıtma fişi açıklamasının program tarafından otomatik olarak aktarıldığı alandır. Kullanıcı, açıklama bilgisinde değişiklik yapabilir. |
| Muhasebe Kodu | Yansıtma fişi oluşturulacak muhasebe hesap kodları için başlangıç ve bitiş aralığı girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, muhasebe kodları arasından seçim yapılır. |
| Ay Kodu Aralığı | Yansıtma yapılacak ay için başlangıç ve bitiş aralığı girilen alandır. |
| Referans Kodu | Muhasebe → Kayıt → [Muhasebe Parametreleri](<../../Kayıt - Muhasebe/Muhasebe Parametreleri.md>) → “Fişlerde Referans Kodu Sorulsun” parametresinin işaretlenmesi ile aktif hale gelen alandır. Yansıtma fişi için referans kodu girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| Proje Kodu | Yardımcı Programlar → Kayıt → [Şirket-Şube Parametre Tanımları](<../../../../Genel/Yardımcı Programlar/Kayıt - Yardımcı Programlar/Şirket - Şube - Parametre Tanımları.md>) → "Proje Uygulaması Var" parametresinin işaretlenmesi ile aktif hale gelen alandır. Yansıtma fişi için proje kodu girilir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları arasından seçim yapılır. |
| Şubeler Dahil Yapılsın | Yansıtma fişi oluşturma işlemine şubelerin de dahil edilmesi için kullanılan seçenektir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
