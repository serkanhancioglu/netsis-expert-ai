# Yansıtma Girişi (Diğer Hesaplar)

Yansıtma Girişi (Diğer Hesaplar), "Yansıtma Girişi" ekranında olmayan **diğer gider hesaplarının** yansıtılması için kullanılan bölümdür.

| Yansıtma Girişi (Diğer Hesaplar) Ekranı |  |
| --- | --- |
| Muhasebe Kodu | Yansıtma karşılığı girilen muhasebe kodunun izlendiği alandır. |
| Yansıtma Kodu | Yansıtma fişinin oluşturulması için, 7 rakamı ile başlayan gider hesaplarının yansıtma karşılıklarının girilmesini sağlayan bölümdür. Tanımlanacak yansıtma hesaplarının, daha önce “Muhasebe Hesap Planından” tanımlanması gerekir. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile hesap kodları arasından seçim yapılır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır. Yansıtma Girişi (Diğer Hesaplar) kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
