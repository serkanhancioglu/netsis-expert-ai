# Fiş Bazında Yuvarlama Farkı Kapatma

Fiş Bazında Yuvarlama Farkı Kapatma, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Fiş Bazında Yuvarlama Farkı Kapatma, yuvarlamadan kaynaklanan farkların, entegrasyondan aktarılırken ve yevmiye fişinden çıkarken program tarafından kapatılmasını sağlayan bölümdür. Fiş Bazında Yuvarlama Farkı Kapatma, önceden oluşturulan ya da fark kapatılmadan çıkılan yevmiye fişindeki yuvarlama farklarının hızlı bir şekilde kapatılması için kullanılır. Bu işlem sonucu çıkacak "Fiş Bazında Yuvarlama Farkı Raporunda" hangi fişlerde fark olduğu izlenir ya da seçenekli olarak bu farkların program tarafından kapatılması sağlanır.

![](../../../../_assets/8fbb44af0da947139ea4.png)

Fiş Bazında Yuvarlama Farkı Kapatma ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fiş Bazında Yuvarlama Farkı Kapatma Ekranı |  |
| --- | --- |
| Ay Kodu | Yuvarlama farklarının kontrol edileceği fişlere ait ay bilgisinin girildiği alandır. |
| Fiş No Aralığı | Yuvarlama farklarının kontrol edileceği fişler için başlangıç ve bitiş numara aralığı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Fiş Tipi | Yuvarlama farklarının kontrol edileceği fişler için fiş tipi kısıtı verilen alandır. Mahsup, Tediye, Kapanış Fişi, Tahsil, Açılış Fişi ve Hepsi seçeneklerinden oluşur. "Hepsi" seçeneğinin işaretlenmesi ile, fiş tiplerine bakılmadan verilen kısıtlara uyan tüm fişler kontrol edilir. |
| Resmi Defter Basımı Çekilmiş Fişler Düzeltilsin | Yukarıda verilen kısıtlara uyan ve resmi defter basımı yapılmış fişlerin de kontrol edilmesi ve gerekirse yuvarlama farklarının kapatılması için kullanılan seçenektir. İşaretlenmediği zaman, yuvarlama farkı bulunan fişin resmi defter basımı yapıldıysa, yuvarlama farkları kapatılmaz. |
| Kayıtlara Geçilsin | Girilen aralıklara uyan fişlerde yuvarlama farkı tespit edildiğinde, farkın program tarafından kapatılması için kullanılan seçenektir. Aksi takdirde, yuvarlama farkları kapatılmayarak sadece işlem tamamlandıktan sonra çıkan "Fiş Bazında Yuvarlama Farkı Sonuç Raporunda" listelenir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
