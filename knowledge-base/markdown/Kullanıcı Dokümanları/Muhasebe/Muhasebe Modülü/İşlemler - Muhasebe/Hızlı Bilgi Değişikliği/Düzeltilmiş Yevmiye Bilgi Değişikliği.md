# Düzeltilmiş Yevmiye Bilgi Değişikliği

Düzeltilmiş Yevmiye Bilgi Değişikliği, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Düzeltilmiş Yevmiye Bilgi Değişikliği, Enflasyon muhasebesinin kullanıldığı durumlarda işlev kazanan bir bölümdür.

Enflasyon muhasebesi ile ilgili bu bölümün kullanımı hakkında detaylı bilgi için; Muhasebe → Ekler → [Ek-1 Enflasyon Muhasebesi](<../../Ekler - Muhasebe/Ek-1 Enflasyon Muhasebesi/index.md>) dokümanına bakılabilir.

![](../../../../../_assets/46f001398f21dc1c2c7e.png)

Düzeltilmiş Yevmiye Bilgi Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Düzeltilmiş Yevmiye Bilgi Değişikliği Ekranı |  |
| --- | --- |
| Ay Kodu | Düzeltilmiş yevmiye bilgi değişikliği için yevmiye defteri çekilen son ay kodunun girildiği alandır. |
| Nakli Borç Yekün | İlgili ay sonunda yevmiye defterinde oluşan borç toplamının girildiği alandır. |
| Nakli Alacak Yekün | İlgili ay sonunda yevmiye defterinde oluşan alacak toplamının girildiği alandır. |
| Yevmiye No | Düzeltilmiş yevmiye madde numarasının girildiği alandır. |
| Yevmiye Çekim Tarihi | Yevmiye defterinin “Resmi Basım” seçeneği işaretlenerek, defter çekiminin yapıldığı tarihin izlendiği alandır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
