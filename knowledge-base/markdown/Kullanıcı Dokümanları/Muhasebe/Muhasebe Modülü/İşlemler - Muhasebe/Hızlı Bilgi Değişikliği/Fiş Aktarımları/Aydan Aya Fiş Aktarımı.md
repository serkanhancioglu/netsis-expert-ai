# Aydan Aya Fiş Aktarımı

Aydan Aya Fiş Aktarımı, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Aydan Aya Fiş Aktarımı, farklı aya ait bir yevmiye fişinin aynı aya veya başka bir aya, istenen “Fiş Numarası” ile aktarılmasını sağlayan bölümdür.

![](../../../../../../_assets/faba51781db193ca1648.png)

Aydan Aya Fiş Aktarımı ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Aydan Aya Fiş Aktarımı Ekranı |  |
| --- | --- |
| Kaynak Ay | Başka bir aya veya aynı aya, başka bir fiş numarasıyla aktarılması istenen fişin bulunduğu ay kodunun girildiği alandır. |
| Kaynak Fiş No | Başka bir aya aktarılacak fiş numarasının girildiği alandır. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Hedef Ay | Fişin aktarılacağı ay kodunun girildiği alandır. |
| Hedef Fiş No | Hedef ay için aktarılması istenen fiş numarasının girildiği alandır. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Hedef Fiş Tarihi | Hedef ay için fiş tarihi girilen alandır. |
| Evrak Tarihi Hedef Fiş Tarihi Olsun | Evrak tarihinin hedef fiş tarihi olarak aktarılması için kullanılan seçenektir. |
| Değişecek Açıklama | Aktarılacak fiş için değiştirilmesi istenen açıklama bilgisinin girildiği alandır |
| Yeni Açıklama | Aktarılacak fiş için yeni açıklama bilgisi girilen alandır. |
| Eski Fiş No Silinsin | Fiş aktarımından sonra, kaynak fiş numarasının silinmesi için kullanılan seçenektir. Boş bırakıldığında, kaynak fiş numarası hedef aya aktarılır ve silinmez. Hedef fiş numarasında başka bir kayıt varsa, virman yapılması ile ilgili sorgulama program tarafından ekrana getirilir. Onaylandığında, virman işlemi yapılarak iki fiş birleştirilir. |
| ![](../../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. |
| ![](../../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
