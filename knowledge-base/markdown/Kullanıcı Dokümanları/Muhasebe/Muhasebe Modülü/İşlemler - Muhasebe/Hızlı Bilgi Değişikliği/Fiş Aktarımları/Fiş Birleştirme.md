# Fiş Birleştirme

Fiş Birleştirme, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Fiş Birleştirme, girilen tarihte aynı tipte olan (Mahsup, Tahsil, Tediye, Açılış, Kapanış) fişlerin tek bir fiş haline getirilmesini sağlayan bölümdür.

![](../../../../../../_assets/af619ae7f0a3dc482e6a.png)

Fiş Birleştirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fiş Birleştirme Ekranı |  |
| --- | --- |
| Tarih | Fiş birleştirme için tarih girilen alandır. Girilen tarihe uygun olmayan fişler, birleştirme işlemine dahil edilmez. |
| Fiş No Aralığı | Fiş birleştirme için başlangıç ve bitiş numara aralığı girilen alandır. Girilen aralığa uygun olmayan fişler, birleştirme işlemine dahil edilmez. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Fiş Tipi | Yevmiye fişlerinin birleştirileceği fiş tipinin seçildiği alandır. Mahsup, Tahsil, Tediye, Açılış Fişi, Kapanış Fişi ve Hepsi seçeneklerinden oluşur. "Hepsi" seçeneği işaretlendiğinde (tüm fişler kendi fiş tipleri ile) verilen tarihe uygun fişlerin hepsi birleştirilir. |
| Eski Fişler Silinsin | Fiş birleştirme işlemi gerçekleştikten sonra, eski fişlerin silinmesi istendiğinde işaretlenmesi gereken alandır. |
| Değişen Fiş No Açıklama-2'ye Atılsın | Fiş birleştirme işlemi gerçekleştikten sonra, oluşan yeni fişin "Açıklama 2" alanına eski fiş numaralarının aktarılması için kullanılan seçenektir. |
| ![](../../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. |
| ![](../../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
