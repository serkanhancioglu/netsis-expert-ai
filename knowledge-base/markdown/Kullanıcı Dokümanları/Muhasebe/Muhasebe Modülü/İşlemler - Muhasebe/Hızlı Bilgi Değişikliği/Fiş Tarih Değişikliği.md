# Fiş Tarih Değişikliği

Fiş Tarih Değişikliği, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Fiş Tarih Değişikliği, aynı aya ait olması şartıyla, yevmiye fişlerinin sadece gün tarihlerinin değiştirilmesini sağlayan işlemdir.

![](../../../../../_assets/0832f7e19189b16ab12d.png)

Fiş Tarih Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fiş Tarih Değişikliği Ekranı |  |
| --- | --- |
| Ay Kodu | Tarihi değiştirilecek fiş için ay kodunun girildiği alandır. |
| Fiş No | Tarihi değiştirilecek fiş numarasının girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Tarih | Girilen fiş tarihinin otomatik olarak aktarıldığı alandır. Kullanıcı müdahale edemez. |
| Yeni Tarih | İlgili fişe verilmesi istenen gün değerinin girildiği alandır. |
| Evrak Tarihi Değiştirilsin | Evrak tarihinin de değiştirilmesi için kullanılan seçenektir. |
| Yeni Evrak Tarihi | "Evrak Tarihi Değiştirilsin" seçeneğinin işaretlenmesi ile aktif hale gelen alandır. Yeni evrak tarihinin girilmesini sağlar. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
