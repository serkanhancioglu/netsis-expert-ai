# Proje Kodu Değişikliği

Proje Kodu Değişikliği, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Proje Kodu Değişikliği, ön muhasebe modüllerinde veya muhasebe modülünde kaydedilen proje kodlarını değiştirmek için kullanılan bölümdür.

![](../../../../../_assets/a88588779b03cc6934d4.png)

Hızlı Proje Kodu Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Hızlı Proje Kodu Değişikliği Ekranı |  |
| --- | --- |
| Eski Proje Kodu | Değiştirilmesi istenen proje kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları arasından seçim yapılır. |
| Yeni Proje Kodu | Yeni proje kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, proje kodları arasından seçim yapılır. |
| Eski Proje Kodu Silinsin | Proje kodu değişiklik işlemi bittikten sonra, eski proje kodunun silinmesi için kullanılan seçenektir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. Tüm modüllerde kullanılan eski proje kodu, yeni proje kodu ile değişir. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
