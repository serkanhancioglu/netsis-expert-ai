# Referans Kodu Değişikliği

Referans Kodu Değişikliği, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Referans Kodu Değişikliği, ön muhasebe modüllerinde veya muhasebe modülünde kaydedilen referans kodlarını değiştirmek için kullanılan bölümdür.

![](../../../../../_assets/4cec3b8b5f3abc7bbb17.png)

Referans Kodu Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Referans Kodu Değişikliği Ekranı |  |
| --- | --- |
| Eski Referans Kodu | Değiştirilmesi istenen referans kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| Yeni Referans Kodu | Yeni referans kodunun girildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, referans kodları arasından seçim yapılır. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. Tüm modüllerde kullanılan eski referans kodu, yeni referans kodu ile değişir. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
