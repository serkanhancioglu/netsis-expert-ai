# Yevmiye Detay Değişikliği

Yevmiye Detay Değişikliği, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Yevmiye Detay Değişikliği, yevmiye fiş detaylarının değiştirilmesi için kullanılan işlemdir.

![](../../../../../_assets/e9e1f3d1aa03ca042b48.png)

Yevmiye Detay Değişikliği ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Yevmiye Detay Değişikliği Ekranı |  |
| --- | --- |
| Hesap Türü | Yevmiye detay değişikliği yapılacak hesap türünün seçildiği alandır. Ana, Grup, Muavin ve Hepsi seçeneklerinden oluşur. |
| Hesap Kodu Aralığı | Yevmiye detay değişikliği için başlangıç ve bitiş hesap kodu aralığı kısıtı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Hesap Kodu Maskesi | Yevmiye detay değişikliği için hesap kodlarına filtre tanımlayarak kısıt verilmesini sağlar. **Örneğin** Ana hesap kodu 1 rakamı ile başlayan hesapların listesinin alınması için bu alana 1% rakamının yazılması gerekir. Maskeleme işleminde alt çizgi “\_” tek bir karakter yerine, yüzde “%” birden fazla bilinmeyen karakter yerine kullanılır. |
| Hesap Hariç Aralığı | Yevmiye detay değişikliği için kısıt verilirken hariç tutulması istenen hesaplar için başlangıç ve bitiş hesap kodu aralığı girilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, hesap kodları arasından seçim yapılır. |
| Grup Kodu Aralığı | Yevmiye detay değişikliği için grup kodu kısıtı verilen alandır. |
| Kullanıcı No | Yevmiye detay değişikliği için kullanıcı numarası kısıtı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, kullanıcı numaraları arasından seçim yapılır. |
| Ay Kodu | Yevmiye detay değişikliği yapılacak ay kodunun girildiği alandır. |
| Tarih Fiş Aralığı | Yevmiye detay değişikliği için tarih fiş aralığı seçilen alandır. Tarih, Fiş Numarası ve Evrak Tarihi Aralığı seçeneklerinden oluşur. İşaretlenen seçenek için başlangıç ve bitiş aralığı girilerek kısıt verilir. |
| Fiş Tipi | Yevmiye detay değişikliği için fiş tipi kısıtı verilen alandır. Mahsup, tahsil, Tediye, Açılış Fişi, Kapanış Fişi, Hepsi seçeneklerinden oluşur. |
| Belge Türü Boş Olanlar Listelensin | Yevmiye detay değişikliği için verilen kısıtlar dikkate alınarak, "Belge Türü" boş olan fişlerin listelenmesi için kullanılan seçenektir. |
| Belge No Boş Olanlar Listelensin | Yevmiye detay değişikliği için verilen kısıtlar dikkate alınarak, "Belge Numarası" boş olan fişlerin listelenmesi için kullanılan seçenektir. |
| Ödeme Türü Boş Olanlar Listelensin | Yevmiye detay değişikliği için verilen kısıtlar dikkate alınarak, "Ödeme Türü" boş olanların listelenmesi için kullanılan seçenektir. |
| ![](../../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilerin onaylanarak işlemin başlatılmasını sağlayan butondur. Butona basılması ile görüntülenen "Yevmiye Detay Değişikliği" ekranı ile, değiştirilmesi istenen fiş detayının üzerine geldikten sonra farenin sağ tuşu veya klavyede yer alan boşluk tuşuna basılarak detay değişikliği yapılır. Yapılan değişikliklerin kaydedilmesi için Değişen Bilgileri Sakla ![](../../../../../_assets/3d2f85f156d8993577ca.png) butonuna tıklandığında, "Muhasebe fiş bilgileri güncellenecektir. Devam etmek istiyor musunuz? şeklindeki uyarı ekranına onay verildikten sonra işlem başarıyla sonlanır. ![](../../../../../_assets/3e6804ce019b3703203b.png) |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
