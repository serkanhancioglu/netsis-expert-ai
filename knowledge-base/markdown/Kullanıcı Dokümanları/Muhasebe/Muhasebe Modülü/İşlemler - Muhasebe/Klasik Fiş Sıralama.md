# Klasik Fiş Sıralama

Klasik Fiş Sıralama, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Ön muhasebe ile entegre çalışıldığında; entegrasyondan muhasebeye fiş aktarılırken, genelde hesapların çalışma şekli (Borç/Alacak durumu) dikkate alınmadan aktarılır. "Klasik Fiş Sıralama", yevmiye fiş kayıtlarını ekranda ve klasik yevmiye fiş listesi dışında, yevmiye fiş listesinden klasik fiş sıralaması şekliyle, önce borç sonra alacak kayıtları sıralanacak şekilde izlenmesi istendiğinde kullanılan bir işlemdir. "Klasik Yevmiye Fiş Listesi" bölümünden alınacak döküm, zaten Borç/Alacak sırasında olduğundan bu liste için ayrıca sıralama yapmaya gerek yoktur. Ancak, diğer bölümlerde de yevmiye fişlerini klasik sırada izlemek için bu işlemin kullanılması gerekir.

![](../../../../_assets/13ff8975d19b33474913.png)

Klasik Fiş Sıralama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Klasik Fiş Sıralama Ekranı |  |
| --- | --- |
| Ay Kodu | Klasik fiş sıralaması yapılacak ay kodunun girildiği alandır. |
| Başlangıç Fiş No | İlgili ay kodundaki ilk fiş numarasının otomatik olarak aktarıldığı alandır. İstendiği zaman değiştirilebilir. Girilen fiş numarasından başlayarak sıralama yapılır. Boş bırakılmaz. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaralarına ulaşılır. |
| Bitiş Fiş No | İlgili ay kodundaki son fiş numarasının otomatik olarak aktarıldığı alandır. İstendiği zaman değiştirilebilir. Girilen fiş numarasından başlayarak sıralama yapılır. Boş bırakılmaz. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaralarına ulaşılır. |
| Şubeler Dahil | Klasik fiş sıralama işlemine şubelerin dahil edilmesi için kullanılan seçenektir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
