# Yevmiye Kontrol

Yevmiye Kontrol, Muhasebe Bölümünde, "İşlemler/Muhasebe Modülü" menüsünün altında yer alır. Yevmiye Kontrol, alınan çeşitli dökümlerde, mizanla fiş bakiyelerinin tutmaması durumunda kullanılan bölümdür. Bunun dışında kullanılması gereken yerler, program destek firması tarafından saptanır.

![](../../../../_assets/afa2ee07f28f6501eb60.png)

Yevmiye Kontrol ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Yevmiye Kontrol Ekranı |  |
| --- | --- |
| **Şubeler Dahil Yapılsın** | Yevmiye kontrol işleminin şubeler için de yapılması istendiğinde işaretlenmesi gereken seçenektir. "Yevmiye Kontrol "menüsü sadece "admin" olan kullanıcıların ekranına gelir. Admin kullanıcı kaydı hakkında detaylı bilgi için; Genel → Kullanıcı İşlemleri → Kayıt → [Kullanıcı Kayıtları](<../../../Lojistik - Satış/Kargo - Gönderi/Kayıt - Kargo - Gönderi/Kargo Kullanıcı Kayıtları.md>) dokümanına bakılabilir. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
