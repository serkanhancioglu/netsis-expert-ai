# Alternatif Reçete Kaydı Ekranında Kullanılan Sağ Tuş Seçenekleri

Alternatif Reçete Kaydı ekranının grid alanında iken farenin sağ tuşu ile ekrana gelen sağ tuş seçenekleri şunlardır:

| Alternatif Reçete Kaydı Sağ Tuş Seçenekleri |  |
| --- | --- |
| Açıklama Düzenle | Alternatif reçete kaydı için girilen açıklama alanının düzenlenmesi için kullanılan seçenektir. |
| Varsayılan Reçete Yap | Mevcut reçetenin silinmeyerek alternatif reçete olarak kaydedilmesi için kullanılan seçenektir. |
| Gönder | Bilgilerin Excel’e aktarılması, grafik hazırlanması ve akıllı gride gönderilmesi için kullanılan seçenektir. |
