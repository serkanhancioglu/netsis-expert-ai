# Bütçe Planlama

Bütçe Planlama, Üretim modülünde Kayıt/Üretim menüsünün altında yer alır. İşletmenin durumuna bakılmaksızın aylık girilen üretim hedefleri için aylık ihtiyaç çıkarılmasını sağlayan bölümdür. Aylık hedeflerin elle (Manuel) girilmesi gerekir. Kullanıcının belirlediği hedeflere göre ihtiyaçlar hesaplanarak listelenir.

Bütçe Planlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Bütçe Planlama Ekranı |  |
| --- | --- |
| Stok Kodu | Bütçe planlaması yapılacak stok için kod bilgisi girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, stok kodlarına ulaşılır. |
| Asorti Kodu | Asorti kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, tanımlanan özellik kodlarına ulaşılır. |
| Asorti Kodu Açıklaması | Asorti koduna ait açıklama bilgisinin otomatik olarak ekrana girildiği alandır. |
| ![](../../../_assets/dc5fe4574a410c6e8f95.png) Kayıtları Sil | Griddeki kayıtların silinmesi için kullanılan butondur. |
| ![](../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Bütçe planlama için girilen bilgilerin kaydedilmesini sağlayan butondur. |
| ![](../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgilerden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
