# Fire Kodu Tanımları

Fire Kodu Tanımları, Üretim modülünde Kayıt/Üretim menüsünün altında yer alır. Üretimde kullanılacak fire kodlarının tanımlanması için kullanılan bölümdür.

Fire Kodu tanımları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Fire Kodu Tanımları Ekranı |  |
| --- | --- |
| Fire Kodu | Tanımlaması yapılacak fire kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) fire kodlarına ulaşılır. |
| Fire Açıklama | "Fire Kodu" alanında tanımlaması yapılan fire için isim bilgisi girilen alandır. |
| Hareket Tipi | Tanımlanan fire için hareket tipi girilen alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile hareket tipleri arasından seçim yapılır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
