# Planlanan Bileşen Değişiklikleri Ekranında Kullanılan Sağ Tuş Seçenekleri

Planlanan Bileşen Değişiklikleri ekranının grid alanında iken farenin sağ tuşu ile ekrana gelen seçenekler şunlardır:

| Planlanan Bileşen Değişiklikleri Ekranı Sağ Tuş Seçenekleri |  |
| --- | --- |
| Revizyon Kopyalama | Revizyon kopyalanması için kullanılan seçenektir. |
| Revizyon Hata Listesi | Revizyon hata listesi almak için kullanılan seçenektir. |
| Reçete Yansıtma İptali | Reçete yansıtma iptali için kullanılan seçenektir. |
| Gönder | Bilgilerin Excel’e aktarılması, grafik hazırlanması ve akıllı gride gönderilmesi için kullanılan seçenektir. |
