# Şube/Lokal Depo Tanımlamaları

Şube Lokal Depo Tanımlamaları, Üretim modülünde Kayıt/Üretim menüsünün altında yer alır. Üretimde kullanılacak şube/lokal depo tanımlamalarının yapılmasını sağlayan bölümdür.

Şube Lokal Depo Tanımlamaları ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Şube/Lokal Depo Tanımlamaları Ekranı |  |
| --- | --- |
| Fabrika Kodu | Şube/Lokal Depo tanımlaması yapılacak fabrika kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, fabrika kodlarına ulaşılır. |
| Şube/Depo | Girilen fabrika kodunun şube için mi yoksa depo için mi tanımlanacağının seçildiği alandır. |
| Kod | Şube/Depo seçiminin yapılmasına göre ilgili şube kodunun/depo kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile ilgili kodlara ulaşılır. |
| Depo Tipi | Şube veya Lokal Depo tanımlaması yapıldıktan sonra ilgili depo tipinin seçildiği alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile depo tipi olarak kullanılacak olan yer seçimi yapılır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
