# Kaynak Tanımlama Ekranında Kullanılan Özel Seçenekler

Kaynak Tanımlama ekranında grid ekran üzerinde iken sağ fare tuşu ile ekrana gelen seçenekler şunlardır:

| Kaynak Tanımlama Ekranı Sağ Tuş Seçenekleri |  |
| --- | --- |
| Tablo Özel Parametrelerini Belirle | Kaynak Özel Parametreleri ekranından özel parametre tanımlanmasını sağlayan seçenektir. İlgili kaynak için Grup Kodu ve Değer tanımlanmasını sağlar. ![](../../../../../../_assets/39a78a69de241acfcb84.png) |
| Gönder | Ekranda bulunan grid bilgisinin Excel programına aktarılmasını sağlar. Uygulama başladığında, “Bilgiler karşı uygulamaya gönderiliyor “ mesajı ile karşılaşılır ve işlem bittiğinde ilgili uygulamaya geçilir. Böylece, grid ekranında bulunan tüm bilgiler seçilen uygulamaya aktarılır. |
