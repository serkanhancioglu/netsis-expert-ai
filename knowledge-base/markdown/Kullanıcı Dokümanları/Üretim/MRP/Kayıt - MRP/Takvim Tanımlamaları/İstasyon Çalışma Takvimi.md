# İstasyon Çalışma Takvimi

İstasyon Çalışma Takvimi, Üretim Bölümü'nde, "Kayıt/MRP" menüsünün altında yer alır. İşletme için genel anlamda tanımlanan takvim, iş istasyonu bazında farklılık gösteriyorsa, İstasyon Çalışma Takvimi bölümünde genel takvim, iş istasyonuna yansıtılır.

İstasyon Çalışma Takvimi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İstasyon Çalışma Takvimi Ekranı |  |
| --- | --- |
| İstasyon Kodu | İstasyon çalışma takvimi için istasyon kodu tanımlanan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, istasyon kodlarına ulaşılır. |
| Takvim Kodu | İstasyon çalışma takvimi için takvim kodu tanımlanan alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, takvim kodlarına ulaşılır. |
| Ay | Tanımlanan takvim için ay bilgisi girilen alandır |
| Yıl | Tanımlanan takvim için yıl bilgisi girilen alandır |
| ![](../../../../../_assets/af2381dffd91899333ef.png) Takvim Oluştur | Fabrika Çalışma Takviminin ekrana getirilmesini sağlayan butondur. İstasyon bazında, vardiyalarda değişiklik yapılacak ise kullanıcılar tarafından düzenlenebilir. |
| Tarih | İstasyon çalışma takvimi için tarih girilen alandır. |
| Vardiya Sayısı | Tanımlanan takvim için vardiya sayısı girilen alandır. Vardiya sayısı hesaplanırken "MRP Parametreleri" bölümünden tanımlanan vardiyalar baz alınır. **Örneğin;** Parametrelerde 2 vardiya için süre girilmişse oluşan takvimde günlük vardiya sayıları 2 olarak oluşturulur. Oluşturulan takvimdeki sapmalar kullanıcı tarafından düzeltilebilir. **Örneğin;** Pazar günleri çalışılmıyor ise, Pazar günlerinin vardiya sayısının sıfırlanması ve arada bayram günleri var ise bunlara da müdahale edilmesi gerekir. Aynı şekilde, normal vardiya sayısından fazla vardiya yapılması düşünülüyor ise, bu günler için vardiya sayılarının arttırılması gerekir. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

İstasyon Çalışma Takvimi ekranında kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
