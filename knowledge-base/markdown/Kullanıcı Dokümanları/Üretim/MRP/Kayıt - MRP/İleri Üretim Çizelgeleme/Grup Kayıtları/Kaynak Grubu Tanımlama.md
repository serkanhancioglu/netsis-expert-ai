# Kaynak Grubu Tanımlama

Kaynak Grubu Tanımlama, Üretim Bölümü'nde Kayıt/MRP menüsünün altında yer alır. İleri Üretim Planlama uygulamasında kullanılacak kaynak grubunun tanımlanması için kullanılan bölümdür. Burada tanımlanan kaynak grupları “Kaynak Tanımlama” ekranındaki “Grup Kodu” alanında kullanılır.

Kaynak Grubu Tanımlama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Kaynak Grubu Tanımlama Ekranı |  |
| --- | --- |
| Grup Kodu | İleri Üretim Planlama uygulamasında kullanılacak kaynak grubu için grup kodu tanımlanan alandır. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, grup kodları arasından seçim yapılır. |
| Açıklama | "Grup Kodu" alanında tanımlanan grup için açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
