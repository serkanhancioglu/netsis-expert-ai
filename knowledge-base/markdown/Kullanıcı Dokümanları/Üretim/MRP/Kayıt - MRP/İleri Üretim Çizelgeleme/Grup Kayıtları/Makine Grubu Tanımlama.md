# Makine Grubu Tanımlama

Makine Grubu Tanımlama, Üretim Bölümü'nde Kayıt/MRP menüsünün altında yer alır. İleri Üretim Planlama uygulamasında kullanılacak makine grubunun tanımlanması için kullanılan bölümdür. Burada tanımlanan makine grupları “Makine Tanımlama” ekranındaki “Grup Kodu” alanında kullanılır. Benzer şekilde Makine-Kaynak Eşleştirme ekranlarında da operasyon gruplarının kullanımı kolaylık sağlar.

| Makine Grubu Tanımlama Ekranı |  |
| --- | --- |
| Grup Kodu | İleri Üretim Planlama uygulamasında kullanılacak makine grubu için grup kodu tanımlanan alandır. Rehber butonu ![](../../../../../../_assets/088477bb321d1b20c939.jpg) ile, grup kodları arasından seçim yapılır. |
| Açıklama | "Grup Kodu" alanında tanımlanan grup için açıklama bilgisi girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Makine Grubu Tanımlama kaydının iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
