# Operasyon Tanımlama Ekranında Kullanılan Sağ Tuş Seçenekleri

Operasyon Tanımlama ekranında farenin sağ tuşu ile ekrana gelen seçenekler şunlardır:

| Operasyon Tanımlama Sağ Tuş Seçenekleri |  |
| --- | --- |
| Operasyonu Yapabilecek Makine Belirle | Operasyon-Makine Eşleştirme ekranına erişim sağlanarak, operasyonu yapabilecek makinenin belirlenmesi için kullanılan seçenektir. |
| Operasyonda Kullanılacak Kaynakları Belirle | Operasyon-Kaynak Eşleştirme ekranına erişim sağlanarak, operasyonda kullanılacak kaynakların belirlenmesi için kullanılan seçenektir. |
| Operasyona Ait Hazırlık Süreleri Girişi | Hazırlık Süresi Tanımlama ekranına erişim sağlanarak, operasyona ait hazırlık sürelerinin tanımlanması için kullanılan seçenektir. |
| Gönder | Bilgilerin Excel’e aktarılması, grafik hazırlanması veya akıllı gride gönderilmesi için kullanılan seçenektir. |
