# Vardiya Planı İzleme

Vardiya Planı İzleme, Üretim Bölümü'nde Kayıt/MRP menüsünün altında yer alır. Vardiya Planı'nı tablo halinde izlemek için kullanılan bölümdür.

Vardiya Planı İzleme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Vardiya Planı İzleme Ekranı |  |
| --- | --- |
| Başlangıç/Bitiş Tarihi | İzlenmesi istenen vardiya planı tarihinin girildiği alandır. Başlangıç/Bitiş tarih aralığı girilmesi gerekir. |
| Vardiya Plan No | İzlenmesi istenen vardiyanın seçildiği alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, vardiya plan numaraları arasından seçim yapılır. |
| Fabrika/İş İstasyonu/Makine/Kaynak | Fabrika seçeneğinde Şirket Kodu ve İşletme Kodu alanları sistem tarafından otomatik olarak ekrana getirilir. İş İstasyonu, Makine ve Kaynak seçeneklerinde ise ilgili kod alanlarının kullanıcı tarafından seçilmesi gerekir. |
| ![](../../../../../_assets/8caf76dbdd5add61882d.png) Planı İzle | Girilen kısıtlar doğrultusunda, vardiya planının tablo halinde izlenmesi için kullanılan butondur. **Örnek Tablo:** ![](../../../../../_assets/831cd487cc2c89f0292c.png) |
