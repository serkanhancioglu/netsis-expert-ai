# Çizelgeleme Özel Parametreleri

Çizelgeleme Özel Parametreleri, Üretim Bölümü'nde Kayıt/MRP menüsünün altında yer alır. İleri Üretim Çizelgeleme modülünde, parametreye bağlı özel işlemlerin yapılması için tanımlama yapılmasını sağlayan bölümdür. Bu bölümde girilen değerlere göre aktif hale gelen bazı uygulamalar için, girilen değerlerin büyük ya da küçük harfle girilmesi önem taşır. Çünkü, tanımlamada yapılan bir yanlışlık, uygulamanın çalışmayacağı anlamına gelir.

Çizelgeleme Özel Parametreleri ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Çizelgeleme Özel Parametreleri Ekranı |  |
| --- | --- |
| Grup Kodu | Özel parametre için grup kodu tanımlaması yapılan alandır. |
| Anahtar | Özel parametre için anahtar tanımlaması yapılan alandır. |
| Değer | Özel parametre için değer girilen alandır. |

İlgili alanlara bilgi girişi yapıldıktan sonra klavyeden \<tab\> tuşuna basılarak ilerlendiğinde oluşturulması istenen kayıt alt ekrana aktarılır.

Kaydın iptali için, silinmesi istenen kaydın üzerinde çift tıklandıktan sonra “Kayıt Sil” ![](../../../../../_assets/2df4b343310bcd16b01e.jpg) butonuna tıklanması gerekir.
