# Vardiya Bazında Üretim Planı Raporu

Vardiya Bazında Üretim Planı Raporu, Üretim Bölümü'nde, "Kayıt/MRP" menüsünün altında yer alır. Vardiya Bazında Üretim Planı Raporu, Vardiya Bazında Üretim Planı yapmak için rapor alınmasını sağlayan bölümdür.

Vardiya Bazında Üretim Planı Raporu ekranı, Ön Sorgulama sekmesinden oluşur.

**Ön Sorgulama**

Vardiya Bazında Üretim Planı Raporu ekranı Ön Sorgulama sekmesinde yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| Vardiya Bazında Üretim Planı Raporu Ekranı |  |
| --- | --- |
| Taslak No.su | Vardiya Bazında Üretim Planı Raporu almak için taslak numarası kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, taslak numaraları arasından seçim yapılır. |
| ![](../../../../../_assets/7ba39f9046a578093326.png) Rapor | Yukarıdaki alanlara girilen bilgiler doğrultusunda, rapor almak için kullanılan butondur. Bu seçenek sayesinde, 13684 satırın üstündeki raporlamaların da tek sayfa üzerinden raporlanması sağlanır. "Rapor" seçeneği Text Dosya, Excel Dosya, VTS Format, HTML kayıt türlerini desteklerken, "Gelişmiş Rapor" seçeneği Excel Workbook, Excel Template, Excel 97-2003 Workbook, Excel 97-2003 Template, Comma Delimited, Text Document, Web Page, XML Document, PDF Document kayıt türlerini destekler. |
