# İş Emri Kullanım Raporu / İÜP

İş Emri Kullanım Raporu/İÜP, Üretim Bölümü'nde, "Kayıt/MRP" menüsünün altında yer alır. İş Emri Kullanım Raporu/İÜP, iş emri kullanım raporunun taslak numarası kısıdı verilerek alınmasını sağlayan bölümdür.

İş Emri Kullanım Raporu ekranı; Ön Sorgulama sekmesinden oluşur.

**Ön Sorgulama**

İş Emri Kullanım Raporu/İÜP ekranı Ön Sorgulama sekmesinde yer alan alanlar ve içerdiği bilgiler aşağıdaki şekildedir:

| İş Emri Kullanım Raporu Ekranı |  |
| --- | --- |
| Taslak No.su | İş Emri Kullanım Raporu almak için taslak numarası kısıdı verilen alandır. Rehber butonu ![](../../../../../_assets/088477bb321d1b20c939.jpg) ile, taslak numaraları arasından seçim yapılır. |
| ![](../../../../../_assets/7ba39f9046a578093326.png) Rapor | Yukarıdaki alanlara girilen bilgiler doğrultusunda, rapor almak için kullanılan butondur. Butonun sağ tarafında yer alan aşağı ok tuşu, "Gelişmiş Rapor" seçeneğinin kullanılmasını sağlar. Kullanıcı, "Gelişmiş Rapor" seçeneği ile ekrana gelen tablo üzerinde hesaplama yapabilir. Bu seçenek sayesinde, 13684 satırın üstündeki raporlamaların da tek sayfa üzerinden raporlanması sağlanır. "Rapor" seçeneği Text Dosya, Excel Dosya, VTS Format, HTML kayıt türlerini desteklerken, "Gelişmiş Rapor" seçeneği Excel Workbook, Excel Template, Excel 97-2003 Workbook, Excel 97-2003 Template, Comma Delimited, Text Document, Web Page, XML Document, PDF Document kayıt türlerini destekler. |
| ![](../../../../../_assets/e3223333470668512f5f.jpg) Oku | Daha önceden saklanan kısıtların aynısının ekrana getirilmesini sağlayan butondur. **Oku** butonu ile sadece "en son saklanan kısıtlar" ekrana getirilir. |
| ![](../../../../../_assets/53859e19eb2737b88a17.jpg) Sakla | Ön Sorgulama sekmesinde verilen kısıtlar ve işaretlenen tüm seçeneklerin saklanması için kullanılan butondur. İş Emri Kullanım Raporu almak için kısıt verildikten sonra bu butona basıldığında, onaylama ekranı görüntülenir. Onaylama ekranında "Evet" butonuna basılması ile belirlenen kısıtlar bir sonraki İş Emri Kullanım Raporu alma işleminde kullanılmak üzere saklanır. |
| ![](../../../../../_assets/4ad6cc61ca2c42a19c85.jpg) Yardım | İş Emri Kullanım Raporu ekranı hakkında standart yardım bilgisi için kullanılan butondur. |
| ![](../../../../../_assets/973111d004995dca0113.jpg) İptal | İş Emri Kullanım Raporu almak için verilen kısıtların iptal edildiği butondur. |
