# Müşteri Siparişi Önceliklendirme

Müşteri Siparişi Önceliklendirme, Üretim Bölümü'nde, "İşlemler/MRP" menüsünün altında yer alır. Müşteri Siparişi Önceliklendirme, öncelik sağlanacak müşteri siparişleri için kısıt girilmesini sağlayan bölümdür.

Kısıt Girişi yazısının solunda yer alan artı + simgesine tıklanması ile kısıt alanları görüntülenir. İleri Kısıt Girişi yazısının solunda yer alan artı + simgesine tıklanması ile ileri kısıt verilecek alanlar görüntülenir.

Müşteri Siparişi Önceliklendirme ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Müşteri Siparişi Önceliklendirme Ekranı |  |
| --- | --- |
| Tarih Aralığı | Öncelik sağlanacak müşteri siparişi/siparişleri için tarih aralığı girilen alandır. |
| Sipariş No Aralığı | Öncelik sağlanacak müşteri siparişi/siparişleri için sipariş numarası aralığı girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, sipariş numaraları arasından seçim yapılır. |
| Cari Kodu | Öncelik sağlanacak müşteri siparişi/siparişleri için cari kod girilen alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
| Sipariş Satırları Getirilsin | Seçeneğin aktif hale gelmesi için MRP Parametreleri → Sipariş Bazında Rezervasyon Sistemi" parametresinin işaretlenmesi gerekir. "Sipariş Satırları Getirilsin" seçeneği işaretlenerek "Kayıtları Getir" butonuna tıklandığında müşteri siparişleri satırlarıyla beraber detaylı olarak ekrana getirilir. Alt bölümdeki grid üzerinde "Sipariş Numarası" alanından sonra "Sipariş Sıra No" alanı görünür hale geleceği için de, siparişin satırları bazında ayrı öncelik bilgisi girilerek kayıt yapılabilir. |
| ![](../../../../_assets/76b2ca9b27bd71950d5a.png) Kayıt Getir | Kısıt alanlarından girilen bilgilere göre öncelik sağlanacak müşteri sipariş kayıtlarının getirilmesi için kullanılan butondur. |
| ![](../../../../_assets/cbaf796f6acca9742d4a.png) Tüm Kırılımları Aç | Müşteri siparişi önceliklendirme grup bazında oluşturulduğunda alt bölümde yer alan grid ekrandaki kayıtlar da gruplanarak gelir. Bu grupların tümünü açmak için kullanılan butondur. |
| ![](../../../../_assets/170ff530aa023dc20601.png) Tüm Kırılımları Topla | Müşteri siparişi önceliklendirme grup bazında oluşturulduğunda alt bölümde yer alan grid ekrandaki kayıtlar da gruplanarak gelir. Bu grupların tümünü kapatmak için kullanılan butondur. |
| ![](../../../../_assets/66bf270db1bf5bd3b86d.png) Kaydet | Öncelik sağlanacak müşteri siparişinin/siparişlerinin kaydedilmesi için kullanılan butondur. |
| ![](../../../../_assets/d81c078f63d2fb8d9333.png) Otomatik Öncelik | Öncelik sağlanacak müşteri siparişinin/siparişlerinin program tarafından otomatik olarak yapılması için kullanılan butondur. |
