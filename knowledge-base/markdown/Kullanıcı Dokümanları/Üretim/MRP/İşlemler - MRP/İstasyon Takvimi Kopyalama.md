# İstasyon Takvimi Kopyalama

İstasyon Takvimi Kopyalama, Üretim Bölümü'nde, "İşlemler/MRP" menüsünün altında yer alır. İstasyon Takvimi Kopyalama, kaynak istasyon takviminin hedef istasyon takvimine kopyalanması için kullanılan bölümdür.

İstasyon Takvimi Kopyalama ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| İstasyon Takvimi Kopyalama Ekranı |  |
| --- | --- |
| Kaynak İstasyon | Kopyalanması istenen kaynak istasyon takviminin seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, istasyon kodları arasından seçim yapılır. |
| Hedef İstasyon | İstasyon takviminin kopyalanacağı hedef istasyonun seçildiği alandır. Rehber butonu ![](../../../../_assets/088477bb321d1b20c939.jpg) ile, istasyon kodları arasından seçim yapılır. |
| Ay/Yıl | İstasyon takviminin kopyalanacağı ay/yıl bilgisinin girildiği alandır. |
| ![](../../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilgilere göre istasyon takviminin kopyalanması için kullanılan butondur. |
| ![](../../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
