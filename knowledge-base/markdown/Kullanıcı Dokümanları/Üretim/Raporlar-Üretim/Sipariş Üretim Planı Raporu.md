# Sipariş Üretim Planı Raporu

Sipariş Üretim Planı Raporu, Üretim Bölümü'nde Raporlar/Üretim menüsünün altında yer alır. Müşteri siparişine bağlı mamul, yarı mamul, iş emirleri ve bu iş emirlerinin üretim ve üretim akış kontrol kayıtlarının izlenmesini sağlayan bölümdür. Ayrıca, Çizelgeleme Uygulamasının makine bazında çıkardığı üretim planının raporlanmasını sağlar. Planlanan ve gerçekleşen kayıtlar arasındaki farklılıkların görülmesi açısından fayda sağlar.

Sipariş Üretim Planı Raporuna; Müşteri Siparişi - "Kalem Bilgileri" sekmesi sağ tuş menüsü ve İş Emri ekranı sağ tuş menüsü yollarından da erişilebilir. Sipariş Üretim Planı Raporu ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Sipariş Üretim Planı Raporu Ekranı |  |
| --- | --- |
| İş Emri Detayı Getirilsin | Sipariş üretim planı raporuna iş emri detayının getirilmesi için kullanılan seçenektir. |
| Sipariş Tipi | Sipariş üretim planı raporu almak için sipariş tipi kısıdı girilen alandır. Alanın sağ tarafında yer alan aşağı ok butonu ile sipariş tipleri arasından seçim yapılır. |
| Sipariş No Aralığı | Sipariş üretim planı raporu almak için sipariş numarası aralığı kısıdı girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, sipariş numaraları arasından seçim yapılır. |
| Sipariş Kontrol Aralığı | Sipariş üretim planı raporu almak için sipariş kontrol aralığı kısıdı girilen alandır. |
| Stok Kodu Aralığı | Sipariş üretim planı raporu almak için stok kodu aralığı kısıdı girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile stok kodları arasından seçim yapılır. |
| Cari Kodu Aralığı | Sipariş üretim planı raporu almak için cari kodu aralığı kısıdı girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, cari kodlar arasından seçim yapılır. |
