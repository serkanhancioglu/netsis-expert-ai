# Konfigürasyon Silme

Konfigürasyon Silme işlemi, Üretim Bölümü'nde İşlemler/Üretim menüsünün altında yer alır. "Belgede Kullanılmış Fakat Belge Bağlantısı Kopmuş Konfigürasyonları Sil" seçeneği seçilerek "Tamam" butonuna tıklandığında, Konfigürasyon Silme işlemi gerçekleştirilir.
