# Reçete Devri

Reçete Devri, Üretim Bölümü'nde İşlemler/Üretim menüsünün altında yer alır. Reçetelerde, "Planlanan Bileşen Değişikliği" bölümünden, geleceğe yönelik değişikliklerin yapıldığı ve geçerlilik tarihlerinde reçetelerin yenilendiği durumlarda, reçete dosyasında geçmişe yönelik birçok kayıt birikir. Özellikle sene sonu devirlerden sonra, reçete dosyasında birikmiş bu kayıtları silmek için kullanılan bölümdür.

Reçete Devri işlemi ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Reçete Devri Ekranı |  |
| --- | --- |
| Revizyon No | Kendinden önceki geçmişe yönelik tüm kayıtların silineceği baz revizyon numarasının girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, revizyon numaraları arasından seçim yapılır. |
| ![](../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. "Reçete Devri" bölümü eski reçeteleri siler. Reçete dosyası çok büyüdüğünde, çok eski kayıtlar bulunuyorsa çalıştırılabilir. Yıl sonu devirde reçeteler aynen kopyalanır. Bu devir kullanıcının isteğine göre çalıştırılabilir. |
| ![](../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
