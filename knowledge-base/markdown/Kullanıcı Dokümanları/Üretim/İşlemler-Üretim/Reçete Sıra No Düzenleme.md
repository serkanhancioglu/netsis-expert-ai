# Reçete Sıra No Düzenleme

Reçete Sıra No Düzenleme işlemi, Üretim Bölümü'nde İşlemler/Üretim menüsünün altında yer alır. Reçete bileşenlerinin sıra numaralarını düzenlenmek için kullanılan alandır.

Reçete Sıra No Düzenleme işlem ekranında yer alan alanlar ve içerdiği bilgiler şunlardır:

| Reçete Sıra No Düzenleme Ekranı |  |
| --- | --- |
| Tüm Mamuller İçin Çalıştırılsın | Reçete sıra numaralarının tüm mamuller için düzenlenmesi istendiğinde kullanılan seçenektir. |
| Mamul Kodu | Sıra numarası düzenlenecek reçete için mamul kodu girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, mamul kodları arasından seçim yapılır. |
| Yapılandırma Kodu | Sıra numarası düzenlenecek reçete için yapılandırma kodu girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, yapılandırma kodları arasından seçim yapılır. |
| Yapılandırma Kodu Açıklaması | "Yapılandırma Kodu" alanında girilen yapılandırma koduna ait açıklama bilgisinin program tarafından otomatik olarak getirildiği alandır. |
| ![](../../../_assets/39d77b8716226638d9ce.jpg) Tamam | Girilen bilginin onaylanmasını sağlayan butondur. |
| ![](../../../_assets/973111d004995dca0113.jpg) İptal | Girilen bilgiden vazgeçilmesi halinde ekrandan çıkmak için kullanılan butondur. |
