# Toplu Rezervasyon İptali

Toplu Rezervasyon İptali işlemi, Üretim Bölümü'nde İşlemler/Üretim menüsünün altında yer alır. Rezervasyon iptallerinin toplu şekilde yapılmasını sağlayan bölümdür.

Rezervasyon İptal Bilgileri; D.A.T. Fişi Bilgileri ve Rezervasyon İptal İşlemi olmak üzere üç sekmeden oluşur.

**Rezervasyon İptal Bilgileri**

Toplu Rezervasyon İptali işlemi Rezervasyon İptal Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Toplu Rezervasyon İptali Ekranı |  |
| --- | --- |
| Tüm Depolar | Toplu rezervasyon iptalinin tüm depolar için yapılması istendiğinde kullanılan seçenektir. |
| Çıkış Depo Kodu | Toplu rezervasyon iptalinin belli bir çıkış depo kodu için yapılması istendiğinde kullanılan seçenektir. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, çıkış depo kodları arasından seçim yapılır. |
| İş Emri No Maskesi | Toplu rezervasyon iptali için iş emri numarası maskesi kısıdı girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, iş emri numaraları arasından seçim yapılır. |
| Teslim Tarihi | Toplu rezervasyon iptali için teslim tarihi kısıdı girilen alandır. |
| Mamul Kodu Maskesi | Toplu rezervasyon iptali için mamul kodu maskesi kısıdı girilen alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, mamul kodları arasından seçim yapılır. |
| İleri Kısıt Ver | Mamul için ileri kısıt verilmesi istendiğinde kullanılan seçenektir. Klavyede bulunan \<tab\> tuşu ile ilerlendiğinde Stok İleri Kısıt Ekranı görüntülenir. |
| ![](../../../_assets/509ca33f831549923dcb.png) İleri | D.A.T. Fişi Bilgileri sekmesine ilerlemek için kullanılan butondur. |

**D.A.T. Fişi Bilgileri**

Toplu Rezervasyon İptali işlemi DAT Fişi Bilgileri sekmesinde yer alan alanlar ve içerdiği bilgiler şunlardır:

| Toplu Rezervasyon İptali |  |
| --- | --- |
| Serbest Bırakma İşlemi Sonrasında D.A.T Fişi Oluşturulsun | Serbest Bırakma işlemi sonrası Depolar Arası Transfer fişinin oluşturulması için kullanılan seçenektir. |
| Fiş No | Toplu rezervasyon iptalinin yapılacağı fiş numarasının girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, fiş numaraları arasından seçim yapılır. |
| Tarih | Toplu rezervasyon iptalinin yapılacağı fiş numarasına ait tarih bilgisinin girildiği alandır. |
| Fiili Tarih | Toplu rezervasyon iptalinin yapılacağı fiş numarasına ait fiili tarih bilgisinin girildiği alandır. |
| Giriş Depo Kodu | Toplu rezervasyon iptalinin yapılacağı giriş depo kodunun girildiği alandır. Rehber butonu ![](../../../_assets/088477bb321d1b20c939.jpg) ile, depo kodları arasından seçim yapılır. |
| Satır Açıklama | Toplu rezervasyon iptalinin yapılacağı D.A.T fişi için açıklama bilgisi girilen alandır. |
| Ek Açıklama | Toplu rezervasyon iptalinin yapılacağı D.A.T fişi için ek açıklama bilgisi girilen alandır. |
| ![](../../../_assets/d22a7d7b5ee5869d7e59.png) Geri | Rezervasyon İptal Bilgileri sekmesine geri dönmek için kullanılan butondur. |
| ![](../../../_assets/509ca33f831549923dcb.png) İleri | Rezervasyon İptal İşlemi sekmesine ilerlemek için kullanılan butondur. |

**Rezervasyon İptal İşlemi**

Rezervasyon İptal İşlemi sekmesi, Hammadde Rezervasyon İptal Tablosunun görüntülendiği sekmedir. Tüm Rezervasyonları Sıfırla butonu ile rezervasyonlar sıfırlanır. İşlemleri Gerçekleştir butonu ile de, rezervasyon iptal işlemleri gerçekleştirilir.
