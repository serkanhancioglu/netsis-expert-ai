# Netsis Kod Tanımlama

**Cari modülü-Kayıt-Cari Parametreleri** ekranında Cari İsim Sorgulama Kaynağı olarak Türmob seçilmesi durumunda aktif gelen TÜRMOB Bağlantı Bilgileri alanına **TÜRMOB Mükellef Bilgileri Sorgulama Kodu** girilmelidir.

Mali müşavir Token bilgisinin sonuna ~ (tilda) işareti eklenip eLogo sipariş portalı üzerinden alınan Token bilgisi eklenmelidir.
